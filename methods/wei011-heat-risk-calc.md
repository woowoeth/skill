# 热射病风险计算器

核心原理：决定热射病的不是气温，是**湿球温度**（气温+湿度的组合）。人靠出汗散热，湿度越高汗越蒸发不掉。48°C 的干热（吐鲁番）可能只是 I 级风险，35°C 的桑拿天（长沙/武汉）却是 III 级高危。

## 用法

```bash
python3 <skill-dir>/heatrisk.py <城市名> [城市名2 ...] [--json]
```

- 中文城市名直接传（吐鲁番、武汉…）；报"找不到城市"时改传拼音（如 Dunhuang）
- 多个城市自动输出危险度排行（按湿球温度，不按气温）
- `--json` 给 agent 用：每天 `tmax`（最高气温）、`tw_max`（最高湿球温度）、`level`（风险等级）、`advice`
- 零依赖纯标准库，零 API Key，数据来自 open-meteo 实时预报（7 天）

## 风险等级（按当日最高湿球温度 Tw）

| Tw | 等级 | 含义 |
|---|---|---|
| ≥31° | IV 级·极度危险 | 一切户外活动都危险（35° 是人类生存理论极限，Sherwood & Huber PNAS 2010）|
| ≥28° | III 级·高危 | 户外劳动/运动有热射病风险，老人儿童室内也需降温 |
| ≥25° | II 级·警戒 | 长时间户外需强制补水休息 |
| ≥22° | I 级·注意 | 高危人群（户外工作者/老人/慢病）注意 |
| <22° | 0 级·常规 | 常规防暑 |

## 回答用户时的要点

1. 报当天和整周最危险一天的等级+建议；用户问"能不能跑步/军训/工地开工"按等级直接给行动建议
2. 强调湿球温度和气温的差别（用户直觉是看气温，这正是要纠正的）
3. 医疗免责：这是风险提示工具，出现热射病症状（高热无汗、意识模糊）立即就医
