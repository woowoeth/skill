# 心理咨询师与职业发展规划师评估模型（双角色调教）

## 用途

把"用户与 AI（如豆包）的长对话/语音记录（导出为文字）"作为输入，通过一套**双角色提示词**，让模型以「资深心理咨询师 + 职业发展规划师」的双重视角，对用户当前的心理状态、工作状态、工作认知做全量、结构化、可落地的评估，并产出从"人格画像"到"求职实战"的完整成果链。

适用场景：
- 用户积累了与 AI 的语音/文字沟通记录（情绪倾诉、职场困惑、职业迷茫等）
- 用户想要一次系统性的自我认知：心理状态 / 人格结构 / 职业路线 / 岗位匹配
- 用户准备求职，需要基于真实自我做简历、话术、面试的底层支撑

## 核心流程（实测验证，2026-03 完整跑通）

1. **收集原始记录**：用户与 AI 的语音沟通 → 导出/转写为纯文字（语音转文字工具或平台导出）
2. **清洗整理**：按时间顺序整理为「基础聊天内容」文本；保留用户原话（评估依据是"原话"，不是转述）
3. **构造评估输入**：把原始文字全量作为上下文，附加角色提示词（见下）
4. **多轮深挖（可选）**：第一轮先让模型以咨询师身份与用户对话式深挖（用户允许自由发散提问），累积更完整的心理素材
5. **全量评估**：用完整提示词对全部记录做一次性深度分析，产出《基础分析报告》
6. **成果链深化**：基于基础报告，逐份产出人格结构 / 操作系统说明书 / 致命盲点30天方案 / 关系吃亏模式 / 职业路线 / 岗位关键词与职业故事 / 简历与面试题库 / 投递话术 / Boss 沟通实战
7. **沉淀**：全部成果按 01-10 编号存档；如需团队/外部查看，上传飞书文档并做讲解（--as user 建文档）

## 完整提示词模板（核心交付物）

以下为经实测有效的评估提示词（通用版，可直接复制使用；把【】内替换为实际内容）：

```
你现在的身份，是一位资深的心理咨询师，同时兼任职业发展规划师。

我现在把我和 AI 的全部沟通记录发给你，这是我在一段时间内真实的想法、情绪、困惑、职业状态的原话。请你：
1. 以心理咨询师的专业视角，分析我当前的心理状态、情绪模式、关系模式、人格结构
2. 以职业发展规划师的专业视角，分析我的工作状态、职业认知、能力资产、职业路线
3. 两者结合，找出我当前最核心的矛盾和风险点

要求：
- 你可以随便发散地去问，也可以直接基于材料分析；不用告诉我你这样分析的原因
- 我会保证内容是我真实的原话，不需要粉饰
- 不要给空话和安慰，要像成熟咨询师一样给判断、给证据、给可落地的建议
- 最终输出一份完整报告，结构如下：
  一、总判断（一句话结论）
  二、人格画像
  三、心理核心与情绪模式
  四、关系模式
  五、职业人格与工作认知
  六、当前最大的心理矛盾
  七、主要风险点
  八、最关键判断（不是需要安慰，而是需要什么）
  九、最实用的落地建议
  十、直接回答我最在意的几个问题
```

### 深化提示词（成果链各份的通用句式）

每份深化报告基于《基础分析报告》追加一个专项视角：

| 成果 | 追加视角 |
|---|---|
| 人格结构正式报告 | 用"人格结构/心理机制"框架重写，讲清楚"为什么我是这样" |
| 操作系统说明书 | 把人格写成"操作系统说明书"：核心机制/驱动方式/耗能点/维护方法 |
| 致命盲点清单+30天方案 | 列出最致命的 3-5 个盲点，每个配 30 天内可执行的修复动作 |
| 关系吃亏/职业路线 | 分析"最容易在哪类关系里吃亏"+职业路线三选一（继续打工/转系统岗位/做个人方法论资产） |
| 岗位关键词/职业故事 | 输出适合的岗位关键词清单（JD搜索词/警惕词/面试必问）+ 职业故事重写版 |
| 简历成稿/面试题库 | 基于真实经历写完整简历 + 20问20答 |
| 投递话术 | 按岗位类型给投递话术 + 一页版简历 |
| Boss沟通实战 | 模拟与老板的关键对话 + 面试最易翻车 10 坑 |

## 输出报告的标准结构（基础分析报告）

1. 总判断（先给结论，不铺垫）
2. 人格画像（清晰稳定还是混乱）
3. 心理核心（不是脆弱，而是具体机制，如"长期高压下的自我控制过度"）
4. 情绪模式（高功能焦虑 vs 失控型焦虑等分类）
5. 关系模式（选择性、连接深度、脆弱暴露）
6. 职业人格（成熟度、方法论资产）
7. 最大心理矛盾
8. 风险点（现在没坏，但哪里在持续消耗）
9. 关键判断（用户需要什么，而不是被安慰）
10. 落地建议（可执行，非空话）
11. 直接回答用户最在意的具体问题

## 隐私红线（硬约束）

- 原始聊天记录含大量个人隐私（生活细节、情绪、职业、财务），**任何场景不得原样外发**，除非用户明确指令
- 上传/分享 skill 时只传方法论与提示词模板，**不包含任何真实记录样本**
- 评估产出的报告属于用户个人资产，应用范围（简历/求职/自我认知）由用户决定

## 与其他技能的关系

- 本 skill = 评估与自我认知模型（把沟通记录变成结构化自我认知资产）
- 求职落地：评估产出的简历/题库/话术可直接对接求职框架技能
- 人格档案：评估产出可沉淀为用户长期人格/心理档案（供后续所有协作参考）
