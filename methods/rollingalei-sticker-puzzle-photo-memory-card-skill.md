# 贴纸拼图-照片记忆卡

将一张源照片转化为两张相互匹配的位图交付物：

1. 一张成品 3:2 旅行记忆卡。
2. 一张 3:2 透明 PNG 贴纸页，包含相同的六枚贴纸图案。

两张图片均使用图片生成/编辑工具生成。**所有图片生成必须固定使用最强模型 `seedream_5.0_pro`（model_version=seedream_5.0_pro）**，以保证记忆卡细节质量完美。不要用滤镜或代码模拟插画效果。本地处理仅用于去除纯色色度键背景和验证透明度。

## 工作流程

1. 充分查看源照片的全部有用细节。
2. 识别场景结构、情感中心、主导空间姿态，以及一个紧凑的识别锚点。
3. 选取恰好六枚有意义的、源自原图的贴纸图案，以及恰好三个简洁的中文关键词短语（每个2-4字），用纤细、自然的真人手写中文风格书写，类似情书体：笔画纤细精致，略带自然连笔，随意温暖，像真人手写而非刻板书法。
4. 判断原图中是否有某个可见文字项真正标识了地点。默认为 `无`；拒绝广告、菜单、价格、指示牌、时间戳和产品标签。
5. 阅读 [references/style-guide.md](references/style-guide.md)。
6. 先生成完整记忆卡。将其六枚贴纸作为第二张图的视觉基准。
7. 检查记忆卡。如果媒介、排版、贴纸数量、关键词或可读文字有误，重新生成一次。
8. 基于源照片和成品记忆卡生成独立的贴纸页。包含完全相同的六枚图案、形状、颜色、媒介和暖白色手剪边缘。
9. 通过内置的图片生成透明度工作流制作透明效果：在统一的可移除色度键颜色上生成贴纸页，然后运行已安装的 `remove_chroma_key.py` 辅助脚本。选择贴纸中不存在的键色；植被多的场景优先用 `#ff00ff`，其他场景用 `#00ff00`。
10. 验证最终 PNG。必须是 RGBA 格式，四个角的 alpha 值必须为 0，六枚贴纸除抗锯齿边缘外必须完全不透明，不得残留键色色边。如有需要，用稍强的容差或 `--edge-contract 1` 重试一次去背景。
11. 使用自动方向拼图脚本将原图和成品记忆卡拼接。脚本通过 EXIF 自动检测方向：
    - **横版照片**（宽 >= 高）：上下拼图（原图在上，记忆卡在下）。
    - **竖版照片**（高 > 宽）：方案B — 将竖图居中放在横版画布上，左右加暖白纸边，然后与记忆卡上下堆叠。输出为适合社交媒体的竖版长图。

## 交付物1：完整记忆卡

- 使用一张 3:2 横版画布，暖白色未涂布纸底，四周有连续的 4-5% 外边距。
- 将左侧 66-68% 区域构建为一个竖向单元：一幅大幅近方形的**完全无框**插画，下方是浅露纸的关键词区。插画必须直接画在卡纸上，**不要任何纸张边框、衬边、白边、内卡、留白边距**——插画的粗糙颜料边缘直接接触卡片的暖白纸底。插画四周（上下左右四边）有明显的、粗糙的、像自然干透的水粉/丙烯颜料边缘——颜料干透后自然收缩形成的不规则毛边和肌理，四边都有明显的粗糙感和颜料颗粒感，像一幅真正画在纸上的画，整体性强，边缘自然不规整。不要硬边、轮廓线、描边、圆角框、阴影或贴纸边。
- 在插画下方居中排列恰好三个源自场景的中文关键词短语（每个2-4字），用居中圆点分隔：`[关键词一] · [关键词二] · [关键词三]`。使用纤细、自然的真人手写中文字体，类似情书体：笔画纤细精致，略带自然连笔，随意温暖，像真人用细钢笔书写。淡墨色调，周围无框无标签。绝不使用粗体、厚重、刻板或印刷感字体。
- 右侧 30-32% 区域放置恰好六枚独立的模切贴纸。**六枚贴纸必须各不相同，同一物品不得重复出现（如不得出现两辆摩托车、两艘船、两道彩虹等）。** 使用全构图高度，大小层次不齐，间距松弛。每枚贴纸必须呈现为实体模切纸贴纸：厚实醒目的不规则暖白色手剪边缘（清晰可见，非细边），明显的扁平偏移纸阴影（轻微右下偏移， muted 灰棕色，使贴纸从卡片上弹出），不规则有机轮廓像剪刀手剪的，非几何或均匀。贴纸边缘内的插画使用与主插画相同的水粉/剪纸媒介。
- 通过剪影、比例、位置、关系和标志性颜色，以与整张卡片相同的媒介保留识别锚点。**人物必须有清晰可辨的脸部特征（简化色块表现的眼睛、鼻子、嘴巴和表情），不得出现无脸空白头部或模糊缺失的五官。**
- 不添加标题、说明文字、日期、书写区域、邮戳、地址行、副标题、水印或签名。

## 交付物2：透明贴纸 PNG

- 使用独立的 3:2 横版画布。
- 包含与成品记忆卡完全相同的六枚贴纸；不得重新设计、替换、拆分、合并或添加图案。**六枚贴纸必须各不相同，同一物品不得重复出现。**
- 将贴纸分两排宽松排列，留有充足的透明空间。每枚贴纸完整可见、相互分离、不被裁切。
- 保留每枚贴纸周围厚实的不规则暖白色模切边缘。
- 移除卡片纸张、阴影、页脚、关键词、标题、标签和所有可读文字。
- 不添加整体底页、面板、框架、纹理、地面、反射或投影/接触阴影。
- 交付带有 Alpha 通道的真实 PNG。棋盘格、黑色或白色预览背景不是文件的一部分。

生成色度键背景时，明确要求完全均匀的纯色背景，无光照变化、纹理、渐变、阴影、反射，贴纸插画内部也不得有键色。使用已安装的辅助脚本：

```bash
python "<skill_dir>/scripts/remove_chroma_key.py" \
  --input <chroma-source.png> \
  --out <transparent-stickers.png> \
  --auto-key border \
  --soft-matte \
  --transparent-threshold 12 \
  --opaque-threshold 60 \
  --despill
```

将 `<skill_dir>` 替换为本技能目录的绝对路径。如果辅助脚本需要 Pillow，用 `pip install Pillow` 安装。如果柔边去背景残留色边，用 `--edge-contract 1` 重试一次；如果硬键去背景对不透明纸贴纸效果更好，使用采样的键色和适中容差。在检查 Alpha 通道之前，绝不得声称已透明。

## 共享艺术方向

- 从 5-8 个源自原图的宽泛哑光色系重建场景。
- 让第一眼看到的是 3-6 个超大的钝形色块和安静的负空间。
- 使用不透明水粉、剪纸、丝网印刷或类似的填充，带有细腻均匀的纸纹、粉笔感手剪边缘、轻微颜料变化和柔和套印偏差。
- 将植被压缩为 1-3 个块状色调团；将建筑和地形简化为平面；**将人和动物简化为有清晰脸部特征的紧凑剪影——用简化色块表现眼睛、鼻子、嘴巴和表情，不要无脸的空白头部，不要模糊或缺失的五官**。人物脸部保持水粉剪纸风格的简化色块，但必须有可辨识的五官和表情。
- 使用扁平彩色阴影而非渐变。近黑色保持稀疏。
- 保持氛围观察性、开阔、人文、缓慢、轻度怀旧。
- 贴纸必须有实体模切纸物件的感觉：厚实醒目的暖白色边缘，清晰的扁平偏移阴影，不规则手剪轮廓。它们应从卡片表面弹出，而非融入其中或看起来像平面印刷形状。
- 避免照片写实、照片拼贴、马克笔笔触、水彩晕染、湿笔晕染、光泽3D、戏剧性光照、精细叶片或解剖、抛光矢量、动漫、剪贴画和无关物件。

## 图案与关键词规则

- 选择六枚可见图案，保持有用的多样性：一个主体片段、存在时的成组或成对变体、一个环境形态、一个结构片段、一个功能物件、一个小的氛围或尺度提示。
- 当选择成组图案时，将可见的一组视为一枚贴纸。
- 保持六枚图案粗放、源自原图、在两个交付物中风格完全一致。**六枚贴纸必须各不相同，同一物品不得重复出现（如不得出现两辆摩托车、两艘船、两道彩虹、两座相同山峰等）。**
- 当贴纸重复地标标牌时，移除文字。
- 书写三个精准的中文关键词短语（每个2-4字），基于场景、光线、物件或空间感受。优先用 `烟火人间`、`山色空蒙` 或 `晚风轻拂`，而非 `旅行` 或 `美丽` 这类泛词。以纤细、自然的真人手写风格呈现，类似情书体：笔画纤细精致，略带连笔，随意温暖，像真人用细钢笔书写。淡墨色调。绝不粗体，绝不刻板，绝不标准印刷字体。

## 质量检查

### 完整卡片

- 场景一眼可识别，但第一眼读到的是大形状和安静空间。
- 整张作品使用统一的哑光水粉/剪纸/颗粒媒介；没有任何区域看起来像照片、马克笔绘制或水彩绘制。
- 左侧插画占主导且**完全无框**（无纸张边框、衬边、白边、内卡），粗糙颜料边缘直接接触卡片纸底，四周（上下左右）有明显的粗糙干透颜料边缘（自然收缩的不规则毛边和肌理，像真正画在纸上的画）；右侧栏包含恰好六枚分离的贴纸，大小层次清晰，**六枚各不相同无重复**。
- 恰好三个中文关键词短语以纤细情书体风格的真人手写体出现在左侧图片下方一次。
- 无意外的可读文字、水印、签名或照片拼贴残留。

### 透明 PNG

- 文件格式为 PNG，图像模式为 RGBA。
- 四个角的 alpha 值均为 0。
- 恰好保留六枚贴纸物件；无裁切、接触或重复。
- 贴纸设计与卡片上的一致，并保留暖白色手剪边缘。
- 无纸张底页、彩色背景、键色光晕、阴影、标签或额外碎片残留。

## 交付物3：拼图对比图（自动方向）

拼图脚本自动检测原图方向（含 EXIF 处理）并选择布局：

**横版模式（宽 >= 高）：**
- 原图在上，记忆卡在下，上下堆叠。
- 两者缩放到相同宽度（默认 1440px）。
- 硬边拼接，无混合或羽化。

**竖版模式（高 > 宽）— 方案B：**
- 将竖版照片居中放在横版画布上（宽 2048px），左右加暖白纸边。
- 将加了纸边的原图（上）和记忆卡（下）上下堆叠。
- 输出为竖版长图（如 2048×2730），适合抖音/小红书图文发布。

使用已安装的辅助脚本：

```bash
python "<skill_dir>/scripts/merge_auto.py" \
  --original <original-photo.jpg> \
  --card <memory-card.png> \
  --out <merged-comparison.png>
```

添加 `--mode portrait` 或 `--mode landscape` 可覆盖自动检测。

## 交付

展示全部三张成品图片并提供文件链接。清晰标注为 `原图+记忆卡上下拼图`、`完整旅行记忆卡`、`透明底贴纸 PNG`。简要说明识别锚点、六枚贴纸图案、三个中文关键词短语，以及所有保存路径。仅在 Alpha 验证成功后，说明 PNG 背后的深色或棋盘格预览代表透明。
