# 看见生活 · See Life — 五感壁纸 Skill

> 每天一句感受，变成一张属于你的壁纸。

## 触发方式

用户说以下类似的话时触发：

- "帮我生成一张五感壁纸"
- "今天我闻到了……帮我做张壁纸"
- "记录一下今天的感受，做成壁纸"
- "看见生活"
- "五感记录"
- 或者直接描述感受："今天吃了意大利面很幸福"

---

## 工作流

### Step 1 · 收集感受

从用户的话里抓取：

1. **感官类型**（视觉/听觉/嗅觉/触觉/味觉）— 从内容推断
2. **情绪类型**（温暖/平静/思念/明亮/孤独/力量）— 从内容推断
3. **核心句子** — 提炼用户原话中最有画面感的部分，不超过 3 行
4. **英文翻译** — 把中文核心句子翻译成简洁优美的英文，跟在对应中文下方

如果用户直接说了完整的话，不用再追问，直接进 Step 2。
只有信息太模糊时才轻轻问一句："今天这个感受，是暖的还是凉的？"

### Step 2 · 匹配情绪风格

根据情绪自动匹配渐变背景色+文字色+图形色（见下方情绪系统表）。

### Step 3 · 选择共鸣语句

从语录库中选一句与用户感受共鸣的诗人/哲学家引言。
要求：
- 不能比用户的话抢风头
- 要和情绪对得上
- 中西方都可以
- 作者名中英文都写

### Step 4 · 绘制意象插图

根据用户描述的内容，用 SVG 绘制抽象意象图形。

**风格参考：6 位艺术家（根据情绪选择）**

| 情绪 | 首选艺术家 | 画风 |
|------|-----------|------|
| 🌅 温暖 | Miró 米罗 | 有机色块+粗线+星星 |
| 🌊 平静 | Calder 考尔德 | 悬挂平衡+极简+漂浮 |
| 🌙 思念 | Klee 克利 | 细线+色块拼贴+诗意 |
| ⚡ 明亮 | Miró 米罗 | 大胆原色+童趣+星星 |
| 🍂 孤独 | Kusama 草间弥生 | 无限圆点+渐变扩散 |
| 🔥 力量 | Kandinsky 康定斯基 | 同心圆+张力线+几何 |

SVG 绘制规则：
- 图形放在壁纸**中上部分**（top: 350px 左右）
- viewBox="0 0 600 700"
- 线条粗细要有**明确对比**：粗线 12-14px / 中线 6-7px / 细线 2-3.5px
- 色块要**大**，有存在感（r=80-110 的圆，大面积有机形）
- 透明度 0.3-0.55
- 元素数量 5-8 个主要形状 + 散落圆点
- 所有线条 stroke-linecap="round"
- **把用户感受中的意象抽象化**，不画具象物体

### Step 5 · 渲染壁纸

1. 基于 `assets/template-final.html` 模板
2. 替换占位符：内容、情绪、渐变色、插图 SVG
3. 用 Playwright 渲染为 PNG
4. 默认尺寸：1264×2780（一加13）

### Step 6 · 存档

1. 用户记录保存到 `entries/YYYY-MM-DD.md`
2. PNG 保存到 `output/`，同时复制到 `~/Downloads/` 方便传手机
3. 文件名格式：`看见生活-YYYY-MM-DD.png`

### Step 7 · 交付

把壁纸展示给用户。语气安静：
- "今天的壁纸做好了，已经放在 Downloads 里。"
- 不过度解释设计决策

## 视觉定稿

### 排版结构（从上到下）

```
┌────────────────────────────┐
│                            │
│     (锁屏时钟区域)          │  ← 顶部 15% 不放重要内容
│                            │
│                            │
│     ╔══════════════╗       │
│     ║  SVG 意象图形  ║       │  ← 中上部分，top: 350px
│     ║  (Miró/Klee等) ║       │
│     ╚══════════════╝       │
│                            │
│                            │
│  Sacramento 花体            │  ← "Something I tasted"
│                            │
│  中文宋体 200极细 大字       │  ← 第一句
│  Cormorant 小斜体           │  ← 对应英文
│                            │
│  中文宋体 200极细 大字       │  ← 第二句
│  Cormorant 小斜体           │  ← 对应英文

```

### 背景系统

**风格：Instagram 式多色渐变流动**

每种情绪对应不同的渐变方向和色彩：

| 情绪 | 渐变色（145°-170° 斜向） |
|------|------------------------|
| 🌅 温暖 | 奶杏 → 桃粉 → 玫粉 → 淡紫 → 雾蓝 |
| 🌊 平静 | 淡蓝 → 雾白 → 薄荷绿 → 淡青 |
| 🌙 思念 | 深紫 → 靛蓝 → 暮色粉 → 深蓝 |
| ⚡ 明亮 | 奶杏 → 桃粉 → 玫粉 → 淡紫 → 雾蓝 |
| 🍂 孤独 | 深灰 → 冷紫 → 暗蓝 → 深灰 |
| 🔥 力量 | 深黑 → 深棕 → 暗金 → 暗红 |

## 设计原则

1. **中英双语** — 中文是主角（大字细宋体），英文是影子（小号斜体衬线跟在下方）
2. **Instagram 渐变** — 多色流动背景，有活力但不刺眼
3. **细线宋体** — 中文用 200 极细字重，克制、有呼吸感
4. **意象不是插画** — Miró/Klee/Kandinsky 风格的抽象 SVG，感觉到而不是认出来
5. **粗细对比** — SVG 线条必须有 14px/7px/3px 三档，形成层次
6. **诗人是配角** — 引言小字、低透明度，呼应但不抢
7. **壁纸位置感** — 图形避开时钟区（top 350px+），文字在下半部分
8. **暖棕文字** — 不用纯黑，用深棕/暖色系文字融入渐变背景
9. **每张都不同** — 即使同一情绪，SVG 形状和布局要有变化
10. **交付到 Downloads** — 每次生成自动复制到 ~/Downloads/ 方便传手机
