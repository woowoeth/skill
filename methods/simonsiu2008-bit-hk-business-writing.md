# 港式商業寫作（Hong Kong Business Writing）

把內地商業寫法轉成香港書面語，或從零寫出港式語感的商業文件。

## 核心原則（先理解，再看詞表）

香港商業寫作與內地商業寫作的根本差異不是詞彙，而是**姿態**：

| 維度 | 內地慣性 | 香港慣性 |
|---|---|---|
| 誰下判斷 | 作者／品牌直接宣告 | 讓數據和當事人說話，作者只串場 |
| 說服工具 | 造詞 + 排比 + 形容詞 | 具體場景 + 前後對比 |
| 順序 | 願景 → 做法 | 痛點 → 做法 → 效益 → 意義 |
| 語氣 | 宏大、肯定 | 克制、留餘地（敢寫「未做到什麼」） |

**最核心的一招**：把「大幅提升效率」換成「過去需要滯後一天，現時是實時」。用時間軸對比替代形容詞。

## 敘事骨架（七步，提案／案例／報道通用）

1. **定調句**——一句話講完「誰做了什麼」，不含背景不含評價
2. **背景鋪墊**——用數字建立份量（成立年份、門市數、上市地位）
3. **痛點**——由客戶高層親口說，用場景不用形容詞
4. **方案核心**——給方案一個可記的名字（如「四合一實時管理」），再分點，每點「動作+機制+效果」
5. **成效對比**——過去 vs 現時
6. **第三方背書**——順序：技術方 → 方案方 → 客戶高層，最高讚美留給客戶
7. **展望收尾**——下一步，不喊口號

## 高頻禁用詞（一用就露餡）

**內地互聯網黑話，直接替換**：
- 賦能 → 提升…能力／協助
- 助力 → 協助／支持／推動
- 打通 → 整合／連通
- 閉環 → 全流程
- 抓手 → 切入點
- 顆粒度 → 細緻程度
- 沉澱 → 累積
- 對齊 → 達成共識
- 復盤 → 檢討／事後總結
- 賽道 → 領域／市場
- 風口 → 熱潮／趨勢
- 紅利 → 優勢／機遇
- 全鏈路 → 全流程／端到端
- 數智化 → 數碼化／智能化
- 打法 → 策略／做法
- 護城河 → 競爭優勢
- 存量／增量 → 現有／新增

**基礎用語（簡轉繁時最容易漏）**：
| 內地 | 香港 |
|---|---|
| 信息 | 資訊 |
| 視頻 | 影片 |
| 服務器 | 伺服器 |
| 帶寬 | 頻寬 |
| 默認 | 預設 |
| 運營 | 營運 |
| 門店 | 門市／分店 |
| 營收 | 收益／營業額 |
| 大陸（市場） | 內地 |
| 質量 | 質素（服務）／品質（產品） |
| 非營利機構 | 非牟利機構 |
| 隱私 | 私隱 |
| 合同 | 合約 |
| 創始人 | 創辦人 |
| 首席執行官 | 行政總裁 (CEO) |
| 首席執行官（運營） | 首席營運官 (COO) |
| 董事長 | 主席 |
| 算法 | 演算法 |
| 轉化／轉化率 | 轉換／轉換率 |
| 移動端 | 流動裝置 |
| 客服 | 客戶服務 |

**職銜／公司**：首次提及用全稱「鴻福堂集團控股有限公司主席兼執行董事謝寶達」，職銜與姓名之間不加「的」，學銜保留（博士），英文縮寫放括號。

## 港式高頻句式（背這十個）

- 以⋯⋯為核心
- 為⋯⋯奠定基礎 / 鋪路 / 提供後盾
- 不單⋯⋯更⋯⋯；除了⋯⋯更⋯⋯
- 現時⋯⋯過去⋯⋯
- 毋須再⋯⋯（否定式強調效率，比「大幅提升」有力）
- 一站式⋯⋯
- 銳意⋯⋯／致力於⋯⋯
- 是次⋯⋯（替代「本次」）
- 現時（替代「目前」）
- 透過（替代「通過」）

## 排版細節（快速分辨點）

- 引號用 `「」`，內層 `『』`；**不是** `“ ”` `' '`
- 中英文／中數字之間**加半形空格**：「使用 UXRetail 系統」「覆蓋 6 個平台」
- 省略號六點 `……`，破折號佔兩格 `——`
- 逗號停頓用 `，`，`、` 只用於並列詞
- 商業稿全文感嘆號不超過一個（最好零個）
- 量詞：公司門市用「間」，系統用「套」，方案計劃用「項」
- 「逾」替代「超過」；金額用「港元」；年份寫全

## 引語用法

- 動詞分工：**表示**（正式立場）／**指出**（問題觀察）／**提到**（補充細節）／**解釋**（交代原因）
- 進階技巧：用「不過」先寫出質疑再回答，可信度明顯提升
- 引語不追求漂亮，追求像人話；帶保留（「起碼」「先處理最重要的」）比「非常滿意」可信

## 執行流程

1. 通讀原文，標出所有內地黑話與基礎用語（用 Grep 批量替換最快）
2. 檢查是否有「過去 vs 現時」對比，沒有就補一組
3. 檢查評價是否都掛在具體的人身上，不是就改為引語
4. 加一個「不過⋯⋯」的限制與回應
5. 套排版細節（引號、空格、量詞）
6. 朗讀一遍：句子須換氣兩次以上就拆開（港式中文句子偏短）

## 文體分層（先選層，再動筆）

香港商業中文是四層系統，不是一種風格。動筆前先判斷這份稿落在哪一層：

| 層 | 代表 | 適合場合 | 中英夾雜度 |
|---|---|---|---|
| 一、公文體 | news.gov.hk、政府新聞公報 | 對政府文件、法規相關稿 | 極低 |
| 二、財經報道體 | 信報、明報、文匯報財經版 | 商業文件、融資新聞稿、B2B 提案 | 詞彙夾雜，規範 |
| 三、都會報道體 | HK01、經濟一週 | 營銷文案、社群、客戶溝通 | 中 |
| 四、職場口語體 | WhatsApp、內部電郵 | 日常溝通 | 高，但不進書面稿 |

層數選錯，詞彙再準也會怪：用公文體寫 WhatsApp 像機械人，用口語夾雜寫新聞稿不專業。

## 中英夾雜四級規範

港式專業寫作是「**詞彙夾雜**」，不是「句式夾雜」。整句切換英文只存在於英文報章、廣告文案和引用口語原話。

- **A 級 · 正式稿直接用**：無通行譯名的品牌產品（iPhone、MINIMAX）；市場慣用縮寫（IPO、GEM、T+1、H股、A+H、KOL、ESG）；法規編號（《上市規則》第18A章）；股票代碼（(02513.HK)）
- **B 級 · 首次中英並列**：中文全稱在前、英文縮寫括號在後，之後只用其一。「創投機構(VC)及私募股權機構(PE)」「提示詞 (Prompt)」「AI 代理 (AI Agent)」「『閃電配售』制度（又稱『先舊後新』配售）」——同一縮寫全文不要混用兩種形式
- **C 級 · 電郵可以、新聞稿不行**：brief（→撮要）、quote（→報價）、follow（→跟進）
- **D 級 · 書面稿禁用**：case（→項目／個案）、book（→賬簿）、deck（→簡報）、pitch（→提案）、「share 一下」「confirm 到」

## 港式文言連詞（書卷氣的來源）

《政府公文寫作手冊》明文：「雖說採用白話，卻不是完全摒棄文言用語。」文言連詞殘留密度是港式與內地書面語的最大隱性差別。每千字補三五處即可，多了變公文腔：

- 視乎（→取决于）、亦（→也）、並（→并）、與（→和）、倘／若（→如果）
- 藉此／藉着（→借此）、有見及此（→有鉴于此）、當局（→相关部门）
- **政府公報用「會」表將來**（「政府會研究」），不用「將」——商業稿同理

## 學習取樣地圖

| 想練 | 去哪 | 注意 |
|---|---|---|
| 規範用詞／稱謂／數字 | news.gov.hk 中文版 | 全港最嚴謹的三重審校 |
| 財經語感 | 信報、明報、文匯報財經版 | 中英夾雜分寸 |
| 都會文案 | HK01、經濟一週 | 貼近港人語感 |
| B2B 公關稿 | 美通社香港、HKTDC | 引語與數據處理 |
| 法律措辭 | 律政司雙語法例 | 術語權威來源 |
| ⚠️ 大公報 | 僅學政論結構與對仗標題 | **左派報紙，書面語貼近內地政論體（「砥礪前行」「由治及興」），不可當港味教材**；涉及政府關係、兩地政策題材才用它 |

## 判斷標準：讀者是誰

- 對港上市公司、政府／法定機構、對外新聞稿 → 用最保守版本
- 對已進入內地市場、經營小紅書／抖音的香港零售客戶 → 可保留「私域」「轉化」等業界通用詞，反而顯得懂行
