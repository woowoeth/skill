# 英语基本功建站

处理“开始、批改、继续、复测、备份”或恢复学习时，先读 [短口令操作规程](references/short-commands.md)，再读取当前项目的 `AGENTS.md` 和 `.english-basics.json` 定位真实练习器及数据。用户不必反复粘贴身份编号、长请求或后台命令；这些信息由 Agent 从本项目配置和待批记录取得，不依赖之前的聊天记忆。

新建项目时，再读 [现成模板与课程接入](references/practice-template.md)，使用随包 `scripts/setup.py --project 目标目录` 安装完整技能、现成练习器和持久项目入口；沿用现成界面、API 和状态机，不再从零生成。制定正式材料与学习计划时阅读 [建设与训练规范](references/workflow.md)。

用户要求建站时实际复制、配置、运行并验收；只咨询或安装技能时完成对应请求。接续已有项目先读操作手册和数据，沿用其技术栈与已确认规则，不用模板覆盖学习档案。

## 引导与计划

安装并打开网站后，若尚无学习目标，主动开始引导，不等用户自己想到“我要练……”。首条回复简短说明已就绪、目前有三个样例词，并问“你想先练阅读、听力还是写作？”；用户也可以回复“先试试”。具体接续规则见 [首次引导](references/short-commands.md#安装后的首次引导)。仅安装技能、不开始使用时完成安装即可。

用户回复“阅读”“听力”“写作”就是选择模块，按已知情况只追问下一项必要信息；不让用户改写成完整提示词。选择“先试试”才按三个词熟悉流程，说明它不是完整词表、考纲或考试原声课程。已有目标或学习记录时沿用，已知信息不重复问。

用户提出正式目标，例如“我要练中考阅读”，每次只问一个当前必要且尚未知的问题；先确定适用地区/范围等真实缺项，再由 Agent 自动查找核验材料。不要求用户回答端口、数据路径、课程 ID、JSON 或后台参数。报告真实资料数量，由用户确定范围、目标量与首测进度；首测后按实际薄弱项安排已确认五阶段，给出可调整的题量与批量，不擅自增题或加轮。常规保存、运行和批改直接继续。

每次交接都根据刚读取的真实状态，简短交代“现在完成了什么、下一步做什么、去哪里做”；不能只报告安装、保存或批改成功就停住。需用户回答时只问一个必要问题；需网页操作时给实际地址及对应位置；Agent 能直接完成的下一步继续执行。安装、材料、题量、作答、订正、阶段切换、复测结束和退出恢复按[逐步交接](references/short-commands.md#每一步都给出具体下一步)引导，不增加用户口令长度，也不承诺在空闲时自动监看网页点击。

复测按所有约定中间练习轮次的实际完成情况开启，不规定统一等待日数、固定题量或统一完成速度。订正通过只关闭对应订正；一题重做不算整轮复测。预计完成日期只用于规划。范围或进度变更保存版本，不改写已作答记录。

## 固定路线与边界

- 阅读：看词写义首测 → 薄弱词选义 → 固定句无选项辨义 → 同句英译中 → 看词写义复测。认词和翻译分别计分；接续已有课程时保留其已确认资源和规则。
- 听力：听音写义首测 → 薄弱词听词选义 → 无选项听词写义 → 听句译中文 → 听音写义复测。整理用户选定范围需要的固定考试原声库；不同原声组数与派生题数分别统计，不靠重复切片凑容量。不加入听句选义。
- 写作基本功：听音拼写首测 → 听音写词 → 句中填词 → 整句中译英 → 听音拼写复测。第二阶段围绕首测真实薄弱池听词音、独立输入英文，不给英文选项；用户选择全量巩固时按确认范围练。填词给中文和英文骨架；下一轮复用同一句，只给中文，独立写完整英文。整句翻译属于默认阶段，不加入看中文写单词。听音写词练习与首测、复测分开统计；填词、中译英、听力理解与认词成绩也分开。
- 整批提交后显示反馈，对已确认的错误提供讲解与订正：听力对照英文和中文重听；拼写查看正确词形和含义并再次听音。讲解与订正属于错题反馈，不独立计为学习轮，不用于增加已完成轮次数。
- 首版不扩展口语、长作文、自动生成新文章或声音、陌生材料必测。实际录音不足先查找，仍缺则请用户补充或调整范围；歧义声音不能强判唯一答案。

当前模板每个课程条目都要求真实词音和对应固定句音频，即使用户先练阅读也不能省略。Agent 根据真实词表、收录义项、固定例句与来源填写 `private/course.json`，并放入匹配录音；材料不齐时继续准备或由用户调整范围，不能用静音、合成声音或重复样例冒充原声。具体字段与限制见 [课程接入说明](references/practice-template.md#准备观众的真实课程)。

获取历史音频的参考见 [音频获取核验](references/audio-source-check.md)。它只证明曾取得样本，不是已核验的正式题库。

## 批改反馈与建议

编写网站的批改提示、处理实际作答或验收反馈时，读取并应用 [批改反馈要求](references/grading-feedback.md)。词义依据是选词来源词表的收录义项和收录例句的具体语境义；接受同一目标义的不同表达，不临时扩大考查范围。

对实际错误指出具体位置、解释依据、给参考表达和可执行的原题订正建议；整批总结须有真实作答记录支持。保留既定轮次、首测薄弱清单和错题订正，反馈不触发自动生成针对性新题、追加材料或调整路线。用户另行要求调整时再处理。

## 实现与验证

新项目由 `scripts/setup.py` 安装 Python 标准库后端、SQLite 持久化、现成学习工作台和项目发现入口。入门三词可立即用于熟悉操作；改为正式课程时先补齐真实材料，使用独立的正式学习档案，保留旧样例记录并更新项目定位。不要在技能的 `assets/` 目录直接开始学生课程，也不要把验收数据作为正式记录。模板的首测和复测固定全量，中间三阶段按首测薄弱项或用户选择全量；每阶段首次开始即冻结范围与批量，后续计划修改只影响尚未开始的阶段。

客观题与明确拼写、填词由后端判；开放题提交后，用户在本项目说“批改”即可。Agent 按配置定位，必要时 `study.py start`，再用 `study.py pending` 读取本项目全部真实待批原答和订正。对每个请求读取冻结规则、材料及[批改反馈规范](references/grading-feedback.md)，生成独立的完整结果文件并逐个 `study.py apply 文件`。不向用户打印 JSON；简短报告实际写回数量，并按结果指向原题订正、待核对处理或下一批/阶段的具体位置。无待批则按真实进度指向尚未提交的作答或已就绪的下一步，不造数据。详见[短口令规程](references/short-commands.md)。网页不自动连接当前聊天。

按稳定目标和材料版本记录原答、帮助、反馈、订正、各轮与复测。后端检查全部前置轮次真实完成才开放复测；重复提交不能增加覆盖数。保留首次错误、薄弱项来源和复测结果，不能用学习轮正确答案覆盖首次成绩。本模板的首测与复测均覆盖课程完整范围；其他覆盖方式须另做版本化实现并明确分母，不能只修改文案。

验证作答、批改、订正、前置轮未完成不开放复测、完成后开放、调整尚未开始阶段的计划、刷新重启和数据连同音频的备份恢复。隔离小样本只用于验证功能，不代表正式课程已学完。

交付真实可访问地址、实际启动命令、资料数量与缺口、已验证事项、操作手册及继续方法。运行环境或关键材料缺失时如实说明，不宣称完整网站已建成。
