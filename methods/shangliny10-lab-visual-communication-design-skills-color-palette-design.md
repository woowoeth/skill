# 色彩搭配设计

## 配色流程

1. **明确目标** — 品牌调性/情绪关键词、使用场景（印刷/屏幕/UI）、目标受众文化背景
2. **选择主色** — 基于情绪关键词或品牌意象，从色轮中选定主色相
3. **确定配色策略** — 单色/类比/互补/分裂互补/三角/四角/中性+强调
4. **构建色阶** — 主色生成 5-9 级明暗色阶（Tints/Shades）
5. **添加辅助色** — 1-2 个辅助色，同样生成色阶
6. **中性色系统** — 黑/白/灰系列，带色相偏移（非纯灰）
7. **验证与调整** — 对比度检查、色盲模拟、印刷打样、多图统一调色

## 色彩基础

### 色彩三属性
- **色相（Hue）**：颜色的基本相貌（红/橙/黄/绿/蓝/紫）
- **饱和度（Saturation）**：颜色的纯净程度，0% 为灰色，100% 为最纯
- **明度（Value/Lightness）**：颜色的明暗程度，0% 为黑，100% 为白

### 色轮关系
```
        红 (0°)
       /    \
    橙(30°)  紫红(330°)
     /          \
  黄(60°)      紫(300°)
    |            |
  黄绿(90°)    蓝紫(270°)
     \          /
    绿(120°)  蓝(240°)
       \    /
      蓝绿(180°)
```

## 配色策略

### 1. 单色配色（Monochromatic）
- 同一色相的不同明度/饱和度变化
- **优点**：和谐统一、高级感、不易出错
- **缺点**：缺乏对比、可能单调
- **适用**：高端品牌、极简设计、背景系统
- **示例**：深蓝 #1E3A5F → 中蓝 #2E5C8A → 浅蓝 #7EB3D9 → 淡蓝 #C5E0F0

### 2. 类比配色（Analogous）
- 色轮上相邻 3-5 个色相（间隔 30°-60°）
- **优点**：自然和谐、有丰富度、视觉舒适
- **缺点**：对比不足、重点不突出
- **适用**：自然主题、插画、背景氛围
- **示例**：蓝 #2E5C8A + 蓝绿 #2E8A7C + 绿 #5C8A2E

### 3. 互补配色（Complementary）
- 色轮上相对的两个颜色（间隔 180°）
- **优点**：对比强烈、视觉冲击、活力十足
- **缺点**：搭配不当会刺眼、廉价感
- **适用**：促销、运动品牌、强调按钮
- **示例**：蓝 #2E5C8A + 橙 #E8823C（降低一方饱和度避免冲突）
- **技巧**：一方大面积低饱和，另一方小面积高饱和

### 4. 分裂互补（Split Complementary）
- 基色 + 其互补色两侧的颜色（间隔 150° 和 210°）
- **优点**：有对比但不刺眼、更丰富、更易掌控
- **缺点**：比互补色稍复杂
- **适用**：大多数设计场景，通用性强
- **示例**：蓝 #2E5C8A + 红橙 #E85C3C + 黄橙 #E8A23C

### 5. 三角配色（Triadic）
- 色轮上等距的三个颜色（间隔 120°）
- **优点**：平衡、有活力、丰富多样
- **缺点**：不易协调，容易杂乱
- **适用**：儿童品牌、创意行业、插画
- **示例**：红 #C83C3C + 黄 #E8C23C + 蓝 #3C6EC8（降低饱和度统一调性）
- **技巧**：选一个为主色，另外两个为辅助色

### 6. 四角配色（Tetradic）
- 色轮上两对互补色（矩形或正方形排列）
- **优点**：最丰富、可能性最多
- **缺点**：最难掌控，极易杂乱
- **适用**：复杂界面、多类别数据可视化
- **技巧**：严格控制一个主色，其他色小面积使用

### 7. 中性+强调色（Neutral + Accent）
- 大面积中性色（黑/白/灰/米色）+ 小面积强调色
- **优点**：高级、百搭、重点突出、最安全
- **缺点**：可能过于保守
- **适用**：企业品牌、UI 设计、高端产品
- **示例**：深灰 #1A1A1A + 浅灰 #F0F0F0 + 白 #FFFFFF + 强调红 #E63946

## 情绪与色彩关联

| 色相 | 正面情绪 | 负面联想 | 适用行业 |
|------|---------|---------|---------|
| 红 | 热情、力量、爱情、紧迫 | 危险、愤怒、停止 | 餐饮、零售、运动、医疗 |
| 橙 | 活力、温暖、友好、创意 | 廉价、警告 | 餐饮、科技、儿童、社交 |
| 黄 | 快乐、乐观、智慧、注意 | 怯懦、警告、廉价 | 教育、能源、交通、快餐 |
| 绿 | 自然、健康、成长、财富 | 嫉妒、毒药 | 环保、医疗、金融、农业 |
| 蓝 | 信任、专业、冷静、科技 | 冷漠、忧郁 | 金融、科技、医疗、企业 |
| 紫 | 奢华、创意、神秘、灵性 | 颓废、暧昧 | 美妆、奢侈品、创意、宗教 |
| 粉 | 温柔、浪漫、女性、甜美 | 幼稚、脆弱 | 美妆、母婴、婚庆、甜品 |
| 棕 | 稳定、自然、质朴、可靠 | 沉闷、保守 | 咖啡、户外、家具、食品 |
| 黑 | 高端、权力、优雅、神秘 | 死亡、沉重、邪恶 | 奢侈品、科技、时尚、高端 |
| 白 | 纯净、简洁、医疗、和平 | 空洞、冰冷 | 医疗、科技、极简、婚礼 |
| 灰 | 专业、中立、稳重、现代 | 无聊、压抑 | 企业、科技、建筑、UI |

## 色彩比例法则

### 60-30-10 法则
- **60% 主色**：背景、大面积区域
- **30% 辅助色**：次级区域、卡片、侧边栏
- **10% 强调色**：按钮、链接、关键信息、图标

### 70-20-10 法则（更保守）
- 适用于企业级、专业感强的设计

### 50-30-20 法则（更活泼）
- 适用于创意、消费、年轻化品牌

## 色阶构建方法

以主色 HSL(210, 60%, 45%) 为例，生成 9 级色阶：

| 级别 | 明度调整 | 饱和度调整 | 用途 |
|------|---------|-----------|------|
| 50 | +45% | -20% | 最浅背景、hover 背景 |
| 100 | +35% | -15% | 浅背景、选中态 |
| 200 | +25% | -10% | 边框、分割线 |
| 300 | +15% | -5% | 禁用态、次要文字 |
| 400 | +5% | 0% | 悬浮态 |
| 500 | 0% | 0% | **主色（基准）** |
| 600 | -10% | +5% | 点击态/按下态 |
| 700 | -20% | +10% | 深色背景、标题 |
| 800 | -30% | +10% | 最深文字、深色模式 |
| 900 | -40% | +5% | 极端深色 |

## 中性色系统

避免使用纯灰（饱和度 0%），加入色相偏移更有质感：

### 冷灰（偏蓝）
- 适合：科技、金融、专业 UI
- 基准：HSL(210, 10%, X%)

### 暖灰（偏棕/橙）
- 适合：自然、家居、文艺、印刷品
- 基准：HSL(30, 10%, X%)

### 中性灰（微偏绿）
- 适合：通用、医疗、教育
- 基准：HSL(160, 5%, X%)

### 文字色阶（以暖灰为例）
| 用途 | 色值 | 对比度（白底） |
|------|------|---------------|
| 主标题 | #1A1A17 | 16.5:1 |
| 正文 | #33332E | 12.6:1 |
| 次要文字 | #595952 | 7.5:1 |
| 辅助文字 | #8C8C82 | 4.2:1 |
| 禁用文字 | #BFBFB5 | 2.5:1 |
| 分割线 | #E5E5DD | 1.3:1 |
| 背景 | #FAFAF7 | — |

## 印刷色彩管理

### RGB vs CMYK
- **RGB**：屏幕显示，色域大，色彩鲜艳
- **CMYK**：印刷输出，色域小，部分 RGB 颜色无法印刷

### 常见超色域颜色（RGB 转 CMYK 会变暗/变灰）
- 亮蓝 #0066FF → 印刷偏暗
- 亮绿 #00FF00 → 印刷偏灰
- 橙色 #FF6600 → 印刷偏暗
- 紫色 #9933FF → 印刷偏灰

### 解决方案
- 设计时开启 CMYK 预览（Photoshop/Illustrator）
- 超色域颜色选择 Pantone 专色替代
- 重要品牌色指定 Pantone 色号
- 印刷前打样确认

### 色彩模式转换
- 屏幕设计：sRGB（网页）/ Display P3（Apple 设备）
- 印刷设计：CMYK（四色印刷）/ Pantone（专色）
- 转换时注意：黑色文字使用单黑（C0 M0 Y0 K100），不用四色黑

## 无障碍色彩

### 对比度标准（WCAG 2.1）
- **正文文字**：≥ 4.5:1（AA 级）/ ≥ 7:1（AAA 级）
- **大文字（≥18pt 或 ≥14pt 粗体）**：≥ 3:1（AA 级）
- **UI 组件/图形**：≥ 3:1（与相邻颜色）

### 色盲友好设计
- **红绿色盲**（最常见，约 8% 男性）：避免只用红绿区分信息
- **蓝黄色盲**（罕见）：避免蓝黄对比
- **全色盲**（极罕见）：依赖明度对比

### 色盲友好配色方案
- 蓝 + 橙（最安全的对比组合）
- 蓝 + 黄
- 避免：红 + 绿、绿 + 棕、蓝 + 紫
- 所有颜色信息需辅以图标/文字/形状/纹理

## 多图统一调色

### 图片调色流程
1. 确定品牌主色调（HSL 色相值）
2. 所有图片应用统一的色彩平衡（阴影/中间调/高光分别偏移）
3. 统一饱和度（±10% 范围内）
4. 统一对比度曲线
5. 添加统一的色彩叠加层（透明度 5%-15%）

### 多图排版色彩协调
- 同组图片的主色调应在色轮 60° 范围内
- 若图片色彩差异大，统一转为黑白/单色后再加品牌色叠加
- 图片之间的过渡区域使用中性色缓冲
- 避免高饱和图片相邻放置（会产生视觉冲突）

### 图片与背景色搭配
- 图片主色与背景色为类比色 → 和谐融合
- 图片主色与背景色为互补色 → 突出图片
- 深色背景配明亮图片 → 视觉冲击
- 浅色背景配低饱和图片 → 高级克制

## 配色质量检查

- [ ] 主色/辅助色/强调色比例符合 60-30-10
- [ ] 色彩总数不超过 5 种（不含中性色）
- [ ] 正文文字对比度 ≥ 4.5:1
- [ ] 色盲模拟下信息可区分
- [ ] 印刷品已检查 CMYK 色域
- [ ] 深色/浅色模式下均可用
- [ ] 多图调色统一，无色彩跳跃
- [ ] 品牌色在所有媒介中一致
- [ ] 无纯黑（#000）和纯白（#FFF）（除非刻意设计）
- [ ]  hover/active/disabled 状态色阶完整
