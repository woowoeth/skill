# 景甜体改写

把用户给出的任意文稿、故事、经历、品牌材料或发言稿，改写成《我的女友景甜》那种第一人称记账体。改的是「怎么说」，不是把原文改成孙宇晨和景甜的故事。

改写前先读：

1. [references/style-system.md](references/style-system.md) — 十六手法、乐章、句法、量化自检、反例
2. [references/specimen.md](references/specimen.md) — 标本原句，按手法编号标注。**至少扫一遍这里的密度**，这个文体最容易输在稀
3. [references/examples.md](references/examples.md) — 映射示范与成稿

标本是 2026-08-27 孙宇晨长文《我的女友景甜》。只借方法，不借情节、人名、奢侈道具。

## 流程

### 1. 抽账本

从原文抽出一张账本，缺项就空着，不要补豪华生活：

- **我**：买单的人、等待的人、事后记账的人
- **对方**：让一个地方空下来的人/物/公司/产品
- **被抵押的与被要走的**：一样属于身体、时间或名字（押上去取不回来），一样是钱、额度或一句回复
- **起源**：最早、最便宜、未完成的靠近
- **规模阶梯**：后来越来越大的陪衬（人、项目、房间、预算）——人和物要能排进同一份清单
- **空置现场**：因对方而空、却还在被维护的地方
- **外围劳动者**：清洁工、助理、骑手、前台、摄影师——不知道自己在谁的故事里
- **工艺亲密**：唯一几乎不像交易的手艺或身体程序
- **账本细目**：钱、名字、账户、页数、时长、次数
- **称谓变化**：对方要求过、或处境改变过怎么称呼彼此吗
- **我知道但没说的**：叙述者手里那条能当场接住对方、却被主动扣下的事实
- **对方说出的终局条款**：对方用自己行业或处境的规矩，无意中讲出这段关系将如何结束
- **代为拒绝的第三方**：额度、条款、排期、制度、工具、别人的一句话——那个替叙述者说不的东西
- **那一次没有立刻说好**：唯一的停顿或拒绝
- **遗物**：人走之后还在的物件、账单、提醒、未拆的东西
- **循环空景**：结尾能回到的公共的空（散场、下班、海、群、服务器还开着）

原文没有的项，整段删掉对应乐章，不许用湾流、私人岛屿、取卵、五千万去填。

### 2. 定篇幅

| 模式 | 何时 | 字数 | 乐章 |
|------|------|------|------|
| 短帖 | 原文只有一段，或用户要发 X/朋友圈 | 600–1200 | 3：开场空置 → 一笔账或一道工艺 → 拒绝与遗物 |
| 标准 | 默认 | 2500–4500 | 5：冷开 + 起源阶梯 + 清空/工艺/称谓切换 + 停顿 + 遗物循环 |
| 长文 | 用户要完整对标，或原文事实够密 | 4500–8000 | 6：冷开 → 起源与阶梯 → 见面与清空 → 工艺与账本 → 停顿 → 遗物与空城 |

标本本身约四千五百字。用户指定字数时听用户的。事实不够就写短帖，不要注水。

### 3. 映射乐章

按 [style-system.md](references/style-system.md) 的乐章顺序重建，每一乐章只做一件事。用原文事实填结构，不把标本的香蕉、胶带、Claude、维港烟花搬过来，除非用户原文里真有。

标题默认：`我的` + 关系称谓 + 专名。要硬、短、不像副标题。用户已起标题则优先保留，除非它太抒情。

### 4. 落笔

- 第一人称。中文。英文稿默认译写为中文景甜体；用户明确要英文再写英文短行。
- 叙述者像在做尽职调查，不像在写情书。
- **对话不用引号**：`她说，工单上写着两居。` 标签只用「我说 / X 说」，X 是当前称谓。
- 默认应答是「我说好。」「我说好吧。」「我没问为什么。」；扣下事实的写法是「我没有说。」，后面不补解释。
- 称谓一旦切换就整段用下去，收尾回落到最正式或最陌生的那个。
- 情绪不命名。用重量、价格、秒数、心跳、账单、还在运转的无用劳动代替。
- 比喻的喻体只取权力机构、行政程序、医疗程序、宗族制度，约每千字一处，落地后立刻回到物件。
- 那一次拒绝由第三方替叙述者说出，写它的不为难，不写它的正确。

### 5. 语言过一遍

对照 [style-system.md](references/style-system.md) 末尾的**量化自检表**核一遍句长分布、数字密度、「我说好」次数、长段数、比喻类型。

然后删掉：情绪形容词、金句升华、排比抒情、解释对方动机、感叹号、省略号煽情、对话引号。数字尽量写成汉语（三点五微克、一百五十块、十一秒），专名、品牌、型号、年份保持原样。

**最后检查结尾**：停在一件没有发生的事上。如果最后一句能被当成人生道理，重写。

## 输出

默认：

```markdown
# {标题}

{正文}

---

## 改写说明
- 被抵押的与被要走的：…
- 空置现场：…
- 那一次没说好，由谁代说：…
- 事实边界：原文没有、因此没写的东西
```

用户说只要成稿、直接发、不要说明时，只输出标题和正文。

可附 2 个备选标题，不要附 5 个。

## 硬边界

- 不发明原文没有的事实、数字、性关系、违法行为、医疗细节、真实第三方丑闻。
- 不把任意文稿写成孙宇晨/景甜同人。不套用湾流 G700、蒙太奇拉古纳海滩、卡特兰香蕉、取卵、五千万美元，除非用户原文就有。
- 不换词照抄标本的签名句（「X 喜欢一个地方因为 X 而空着」「凌晨三点的 Y，什么都没有发生」）。手法复用，句子自己写。
- 景甜体的奢华是「空的基础设施还在运转」，不是「炫富清单」。原文若是合租、加班、小生意，就写那个尺度的空和账。
- 原文若含身体/性，写成程序、中断、遗物，不写成色情。原文没有，不要加。
- **「账本细目」和「一份四十几页的调查」是这套方法里最容易造成真实伤害的道具。** 涉及真实在世之人的私生活：只改写用户已经写在稿里的内容，不补隐私，不为了密度去罗列真人的亲属姓名、账号、住址、病史、涉罪传闻。用户要公开发表且稿件像在指控真人时，在正文外提示一次发布风险，并加一句「本稿是否需要虚构声明，由你决定」，不要擅自加「本文纯属虚构」除非用户在写小说。
- 「代为拒绝的第三方」可以是额度、条款、排期、制度、某个人。不要每篇都写成 AI 替主角拒绝——那是标本那一次的选择，不是格式条款。
