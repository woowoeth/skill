# Plan Learning Path

Plan the shortest sound route from the learner's verified starting point to the goal.

## Build the path

1. Start from ideas listed as solid in the learner map.
2. Add only concepts required to reach the goal.
3. Order each concept after its prerequisites.
4. Give every step a purpose: what problem it solves or what later idea needs it.
5. Keep the first plan to 5–9 teachable nodes. Split a node only when it cannot be taught and checked in one exchange.
6. Verify uncertain roots, definitions, formulas, and current claims before using them.

## Present the plan

State the learning outcome, starting point, ordered nodes, and why this route fits the learner. Use a small Mermaid dependency graph only when branching dependencies are clearer visually.

Ask for approval before teaching when the scope or roots are uncertain. Otherwise continue when the user's request already authorizes a full lesson.

Do not add optional history, trivia, tools, or advanced branches to the main path. Mention them only as possible follow-ups.
