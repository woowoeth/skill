# 俊达换装导演 · Junda Outfit Director

把同一角色的多套造型变成可以执行的图片与视频方案。默认沿用成年女性、五人拼贴和 8 秒换装的创作基线；用户已指定的角色、造型、动作和机制优先。

制作完整视频需要搭配生图模型与视频生成模型。推荐工作流是 **Codex + 当前可用的生图工具 → 审核首帧 / 必要的尾帧 → Seedance 2.0 → 播放验收**。本 Skill 提供导演规则和提示词；模型能力由当前宿主与服务入口提供。先判断用户要方案、图片还是视频，只执行本次要求的阶段。

## 入口与按需阅读

普通单人写真、单套服装展示、通用剧情短片不自动使用本 Skill。

| 用户任务 | 执行方式 | 必读参考 |
| --- | --- | --- |
| 先推荐几组穿搭 / 参数 | 推荐 4–8 组；用户给了数量则按要求；暂不展开完整脚本 | [参数预设](references/parameter-presets.md) |
| 已有角色 / 参考图，直接设计 | 锁定输入，补全合理缺项，交付图片与视频方案 | [图片导演](references/image-direction.md)、[动作与表情](references/motion-and-expression.md)、[交付格式](references/delivery-format.md) |
| 只更换换装方式 | 保留角色、服装、时长和镜头，替换触发与必要动作；多方案通常 3–6 个 | [机制库](references/transition-library.md) |
| 只优化表情 / 修正结尾回到初始服装 | 只调整用户点名的轨道和状态；保留已锁定舞蹈 | [动作与表情](references/motion-and-expression.md)、[连续性验收](references/continuity-and-expression-qc.md) |
| 实际生成图片、适配模型或交给视频工具 | 核实工具可用性与素材用途，按已批准方案执行 | [工具搭配](references/toolchain.md) |

每次选择、推荐或替换 M 机制时读机制库。每次交付完整方案时读交付格式。最终造型不同于初始造型、四次及以上换装、用户要求镜头互动或准备提交视频时，必读连续性验收；默认五套造型方案也满足此条件。

## 参数与输入

用户明确给出的参数全部锁定。分别标记 `用户指定`、`参考提取`、`系统补全`，不要为了填写表格重复提问。

- 角色：脸型、五官、肤色、成年年龄感、体型、发型 / 发色、头饰 / 耳饰、气质。
- 造型：使用稳定编号 `L0`（初始）和 `L1…Ln`（后续），写清位置与服装对应关系。
- 画面：比例、人数、布局、背景、光线、配色、贴纸轮廓、机位。
- 视频：时长、动作来源、M 机制与确认状态、卡点、表情轨、贴纸状态、最终造型展示区间、声音。

有参考图时先实际查看，再提取可见外貌、服装、人物位置、大小、朝向和摄影质感；分清中央造型与贴纸造型。不能凭图片推断真实人物的国籍或族裔，相关身份只记录用户明确提供的设定；保持可见面部特征即可。看不清的非核心细节可标记补全，不能假装已识别。

无参考图也能使用。没有角色设定时默认原创中国成年女性、视觉年龄 22–28 岁、自然东亚面部特征；在参数与图片 / 视频提示词中写明这是系统补全的虚构设定。用户给了其他成年角色时沿用，不用默认值覆盖。角色默认值可用时不为此追问；多套服装既未提供也未授权推荐，或镜头与机制确实冲突时，只问最关键的一项。

默认值：图片与视频 9:16，视频 8 秒，浅灰白无缝影棚，柔和漫射棚拍光，白色手绘虚线贴纸，固定机位，无文字 / Logo / 水印，无 BGM、台词或唱歌，声音仅服务换装节点。真实模型的时长 / 比例限制在提交时核实，8 秒是创意默认值而非接口承诺。

## 图片是结构母图

默认初始画面为同一角色的 5 个版本：中央偏右大人物约占画面宽度 60%–65%；四贴纸位于左上、右上、左中、左下；右下留白。中央无描边，四贴纸各有独立人体轮廓虚线，无矩形缩略图。

- `L0` 位于中央；`L1–L4` 按上述位置顺序对应。用户已有位置或顺序时以用户为准。
- M1、M8、M9 需要人物贴合时，参与运动的贴纸必须是完整全身抠像，头肩腰与主体可对齐。右上也不能用半身代替。
- M10 等贴纸静态展示方案可沿用参考图的右上半身紧凑构图，明确标记“半身静态贴纸”；不把它写成全身抠像。
- 默认五人时禁止额外第六人。用户明确要 3–6 套时，人数改为所需造型数、换装次数为造型数减一，重新说明布局，不能沿用“五人 / 禁止第六人”的固定限制。
- 同一张脸、年龄感、体型、肤色、发型与饰品连续。服饰本身可分层穿搭；禁止的是换装后两套服装错误残留融合。

首帧详细写法、镜头和图片验收见图片导演参考。每个镜头必须在图片与视频中一致。

## 机制确认与贴纸状态

M 是换装机制编号，表示服装通过什么动作或视觉事件切换，不是模型名称或质量等级。用户口中的“表达方式”“转场方式”可按换装机制理解。用户想看实际效果或按案例选机制时，读 [案例索引](references/showcase.md)。

用户已指定 M 机制直接采用。未指定时按风格推荐 2–3 种并给出首选；纯创意草案可以用推荐机制完成，标记 `系统推荐 / 待确认`。进入最终生成前明确显示机制状态。用户说“按推荐做”“你来决定”即授权采用推荐并记为已确认，不重复索要同一确认。母图通过本身不等于机制已确认。

优先候选：互动拼贴 M1；大袖汉服 M2；古典扇面 M5；贴纸设计 M8；现代节奏舞蹈 M10。一个短片通常使用一种，最多两种；组合机制在不同换装点交替，每次强拍只承担一个换装因果。

| 机制 | 四周贴纸行为 | 最后画面 |
| --- | --- | --- |
| M1 完整人物飞入 | 点击后生成飞入副本，同时原位置移除留空；对齐后副本消失 | 被用过的贴纸不再出现；默认四次后只剩中央人物 |
| M8 翻页 / M9 分身融合 | 目标从原位置移动到中央，原位置留空，贴合后融合消失 | 按消耗记录保持空位 |
| M2–M7、M10–M12 | 默认贴纸静态保留，只改变中央服装；明确需要的高亮不算位移 | 保持原布局与贴纸数量 |

用户自定义贴纸行为时先锁定，并贯穿首帧、时间轴和尾帧。不能把 M1 的“贴纸消失”强套到 M10，也不能为 M1 尾帧恢复已消耗的贴纸。

M1 顺序必须明确：点击 → 完整人物副本出现、源位置同时消失 → 副本斜向飞入放大 → 头肩腰和当前动作对齐 → 中央切换服装、副本与其虚线消失 → 原动作继续。不得让副本和源贴纸并存造成额外人物，不飞入衣服或矩形卡片。

## 动作、时间与表情

无动作参考且采用默认 8 秒方案时，四次换装完成点为约 1.25、2.95、4.40、6.55 秒；6.55–8 秒持续最终造型。只在无既有动作、无用户卡点时，才可按总时长等比例缩放。

用户指定的动作顺序、幅度、方向、节奏和连续性全部锁定；从真实动作峰值安排换装，不平均切段。若时长容纳不下原动作、换装和收尾，说明冲突并提出延长、减少造型或换取动作段的选择，不暗中缩小舞蹈。

M10 无需动作参考即可创作连续步法、重心转移、手臂轨迹和清晰强弱拍。不能要求用户必须补参考视频，也不能退化为原地摆姿。有参考视频时，只有用户要求的动作 / 节奏被继承；不会因动作参考替换主角身份或服装。

动作轨与表情轨分开。优化表情只能改眼神、眼睑、嘴角、下颌和极小头部角度，不增删、缩小或改写舞蹈。每个动作段给出可读出的表情承接；“跟镜头互动”是指定时间回看镜头，不意味着移动摄影机。

短片的可执行时间轴、现代风微表情与衣料物理见动作与表情参考。表情以已锁定角色气质为准，不对冷峻人物强加笑容。

## 首尾状态与实际执行

先写 `L0 → L1 → … → Ln（T 秒至结束）`，再写贴纸状态变化。最终造型不同于初始时，首帧不能充当尾帧。支持且当前模式可同时使用首尾帧的模型，准备同角色、最终造型、正确剩余贴纸的独立尾帧；不支持时，用明确的最终状态与展示区间补强，并标记视觉约束较弱。

图片生成和视频生成遵循已有授权：用户只要提示词就交付提示词；用户要图片且工具可用就生成、展示并保存；视频提交前核对已确认素材、机制、目标模型和本次生成授权。安装本 Skill 不代表已连接视频服务。生成失败保留结果与任务编号，先定位问题，不擅自更换提供商或新增付费重试。

交付完整方案时按参考输出 8 项：参数、首帧提示词、视频时间轴、独立表情轨、机制确认、精简模型提示词、约束、首尾状态与验收。只要一个阶段时只交付相关项。已输出提示词、已生成资产、已提交视频、已播放验收分别记录，不能混称“完成”。
