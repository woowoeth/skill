# 小红书评论引流（通用方法论版）

主动搜索目标领域关键词 → 他人评论区发引流评论（卖房/商品/服务均可适配）。适用于小红书引流号运营。

## 触发条件

- 用户要求账号评论/引流/主动评论/跑评论轮次
- 查看账号评论统计（今日/累计）

## 模式定位（2026-09-07 外部实测吸收）

- **推荐流优先 + 搜索仅低频兜底**：高频关键词搜索会触发账号级安全验证（实测结论）。主流程 = 推荐流采集；搜索降级为兜底——整轮 0 命中才启用，**1 词/轮、间隔 ≥4h**、触发风控自动冷却 24h
- **画像投喂（养号）**：≤2 轮/天，从推荐流挑目标领域笔记 ≤2 篇，详情页停留 10-20s，低频点赞 ≤2/轮；绝不评论不发布
- **三层分离**：机械层不做语义判断；语义判断全交 LLM；发布独立显式动作
- **状态机**：replied/seen/skipped 三集合分离；pending 超 3h 防死锁；互斥锁
- **发布回显验证**：成功判据 = 页面出现回复内容；失败不落库不重试
- **冷却信号**：页面标题"安全验证/请求太频繁"→ 停 24h，重启后依然生效

## 运行机制

- 脚本：搜索模式（关键词池 + 评论变体都在脚本内，改文案直接改脚本）
- 手动批量：多轮串行，轮间休息 10-15min
- cron：白天 2-3 轮 + 夜间轮，均为搜索模式；**单轮≤20 条**（平台频率红线）
- 去重：一帖只评一次，跨轮生效（去重文件持久化）
- 真人频率：评论间 90-150s、关键词间 120-240s
- **每轮搜索关键词上限 22 个**（实测 180 次/天触发搜索风控）
- **关键词轮转**：词表扩宽后固定起始偏移，每轮推进取模回绕，轮次间循环覆盖全表
- **掐掉低产词**：过滤后可用帖 <3 直接跳过该词，不为零星帖耗整轮
- **串行禁并发**：多轮/多账号严格逐个跑，禁止并行（并发曾拖垮实例）

## 关键词策略

- **核心方法论**：引流跑量瓶颈 = 新帖供给。对抗去重库饱和的正确方式是**扩地理/场景长尾词挖新区新帖池**
- 词序：核心转化词置前 → 地段下钻词（实测富矿）→ 各区买房 → 场景/泛生活 → 饱和泛词（自动跳过）
- 求助型/提问型优先
- **动态扩词**：每轮评论成功后自动从帖子标题提取新地段词（正则 `([\u4e00-\u9fa5]{2,4})(?:买房|看房|楼盘|新房|置业)` → `X买房`），持久化并在加载时并入词池；每轮限 3 个防失控；过滤已覆盖区词/无意义词根
- 让搜索池跟着市场新盘走，对抗去重饱和

## 评论边界红线（卖房/商品引流通用）

- ❌ 禁提学区（非优势项不主动提）
- ❌ 禁凸显底价/具体售价
- ✅ 可提成本与让利角度（成本高、精装白送、买家捡漏）
- ✅ 可提核心卖点：位置/配套/交通/环境/品质
- ✅ 挂价区间可提
- 发文铁律：柔和防水军、零批判词、先扬后抑
- 黑名单账号：特定竞对不评论其帖子

## 频率上限与观察机制

- 决策：先让动态扩词跑一周观察单轮产出是否自然上升；稳定达标则不加轮（风险更低）
- 每日健康监控：正常静默；失败率>20% 或失败≥6 条推警告；历史存 CSV 供周趋势
- 实测基线：闲时轮 0 失败 vs 高峰轮 50% 失败 → 高峰禁跑实证

## ⚠️ 被ban判定与冷却（最高优先）

- **判定**：回复功能受限（UI 失败/提交未确认）= 频率过高被ban；点赞超时同源
- **复盘修正**：被ban可能性需交叉验证——读帖接口间歇失败、UI 层错误、只读也失败、末轮仍全成功 → 更可能 MCP 服务/会话异常 + 密集调用临时限流。但降频+冷却策略依然正确（宁保守）
- **对策**：①降频 ②冷却期停跑 ③期间账号不管（禁任何操作）④冷却后低频率单测恢复
- **解封检测**：状态机文件 + 定期检测 cron；检测前先重启容器清会话状态再低频测（1 搜索 + 1 评论）；成功=解封推送确认，失败=自动排 3 天后
- **用户指令**：遇到平台限制直接告知"被ban"，不搞复杂替代方案
- **测试纪律**：写操作测试必须低频——单次 1-2 条、间隔≥10min、避开评论轮次时段、优先只读验证；新功能先列方案确认再测

## 平台风控规则（联网验证 + 实测）

| 风险项 | 阈值/规则 | 应对 |
|---|---|---|
| 连续请求间隔 <30s | 高风险（间隔差 5s 即不同风控等级） | 评论 90-150s |
| 搜索频率 ~180 次/天 | 触发搜索页风控 | 每轮≤22 关键词 |
| 短时间评论太频繁 | 平台明文：触发评论功能限制 | 单轮≤20，间隔 90-150s |
| 高峰时段评论 | 实测 50% 失败 | 禁高峰全排闲时 |
| 日评论提交总量 | 单轮稳定 11-13 条 | 日总量≤50-60，轮间≥2h |
| 过度商业推广 | 平台明文限制项 | 话术柔和+频率控制，无法完全消除 |
| 处罚分级 | 轻度=功能受限→中度=大部分受限→重度=永久封禁；180 天累计 3 次轻中度=冻结 | 登录保持=未到封禁级 |

**被限制时处理（实测）**：停跑 → 冷却数小时 → 单测搜索恢复再跑；勿重复搜索加重风控。

## 运行纪律

- 只主动发评论，不回复评论（除非开通）；评论有回复不推送提醒，用户自行处理
- 达单轮上限即停（脚本逻辑）
- 每日复盘含评论章节：今日新增 N 条/累计 M 帖

## 隐私红线

- 引流话术、账号人设、小区/商品信息一律不写入公开 skill
- 上传/分享前必须做隐私扫描（姓名/手机号/小区/财务/账号名/内部路径）
