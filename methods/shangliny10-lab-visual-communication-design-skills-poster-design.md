# 海报设计

## 设计流程

按以下顺序推进，每步确认后再进入下一步：

1. **需求拆解** — 明确主题、目标受众、投放场景（线上/线下/印刷）、尺寸比例、必须包含的信息（标题、副标题、时间地点、Logo、二维码等）
2. **创意概念** — 围绕核心信息提炼 1-2 个视觉隐喻或叙事角度，避免堆砌
3. **版式草图** — 确定构图方式（居中/对称/对角线/三分法/满版/留白），规划视觉层级
4. **字体系统** — 标题字体、正文字体、辅助文字的字号/字重/字距搭配
5. **色彩方案** — 主色+辅助色+强调色，控制在 3-5 色内
6. **元素整合** — 图片/插画/图形/纹理的选择与处理，统一视觉语言
7. **输出规范** — 分辨率（印刷 300dpi / 屏幕 72dpi）、色彩模式（CMYK/RGB）、出血位（印刷 3mm）、文件格式

## 构图法则

| 构图类型 | 适用场景 | 视觉效果 |
|---------|---------|---------|
| 居中对称 | 正式、高端、仪式感 | 稳定、庄重、聚焦 |
| 对角线 | 运动、活力、冲突 | 动感、张力、引导视线 |
| 三分法 | 人物、风景、叙事 | 自然、平衡、呼吸感 |
| 满版出血 | 视觉冲击、沉浸式 | 震撼、包围、强势 |
| 大面积留白 | 极简、文艺、高端 | 高级、克制、聚焦文字 |
| 网格系统 | 信息密集、学术 | 秩序、理性、易读 |

## 字体层级规范

- **主标题**：占画面高度 1/8~1/5，字重 Bold/Black，字距可适当收紧
- **副标题**：主标题字号的 40%-60%，字重 Medium/Regular
- **正文信息**：副标题字号的 50%-70%，字重 Regular/Light
- **辅助信息**（地址、版权等）：正文字号的 60%-80%，字重 Light
- 中英混排时，英文字号比中文小 10%-15% 以保持视觉平衡

## 色彩策略

- **主色**（60%）：奠定情绪基调，来自品牌色或主题意象
- **辅助色**（30%）：支撑主色，可使用邻近色或同色系深浅变化
- **强调色**（10%）：用于关键信息（标题、按钮、价格），使用对比色或互补色
- 避免使用纯黑（#000000）和纯白（#FFFFFF），改用深灰（#1A1A1A）和米白（#FAFAFA）增加质感

## 常见类型要点

### 活动海报
- 时间、地点、主办方必须清晰可读
- 主题视觉与活动调性一致（音乐节→奔放、讲座→知性、展会→专业）
- 预留票务/报名二维码位置

### 商业促销海报
- 价格/折扣信息是视觉焦点，字号最大
- 使用高饱和度强调色制造紧迫感
- 产品图必须精修，背景简洁突出主体

### 电影/戏剧海报
- 叙事性优先，一个核心意象胜过多个元素堆砌
- 标题字体需定制或高度风格化
- 氛围营造靠色调和光影，不靠文字说明

### 公益海报
- 概念先行，用视觉隐喻传递观点
- 避免说教式文字，让画面自己说话
- 克制使用色彩，单色或双色往往更有力量

## 质量检查清单

- [ ] 3 米外能看清主标题
- [ ] 核心信息 3 秒内可获取
- [ ] 字体不超过 2 个家族
- [ ] 色彩不超过 5 种
- [ ] 无对齐混乱（所有元素至少有一条对齐线）
- [ ] 无孤行/孤字（标题换行后最后一行不少于 2 字）
- [ ] 图片分辨率满足输出要求
- [ ] 印刷品已设置出血位和 CMYK 模式
