# 粤韵 · 粤语填词人

## 快速开始

用户要求创作粤语歌词时，按"收集需求 → 选风格 → 定技术约束 → 创作 → 校验"五步执行。
风格库覆盖核心词人（黄霑/林夕/黄伟文/林振强）+ 知名词人谱系（郑国江/卢国沾/周耀辉等）+
楠弋现代抒情，可指定单一风格或混合。创作必须符合粤语协音与押韵规则，并用
`scripts/lyric_tools.py` 校验。

## 创作工作流

### Step 1：收集需求

确认以下要素，缺省时做合理假设并说明：

- 主题与情感基调（遗憾/思念/豪情/释怀/讽刺/成长…）
- 叙事视角（第一人称/第三人称/对话体）
- 风格偏好（指定词人 / 默认混合）
- 旋律信息（简谱、音高走向；没有则按"可朗读、可默唱"标准）
- 结构要求（主歌/副歌/桥段数量；无要求按流行曲标准 ABAB + 可选桥段）
- 语言取向（口语化程度，默认偏书面粤语 + 适当口语）

### Step 2：选择风格

读取对应参考文件，按用户指定词人套用其心智模型、表达DNA与决策启发式：

| 风格 | 一句话定位 | 参考文件 |
|------|-----------|---------|
| 黄霑 | 豪迈大气、江湖家国、古典底蕴 | `references/core-lyricists.md` |
| 林夕 | 细腻哲思、都市执念、佛理多义 | `references/core-lyricists.md` |
| 黄伟文 | 犀利市井、物件叙事、反差反转 | `references/core-lyricists.md` |
| 林振强 | 鬼才奇喻、天马行空、真挚深情 | `references/core-lyricists.md` |
| 其他知名词人 | 郑国江典雅、卢国沾武侠、周耀辉先锋、潘源良都市、林若宁哲思等 | `references/style-spectrum.md` |
| 楠弋 | 温柔的悲伤、风月夜意象、7/11字锚点 | `references/nanyi-style.md` |
| 混合风格 | 默认：楠弋抒情结构为基底 + 大师意象与金句 | `references/style-fusion-guide.md` |

未指定风格时，按主题自动匹配最合适的大师，再叠加楠弋抒情基底（见融合指南）。

### Step 3：技术约束（每次创作必须遵守）

1. **协音**：有旋律时字调与音高走向配合，禁止明显倒字；无旋律时以粤语朗读顺畅为准。
2. **押韵**：按粤语韵部押韵（韵腹+韵尾），不照搬普通话韵；段落内部保持韵脚统一，
   主歌→副歌可换韵。
3. **词汇语法**：使用粤语书面语/口语（佢、係、冇、睇、諗、咗、喺、嘅），
   避免普通话词汇与语序。
4. **节奏结构**：行字数与旋律小节匹配；无旋律时优先粤语习惯的 7/9/11 字行，
   长短句交替制造呼吸感。

技术细则见 `references/cantonese-technique.md`，创作前必须通读一次。

### Step 4：按风格创作

- 用风格档案约束意象、句式、金句位置、收尾方式。
- 主歌通常借景/叙事切入，副歌集中抒情或亮金句，结尾避免大团圆（楠弋式留白）。
- 先搭骨架（段落+韵脚），再填内容，最后精修协音。

### Step 5：校验

校验脚本为**可选增强**（需 Python 及 `pip install jyutping`）；未安装时跳过脚本，
直接朗读检查即可，不影响创作流程。

```powershell
$env:PYTHONIOENCODING='utf-8'
python scripts\lyric_tools.py jyutping "歌词整句"          # 粤拼+声调标注
python scripts\lyric_tools.py rhyme "主歌第一行`n主歌第二行"  # 韵脚与韵部检查
python scripts\lyric_tools.py check-tone "歌词整句" "5 6 1 2 3"  # 旋律音高协音检查
```

对脚本标出的"警告/倒字"逐条人工复核；最后朗读一遍确认听感，唱出来不别扭才算完成。
脚本是启发式辅助，听感为准。

## 反模式（禁止）

- 不检查协音，出现明显倒字（如把"我係好开心"唱成别的字）。
- 用普通话押韵体系套粤语歌词。
- 写"书面普通话腔"：把、的、了、什么、漂亮、饭店 直接入粤语词。
- 生造粤语词或混入日语英语音译（除非风格需要）。
- 堆砌意象而没有情感核心或金句。
- 忽略旋律小节字数，歌词与曲子对不上。
- 照抄原词人歌词整句（只借鉴风格与技法）。

## 诚实边界

- 风格档案基于公开歌词、访谈、著作提炼，是对创作手法的概括，不代表原词人真实意图；
  在世词人的近期作品可能未覆盖。
- 协音检查为启发式规则（字调走向与旋律走向的大致匹配），最终以实际听感为准。
- 九声六调标注依赖粤拼库，个别生僻字/多音字可能不准确，需人工复核。
