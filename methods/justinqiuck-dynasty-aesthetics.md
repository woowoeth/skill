# 王朝美学设计系统

**核心逻辑**：不是画朝代场景，而是**用某个朝代的美学基因去做任何主题的海报**。

就像从一幅古画里裁下一个局部——它有那个朝代的配色、质感、线条，但主题可以是"凋零"、"自由"、"咖啡品牌"、任何东西。

## 用户引导入口

**当本 skill 被触发时，先执行信息收集，再进入生成流程。**

### 必需信息（缺一不可）

| # | 问题 | 为什么需要 | 示例 |
|---|------|-----------|------|
| ① | **哪个朝代？** | 三朝美学方向完全不同 | 唐 / 宋 / 秦 |
| ② | **情绪/主题是什么？** | 驱动全部视觉决策 | "凋零""探索""权力""自由" |
| ③ | **海报上要写什么字？** | 展示文字——真正印在画面上的 | "人类与AI会如何相处" 或 "秋水" |

### 可选信息（有默认值）

| # | 问题 | 默认值 | 什么时候追问 |
|---|------|--------|------------|
| ④ | **用在什么平台/场景？** | 通用海报 3:4 | 只在用户提到具体场景时加载 modern-applications.md |
| ⑤ | **要不要人物/肖像？** | 无人物（纯概念） | 用户说"人物""肖像""人像"时切换为 portrait 类型 |

| ⑦ | **有参考图吗？** | 无（Mode A） | 用户上传图片时切换为 Mode B（参考图工作流） |

- 用户提到"宋/大宋/南宋/北宋" → 宋朝

## 第二步：双通道文字解析

用户输入的文字分为两个独立通道：

### 通道一：情绪文字（驱动视觉）

**作用**：定义海报要传达的情绪/氛围。给AI理解方向，转化进提示词的视觉表达中。**本身不出现在海报上。**

示例：用户说"凋零"，AI理解后转化为氧化褪色、剥落质感、留白构图——但"凋零"这两个字不一定出现在海报上。

### 通道二：展示文字（印在海报上）

**作用**：真正出现在海报上的文字。可以是标题、品牌名、slogan、诗词。与情绪文字完全独立。

示例：情绪文字是"凋零"，但海报上印的是品牌名"秋水"或slogan"万物有时"。

### 用户输入的三种情况

| 输入方式 | 情绪文字 | 展示文字 | 处理 |
|---------|---------|---------|------|
| 只给一个词："凋零" | 凋零 | 凋零（同词复用） | 一个词同时驱动视觉和展示 |
| 给两个词："情绪是凋零，标题写秋水" | 凋零 | 秋水 | 分别处理 |
| 给场景："用凋零的感觉做一个咖啡品牌海报" | 凋零 | （追问品牌名/slogan） | 需追问展示文字 |

### 情绪映射表（三朝通用）

| 情绪轴 | 唐 | 宋 | 秦 |
|--------|---|---|---|
| 盛/华/满 | 矿物色饱和、金箔、满构图 | 物我两忘——满的是注意力深度 | 重复单元的阵列——满的是秩序 |
| 衰/凋/残 | 氧化褪色、剥落肌理、留白 | 枯枝、开片裂纹、极端留白 | 铁锈沿网格蔓延——系统在崩溃中维持秩序 |
| 静/寂/空 | 水墨灰度、大留白、单色克制 | 边角构图、月光如水、极简 | 地宫暗光、被封存的寂静 |
| 动/飞/舞 | 飞天飘带S曲线、金尘悬浮 | 减笔写意、一笔定型 | 兵器弧线——功能驱动的精确运动 |
| 冷/清/远 | 石青冷调、薄雾消融 | 天青单色、雨后天光、清冷淡韵 | 铁灰天光——没有温度的世界 |
| 暖/醇/厚 | 赭石温厚、琉璃辉煌、烛光 | 茶汤透光——唯一允许的温暖 | 火光映铁——唯一的热来自锻造和战场 |
| 刚/劲/雄 | 颜体骨力、朱砂浓烈 | 瘦金线锐利、理学格物的精确 | 水德威压、网格、青铜、篆刻 |
| **探索** | 丝路冒险——自信地走向未知 | 理学格物——精确凝视未知 | 永恒执念——为死后世界建造 |

## 第三步：嫁接规则

### 核心原则

**美学是气质，不是元素。**

- ❌ "画面里出现一个唐朝仕女" → 这是画场景
- ✅ "色彩取自唐三彩的矿物饱和度，质感像氧化的壁画表面" → 这是用美学

### 嫁接三步法

1. **提取关键词的核心视觉隐喻**
   - "凋零" → 剥落、褪色、枯的线条、残的形态
   - "自由" → 飘带、风、不受束缚的曲线、打破边界
   - "咖啡" → 醇厚的深色、温暖、缓慢的时间感

2. **用唐朝美学语言重新编码**
   - 剥落 → 壁画矿物色的氧化褪色质感
   - 飘带 → 飞天飘带的曲线韵律
   - 醇厚 → 赭石+金箔的温厚质感

3. **组合为视觉描述**
   - 不是"一个唐朝场景"
   - 而是"以唐朝壁画的肌理为质感基底，色彩取自氧化后的矿物色——赭石、铜锈绿、残金——来表达凋零的主题"

**备选输出：叙事提示词（用于 Midjourney / Stable Diffusion）**

当用户指定 MJ/SD 时，将规格书转化为叙事提示词。转换规则见 `references/prompt-engineering.md` 的备选输出章节。

**核心规则**：无论哪种格式，提示词中**禁止**出现具体的朝代叙事场景。只允许：
- 色彩描述（cinnabar red, oxidized mineral blue, profound black）
- 质感描述（aged mural texture, celadon glaze, cast bronze surface）
- 线条/形态描述（slender-gold strokes, seal-script lines, grid formation）
- 构图/空间描述（vast negative space, corner-weighted, grid formation）
- 光照气质（rain-washed diffused light, iron-grey ambient）

这些是美学语言，不是场景描述。

## 第七步：文字层设计

**AI图像模型无法精确生成中文文字。** 文字层在AI生图后，用设计工具（Figma/PS/Canva）叠加。

### 文字风格选择

提供两种风格供用户选择：

| 风格 | 气质 | 适用情感 |
|------|------|---------|
| **书法** | 手写感、古韵、有人味 | 盛华、刚劲、禅意、凋零 |
| **现代字体** | 干净、克制、当代感 | 任何主题均可，更百搭 |

用户未指定时，根据情感映射自动推荐。

### 核心规则

读取对应王朝的 `typography.md` 获取完整的字体推荐和排版规范。每个王朝有不同的字体推荐体系。

核心原则：
- **文字层必须尊重图像层的构图**：文字放在留白区或密度低的区域，不要遮挡主视觉
- **文字颜色从画面色彩中取**：从 palette 中选对比度足够的色
- **印章是可选的东方感锚点**：一方朱红印章可以瞬间拉升"东方气质"

### 文字层在图像提示词中的预留

生成图像提示词时，**根据文字位置主动留出空间**：

```text
# 如果文字在上方
"upper third of the composition kept deliberately sparse, 
reserved for typographic overlay"

# 如果文字在下方
"lower portion of the frame intentionally open and minimal"

# 如果文字是竖排侧边
"right edge of the composition kept quiet and open"
```

## 模式B：参考图介入

当用户提供参考图（照片/产品图/场景图）时，切换到此模式。

**完整工作流** 读取 `references/image-reference-workflow.md`。

### 核心区别

| | 模式A（纯文字） | 模式B（参考图） |
|---|---|---|
| **输入** | 情绪关键词 + 展示文字 | 参考图 + （可选）情绪关键词 |
| **输出** | 纯AI生成的海报 | 基于参考图的美学转换图像 |
| **保留** | 无（完全生成） | 参考图的核心特征（五官/产品形态/空间结构） |
| **覆盖** | 全部由王朝DNA驱动 | 色调/质感/光照/轮廓/构图由王朝DNA覆盖 |

### 提示词结构

参考图场景必须使用**两段式提示词**：

```
STEP 1 — ANALYZE THE REFERENCE:
  识别需要保留的特征（五官/结构/身份）

STEP 2 — APPLY [DYNASTY] AESTHETIC DNA:
  按维度逐一覆盖（肤色→质感→轮廓→光照→构图→情绪→背景）
  每个维度必须同时说明"变成什么"和"不是什么"
```

### 变形程度

| 程度 | 保留 | 覆盖 | 效果 |
