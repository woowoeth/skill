# 概念学习资料生成 Skill（concept-study-guide）

## 一、适用场景

- 需要系统学习一个**新概念**（技术概念、课程知识点均可），并产出一份可长期保留、可提交、可复盘的学习资料。
- 需要保证资料**来源真实可查**，而不是 AI 生成的"看起来对"的内容。
- 需要在学习多个概念后做**关系梳理**（配合本仓库 `learning-materials/concept-relationship.md` 使用）。

不适用于：需要精确数值/实时数据的查询（如股价、天气）；仅查词义的快问快答。

## 二、输入信息

| 输入项 | 是否必需 | 说明 |
|---|---|---|
| 概念名称 | 必需 | 例如 "Agent"、"大模型的上下文" |
| 学习者背景 | 建议 | 当前水平与用途（如"本科生，初学 AI 课程"），用于控制解释深度 |
| 输出文件名 | 可选 | 默认按 `learning-materials/<概念英文小写>.html` 命名 |
| 指定资料范围 | 可选 | 指定必须参考的教材章节或链接 |

## 三、生成步骤

1. **明确概念边界**：先确认该概念在本课/本文语境下指什么（例如"上下文"指上下文窗口而非上下文工程时，要说明取舍），避免同名概念混淆。
2. **检索可核查来源**：使用 WebSearch/WebFetch 找 2~4 个权威来源（官方文档、知名论文、可信技术博客），逐一确认链接可访问、内容确实支持结论。**严禁凭空编造链接**。
3. **提炼核心问题**：围绕"它解决什么问题 / 内部怎么工作 / 什么时候失效"提炼 3~5 个核心问题，作为资料主线。
4. **撰写结构化解释**：按下方"输出结构"逐节撰写。所有"个人解释"部分只产出**草稿**，并标注 `【TODO：请用自己的话重写】`，由学习者本人改写后才算完成。
5. **设计自测题**：出 3 道自测题（1 道概念辨析、1 道应用、1 道边界/反例），附参考答案要点。
6. **生成 HTML 文件**：输出到 `learning-materials/`，使用统一的浅色主题模板，来源链接用 `<a>` 标注并附"核查日期"。
7. **更新关系文档**：若概念与已有概念存在关系，同步更新 `concept-relationship.md`。

## 四、输出结构

每份学习资料 HTML 必须包含以下九节，顺序固定：

1. **学习目标**：学完后应该能回答什么、能做什么（3 条以内）。
2. **核心问题**：贯穿全文的 3~5 个问题。
3. **个人解释**：学习者自己视角的一句话定义 + 展开。**AI 只写草稿并标注 TODO，学习者必须用自己的话重写。**
4. **核心机制 / 组成**：拆解概念内部结构，用文字 + 图（SVG 或列表）说明。
5. **具体应用场景**：一个具体的、带步骤的例子，而不是泛泛的"可以用于 XX"。
6. **容易混淆的问题 / 使用边界**：与最相近概念的对比；说明该概念什么时候不适用、常见误解是什么。
7. **自测问题**：3 道题 + 参考答案要点（折叠或放在文末）。
8. **参考来源**：2~4 条可核查链接，每条注明"发布方 / 标题 / 访问日期"。
9. **人工核查记录**：列出生成后被人工修改、验证过的内容点，注明日期。

## 五、资料来源要求

- 只引用**真实存在、可公开访问**的来源：官方文档（如 Anthropic Docs、OpenAI Docs）、arXiv 论文、知名工程师博客（如 Lilian Weng）。
- 每条来源必须实际访问核验过内容与资料中的说法一致，并记录核查日期。
- 引用内容用**转述**，不得整段复制原文；转述处标注来源。
- 找不到权威来源的断言，要么删除，要么明确标注"待验证"。

## 六、自检要求

生成后逐项检查，任何一项不通过都要修复后再交付：

- [ ] 文件位于 `learning-materials/`，命名符合约定；
- [ ] 九个输出节齐全，无缺漏；
- [ ] "个人解释"节含 `【TODO：请用自己的话重写】` 标记（或已注明学习者本人改写完成的日期）；
- [ ] 至少 2 条参考来源，链接可访问、发布方可确认；
- [ ] 文中每个事实性断言都能对应到某条来源或明确标注待验证；
- [ ] 应用场景具体（有输入、有步骤、有结果），不是空话；
- [ ] 概念辨析节回答了"它和 X 有什么区别"（X 为最易混淆概念）；
- [ ] 自测题覆盖概念辨析、应用、边界三个维度；
- [ ] 无 API Key、密码、个人隐私等敏感信息；
- [ ] HTML 可直接在浏览器打开，无外部依赖（样式内联，不依赖 CDN 才能阅读正文）。

## 七、流程图

```
输入概念 + 背景
      │
      ▼
确认概念边界 ──► 检索并核验来源 ──► 提炼核心问题
      │
      ▼
按九节结构撰写草稿（个人解释标 TODO）
      │
      ▼
生成 learning-materials/<概念>.html
      │
      ▼
执行第六节自检清单 ──► 不通过则修复 ──► 交付 + 提示学习者人工改写
```
