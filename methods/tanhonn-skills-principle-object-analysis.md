# 事物分析原则

事物分析从对象结构和时空维度两个方面理解分析对象。对象结构说明对象由什么构成、各部分如何协作以及职责和状态如何归属；时空维度说明对象位于何处、覆盖什么范围以及如何产生、变化和失效。

- 对象结构: 读取 [对象结构原则](references/object-structure.md)，分析对象的单元、关系、边界、行为和生命周期。
- 时空维度: 读取 [时空分析原则](references/time-space-analysis.md)，分析对象的变化、快照、阶段、持续性、范围、位置和距离。

具体领域已经提供更准确的对象模型、结构规则或时空约束时，以领域规则为准，并使用本 skill 补充跨领域的分析维度。
