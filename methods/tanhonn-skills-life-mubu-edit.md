# 幕布大纲编辑

## 核心流程

1. 接管目标文档: 按 [幕布文档接管补充规则](references/safe-handoff.md) 确认通用页面接管边界、目标文档、大纲模式和编辑准入。
2. 规划目标大纲: 按 [内容规划规则](references/content-planning.md) 将用户要求和外部材料整理为可执行的编辑草案。
3. 编辑真实节点: 按 [节点编辑规则](references/node-editing.md) 将草案分批落到幕布真实节点和节点描述。
4. 校验并收口: 按 [节点编辑规则](references/node-editing.md) 校验编辑结果，并向用户汇报完成范围、未处理项和风险。
