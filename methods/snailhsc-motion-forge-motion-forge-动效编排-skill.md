# Motion Forge · 动效编排 Skill

根据 SRT 字幕稿，为口播视频生成 Motion Forge 可直接导入的动效编排 JSON（StageDoc）。
用户在编辑台导入 JSON 预览微调，最后导出透明动效层叠回原片。

## 定位原则

是「用动画呈现语义」，不是「给字幕加特效」：卡的内容来自论点和证据，
不是 SRT 原句复述。卡面文字必须明显短于口播原句。

## 工作流程

1. **解析 SRT**：提取每条字幕的 start/end（秒）和文本；同一语义段的相邻字幕合并区间。
2. **分段脚本（先于选卡）**：整篇拆成「章 → 段 → 元素」。段 = 10-30s 恰好一个论点；
   每段标起止秒 / 标题 / 语义色 / 元素列表。
3. **识别内容类型**：钩子设问 / 痛点罗列 / 反转金句 / 数据 / 步骤 / 对比 / 误区纠正……
4. **匹配卡片**：只能用下方卡库里的 kind，严禁发明新类型。按各卡「触发条件」选。
5. **编排落位**：
   - 竖版（9:16）：人物通常居中，卡放上下两段或左右安全区，**不许盖脸**
   - 相邻两张卡不许同 kind；同屏在场 ≤3 张；同段 accent 一致
   - 数字类卡（count-flash）的 countMs 对齐口播说到数字的时刻
   - myth-buster 的 crossMs 对齐口播说「其实/真相」的时刻
   - 时间全部来自 SRT 真实时间，不许臆造
6. **输出纯 JSON**（格式见下）+ 素材清单（用了需录屏/截图的卡，逐卡列出需求）。
7. **交付前必须跑 lint 自检**（硬规则，不许省）：
   ```bash
   npm run -s lint:stage -- <你的编排.json> --duration <视频总秒数>
   ```
   - error（占位演示文案、时间越界）**必须全部修完**再交付
   - warn 不阻断，但要逐条过目，把还在的 warn 附在交付说明里给用户
   - 用户主动说「这段就要快闪/就要叠着放」时，不改成「标准答案」，
     而是在那张卡上写 `"lintOff": ["规则名"]` 保留决定（见下「lintOff」）

## lintOff（用户决定的保留，不是绕过体检）

`lintOff` 是**用户明确拍板**后的记录手段，写进卡片随 JSON 保存：
- 单条规则：`"lintOff": ["flash", "crowd"]`
- 全忽略：`"lintOff": true`（慎用，需用户亲口说「这张别管了」）
- 重排 / 重写 / 加密交付的 JSON，lintOff 必须原样保留，不许顺手清掉

## 偏好与「学一下」

- 选卡与取值先看同目录《我的偏好.md》（不存在则用《我的偏好.default.md》的中性取值）。
- 「学一下」：用户说这个词时，去 `exports/review-logs/` 找最近的 review-log，
  对比 origin（你初排）与 final（用户终稿）的 diff——改了几张卡、换了几种 kind、
  密度/时长/accent 的走向——把规律沉淀进同目录《经验规则.md》，下次编排直接生效。

## 素材目录接力（STATUS.md）

跨会话干活（生成动效 → 剪辑 → 发布往往隔几天）时，在当期素材目录放一份 STATUS.md
（模板见同目录《STATUS.template.md》）：记录当前进度、编排 JSON 位置、导出成品位置、
下一步动作。任何 Agent 接手先读它，别从头猜。

## 输出格式（严格遵守）

```json
{
  "version": 1,
  "canvas": "9:16",
  "theme": "dark",
  "duration": 261,
  "cards": [
    {
      "id": "card-1",
      "kind": "punch-line",
      "start": 0.5,
      "end": 4.2,
      "anchor": "bottom",
      "params": { "text": "买断的才是自己的，*订阅的永远是租的*", "accent": "orange" }
    }
  ]
}
```

- `anchor`：九宫格落位（top-left/top/top-right/left/center/right/bottom-left/bottom/bottom-right），省略则用卡的默认锚点
- `params`：只写需覆盖的字段，其余用卡默认值
- `canvas`：竖版 `9:16` 优先；用户明确要横版才用 `16:9`
