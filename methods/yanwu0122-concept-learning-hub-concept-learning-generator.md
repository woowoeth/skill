# 概念学习资料生成器

## 任务目标
- 本 Skill 用于: 接收任意概念名称，生成一份结构完整、可独立阅读的学习资料(HTML格式)
- 能力包含: 概念深度解读、核心机制拆解、应用场景构建、易混淆点辨析、自测题设计、资料来源标注
- 触发条件: 用户提到"学习某个概念"、"帮我理解XXX"、"生成XXX的学习资料"、"解释一下XXX是什么"

## 前置准备
- 无额外依赖，脚本仅使用Python标准库
- 配色方案参考: 见 [references/color-schemes.md](references/color-schemes.md)

## 输入信息
- 必填：要学习的概念名称（中文或英文均可）
- 可选：用户对篇幅、深度、配色的偏好；指定的输出文件名

## 操作步骤

### 步骤1: 概念调研
收到用户提供的概念名称后，先进行充分调研:
1. 使用 web_search 搜索该概念的权威定义、核心原理、最新发展
2. 查阅至少2-3个可靠来源(官方文档、权威教材、学术论文)
3. 记录所有参考来源的标题、URL和简要说明

### 步骤2: 内容结构化
基于调研结果，按以下结构组织学习内容。所有内容必须用自己的语言重新表述，不得整段照搬AI对话结果或原文。

**学习资料结构规范**:
1. **学习目标** (2-4条): 学完本资料后应掌握什么
2. **核心问题** (2-3个): 理解本概念需要回答的关键问题
3. **概念解释**:
   - 个人解释: 用通俗易懂的语言解释概念本质(100-200字)
   - 核心机制/组成: 拆解概念的运作原理或关键组成部分
   - 关键特征: 列出3-5个区别于其他概念的核心特征
4. **应用场景**: 一个具体的、可感知的应用案例，包含场景描述和分析
5. **概念辨析**: 2-3个容易混淆的问题或使用边界说明
6. **自测问题**: 2-3个检验理解的问题(附参考答案)
7. **参考来源**: 所有引用资料的标题、URL、简要说明(必须真实可访问)

### 步骤3: 构建JSON并生成HTML
将组织好的内容构建为JSON结构，调用脚本生成HTML学习资料。

**JSON格式规范**:
```json
{
  "concept": "概念英文名称",
  "concept_zh": "概念中文名称",
  "subtitle": "一句话定位",
  "color_scheme": "deep_ocean",
  "learning_objectives": ["目标1", "目标2", "目标3"],
  "core_questions": ["问题1", "问题2"],
  "explanation": {
    "personal_interpretation": "通俗解释文本",
    "core_mechanisms": [
      {"title": "机制/组成部分名称", "description": "具体说明"}
    ],
    "key_features": ["特征1", "特征2", "特征3"]
  },
  "application_scenario": {
    "title": "场景名称",
    "context": "场景背景描述",
    "analysis": "结合概念的分析说明"
  },
  "confusion_points": [
    {"question": "容易混淆的问题", "clarification": "澄清说明"}
  ],
  "self_test": [
    {"question": "自测问题", "answer": "参考答案"}
  ],
  "sources": [
    {"title": "资料标题", "url": "https://...", "note": "资料说明"}
  ]
}
```

运行脚本生成 HTML：

```bash
python scripts/generate_learning_material.py --input '<JSON字符串>' --output <概念名>.html
```

### 步骤4: 自检

生成完成后、交付用户前，逐项检查以下内容，任何一项不通过都要先修正再输出：

1. **结构完整**：学习目标、核心问题、概念解释（个人解释＋核心机制＋关键特征）、应用场景、概念辨析、自测问题、参考来源七个部分齐全，无缺项
2. **来源真实**：每条参考来源都是真实可访问的链接，不虚构 URL 和文献；无法核实的来源宁可删除
3. **原创表述**：所有内容已用自己的语言重新组织，没有整段照搬网页原文或 AI 对话记录
4. **文件可读**：生成的 HTML 能在浏览器中独立打开并正常显示
5. **存放规范**：在仓库内工作时，HTML 输出到 learning-materials/ 目录，文件名与既有资料保持一致风格（小写英文＋连字符）
