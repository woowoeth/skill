## 游戏攻略活页手账生成器

### Usage

当用户需要将**游戏攻略、指南、笔记**等文本内容制作成**可打印的活页手账**时，使用此 Skill 生成专业的 HTML 排版文件。

#### 触发条件

用户提到以下关键词或需求：
- "做成手账"、"活页手账"、"打印手账"
- "排版成便携尺寸"、"M5手账"、"A7手账"
- "攻略打印"、"游戏笔记"
- 需要**固定尺寸**、**左侧打孔**、**双面打印**的文档

#### 工作流程

1. **确认需求参数**（如用户未指定，使用默认值）：
   - 成品尺寸（默认：95mm × 170mm，竖版）
   - 打孔边距（默认：10mm）
   - 字体（默认：霞鹜文楷）
   - 配色主题（默认：水蓝+深绿，优雅风格）

2. **分析内容结构**：
   - 识别标题层级（H1/H2/H3）
   - 提取表格、列表、重点框
   - 规划分页逻辑

3. **生成 HTML 文件**：
   - 使用 `ipython` 工具创建完整 HTML
   - 包含正反面镜像排版 CSS
   - 保存到 `/mnt/kimi/output/`

4. **提供打印指南**：
   - 纸张设置
   - 双面打印选项
   - 打孔装订建议

#### 技术规范

**默认排版参数：**
```
尺寸：95mm × 170mm（竖版，适合M5/A7 Slim）
打孔边距：10mm
正反面：奇数页孔在左，偶数页孔在右（镜像对称）
底色：纯白 #ffffff
字体：霞鹜文楷（LXGW WenKai Screen，9pt）
加粗色：深墨绿 #1a3d1a
主题色：水蓝 #7EC4CF（用于标题、边框、装饰）
警示色：深橙 #c46a1a（用于警告框）
高亮：柔和鹅黄 #ffecb3
```

**CSS 核心逻辑（手动双面打印-长边翻转）：**
```css
/* 奇数页：打孔在左，内容靠右 */
.page:nth-child(odd) .punch-area {
    left: 0;
}
.page:nth-child(odd) .content {
    left: 12mm;
    right: 5mm;
}

/* 偶数页：打孔在右，内容靠左 */
.page:nth-child(even) .punch-area {
    right: 0;
}
.page:nth-child(even) .content {
    left: 5mm;
    right: 12mm;
}
```

**打印原理：**
- 第1页（奇数）：孔在左，打印在纸张正面
- 翻转纸张（长边翻转）：孔从左翻到右
- 第2页（偶数）：孔在右，打印在纸张反面
- 结果：两面孔位重合，内容方向一致

**CSS 特性：**
- 使用 `@page` 规则定义纸张尺寸
- 奇偶页选择器实现镜像排版
- 表格保留完整边框和斑马纹
- 事件条目使用左边框突出
- 响应式打印媒体查询

#### 示例

**用户请求：**
> "我想把这个游戏攻略做成活页手账，尺寸170x95mm，左边留1cm 打孔"

**执行步骤：**

1. 确认攻略内容已提供（通过上传文件或粘贴文本）
2. 使用 `ipython` 生成 HTML：

```python
html_template = """
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>攻略手账</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/lxgw-wenkai-screen-webfont@1.7.0/style.css" />
    <style>
        @page { size: 95mm 170mm; margin: 0; }
        
        /* 奇数页：打孔在左 */
        .page:nth-child(odd) .punch-area {
            left: 0;
        }
        .page:nth-child(odd) .content {
            left: 12mm;
            right: 5mm;
        }
        
        /* 偶数页：打孔在右 */
        .page:nth-child(even) .punch-area {
            right: 0;
        }
        .page:nth-child(even) .content {
            left: 5mm;
            right: 12mm;
        }
    </style>
</head>
<body>
    <!-- 按内容分页，每页包含.punch-area和.content -->
</body>
</html>
"""
```

3. 保存文件并提供下载链接：`[文件名](sandbox:///mnt/kimi/output/文件名.html)`

4. 提供打印设置指导：
   - 纸张大小：自定义 95×170mm
   - 双面打印：长边翻转
   - 边距：无
   - 背景图形：勾选

#### 可定制选项

用户可要求调整以下参数：

| 参数 | 可选项 | 适用场景 |
|:---|:---|:---|
| **尺寸** | 95×170mm / 105×148mm(A6) / 80×125mm(M5) | 便携程度 |
| **打孔边** | 左侧 / 右侧 / 顶部 | 活页夹类型 |
| **字体** | 霞鹜文楷 / 思源宋体 / 系统黑体 | 阅读偏好 |
| **主题色** | 水蓝 / 薄荷绿 / 暖橙 / 樱花粉 | 游戏风格 |
| **底色** | 纯白 / 米白 / 淡黄 | 护眼需求 |

#### 注意事项

1. **内容长度控制**：单页内容不宜过多，确保打印后阅读舒适
2. **表格处理**：宽表格可能需要调整列宽或拆分为多页
3. **字体加载**：霞鹜文楷通过 CDN 加载，需网络连接，打印前确保字体已缓存
4. **浏览器兼容**：推荐使用 Chrome/Edge 打印，Safari 可能需调整设置
5. **打印方式**：本方案专为**手动双面打印（长边翻转）**优化，确保孔位对齐
