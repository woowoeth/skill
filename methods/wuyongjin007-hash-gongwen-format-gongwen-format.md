# 公文版式统一规范

## 概述

所有正式中文文档统一采用以下公文版式。本规范是**版式层的唯一标准**，适用于标书、技术方案、技术文档、汇报材料、工作报告、公文等各类正式文档。

本 skill 只规定**版式层**——字体、字号、段落、页面、装订；**内容层**（标点符号、术语翻译、数字格式、括号、文字表述）仍遵循 [[chinese-technical-writing]]。两个 skill 叠加使用。

本规范以中国大唐集团公司汇报材料印刷格式为基准，该格式与党政机关公文版式通行标准一致。个别单位如另有版式要求（如页边距、单位名称微调），以该单位自己的格式文件为准。

## 触发条件

以下任一情况必须应用本规范：
- 用户要求撰写任何正式文档，包括标书、技术方案、技术文档、汇报材料、工作报告、公文、周报
- 用户明确提到"按公文格式""按汇报材料格式"等版式要求
- 输出文档需按企业公文版式排版

## 一、字体与字号

- 标题：方正小标宋简体（小标宋体）、二号（22磅）、居中
- 部门名称：宋体GB2312、三号（16磅）、居中、加粗
- 一级标题：黑体、三号（16磅）
- 二级标题：楷体GB2312、三号（16磅）、加粗
- 三级标题：仿宋GB2312、三号（16磅）
- 四级标题：仿宋GB2312、三号（16磅）
- 正文：仿宋GB2312、三号（16磅）、每段段前缩进两个字符
- 页眉：小四号（12磅）、黑体、加粗
- 页脚：小四号（12磅）、黑体、加粗
- 正文表格：宋体、小四号（12磅）、表头行加粗、行间距22磅

字体回退说明：仿宋_GB2312、楷体_GB2312、方正小标宋简体为公文规范字体，部分电脑未安装。未安装时，仿宋_GB2312 自动回退为仿宋、楷体_GB2312 回退为楷体，字形一致、肉眼无差别；方正小标宋简体需单独安装，或用华文中宋替代，否则标题会回退为默认字体。

## 二、段落与页面设置

- 段落行距：固定值28磅
- 文档网格：指定行网格和字符网格，每行28字、每页22行
- 页边距：上3.5厘米、下3.5厘米、左2.8厘米、右2.8厘米
- 页眉距边界2.5厘米、页脚距边界2.5厘米
- 版式：按A4纸型排版

## 三、装订与印刷

- 文件用纸：A3
- 装订：骑缝订或粘页
- 不另加封面
- 双面印刷

## 四、版式结构

- 标题之后空一行
- 部门名称之后空一行
- 标题层次：一、——（一）——1．——（1）

## 五、Word 生成要点

用 python-docx 生成时，注意以下关键设置：

- 中文西文分别设字体：西文字体用 Times New Roman，中文字体通过 `w:eastAsia` 指定，如 `仿宋_GB2312`、`黑体`、`楷体_GB2312`、`方正小标宋简体`
- 行距固定值28磅：`paragraph_format.line_spacing = Pt(28)` 并设 `line_spacing_rule = WD_LINE_SPACING.EXACTLY`
- 页边距：`section.top_margin = Cm(3.5)`，其余同理；页眉页脚距离用 `header_distance`、`footer_distance` 设为 2.5 厘米
- 文档网格 28字每行、22行每页 属于节属性，需通过 XML 设置 `w:docGrid`
- 正文每段段前缩进两个字符：`paragraph_format.first_line_indent` 设为两个字符宽度，或 `Pt(32)`（三号字两字符约 32 磅）

已提供现成实现，无需手写上述代码：

- `render.py` —— 可复用渲染库，核心入口 `render(content, output_path)`，接收结构化内容（title、dept、header、blocks），输出符合本版式的 .docx；也可作为普通 Python 库 import 使用。
- `mcp_server.py` —— 把 `render()` 封装为 MCP 工具 `render_gongwen`，供智能体调用，需先 `pip install mcp`。

## 六、表格规则

数据类表格允许使用，排版按本规范第一条执行——宋体、小四、表头加粗、行距22磅。方案对比等内容优先用段落或编号列表表述。
