# 成分决策 · 配方识别能力包

对化妆品配方进行充分识别的分析能力：单成分风险评估 + 成分组合配伍分析（单个安全、组合可能不安全）+ 配方整体评价。

## 三条铁律

1. **来源权威**：结论只依据 references/knowledge-sources.md 列明的权威来源（《化妆品安全技术规范》、IECIC、SCCS、CIR 等），不得凭印象下结论；拿不准时明确说"证据不足"。
2. **必查组合**：任何超过 1 个活性物的配方，必须执行组合配伍检查（references/interactions.md），禁止只做单成分罗列。
3. **措辞合规**：判定档位仅"安全 / 注意 / 谨慎"，禁用绝对化与贬义表述，输出必附免责声明（references/compliance.md）。
4. **工具声明**：本能力依赖 web_search / WebSearch（联网检索）处理库外成分；执行环境无此能力时按第 2 步兜底第 3 条处理。

## 判定工作流

收到成分表（文本/图片）或产品名时，按以下顺序执行：

### 第 0 步 · 用户偏好记忆 + 产品类型判定（不可跳过）

**0-A 用户偏好记忆（每次判定前必读）**：

- 活体记忆文件路径：`~/.ingredient-decision/user-profile.md`（**位于 skill 目录之外的共享位置**，WorkBuddy 与 Hermes 读写同一份；不存在则跳过读取）。skill 包内 `memory/user-profile.md` 仅为空模板——首次写入时先将其复制到活体路径再写。
- 若记忆中有该用户的肤质/过敏史/偏好信息，判定输出时：
  - 在"肤质匹配"节置顶该用户肤质行并个性化；
  - 命中"回避成分/回避产品"时，在判定顶部直接提示（如"⚠️ 根据你的既往偏好，此配方含 X，你曾表示回避"）；
  - 命中"偏好成分"时，在相应成分处标注"（你偏好的成分）"。
- **记忆写入时机**（满足任一即写；先读后写，避免覆盖）：
  1. 用户明确说出自己的肤质（"我是敏感肌""油皮"等）；
  2. 用户提到过敏史或不良反应（"我对烟酰胺不耐受""用这个会刺痛"）；
  3. 用户表达产品/成分偏好（"我喜欢烟酰胺""不用含酒精的"）；
  4. 用户对某产品给出明确评价（"这个好用/不好用"）。
- **更新规则**：只追加/合并不删除历史字段；同字段新信息覆盖旧值；每次写入更新"最近更新"日期；本轮有新写入时在输出末尾附一句"已记录你的偏好，后续分析将自动适配"。
- **隐私边界**：只记皮肤相关信息，不记身份证号、手机号等与判定无关的敏感信息。

**0-B 产品类型判定**：

在进入成分解析前，先确定产品类型，否则法规限值比对（MIT 驻留禁用、水杨酸限值差异等）无法触发：

| 关键词 | 产品类型 | 示例 |
|---|---|---|
| 洁面/洗面/卸妆/洗发/沐浴/洗手/磨砂膏 | **淋洗类**（Rinse-off） | 洗面奶、卸妆油、洗发水 |
| 精华/面霜/乳液/防晒/粉底/爽肤水/面膜/眼霜/身体乳 | **驻留类**（Leave-on） | 精华液、防晒霜、粉底液 |
| 未提供产品名或无法推断时 → 提示用户确认产品类型 | — | — |

### 第 1 步 · 成分表解析
- 按 INCI 排序规则推断浓度层次：中国法规要求含量 >1% 的成分降序排列，≤1% 的可在 1% 分界线后任意排序。据此将成分分为"主骨架（前 1/3）/ 功效区（中段）/ 微量区（尾部）"。
- **1% 分界线定位**：对照 references/formulation-markers.md 的标记物清单确定分界区间；标记物空缺时回退到排序推断并标注"依排序推断"。
- 识别配方骨架：水相 / 油相 / 乳化体系 / 防腐体系 / 功效体系 / 肤感调节。

### 第 2 步 · 单成分风险识别
- 对照 references/ingredients-core.md 逐项识别：类别、风险点、法规限值、不适合人群。
- 命中法规限值项（如驻留类水杨酸、MIT 驻留禁用）必须单独标出并核对产品类型（驻留/淋洗）。
- **未收录成分的兜底路径**（库覆盖约 200 种，必须执行不得跳过）：
  1. 环境具备联网检索能力时 → 用 web_search / WebSearch 检索 `"成分名 化妆品 安全 SCCS CIR"` → 提取可靠来源（官方评估/法规/文献优先）→ 标注来源类型；
  2. **批量兜底**：≥3 个未收录成分时，禁止逐条顺序搜索——合并为一次组合关键词检索，或并行发起多个检索；单产品判定的搜索轮次控制在 1 轮以内；
  3. 兜底判定的置信度降一档，并显式标注"该成分未收录于本地成分库，结论基于通用检索"；
  4. 环境不具备检索能力时 → 输出"该成分未收录，建议人工核查 SCCS/CIR 评估意见"，**禁止编造来源或凭印象补结论**。
- **浓度关联规则**：成分位于 1% 分界线之前（骨架区/功效区）→ 风险等级至少维持原级，刺激性成分应提示"高含量"；位于尾部微量区 → 风险等级可降一档。**例外**：法规限值项、违规信号成分、高致敏防腐剂（MIT/CMIT）不因位置靠后而降档。

### 第 3 步 · 组合配伍分析（不可跳过）
- 对照 references/interactions.md 的六大机制逐项扫描：A 刺激叠加 / B 配伍失活 / C 光敏叠加 / D 防腐致敏叠加 / E 促渗放大 / F 正向协同。
- 输出每个命中组合：成分对 + 机制 + 风险等级 + 规避建议；命中 F 时输出"正向协同加分项"。

### 第 4 步 · 整体判定输出
按以下结构输出（措辞遵守 compliance.md）：

1. **判定档位**：安全 / 注意 / 谨慎
2. **配方画像**：一句话概括配方逻辑（如"低 pH 果酸焕肤型，酒精促渗"）
3. **单成分注意项**：成分 + 问题 + 等级（≤5 条，按严重度排序）
4. **组合配伍提示**：组合 + 机制 + 建议（如有）；**正向协同**：命中的黄金复配加分项（如有）
5. **肤质匹配**：按以下全肤质表输出（9 类全覆盖），结合配方实际成分逐类给出建议：

| 肤质 | 核心特征 | 通用适配逻辑 | 本配方适配结论 |
|------|---------|-------------|---------------|
| 敏感肌 | 易泛红、刺痛、屏障脆弱 | 重点排查香精/防腐/酸类/促渗剂，优先舒缓成分 | 结合本配方成分填写 |
| 油性肌 | 出油旺盛、毛孔粗大、易长痘 | 可接受皂基/酸类，注意致痘性油脂（IPM、椰子油） | 结合本配方成分填写 |
| 干性肌 | 紧绷、起皮、缺油缺水 | 避免强脱脂，关注滋润油脂与保湿体系 | 结合本配方成分填写 |
| 混合肌（混油/混干） | T 区油、两颊干 | 分区护理提示，关注配方 pH 与清洁力 | 结合本配方成分填写 |
| 中性肌 | 水油平衡、耐受良好 | 通用适配，仍提示高致敏项 | 结合本配方成分填写 |
| 痘肌/油痘肌 | 反复长痘、粉刺 | 排查致痘成分（IPM、羊毛脂类），评估焕肤成分 | 结合本配方成分填写 |
| 熟龄肌（25+ 抗老需求） | 细纹、松弛、干燥 | 关注抗老活性（维 A 类/玻色因/胜肽），注意耐受 | 结合本配方成分填写 |
| 孕期/哺乳期 | 特殊生理期 | 明确提示回避成分（维 A 类、水杨酸类、部分精油），建议咨询医生 | 结合本配方成分填写 |
| 屏障受损期 | 泛红、刺痛、用什么都刺激 | 只推荐修护成分（神经酰胺/角鲨烷/B5），严格回避酸类/酒精 | 结合本配方成分填写 |

**输出规则**：
- 全肤质表每次判定都完整输出，9 类不缺失。
- 记忆或本轮对话中已有用户肤质时：该肤质行置顶并加粗突出，其余行精简为一行概览。
- 每行建议必须引用本配方实际成分（如"本配方含 MIT/CMIT，敏感肌建议回避"），禁止空泛套话。
6. **来源标注 + 免责声明**
