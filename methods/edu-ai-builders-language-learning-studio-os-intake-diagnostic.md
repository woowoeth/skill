# 入学诊断

## 核心前提

**分数是症状，不是诊断。** 一套真题要 3 小时加批改，换回来的只是一组分数，而分数不区分词汇、定位、选项处理、速度这四种完全不同的教法。

诊断的信息量来自**过程证据**，不来自题量。一道题若要求学生「选之前先划出原文依据句」，就能暴露真题分数永远看不见的东西：**选对了但依据句划错**——假性正确，换个题就崩。这一道题的价值超过二十道只有对错的题。

因此本 skill 不追求覆盖，追求**每分钟的诊断信息量**。

## 输入与输出

输入：学生代号与目标考试；已有成绩或自评（可选）；老师可用的诊断时长（15 / 30 / 45 分钟）；老师自己的真题片段（可选，用来替换默认探针的材料）。

输出 `intake-diagnostic-{slug}-{YYYY-MM-DD}.html`，把模板里的 `/* INJECT_DIAGNOSTIC_DATA */` 整行替换为 `DIAGNOSTIC_DATA = {...};`（不要写 `const`/`let`）。

诊断结束后由页面导出一份档案补丁，写入 `studio/students/{slug}/profile.json` 的 `baseline`、`diagnostics`、`milestones` 三个字段。本 skill 是 `baseline` 与 `diagnostics` 的首次写入方。

## 三层漏斗

### Layer 0 · 分数形状（5 分钟，不占学生时间）

只看已有成绩，判断**往哪儿探**，不下结论。单项之间的落差比总分有信息量：

- 阅读与写作落差 ≥ 1.5：不是语言问题，是产出问题，优先探写作结构。
- 听力与阅读落差 ≥ 1.5：大概率是速度或注意力，不是语言。
- 四项都在 5.0–5.5 且落差 ≤ 0.5：**这个学生不该进应试训练**。语言底子没到，考试技巧教了接不住。当场告诉老师这条分流建议，不要硬做。

没有历史成绩时跳过本层，直接进 Layer 1，并在输出中标注「无基线成绩」。

### Layer 1 · 微探针（10–15 分钟）

不做真题，做**被改造过的真题片段**。每个探针只测一个机制，并强制外化过程。默认探针库见 [probe-bank.md](references/probe-bank.md)，接口见 [probe-contract.md](references/probe-contract.md)。

按 Layer 0 的方向选 4–6 个探针；没有方向时按 Reading 3 个 + Writing 3 个起步。

### Layer 2 · 定向确认（15–20 分钟，只在需要时做）

仅当某条假设**同时拿到支持证据和反证**（页面标为「冲突」）或证据不足时才做，且只针对剩下的 1–2 条假设。这里才用完整真题片段。

## 停止规则

**某条机制假设拿到 ≥2 条独立证据且没有反证时，停止。** 不追求覆盖全部技能。

「老师没时间」的正确答案不是把诊断做快，而是知道什么时候可以不做。页面会在满足条件时提示可以结束。

## 输出三件事

1. **排序后的机制假设**，每条挂着具体证据条目与置信度。
2. **明确写出被排除的假设**，例如「不是词汇问题——依据句都划对了，错在限定词」。排除力比确认力更值钱，也是老师最难被复制的部分。
3. **证据不足的待定项**，标明下次课顺带补测。

给学生看的那一页不给分数，给「你的三个判断习惯」。

## 质量检查

- 任何需要老师超过 15 秒才能判定的探针，不进默认库。划线位置对不对、主谓宾标得对不对，都应该是一眼的事。
- 每条写入档案的假设必须至少有一条探针证据；没有证据的直觉写进 `teacherNote`，不写进 `hypotheses`。
- 不输出预测分数，不承诺提分幅度。
- 「已排除」只能来自实际通过的探针，不能来自老师印象。
- 一次诊断确认的机制不超过 3 条；超过说明探针设计得不够聚焦。

## 边界

它只负责建立起点，不负责后续跟踪。档案维护交给 `student-progress-manager`；模考后的复诊交给 `mock-exam-intervention`；跨周期的假设证伪与练习推荐交给 `learner-model-review`；现有探针都测不了老师想测的东西时，交给 `skill-forge` 造新的。
