# 拯救废片计划

核心理念：照片本身一个像素都不改，用浏览器渲染层做"加一层/减一层"。全部产出 = 一个 HTML 文件 + 浏览器截图。

## 工作流

1. **接收废片**：用户上传照片（路径随平台；Minis 中通常在 /var/minis/attachments/uploads/）。
2. **展示风格库**：第一时间把 `assets/preview-grid.jpg` 发给用户（Minis 中用 `![九宫格](minis://skills/拯救废片计划/assets/preview-grid.jpg)`，其他环境用相对路径 `assets/preview-grid.jpg`）。**这是流程第一步**，先图后字——很多用户不通过文字理解图像，必须先看到视觉风格库，再听你分析；不要先堆文字分析再给图。
   1 黑白纪实 / 2 纸上档案 / 3 跳漂 / 4 暖棕胶片 / 5 青橙色调 / 6 漏光胶片 / 7 电影宽幕 / 8 LOMO / 9 大字杂志
   > 预览图里 5、6 无字（文字只在用户确认要时才加）。
   > 风格 3 跳漂（Bleach Bypass）：去饱和+高反差+银灰调，电影质感，适合夜景/硬光场景。
   > 风格 4 暖棕胶片：暖棕底色+胶片齿孔+划痕+脏点+颗粒，模拟 AGFA Chrome RSX II 电影胶片扫描效果。齿孔用 HTML div 绘制（圆角矩形），可覆盖照片。
   > 风格 9 默认深墨字（亮调照片），暗调照片加 `--ink light` 换白字。
   > 风格 9 定位=**救单调/灰蒙废片**：照片压成近单色高反差，靠影调对比+字图体量差出高级感。用户拿色彩丰富的照片选 9 时主动提醒"这张颜色信息好，建议考虑 5/6/8，9 会把颜色抽掉"。
3. 🔴 **CHECKPOINT · 唯一检查点**（和选风格同一轮问完，不反复打扰）：
   - 文字：**我先看图，默认直接给 2-3 个标题候选**（根据画面内容/情绪拟），用户挑一个或自己写；日期默认今天（YY.MM.DD）。把填空题变选择题。英文小字（--sub）默认用标题的英文翻译或风格相关短语（如 "midnight ride"），用户可自定义。
   - 定位：**优先级链**：①照片 EXIF GPS（自动读取经纬度）→ ②用户设备定位（apple-location 等）→ ③询问用户要填什么地点（如"北京""上海"等城市名，或用户自定义）→ ④都不行则 UNKNOWN。传给 `--location`。
   - 只要图像还是也要边框？（无边框 = 满幅输出；风格 2/5/7/8/9 自带版式，此问题仅对 1/3/4/6 有效，这些风格 --no-frame 时满幅）
   - **风格 9 专属**（选 9 时同一轮问）：看图拟杂志装饰文字候选--竖排中文类别（`--mag-cat`，如"街拍手記/美食手記/旅行的意義"）、英文副标题（`--mag-tagline`）、目录三项（`--mag-toc`，逗号分隔英文短语）。用户不提供则用通用默认值（排版始终完整，不因缺文字留空）。镜头参数（`--lens`）自动从 EXIF 读，无则用默认。签名（`--mag-sign`）默认"Swing Timeline"（Skill 创作者标记）。期号/卷号从日期自动推导。
   > 🛑 用户确认后进入自动执行，不再打断。
4. **渲染**：
   ```sh
   python3 scripts/render.py --photo <用户照片路径> --style <编号> \
     --title "标题" --date "YY.MM.DD" --sub "英文小字" \
     --location "城市名" --out ./out.html
   # 不要文字加 --no-text；不要边框加 --no-frame；青橙/漏光自适应加 --no-auto 关闭
   # 地点自动读 EXIF GPS；手动指定加 --location
   # 风格9 专属（可选）：--mag-cat "街拍手記" --mag-tagline "- A QUIET HOUR -"
   #   --mag-toc "RED LIGHT,RAIN COAT,OLD STREET" --lens "35MM · F2.0 · ISO 400"
   #   --mag-sign "Swing Timeline"（期号/卷号从 --date 自动推导，镜头从 EXIF 读）
   ```
   **画布比例**：默认 `--ratio auto` 按照片宽高比自动分类（3:4 / 4:3 / 16:9 / 9:16 / 1:1），也可手动指定：
   - 3:4 → 1080×1350；4:3 → 1350×1080
   - 16:9 → 1350×759；9:16 → 759×1350；1:1 → 1080×1080
   - 旧参数 `--landscape` 等价 `--ratio 4:3`（兼容）
   - 布局自适应：padding 类风格（1/3/5/6/8）CSS 天然适配；绝对定位风格（2/4/9）用缩放因子；风格4 齿孔数量随画布高度自动调整（~107px 间距）
5. **截图交付**：
   ```sh
   python3 scripts/screenshot.py out.html --engine minis --out final.jpg
   # 引擎四选一：auto（默认，自动检测）/ minis（Minis 内置浏览器）/ chrome（系统 Chrome/Edge headless）/ playwright（跨平台）
   # auto：Minis 环境自动用 minis；其他平台自动用 playwright 或 chrome，无需手动指定
   # 9 个风格全部纯 CSS/SVG 无 JS，截图前 sleep 0.6 足够；若截图里图片未加载完再加大
   ```
   截图保存到 `--out` 指定路径（默认 JPEG）。在 Minis 中建议复制到 `/var/minis/attachments/` 后用 `![拯救后](minis://attachments/xxx.jpg)` 发给用户（其他环境直接给文件路径/图片），附一句风格说明。**交付文件名建议带照片名或时间戳**（如 `夜风刚好_s5.jpg`），避免多次任务互相覆盖（render.py 内部照片文件已用 hash 命名，不会冲突）。

## 纪律

**不要做什么（反例黑名单）**：

| 反模式 | 为什么不要做 | 正确做法 |
|---|---|---|
| 拿用户照片试渲染再给挑风格 | 用户要的是先看风格库再决定，试渲染浪费时间且先入为主 | 第一步永远发内置九宫格 |
| 卡在"你想写什么字"等用户填空 | 用户往往没想法，填空题卡流程 | 看图拟 2-3 个标题候选让用户挑 |
| 用户微调时重做整个流程 | 改参数重跑几秒搞定，不必从头来 | 改 styles.py 参数或 HTML，重新截图 |
| 多模态缺失时装作能看图拟标题 | 看不到图出标题=胡编，信任崩塌 | 显式告诉用户"请给我标题/日期/英文小字" |

**其他规则**：
- 预览只用内置九宫格。
- **自适应**：风格 5 青橙的暖区中心、风格 6 漏光的落点，默认按照片亮度质心/最亮角自动定位（PIL 只读像素做排版决策，不改像素，符合"加层减层"哲学）；想固定落点加 `--no-auto`。
- **比例自适应**：`--ratio auto`（默认）按照片宽高比自动分类到 5 种画布（3:4 / 4:3 / 16:9 / 9:16 / 1:1），screenshot.py 自动匹配画布尺寸。

## 失败模式与兜底

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 用户触发 Skill 但没传照片 | 提示"请上传一张照片" | 等用户上传后再继续 |
| Pillow 未安装（render.py 报 ImportError） | `pip install Pillow` | 告知用户这是必需依赖 |
| 截图引擎全部不可用（screenshot.py 报 SystemExit） | 按错误提示装 playwright 或检查 Chrome PATH | 手动用浏览器打开 HTML 截图 |
| 照片极小（<200px） | 正常渲染（object-fit:cover 会放大） | 提醒用户"分辨率较低，输出可能模糊" |
| 截图里图片未加载完 | 加大 sleep（0.6->1.5s） | 换 chrome/playwright 引擎 |

## 多模态缺失时的回退策略

执行者不具备视觉能力（看不到照片）时：
- **文字侧**：标题必须由用户自己给，我没法出候选（这一步硬退化，没法降级）。检查点显式提示用户"请告诉我标题/日期/英文小字"，不要让用户以为我会自动生成。
- **风格9（大字杂志）文案**：该风格文字是版式核心。标题必须给；杂志装饰文字（mag-cat/mag-tagline/mag-toc）多模态时我看图拟候选，无多模态时用通用默认值（排版始终完整）。镜头参数从 EXIF 自动读，无则用默认。
- **定位**：EXIF GPS 照常读（PIL 读元数据，不依赖多模态）；无 GPS 时建议用户给地点或读设备定位，都不行则 UNKNOWN。
- **风格侧**：仍可正常出 9 格——但没有风格推荐这一步，只能"先看九宫格 → 直接选号"。
- **自适应侧**：亮度质心/最亮角定位照常跑（用的是 PIL 读像素，不依赖多模态）。
- **比例**：自动检测（--ratio auto），无需用户干预。

完整退化梯：有图+多模态 → 有图+无多模态 → 无图→用户指定一切。

## 文件

- `scripts/render.py` — 入口：比例检测（auto/手动）+ 公共逻辑（亮度质心/GPS/颗粒/转义），调 styles.build()。
- `scripts/styles.py` — 9 风格布局（基准坐标 × 缩放因子，自适应全部比例）。
- `scripts/screenshot.py` — 三引擎截图器（minis / chrome / playwright），详见 README.md。
- `scripts/make_preview.py` — 九宫格预览图生成器（用内置样片重渲染 9 风格合成 3×3）。
- `assets/base.jpg` — 内置样片（河谷风景 900×1200）
- `assets/preview-grid.jpg` — 九宫格风格预览图（内置样片渲染，非用户照片；改了风格后用 `python3 scripts/make_preview.py` 重新生成）
