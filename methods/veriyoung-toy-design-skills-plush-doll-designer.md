# 🧸 毛绒玩偶设计技能 (Plush Doll Designer)

> 专业级毛绒玩偶设计全流程指导。从灵感 → 草图 → 版型 → 面料 → 成品，每一步都有据可依。

## 触发场景

当用户提出以下需求时自动激活：
- 设计一个玩偶 / 毛绒玩具 / 布偶 / 公仔
- 想做一只 xxx 风格的玩偶
- 帮我设计一个玩偶的版型
- 如何制作毛绒玩具
- 选什么面料做玩偶
- plush toy / stuffed animal / soft doll design

## 设计流程 (5 阶段)

按以下阶段顺序引导用户，每个阶段输出可视化结果：

### 阶段 1：概念定义

首先通过提问明确设计方向：

| 维度 | 问题 | 选项示例 |
|------|------|----------|
| **角色类型** | 想做什么角色？ | 动物 / 人物 / 幻想生物 / 食物拟人 / 原创IP / 机甲 / 神话生物 |
| **风格定位** | 喜欢什么风格？ | 日系Kawaii / 欧美卡通 / 写实 / 极简 / 怪诞 / 游戏像素 / 动漫二次元 / 影视经典 / 虚拟偶像 / 3D模型 / 奇幻史诗 / 未来科技 |
| **目标用户** | 给谁用？ | 婴幼儿(0-3) / 儿童(3-12) / 成人收藏 / 潮玩 |
| **尺寸** | 多大？ | 掌心(5-10cm) / 标准(20-30cm) / 抱枕(40-60cm) / 超大(80cm+) |
| **功能** | 纯摆设还是？ | 摆件 / 抱枕 / 挂件 / 手偶 / 发声/发光 |

**输出**：设计简报（Design Brief），包含角色名称、风格关键词、尺寸、目标用户画像。

### 阶段 2：造型设计

根据阶段 1 的简报，输出以下内容：

**2.1 比例系统**
- 头身比参考（Q版 1:1 ~ 1:2，标准 1:3 ~ 1:4，写实 1:5+）
- 关键比例：眼距 = 头宽 × 0.4，手长 = 身高的 1/3，脚长 = 身高的 1/5

**2.2 三视图**
- 生成正面、侧面、背面的 ASCII 线稿或 SVG 示意图
- 标注关键尺寸（头高、身长、四肢长度、眼位、鼻位）

**2.3 五官设计**
- 眼睛：豆豆眼（5mm圆） / 椭圆眼 / 刺绣眼 / 塑料安全眼
- 鼻子：三角形 / 椭圆形 / 刺绣 / 塑料鼻
- 嘴巴：微笑线 / W形 / 张嘴 / 无嘴
- 腮红：圆形刺绣 / 粉彩涂抹 / 贴布

**2.4 配色方案**
- 主色调 1-2 个 + 辅色 1-2 个 + 点缀色 1 个
- 输出 HEX 色值，确保色板和谐

### 阶段 3：版型设计

**3.1 拆解部件清单**

将设计拆解为可裁剪的布料片：

```
典型部件清单：
├── 头部：前片×1 + 后片×1（或左右各1）
├── 身体：前片×1 + 后片×1
├── 耳朵：外耳×2 + 内耳×2
├── 手臂：上臂×2 + 下臂×2（或各2片对缝）
├── 腿部：前片×2 + 后片×2
├── 尾巴：×2 片对缝
└── 附件：翅膀/帽子/衣服等
```

**3.2 版型图生成**

对每个部件，用 SVG 或 ASCII 生成版型图，标注：
- 缝份线（虚线），缝份宽度 7-10mm
- 毛向箭头（pile direction）
- 对位点（notch marks）
- 翻转口位置（turning opening）

**3.3 尺寸标注**

每个部件标注具体尺寸（cm），确保各部件比例协调。

### 阶段 4：面料与辅料

根据风格和用途推荐面料，详见 [references/fabric-guide.md](references/fabric-guide.md)。

**快速选料指南**：

| 风格 | 推荐面料 | 手感 |
|------|----------|------|
| 日系Kawaii | 短毛绒 (Minky 3mm) | 柔软细腻 |
| 复古风 | 毛毡布 (Felt) | 挺括有型 |
| 写实风 | 长毛绒 (15-25mm) | 蓬松逼真 |
| 婴幼儿 | 有机棉布 + 水晶绒 | 安全亲肤 |
| 潮玩 | 短毛绒 + PVC 配件 | 精致硬挺 |
| 游戏像素 | 毛毡布 + 魔术贴 | 方正硬挺 |
| 动漫二次元 | 短毛绒 + 高温丝假发 | 丝滑飘逸 |
| 未来科技 | 短毛绒 + 透明PVC + LED | 科技发光 |
| 奇幻史诗 | 植绒 + 人造皮革 | 厚重史诗 |

**辅料清单**：
- 填充物：PP棉（高回弹）/ 羽绒棉（轻盈）/ 颗粒填充（加重）
- 眼睛：塑料安全眼 / 刺绣线 / 纽扣（婴幼儿禁用）
- 关节：塑料关节扣 + 垫片（可动玩偶用）
- 五金：龙虾扣（挂件）/ 磁铁（可拆卸配件）

### 阶段 5：制作指导

> 详细工艺规范见 [references/production-standards.md](references/production-standards.md)

**5.1 缝制工序（三段式）**
1. **阶段 1**：先缝所有小部件（耳朵→角→手臂→腿→翅膀→尾巴），逐件翻面填充，暂放
2. **阶段 2**：缝制身体主体，途中嵌入已填充的四肢（定位针固定），预留背部翻转口，翻面填充，藏针缝收口
3. **阶段 3**：手缝附件（耳朵、角、翅膀、尾巴），刺绣面部细节

**5.2 五官安装**
- 安全眼：填充前从内侧安装，垫片卡紧，90N 拉力自检
- 刺绣五官：填充后手缝，绣线 2-3 股
- 面部针雕：用缝线穿过头部拉紧，塑造眼窝和鼻梁

**5.3 质检清单**
- [ ] 眼睛拉力 ≥ 90N（手指捏住用力拉不松动）
- [ ] 接缝强度 ≥ 70N（双手反方向拉不崩开）
- [ ] 对称性偏差 ≤ 1mm（量左右眼到鼻中线距离）
- [ ] 填充均匀，无硬块无空腔
- [ ] 铁丝末端弯圆 + 胶带包裹，按压触不到尖端
- [ ] 无线头、无污渍、毛向一致

## 输出格式

每次设计完成后，输出以下内容：
1. **设计简报卡片** — 名称、风格、尺寸、配色
2. **三视图 SVG** — 正面/侧面/背面
3. **版型图 SVG** — 每块部件含尺寸标注
4. **面料清单表格** — 名称、用量、颜色
5. **制作步骤摘要** — 关键工序提醒

## 安全规范

> 完整标准见 [references/production-standards.md](references/production-standards.md) 第一章。

**年龄段判定**：
- 0-3 岁：绣眼绣鼻，无铁丝，全棉填充，需过 GB 6675 全项
- 3-6 岁：可安全眼，铁丝需包裹，小零件需警告标识
- 6 岁+：标准宽松，仍需过拉力测试
- 14 岁+/收藏品：需标注"此非玩具"

**核心数值**：眼睛拉力 ≥ 90N | 接缝拉力 ≥ 70N | 铅含量 ≤ 90ppm | 阻燃速度 ≤ 30mm/s
