# 品味 · 标识规范

店主 2026-08-19 定稿。**未经店主同意不要改这份文件里的任何数值。**

## 标记：箸

两根渐细的筷子，上粗下细，四角圆化、尖端收成圆点——像削过用过的木箸，不是切出来的塑料片。
整体逆时针 7°，尖端向内收合：画的是**「挑」这个动作本身**，不是挑完的结果。

素材：`brand/mark.svg`（常规）· `brand/mark-16.svg`（16px 及以下，笔画加粗版）
两者都用 `currentColor`，跟随上下文颜色，不要写死 fill。

### viewBox 必须是 `14 4 33 55`

**不要用 `0 0 64 64`。** 笔画只落在 x∈[14,47]、y∈[4,59] 之间，
用 64×64 会在标记两侧各留约 15 个单位的透明空气，**任何 CSS 间距都会被这截空气推开**。
这是定稿前踩过的坑，别再踩。

## 组合

| 项 | 值 |
|---|---|
| 字 | 「品味」宋体 `Songti SC` / `Source Han Serif SC` / `Noto Serif CJK SC`，字重 **600** |
| 字距 | `letter-spacing: .05em` |
| 标记高度 | **字号 × 1.13**（≈ 字面高的 1.3 倍）。24px 字 → 标记高 27px、宽 16.2px |
| 标记宽高比 | **0.6**（33 : 55），不要拉伸 |
| 标记与字的间距 | **`0.22em`**，用 em 不用 px——字号一变间距自动跟上 |
| 对齐 | `align-items: center` |

```html
<span style="display:flex;align-items:center;gap:.22em">
  <svg viewBox="14 4 33 55" width="16.2" height="27" …></svg>
  <span style="font-family:Songti SC,serif;font-weight:600;letter-spacing:.05em;
               font-size:24px;line-height:1">品味</span>
</span>
```

### 为什么是宋体，不是黑体
箸是**上粗下细的渐变笔形**；宋体本身就是粗细对比的字，横细竖粗、起笔收笔有顿挫，
**跟箸是同一套笔法**。配等线黑体是两种笔法打架，怎么摆都不协调。这不是"宋体好看"，是同源。

### 为什么标记要比字高
箸是竖长笔画，跟方块字等高会显矮。1.3 倍字面高是试出来的：
1.0 倍像个附注，1.45 倍箸开始抢戏。

## Slogan

**跟在「品味」右边，同一行。**

> 𝕍 **品味**　挑得少，是因为看得多

### 这一条改过位置，原因记下来

原来写的是「跟在报头三个数字后面，用一道竖线隔开：
`过手 712 · 上架 152 · 没让它进来 560 ｜ 挑得少，是因为看得多`，
**不要单独当标语用**」。

2026-08-19 店主直接要求搬家，原话：
「你的 logo 品味和下面那行文字贴的太近，**挑得少，是因为看得多，可以直接放在品味后面，
不需要单独一行**」。

所以现在它就是紧跟品牌名的独立标语，而**旧文档那句「不要单独当标语用」已作废** ——
不改文档的后果是具体的：下一个人照文档把它搬回数字后面，再被店主说一次。
（这条是 UX 发现的：代码搬了家，文档没跟上，`renderTally` 里两段注释还自相矛盾。）

它仍然是那三个数字的注脚 —— 把「没让它进来」从缺口翻成资历 —— 只是**位置从注脚挪到了署名旁**。
