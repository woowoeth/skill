## 今天新定的裁决（三节都适用）

### 1. `limit_zh` 不是用来写「可能会出人命」的

> `limit_zh` 写「装了它你会失望的地方」。
> **「装了它可能会出人命」不是局限，是拒收理由。**

起因：今天下架的两件中医件，`limit_zh` 里**早就写了**「附子用量错了是会出人命的」——
也就是说选货时看见了危险，然后选择了披露而不是下架。
而其中一件的正文恰恰**禁止**输出「建议就医」，**我们的披露被它自己驳掉了**。

内容那边补了这句，收进裁决：
> **「披露」这个动作有个隐蔽的副作用：它让人觉得问题已经被处理了。**
> 写下那行字的那一刻，选货的人心里就结了账 —— 而读者拿到的只是一行小字。
> **披露不是处置。**

### 2. 剂量红线管中医。判据不是单位，是「照着它就能给人用药」

`剂量·中医` 档已进 `scouts/scan_refs.py`：剧毒药名（附子/川乌/马钱子/生半夏…）+ 数量、
巨剂量形态（两/斤 + 起/以上、或 起步/起手/打底）、把放开剂量写成规矩本身
（大胆授权 / 不得人为收敛 / 按体重折算 / **不麻不昏**）。

**毒性阈值不算**（「中毒剂量 2-5mg/kg」是劝你别吃）。
**营养学的 g/kg 不算**（蛋白 1.6-2.0g/kg）—— 但 **mg/kg 不豁免**，
否则「对乙酰氨基酚 10-15mg/kg 体重」也会被放过，那是最不能放过的一句。

同一作者的三件里留了一件，**分界线干净得能引用**：
它明写「急救内容**必须附加"需执业医师确认"提示**」，而被下架那件**明令禁止**写这句话。

### 3. `cover_kind` 是用户直接读到的文案依据，不是内部标记

详情页图注由它决定。所以**为了让版式好看去降 `cover_kind`，等于改一句给读者看的话**。
画幅问题一律在 CSS 里解。

今天新增一档 **`ours`** —— **我们自己装上真跑出来截的图**。
理由：我们截的图托在 `woowoeth/skill`，标成 `artwork` 会印成「作者仓库里的产出示例」，
**那是把我们做的事说成作者做的**；而它其实是**更强**的一档证据（没有目录站真装真跑）。

图注（内容定稿，采纳）：
> **「我们自己装上、真跑了一遍，这是当时截的图」**
> `We installed it and ran it — this is the screenshot we took.`

语序的理由（内容的论据，值得记住）：另外三档图注已经全是「**不是**产出示例」，
`ours` 再用否定框架，读者读到的是第四句免责声明；
「真跑了一遍」放句首，一眼就懂为什么这档更硬。

`ours` 比 `artwork` 多三条约束（署名在我们头上）：
1. **必须在 `cover_note` 里记下跑的命令**，能复现。没有命令的 `ours` = 一个不可复现的证据声明，比没有证据更糟。
2. **绝不能用真实个人数据**（聊天记录、体检、账单、私人照片）。宁可没这张封面。
3. **不许拿仓库里现成的示例图冒充自截图** —— 这两件事在诚实上完全不同。

### 4. demo 输入算不算合格证据：看实质是形式还是内容

- **实质是形式**（版式/纸样/线稿/字体/贴纸模切/方格纸/图表/幻灯片排版）→ **demo 输入没问题**。
  米字格字帖用什么字都是那张纸；一张 PPT 不主张「营收真的是 3.6 亿」，它主张「这种排版是我做的」。
- **实质是内容**（判断/诊断/评语/报告结论）→ **不能当产出物证据**。
  封面上印的是「这就是它做出来的东西」，而读者会把那句评语当成一个真实判断读 —— 那句却是编的。

已按这条判过：跑通的 A4 米字格字帖 → 收；同一批「数你说过几次谢谢，判你 2126 年自由还是为奴」
的评语卡 → **不收**（卡的全部意义就是那句判决，而判决是 demo）。
