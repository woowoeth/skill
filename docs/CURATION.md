# 选品标准 / Curation Standard

这家店的信条：**质大于量，只留精品。** 宁可 170 件件件想试，不要 500 件掺水。
上架是例外不是默认；可留可不留的，一律不留。

## 三关（顺序不可颠倒）

### 第一关 · 它是不是一件顾客拿走就能用的 skill？
不是商品的一律拒之门外，无论星多高：
- 框架 / 底座（给开发者搭系统用的，不是装进 agent 就能用的技能）
- 教程 / 幻灯片 / handbook / cookbook / cheatsheet 类仓库
- boilerplate / 项目脚手架
- **别人项目自己的装修配置**（bump-version、update-playbooks、内部运维件、示例件）
- skill 市场 / 管理器 / 竞品聚合站（除非确有独到之处）

判据：clone 下来能不能直接用起来。用不起来 → 下架。

### 第二关 · 够不够格上架？
过了第一关，再看三条（前两条进货员在抓取时把，第三条人工把）：
1. **准入（多信号，召回优先）**：不再一刀切「≥40 星」。星是滞后且有偏的人气指标，会亏待新发布、垂直、非英语、无营销的好项目。改为四条通道任一命中即放行（fork 与命名黑名单始终拒）：
   - **新品快车道**：创建 ≤7 天 且 ≥3 星 —— 给刚出生、还没积累星的好货被看见的机会。
   - **星速度**：创建 ≤14 天 且 ≥25 星 —— 爬升快比存量高更能抓住「正在被认可」的新星。
   - **认真程度信号**：≥10 星 且 满足「有主页/演示、描述≥60字、近30天有维护」中两项 —— 星未达标但看起来是认真做的，放进来让人工再判。
   - **老仓兜底**：≥40 星（站住了一段时间的常规线）。
   - **人工通道**（最高信号）：任何人 `--suggest owner/repo` 直接收录，完全绕过星门槛。一个真人觉得值得推荐，胜过任何自动指标。
   放宽准入意味着进来的东西良莠不齐——这是刻意的取舍：**漏掉好货无法追回，进来的杂质人工巡货删得掉。**
2. **不霸架**：一个仓库塞几十个 skill → 只上一张合集卡 + 最多 3 件样品；小仓库（<6 件）最多 3 件单品，不许倒货车。
3. **真有趣 / 有用 / 有需求**（最主观、最重要）：
   - 同质则砍——已有更好的同类在架、这个没有任何「它独有」的理由 → 下架。宁可一个品类只留最好的一两件。
   - **能不能写出有钩子的点评，本身就是准入测试**。如果只能憋出「一个不错的 X 工具」，它不配上架。

### 第三关 · 要不要进店长推荐？
上架 ≠ 推荐。推荐位固定 **6 个**，人工手选，标准是：
- 一眼就想拿自己试一下（病毒感 / 情感钩子 / 反差）
- 覆盖不同货架，中文精品与好玩玩物兼顾
- 能一句话说清「好在哪」

## 合集卡 vs 样品件
同一个仓库若既有「合集总卡」又有样品件 → **删合集卡、留样品**（顾客要的是具体那把刀，不是礼包）。
仅当仓库没有样品件、合集卡是唯一门脸时，才保留合集卡。

## 封面
优先作者社交预览图 > README 首张真实截图 > 空（前端回退信息卡）。
**禁用 `private-user-images.githubusercontent.com` 链接**（限时签名，会过期 404）。

## 好样本（本店眼中「对」的东西长什么样）
- **adrianpunk/Punk-Skill**：两件视觉生成 skill（文章生封面、照片生头像）。风格库每一种都标注「适合什么内容」，选风格像点菜；宠物拍立得纪念卡是情感钩子。中文精心设计、有真实截图 —— 这就是标准之内的样子。
- **JuliusBrussee/caveman**：一个玩笑做成真产品（省 token），既好玩又有用。
- **blader/humanizer**：把「AI 写作臭味」列到句式级别，实用且反过来是写作课。


## 红线（无条件下架，与星数、作者、授权声明无关）
- **攻击赋能类安全工具**：渗透测试攻击面、C2 架构、横向移动、漏洞利用、红队攻击方法论、OSINT 侦察自动化等——即便标注 authorized/for professionals 也不收。防御向、审计向、加固向的安全 skill 可以收（如 NVIDIA SkillSpector、加固清单）。
- 恶意代码、爬虫绕过反爬、批量盗号等灰产工具。


## 情报源（不是货源）

**YouMind Skills 画廊**（https://youmind.com/skills，公开可访问）是一个平台内 skill 市场，
Research 328 / Write 325 / Image 312 / Slides 74 / Video 21 / Webpage 73，中文创作者居多。

**为什么不直接从它进货**：那些 skill 是平台内资产，靠平台 credits 运行，**没有可 clone 的仓库和 SKILL.md**——
我们每张卡片都承诺"clone 装进 ~/.claude/skills"，搬过来顾客装不了。且部分是创作者的**付费商品**。
自动抓取别人平台的核心资产也不合适。

**正确用法 —— 当情报源**：
1. **看品类空白**：它的分类占比照出我们哪块薄。据此已补入研究型、单一视觉风格两组常驻搜索词。
2. **顺作者回 GitHub**：它的 featured creators 常在 GitHub 也发东西（如王树义 wshuyi，我们已上架其"发 X 长文"），
   顺名字回查能挖到真正可下载的版本。
3. **手动指路**：看到想要的，把公开页链接给店长，由店长去 GitHub 找对应真仓库再上架。

同理适用于任何登录墙内/不可外带的平台市场。

## 兜底
所有下架都是 `hide: true`，记录保留、随时可翻回；所有文案在 editorial 层，可改可撤。
机器只负责「抓来、够格、不霸架」；**「有没有品」这关永远是人在把。**
