# 封面标准 / Cover Standard

一句话：**遮住标题，一个不认识这个技能的人，看图能不能猜出它是干什么的。**

字只能当标签，不能当解释。一张需要读字才成立的图，在卡片尺寸（手机 177×122）上
等于没有图。这条和 ourword 那边「插图不看文字也要懂」是同一条规矩。

## 底线（不满足就不上架）

**每一件在架的 skill 都必须有图。** 没有图的不是「糙」，是「坏」——
货架上一半的卡没有脸，就不是货架。取不到作者的图，就我们自己装上跑一遍截产出物
（`cover_kind: ours`）；连这都做不到的，说明它连让人看一眼的产出都没有，
那它该下架，不该上架。

## 四类明确不要的

按店主 2026-09-06 亲眼看见的分：

| 类 | 为什么不要 | 例 |
|---|---|---|
| **二维码** | 扫码是给手机的动作，出现在货架上就是广告位；而且多半是收款码或拉群码 | `helloianneo-*`、`simon-he95-*` 的封面 |
| **广告 / 赞助图** | 图上卖的不是这个技能 | 「GPT 代充 / 成品号」横幅、Kimi 赞助图 |
| **满屏文字的截图** | 文档、聊天记录、后台界面、图表。缩到卡片尺寸只剩一片灰噪点——原尺寸下越「信息量大」，卡片上越空 | 大部分 README 截图 |
| **与技能无关的图** | 作者头像、通用风景照、随手的 AI 生图。像素上再好看，它说的不是这个技能干的事 | ComfyUI 工作流配一张雪豹；grilling 技能配作者本人 |

第四类最要紧，也最难用脚本判：一张精美的埃菲尔铁塔照片，像素统计上完美，
放在写代码的技能上就是废图。**所以封面只能人看图判，不能算像素。**
（2026-09-06 试过按边缘密度 / 底色占比分类：把干净的线稿判成「几乎空白」，
把满屏文字的截图放过去 —— 按它改只会让货架更花更满。作废。）

## 什么算好

优先级从高到低：

1. **产出物样张**：它做出来的东西本身。海报技能给海报，剪影技能给剪影，
   精灵图技能给精灵图集。这是唯一不用解释的图。（`cover_kind: artwork` / `ours`）
2. **作者自制的头图**，且头图画的是这个技能干的事。（`cover_kind: hero`）
3. 我们自己装上跑一遍截的产出物。（`cover_kind: ours`，图注会写明「我们自己跑的」）
4. **站方样张**（`cover_kind: specimen`）：作者仓里确实没有图（repo_covers 连文件树都翻过了，
   162 件一张没取到）时，按它干的事配一个**能力图形**：视频剪成帧、书拆成块、照片变贴纸、
   字幕落到时间轴 —— 三十来个图形，同一类能力共用一个，像一套图标系统。
   **图上一个字都没有**：第一版把标题和描述排进图里，店主一眼看穿「和下面的标题描述重复了」，
   而且违反本文件自己那句「字只能当标签不能当解释」。作废重做。
   三条硬规则同 `assets/ours/op7418-guizang-social-card-skill.png`：
   不要圆角、不要阴影、不要渐变，一套只许一个 accent。它诚实 —— 图注写「站方按它的能力
   做的样张，不是产出物截图」；它不冒充 —— 不算「真图」，进不了店长推荐。
   生成：`python3 scouts/make_specimens.py`。**只要取得到作者的产出物图，就不该用样张。**

不接受：GitHub OG 卡、社交预览图、logo、徽标、头像。

## 判决怎么落地

判决写在 `editorial/curation.json` 对应条目上（覆盖层，重建 feed 不会丢）：

```json
"cover_verdict": "ok" | "replace" | "remove",
"cover_verdict_why": "一句话：这张图说的是不是这个技能干的事",
"cover_judged_at": "2026-09-06"
```

- `ok`      —— 留。
- `replace` —— 图不行，技能行：换图（先去作者仓里找产出物，找不到我们自己跑）。
- `remove`  —— 这件东西的**唯一**封面是二维码或广告：图在告诉你这个技能是什么，下架。

`scouts/shelf_health.py` 守：在架每一件都要有 `cover_verdict == "ok"`。
没判过的、判成 replace/remove 还没处理的，都是**坏**，不是糙。

## 外链一律本地化

封面文件必须在 `assets/covers/` 下，`cover` 写 `/skill/assets/covers/<id>.<ext>`。
外链会死（`private-user-images.githubusercontent.com` 是带签名会过期的地址），
也让每个访客的浏览器去 ping 第三方。原图留档，站上引 `make_thumbs.py` 出的
`w800/*.webp`。
