# 录取通知书真假鉴定器

两条命令:查校(教育部名单+高仿校名识别)、鉴定(15条规则排雷)。

## 用法

```bash
python3 <skill-dir>/luqu.py 查校 中国邮电大学 --json
python3 <skill-dir>/luqu.py 鉴定 "短信原文..." --json
echo "很长的文本" | python3 <skill-dir>/luqu.py 鉴定 - --json
```

零依赖纯标准库,数据内置离线可用。

## 回答用户时的要点

1. 用户给了校名 → 先`查校`;给了文本 → `鉴定`(文本里的校名会自动查)。
2. 先报结论等级(🔴🟠🟡🟢+风险分),再逐条讲命中的规则和依据,
   高仿校名要点名"它在模仿哪所真学校"。
3. 🟢 也要提醒:未命中规则 ≠ 安全,**唯一的确认标准是省考试院官网
   能查到统招录取记录**;校名为真 ≠ 录取为真。
4. 特别注意"自考助学班冒充统招"——它不是传统诈骗(确实能入学),
   但毕业证性质完全不同,要跟用户讲透这个区别。
5. 结尾必带:考试院官网查录取 / 教育部名单查学校 / 反诈专线96110;
   工具是风险提示,不是司法认定。
