# 跳槽蒙特卡洛模拟器

核心原理：跳槽焦虑的本质是**在拿不到分布的情况下被迫做单次决策**。
这个工具用公开行业信号（裁员率、offer 到达率、涨幅分布、35 岁折减）
把 12 个月的"苟"和"跳"各跑一万遍，把情绪换算成概率。

## 用法

```bash
python3 <skill-dir>/tiaocao.py --industry 互联网 --years 5 --salary 25000 --json
```

- `--industry`：互联网/金融/制造/教育/医疗/体制内/消费零售/文化传媒/地产
  （常见近义词会自动映射，如 IT→互联网、国企→体制内）
- `--years` 工作年限，`--salary` 税前月薪，`--age` 不给则按 22+年限
- `--min-raise 10`：低于 10% 涨幅的 offer 不接（用户说"不涨薪不跳"就调高）
- `--laidoff`：已被裁模式（对比马上将就 vs 等好 offer）
- 零依赖纯标准库，不需要 API Key

## 回答用户时的要点

1. **你是解读层**：跑 `--json` 拿数据，重点讲三个数——
   `p_jump_worse`（越跳越差概率）、`p_no_jump`（想跳没跳成概率）、
   苟 vs 跳的 `income_median` 差值。别把 JSON 全文贴给用户。
2. 用户最想听的是那句"你越跳越差的概率是 X%"——把它放在第一句。
3. 讲清楚模型的机制性结论：大多数行业里"越跳越差"概率其实不高，
   真正的大头风险是"想跳没跳成"（没有达标 offer）；而 35+ 的主要
   惩罚在 offer 到达率，不在单个 offer 的涨幅。
4. 如果用户行业不在表里，选最接近的并说明；用户对参数不满，
   直接告诉他们 PARAMS 表在哪、怎么改。
5. 结尾必须带免责：参数是量级估计，这是概率参考不是职业建议；
   长期"会不会被 AI 替代"是另一个问题（另一个工具 ai-replace-calculator）。
