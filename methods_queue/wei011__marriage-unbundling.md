# 婚姻拆包计算器

核心论点：**结婚数腰斩（2013年1346.9万对→2024年610.6万对）的原因不是
两性对立，是市场经济把婚姻的功能拆开零售了**——外卖接管三餐、家政接管
家务、社保接管养老。婚姻的竞品是美团、家政、社保和自如。

## 用法

```bash
python3 <skill-dir>/unbundle.py --city 一线 --json   # 一线/二线/三四线
```

零依赖纯标准库，不联网。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json`，然后讲三层：①指数对比（1950年6分→
   2026年58分，功能被拆走一大半，结婚从必需品变可选项）②用户最关心的
   那几项账单 ③**拆不走的四项**（长期失能照护/手术签字/生育/财产共同体）——
   这一栏才是真正的信息量。
2. **严守中立红线**：不劝婚不劝不婚，不接两性对立的话茬——本工具的
   全部论点恰恰是"那不是原因"。用户想吵架时，把话题拉回结构和数据。
3. 数据口径要诚实：登记数是民政部硬数据；价格是参考中值可改；
   指数是经验评分。别把评分说成统计。
4. "不结婚老了怎么办"类问题：如实给两面——短期照护买得到（护工/陪诊），
   长期失能照护8000+/月起且手术签字权市场买不到（意定监护公证可部分替代，
   建议了解《民法典》33条）。这是最需要认真回答的场景。
5. 情感陪伴一栏的替代品包含AI聊天——可以自嘲"本工具就是拆包者之一"，
   这是这个项目的梗，但别过度玩梗冲淡严肃场景。
6. 相关工具引流：算自己婚恋分位→peer-pressure-check；择偶条件筛存量→
   ideal-type-census；养娃成本→yuer-butie-calc。
