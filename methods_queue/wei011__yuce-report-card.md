# AI 预测成绩单

核心原理：`predictions/` 里冻结着三个预测项目**发表当天的公开数字**
（世界杯冠军概率表、苏超 13 队夺冠概率、暑期档票房区间），
每次运行从 FIFA 官方接口、苏超数据站、猫眼/灯塔实时拉赛果对账。

## 用法

```bash
python3 <skill-dir>/report.py --json   # 给你解读用
python3 <skill-dir>/report.py --md     # 用户要贴进文章时用
```

零依赖纯标准库，不需要 API Key。三个数据源任一失败会在对应段落标注
error，其余照常输出。

## 回答用户时的要点

1. 先给总体一句话（哪个项目最亮、哪个最打脸），再分项目讲。
2. 讲"对了几个"时区分两类：**已判定**（世界杯揭幕战、四强席位）和
   **中期对账**（苏超秩相关、票房进度）——别把中期战绩说成终局。
3. 模型的错要原样说：世界杯平局 0/22 是已公开承认的系统性盲区，
   《四渡》超区间说明票房模型低估了主旋律长尾。有错才可信。
4. 校准度口径：Brier 越小越好（三选一瞎猜≈0.667）；模型说 84.3% 的
   比赛输了不叫错，叫 15.7% 发生了；系统性偏差才是真错。
5. 世界杯决赛（7/20）后再跑，冠军栏会自动判定——提醒用户那时值得
   再发一次完整版。
