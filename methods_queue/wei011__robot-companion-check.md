# 机器人伴侣陪伴力体检器

回答一个热搜级的问题：**一台全尺寸人形机器人，一天到底能真的陪你几个小时？**

不是看厂商宣传的"续航 2-4 小时"，而是把这 2-4 小时放进一天的真实剧本里——
叫你起床、陪你吃饭、陪你遛弯、陪你看电视、给你守夜——看它什么时候掉链子。

## 何时使用

- 用户提到 99 万机器人伴侣、机器人续航、人形机器人撑不过一晚
- 用户想知道机器人能不能守夜、看护老人、当保姆
- 用户想对比买机器人 vs 请保姆 vs 养狗的每小时成本
- 用户问"要让机器人陪一整天，电池得做多大"
- 用户想查宇树 / 优必选 / 特斯拉人形机器人的真实可用时长

## 怎么用

```bash
cd <本 skill 目录>

python3 run.py                       # 直接体检热搜主角（99万 U1 Ultra，情感陪伴日）
python3 run.py ls                    # 机型库：6 台，含电池容量与数据可信度
python3 run.py spec unitree-h1       # 某台机器的参数、功耗分档、数据来源链接

python3 run.py day --robot ubtech-u1-ultra --script companion
python3 run.py day --robot industry-baseline --script elder_care --years 2
python3 run.py day --script nightwatch --json     # 结构化输出，给 agent 吃

python3 run.py cost --robot ubtech-u1-ultra       # 每小时陪伴成本 vs 保姆/狗/扫地机
python3 run.py battery --hours 16                 # 反推：陪够16小时要多大电池、多重
python3 run.py rank --script elder_care           # 全机型排名
```

纯标准库，零依赖，无需联网。`--json` 输出结构化结果，便于在 agent 流水线里消费。

### 机型 id

`ubtech-u1-ultra`（99万热搜主角）、`ubtech-walker-s2`（会自主换电的工业机）、
`unitree-h1`（功耗标定锚点）、`unitree-g1`、`tesla-optimus-gen2`（功耗标定锚点）、
`industry-baseline`（优必选官方"行业普遍 2-4 小时"口径）

### 剧本 id

`companion` 情感陪伴日 · `elder_care` 居家养老看护 · `housework` 家务保姆日 ·
`showroom` 商演展示日 · `nightwatch` 纯守夜

## 怎么读结果

- **有效陪伴时长**：一天里它真正在陪你/干活的小时数（充电、深度休眠不算）
- **陪伴比 = 有效陪伴 ÷ 补能时长**。小于 1 意味着*你等它的时间比它陪你的时间还长*
- **撑过一整夜的概率**：22:00–07:00 连续守夜一分钟不缺席的概率
- **每小时陪伴成本**：(售价折旧 + 维保 + 电费) ÷ 全年有效陪伴小时

## 模型可信在哪

功耗曲线不是拍脑袋，是拿两台参数完整公开、且彼此独立的机型交叉标定的：

| 锚点 | 依据 | 得到 |
|---|---|---|
| 行走档 | 宇树 H1：864Wh ÷ 官方"连续 1 小时运动续航" | **864 W** |
| 站立档 | Optimus Gen2：2300Wh ÷ 轻中载 8 小时 | **288 W** |

互相验算能对上：用 288W 去算 H1 的静态续航得 3.0 小时，与"H1 静态续航不足四小时"的
公开报道吻合；用 864W 去算 Optimus 的行走续航得 2.7 小时，落在其"重载 3–6 小时"区间下沿。

**一句话：全尺寸人形机器人站着不动约 0.3 kW，走起来接近 0.9 kW——后者相当于一台家用空调的耗电功率。**

未公开电池容量的机型（如 U1 Ultra），由官方续航 × 功耗反推，输出中标注 `[反推]`。
数据可信度分 high / medium / low 三档，写在 `data/robots.json` 里，每条都带来源链接。

## 模拟规则对机器人是友好的

免得被说成刻意黑它：机器人会在空隙里见缝插针回座补电；被你叫到时只要电量够就中断充电出来干活；
支持热插拔的机型（Walker S2）补能只花 3 分钟换电时间；电池留 10% 保护余量。

即便如此，99 万的那台在"情感陪伴日"里的陪伴比仍然是 **0.97**。

## 边界与免责

- 功耗分档中只有站立、行走两档有官方数据支撑，其余（陪聊、搬运、跳舞）为区间插值/外推的估算档，输出中标注"估算档位"。
- 各机型售价、维保率、电价、保姆月薪均可用命令行参数覆盖，默认值是公开量级估算而非精确统计。
- 本工具量的是**能量约束下的可用时长**，不是产品好坏的判决。续航短不等于没价值，只等于：
  别按"它能一直在"来规划你的生活。
