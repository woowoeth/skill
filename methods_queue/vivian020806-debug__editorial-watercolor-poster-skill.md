# Editorial Watercolor Poster

Create one standalone poster per input image. Preserve the image's subject and visual logic; do not make a collage of several source images.

## Input and defaults

Inspect the input image before composing. Infer its category, dominant palette, direction of light, emotional temperature, and usable negative space.

Use these defaults unless the user overrides them:

- Canvas: 3:4 vertical.
- Structure: two horizontal regions in a strict 1:1 height ratio, each 50% of the canvas.
- Upper half: retained source photo with restrained editorial colour grading.
- Lower half: a watercolor interpretation of the same scene or subject.
- Copy: one concise, non-literal English live-caption; add optional small Chinese metadata only when it improves the composition.
- Layout: select one distinct layout mode from `references/layout-system.md`; do not reuse a standard right-aligned title treatment.

Ask a single question only if the user has supplied no image or has requested an essential choice that the image cannot resolve. Otherwise infer the direction and proceed.

## Composition workflow

1. Keep the upper photo structurally faithful. Preserve identity, anatomy, pose, object count, spatial relationship, materials, and broad colour atmosphere. Extend sky, floor, wall, or environmental background only when required to fit 3:4. Never stretch, mirror, or replace the main subject.
2. Match the lower half to the same source image. Use an ivory rough watercolor-paper ground, generous negative space, loose ink-black and grey-brown strokes, dry-brush texture, translucent overlays, natural bloom, and broken pencil-like contours. For faces, use sparse warm grey, pale beige-pink, and muted rose accents; keep the result non-photorealistic.
3. Derive the caption from the scene's implied feeling, not a literal inventory of objects. Read `references/copywriting-system.md` before drafting copy.
4. Place typography after the image structure is stable. Use one layout mode only. Protect the subject's face, eyes, and key silhouette; use the lower half's negative space first.
5. If the image-generation workflow supports it, use two passes: generate the poster structure first, then make a typography-only refinement. Keep the final copy short enough to remain legible.

## Typography rules

- Use varied scale, orientation, clustering, baseline, and density; combine one dominant phrase with small index-like information.
- Prefer black, warm charcoal, muted green, muted red, or one palette-derived accent. Use one accent colour at most.
- Use experimental editorial composition, not decorative filler. Do not place every label in a corner or create a repetitive template.
- Do not use a brand logo, a real publication masthead, or a signature that implies a real artist.
- Render exact text only when the image tool can do so reliably. If text fidelity is weak, produce the design with a clearly marked text-placement plan or revise the typography-only pass.

## Quality gate

Before delivering, read `references/quality-checklist.md` and correct any failed item. If a requested modification conflicts with the strict split, preserved identity, or readable typography, state the conflict briefly and offer the closest compliant adjustment.

## Output

Deliver the final image and a compact design note containing:

- selected layout mode;
- live-caption used;
- one sentence describing the visual direction.
