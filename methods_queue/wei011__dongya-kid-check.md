# 东亚小孩浓度检测器

核心原理：**"懂事"不是性格，是一套可测量的养育模式**。
21 题五维问卷，前三维对齐心理学量表 s-EMBU-C（拒绝/情感温暖/过度保护，蒋奖等2010中文修订），
补充"愧疚负债感""情绪静音"两个东亚特异维度，输出浓度百分比和行动清单。

## 用法

```bash
python3 <skill-dir>/dongya.py --questions          # 拿21道题目(JSON)
python3 <skill-dir>/dongya.py --answers 332210003233333233223 --json   # 21位0-3出分
python3 <skill-dir>/dongya.py --demo               # 典型样本演示
```

零依赖纯标准库，不联网，答案不离开本机。

## 回答用户时的要点

1. **对话式施测**：用 `--questions` 拿题，分3-4批把21题自然地问完（每批5-7题，
   保持0=从不/1=偶尔/2=经常/3=总是），凑齐21位答案串再跑 `--answers X --json`。
   用户没耐心时可以只问每维度最重的题，但要说明是快测版。
2. **解读三段式**：总浓度+档位 → 最高的1-2个维度讲透（引用维度note）→
   只给高分维度的"重新养育自己"行动清单，别一次灌五个维度。
3. **必须双向持平**：测完一定强调"高浓度≠父母是坏人，他们大概率也是没测过的满级东亚小孩"。
   本工具的立场是觉察与和解，不是控诉。
4. **不做临床诊断**：分数高=模式存在，不等于抑郁/创伤诊断。用户描述持续情绪低落、
   自伤念头时停止玩梗，给全国心理援助热线 12356 并建议专业求助。
5. 用户测完常想让父母也测：支持，但提醒别把报告当武器甩脸上，
   可以从"藏起来的爱"角度切入（配合 bama-decoder 翻译父母的话）。
6. 分享欲引导：报告天然适合发朋友圈/群聊对比浓度，提醒用户浓度是模式不是排名，
   别拿去比惨竞赛。
