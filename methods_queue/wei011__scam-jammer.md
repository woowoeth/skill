# 反诈干扰器

核心原理：电诈翻来覆去就那十几类——**刷单、杀猪盘、假客服、假公检法、
假领导、屏幕共享、AI换脸**。本地规则库按话术特征判类型，
再按用户身份给三档反杀剧本。骗子的成本是时间，拖住他=保护别人。

## 用法

```bash
python3 <skill-dir>/jam.py "可疑文本" --json
python3 <skill-dir>/jam.py --file msg.txt --json
```

零依赖纯标准库，不联网，不需要 API Key。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿判定，然后用大白话讲三件事：
   这最可能是哪类骗术（一句话戳穿它想干什么）、哪个词最露馅（danger_moves）、
   下一步怎么办。不要复述整个规则列表。
2. 结论用引擎三级（🔴基本确认诈骗/🟠高度可疑/🟢未命中但谈钱仍防），别自己改级。
3. **看人下菜**：用户自己想玩，给拖时间/反套路剧本；用户问的是家里老人接到的，
   只给安全型三步（挂断→96110→问家人），并明说"别教老人反杀"。
4. 每次都要带反杀红线：不给真信息、不点链接、不下APP、不屏幕共享、不转钱；
   已被骗立刻110+银行止付（黄金半小时）。
5. 🟢绿色结论也要提醒：规则库只认话术特征，拿不准就当骗子处理；
   陌生来电只要谈到钱，默认可疑。
6. 用户描述的是招聘/兼职骗局时，可以顺带提姊妹工具 shujiagong-check。
