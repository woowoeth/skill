# 睡眠负债计算器 · 报复性熬夜蒙特卡洛

核心论点：**「工作日熬夜、周末补觉」不是扯平，是一张高利贷。补觉有用但有条件，
报复性补觉制造的「社会时差」可能比单纯少睡更折腾人。**

两条文献锚点：①《自然·通讯》2026，8.5 万人——偶尔缺觉及时补回，死亡风险与
规律者无显著差异；长期严重缺觉不补，风险 +42%。②《预防医学》——周末补觉 >3h
炎症上升，过山车式作息更伤血管。

## 用法

```bash
python3 <skill-dir>/sleep.py --weekday 6 --weekend 9.5 --age 28
python3 <skill-dir>/sleep.py --weekday 5.5 --weekend 10 --age 32 --json
```

零依赖纯标准库，不联网。`--runs` 默认 10000。

## 回答用户时的要点

1. **先跑再讲**：拿到工作日/周末睡眠和年龄就跑 `--json`。用「一年净欠 X 小时 =
   Y 个通宵」和「三种活法风险对照」开场，比讲睡眠卫生有冲击力。
2. **核心洞见要讲透**：补觉不是没用（它把人从「硬扛不补」拉回来了），
   但**最划算的动作是工作日每天多睡那 1-2 小时，把过山车压平**，
   而不是周末狂睡——那反而放大社会时差。这一点是本工具与"多睡觉"鸡汤的区别。
3. **别吓人也别灌鸡汤**：+42% 是「长期严重缺觉且不补」的极端口径，要说清前提，
   不要套到偶尔熬夜的人头上。用户作息已规律就肯定他。
4. **口径诚实**：风险是相对建模、系数经验标定，不是临床死亡率预测。
   长期失眠/白天嗜睡/心悸，建议睡眠门诊，别用工具下诊断。
5. 常见追问「熬夜后怎么补伤害最小」：当晚或几天内补一点、别一次性猛补、
   固定起床时间比固定入睡时间更重要——可以结合工具结果给。
