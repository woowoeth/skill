# 巴納姆演講

把巴納姆效應限制在建立共鳴的首尾，以真實、具體、只有講者能說的故事支撐中段。產出自然的台灣口語繁體中文，而非星座文、算命話術或空泛雞湯。

## 判斷任務模式

- **從零創作**：先取得題目、真實事件、衝突、轉折與領悟。
- **改寫草稿**：保留事實與原意，診斷首尾、中段故事、情緒曲線與題目意象後再重寫。
- **即席準備**：素材不足且時間緊迫時，先給一句主旨與五段口說骨架，不強求完整逐字稿。
- **講評優化**：指出一項最重要優點與最多三項可執行修改，再提供修訂稿。

## 素材閘門

需要個人故事但素材不足時，先問最多三個短問題：

1. 題目讓你想到哪件真實小事？
2. 當時最難、最尷尬或最意外的是什麼？
3. 事情前後，你的想法改變了什麼？

不得虛構使用者的經歷、感受、對話、職位、家人或成果。可提供標示清楚的「示意故事」，但不能冒充使用者經驗。

## 三分鐘結構

預設寫成約 550–650 個中文字，並依使用者語速調整。

1. **共同入口（0:00–0:25）**：以多數人能代入的人性矛盾、優點代價或未說出口的感受開場。
2. **收窄至我（0:25–0:40）**：由「我們都有」自然轉成「我曾經」。
3. **具體故事（0:40–2:10）**：呈現場景、動作、1–2句短對話、阻礙與升高的壓力。
4. **轉折領悟（2:10–2:35）**：讓領悟從事件中長出來，不另貼大道理。
5. **還給聽眾（2:35–3:00）**：由「我明白」回到「也許你也」，以題目意象形成可記憶的最後一句。

## 巴納姆首尾規則

- 使用普遍經驗打開入口，但立刻以具體故事提高辨識度。
- 允許「有時想靠近、有時又想退開」等人性矛盾，但每篇最多使用一個主要矛盾。
- 不宣稱看穿聽眾，不替聽眾診斷，不以羞恥、恐懼或群體壓力逼迫認同。
- 結尾邀請投射，不武斷說「你一定也是」。優先用「也許」「如果你也曾經」。
- 開頭與結尾必須和中段事件相連；不能替換到任何題目仍完全成立。

## 題目主角化

若題目是鞋、門、雨、照片等具體名詞，讓它至少承擔兩項功能：

- 推動事件；
- 見證人物變化；
- 成為反覆出現的意象；
- 在最後一句產生新含義。

若刪除題目後故事幾乎不變，重新設計故事，而非只增加題目出現次數。

## 語言與舞台感

- 使用台灣自然口語，短句優先。
- 建立「平常狀態 → 壓力升高 → 關鍵轉折 → 新理解」的高低差。
- 只保留一個核心觀點；刪除重複說理。
- 不虛構名言、研究或精確數據。
- 標出三處重要的 `[停頓]`、`[加重]` 或動作提示，但不要讓標記干擾閱讀。
- 避免「首先、其次、最後」、翻譯腔、過度文青與連續金句。

## 預設輸出

依需求提供最少必要內容；完整模式依序輸出：

1. 核心主旨（一句話）
2. 完整三分鐘講稿
3. 三處舞台提示
4. 簡短說明首尾如何建立共鳴與呼應

若使用者要求可直接上台或直接複製，只輸出乾淨講稿與必要舞台提示。

## 完稿檢查

交付前確認：

- 開頭是否讓多數人能進入，卻沒有假裝讀心？
- 30秒內是否進入講者自己的事件？
- 中段是否有可見、可聽的具體細節？
- 題目是否真正參與故事？
- 領悟是否由轉折自然產生？
- 結尾是否把故事還給聽眾並呼應開頭？
- 全文是否可在指定時間內自然說完？
