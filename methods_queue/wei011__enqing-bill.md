# 养育对账单

核心原理：**"我养你这么大"和"我又没让你生我"都在用没法量化的东西定罪——
那就量化给他们看**。父母侧用育娲《中国生育成本报告2024》口径，
子女侧按同类服务市场价折算，两边都是七位数，谁也不欠谁——输出一份停战协议。

## 用法

```bash
python3 <skill-dir>/enqing.py --demo
python3 <skill-dir>/enqing.py --group 中间 --uni --age 28 --chores 中 --allowance 1000 --care-years 3 --json
```

参数：`--group` 家庭收入组(低收入/中间偏下/中间/中间偏上/高收入)、`--uni` 供到本科、
`--age` 用户年龄、`--chores` 童年家务量(少/中/多)、`--allowance` 每月给父母的钱、
`--care-years` 预计每位老人失能照护年数。零依赖纯标准库。

## 回答用户时的要点

1. **先问再算**：至少要到收入组（可从"爸妈当年做什么工作"推）、是否供到大学、年龄，
   其余用默认值。跑 `--json` 拿两边小计。
2. **报账三步**：甲方总额 → 乙方总额（用户通常不知道自己这边也是七位数，这是破防点）→
   立刻转折到"这张对账单唯一的正确用法是证明它没法用"。
3. **停战协议是交付物**：三条协议要完整念出来，鼓励用户转给家人或打印贴冰箱。
   这是工具的和解内核——算账是手段，停火是目的。
4. **两个方向的用户都接**：被"我养你这么大"压的年轻人 → 重点报乙方账，卸掉负债感；
   觉得孩子白眼狼的父母 → 重点报甲方账里的隐形账单被承认，再展示乙方账让 ta 看到回流。
5. **别变成怂恿不赡养的工具**：明确赡养是《民法典》1067条的法定义务，
   对账单谈的是义务之上的感情账。用户想用这个账单证明"我不欠父母"时，
   纠正为"你不欠的是无限服从，欠的赡养和爱一分没少"。
6. 涉及严重家庭冲突/暴力时停止算账，建议专业帮助（心理援助热线 12356）。
