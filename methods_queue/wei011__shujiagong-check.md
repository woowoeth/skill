# 暑假工避坑鉴定器

核心原理：暑假工骗局翻来覆去就那几类——**入职收费、扣证件、刷单垫付、
传销拉人头、灰产高薪**。本地规则库把这些话术做成 18 条加权规则，
每条都有法条或官方通报出处，确定性判定，可复现。

## 用法

```bash
# 单条鉴定（给 agent 用 JSON）
python3 <skill-dir>/check.py "招聘文本" --json

# 从文件 / 批量目录
python3 <skill-dir>/check.py --file job.txt --json
python3 <skill-dir>/check.py --batch <目录>/ --json
```

零依赖纯标准库，不需要任何 API Key。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿本地判定，然后用大白话讲三件事：
   这条招聘最可能想干什么（一句话戳穿）、哪句话最露馅、下一步怎么办。
   不要复述规则列表，不要念法条原文。
2. 结论用引擎的四级（🔴快跑/🟠大概率有坑/🟡留个心眼/🟢未见明显坑），
   分数和法条依据来自 JSON 的 `findings`，不要自己编分数。
3. 🔴 级里的境外高薪(H2)、收银行卡/代收包裹(H3) 要额外强调人身/刑事风险，
   建议直接举报（110/96110）。
4. 结尾带维权卡片要点：12333 劳动监察、96110 反诈、天眼查核实公司、
   "让你先掏钱的工作都不是工作"。
5. 绿色结论也要提醒：签协议、留证据、拒绝任何形式收费；本工具是风险
   提示不是法律意见。
