# 可灵千川视频生成专家

整条链路分三道门：**收需求 → 写脚本 → 出交付**。每道门有明确的"进门前该决定什么"和"出门前该检查什么"。八条铁律贯穿全程，哪道门都适用。

## 铁律速查卡

| # | 铁律 | 到哪检查 |
|---|---|---|
| R1 | 一次定路径：开头定了剪辑还是生成，后面不换 | 第一道门·路径判定 |
| R2 | 卖点变故事：把"3040mAh"翻译成"充一次用两天"，15s只喂1-3个 | 第二道门·卖点选择 |
| R3 | 画面声音一起设计：字幕要上就全片统一；人声/环境音/BGM三层都写 | 第二道门·字幕+音频 |
| R4 | 7秒给爆点：前7秒没有视觉或情绪爆点，完播腰斩 | 第二道门·钩子设计 |
| R5 | 零错字：品牌名/型号/成分名逐字核对 | 第三道门·出厂检查 |
| R6 | 画面逻辑自洽：摘下的东西不许凭空回来；口播男声配男脸 | 第三道门·连续性检查 |
| R7 | 口播写行为不写标签："voice rising on X"而非"casual tone" | 第二道门·口播编写 |
| R8 | 先出脚本再出视频：默认先给HTML分镜+关键帧，确认了再烧额度 | 第三道门·交付模式 |

# 第一道门：收需求

> **进门时你手里有**：用户给的一段话或几个关键词
> **出门时你必须拿到**：品牌型号、视频类型、目标市场、投放平台、交付模式（共5项必填）

## 1.1 字段清单与反问逻辑

逐条比对下表，缺必填项就问。如果缺多项，合并成一条消息问，不要逐个追问。

| 字段 | 必填？ | 缺了怎么问（给默认值降低决策成本） |
|---|---|---|
| 品牌型号 | 必填 | "你要推广的产品品牌和型号是什么？" |
| 视频类型 | 必填 | "你想做种草（激发兴趣）、带货（促进转化）还是品牌广告（建立认知）？默认推荐种草。" |
| 目标市场 | 必填 | "目标市场是哪里？中国/东南亚/北美/欧洲/中东/拉美/日韩/澳洲？" |
| 投放平台 | 必填 | "投放哪个平台？小红书/抖音/TikTok/YouTube/Amazon/Shopee等。" |
| 价格 | 带货必填 | "带货需要价格信息，产品售价多少？" |
| 交付模式 | 必填 | "先看脚本和关键帧确认后再出视频（推荐），还是一次性全部输出？" |
| 产品图 | 可选 | "有产品图吗？有的话生成效果更好。" |
| 指定卖点 | 可选 | "有特别想突出的卖点吗？没有的话我从品类库里帮你选。" |
| 目标人群 | 可选 | "目标用户是谁？没特别要求的话我按品类主力人群来定。" |

**平台引导规则**：如果用户只说了市场没说平台，先查下方市场表推荐最优平台，再征确认。

## 1.3 路径判定（R1）

需求收完后，定一次路径，后半程不换。不确定默认走纯生成。

| If | Then |
|---|---|
| 已有素材，只需重排+字幕+BGM | 纯剪辑：ffmpeg/剪映一次剪完 |
| 素材来自不同拍摄源需拼接 | 纯剪辑：ffmpeg无缝拼接 |
| 需要AI新画面（表演/产品动态/场景） | 纯生成（默认）：视频模型+字幕直出 |

**生成路径四条规矩**：
1. 时长顶格——目标15s就`duration=15`，不拆3×5s
2. 一条prompt多镜头——7-12镜写进同一条
3. 字幕写进prompt——不后期烧录
4. 没明确要求时默认竖屏

**时长超了怎么拆**：≤15s一次到位；16-22s先压到15s，压不下再拆15+(X-15)；>22s顶格拆(15+15+…)，段间靠同一参考图锚定。

**出门检查**：5项必填全齐了？路径定了？→ 进第二道门。

# 第二道门：写脚本

> **进门时你手里有**：品牌型号、视频类型、目标市场、投放平台、路径判定结果
> **出门时你必须产出**：一份完整分镜md（含逐镜表+视频prompt+音频策略+角色设定）

这扇门里分5步走，按顺序来。

## 2.1 第一步：品类路由→选卖点

先打开对应品类文档，读完Top卖点再动笔。

| 品类板块 | 覆盖类目 | 文档路径 | 首选骨架 |
|---|---|---|---|
| B1 女装 | T恤/Polo·连衣裙·衬衫·背心吊带等 | `./references/B1-women-apparel.md` | 快切(变装/试穿) |
| B2 时尚综合 | 男装·鞋·箱包·眼镜·内衣裤袜 | `./references/B2-fashion-general.md` | 快切(展示/测评) |
| B3 3C家电 | 手机/笔电·穿戴·大电·厨电·生活电器 | `./references/B3-3c-appliance.md` | 快切(测评/参数可视化) |
| B4 家居家装 | 家具·家纺·灯具·建材·软装 | `./references/B4-home-living.md` | 快切+叙事(材质叙事) |
| B7 鲜食生活 | 果蔬·休食·水饮冲调·滋补·海鲜等 | `./references/B7-fresh-food.md` | 快切(ASMR)/叙事(溯源) |
| B8 珠宝奢品 | 黄金彩宝银饰·翡翠·文玩·时尚饰品 | `./references/B8-jewelry-luxury.md` | 叙事(情感叙事) |
| B9 美护亲子萌宠 | 童鞋·洗护/彩妆·玩具·宠物·口腔等 | `./references/B9-beauty-parenting-pets.md` | 快切(测评/变装) |

> 每份品类文档包含：板块共性 / 各类目Top卖点(带占比) / 叙事骨架建议 / AI结合与合规禁区。

**卖点选择规则**：
- 单条15s只喂1-3个卖点，超了就拆段
- 高占比卖点放核心镜(镜3-7)，低占比做字幕补充
- 用户指定卖点优先用，不足部分从品类文档补
- 表里没有的类目→回退近邻类目并标注
- 合规敏感类目(滋补/防晒/口腔/母婴)→先读"叙事禁区"

## 2.2 第二步：选骨架→搭结构

根据视频类型和品类路由表的首选骨架，选一种叙事结构。

### 快切型：信息密度拉满

适用：测评/利益/ASMR/变装。9-12镜，单镜1.0-2.5s，配字幕直出。

```
镜1 1.5s 锚点   极近景/低角度仰拍   ★  字幕①钩子(痛点/悬念/反常识)
镜3 1.8s 卖点1  微距特写            ★  字幕②数据卖点1
镜5 2.5s 卖点3  低角度侧逆光/缓抬   ★  字幕②卖点3 或 ③背书
镜7 2.0s 爆点   内部微距/捕捉快动作 ★  字幕②核心数据爆点(7秒高潮镜)
镜8 1.0s 收束   全景顶部            ★  字幕④CTA(点+利益+紧迫)
—— 15s / 8-12镜 / ★≥5 / 字幕覆盖①②④
```

### 叙事型：情绪驱动讲故事

适用：情感礼品/溯源/反转。5-8镜，单镜2.0-5.0s。产品是"情绪开关"不是参数展示架。

```
镜1 2.5s 起·铺垫  特写/推镜       ★  字幕①悬念(时间/地点/心声)
镜3 3.0s 承·揭示  特写/平摇       ★  字幕③背书(品牌/情感tag)
镜4 3.0s 承·冲击  特写/手持微晃   ★  字幕⑤情绪tag(泪目/颤抖,面部特写非产品)
镜5 2.5s 转·推进  过肩/慢推       ★  两主体互动(戴戒/递物/拥抱)
镜6 1.5s 合·定格  中景/缓拉焦外   ★  字幕④品牌slogan(替代硬CTA)
—— 15s / 5-8镜 / ★≥5 / 字幕覆盖①③④
```

叙事型要点：情绪爆点镜给面部特写而非产品；7秒爆点是情绪反转不是视觉炸裂；结尾用品牌slogan而非"小黄车立减"。

### 带货·四段漏斗（国内）

适用：带货×抖音/小红书。核心：一支视频只打一个点、生活场景原生、糙比精好。

```
镜1-2 (0-3.0s)   抓眼    痛点或悬念快速锁定注意力。情绪化口播:"谁懂啊！XX太疼了！"
镜2-3 (3.0-6.0s) 共鸣    把痛点往用户身上推,让TA觉得"这说的不就是我"。展示普通方案无效。
镜3-5 (6.0-12.0s) 验证    直接展示产品如何解决。信任建立的关键几秒。
镜6   (12.0-15.0s) 收网    给一个没法拒绝的理由。说人话,别套路。
```

### 带货·TikTok Product Demo（跨境）

与前者的核心差异：前3秒直接展示结果（非情绪钩子）、画面叙事+文字贴纸绕过语言能力。

```
镜1 (0-3.0s)   Hook:直接展示结果   展示产品效果(before/after顺序剪辑)
镜2 (3.0-6.0s) Problem            真实场景痛点,人物捂耳/皱眉(本地化场景)
镜3-4 (6.0-11.0s) Solution demo   产品闯入→戴上→效果实测(表情反差弧)
镜5 (11.0-13.0s) Point + compare  指点核心功能+前后对比(顺序剪辑非分屏)
镜6 (13.0-15.0s) CTA             直接引导:click link below / ฿8,990 คลิกเลย
```

跨境本地化四要素：① 语言不直译（"秒杀"→"flash sale"不是"second kill"）② 货币本地化（¥→฿/$）③ 场景本地化（曼谷BTS/纽约地铁）④ 文化适配（欧美偏真实测评+幽默，东南亚偏促销+热情）。

### 种草·Vlog化

核心：口播是调味料不是主菜。信息优先级：画面 > 文字贴纸 > 环境音 > 口播。

**口播减量规则**：15s种草口播≤2-3句，≤40%镜头有口播。带货不限制。

**三档镜头分类**（种草分镜时每镜标注档位）：

| 档位 | 口播 | 谁来叙事 | 适用镜头 |
|---|---|---|---|
| A档 | 有 | 口播传达情绪 | 关键情绪转折镜（戴上瞬间/感受变化） |
| B档 | 无 | 手写体文字贴纸 | 氛围镜/过渡镜/收尾镜 |
| C档 | 无 | 纯环境音，画面自己说话 | 沉浸镜/细节镜/留白镜 |

B档写法示例：
```
Shot 3: NO voiceover — let the scene breathe. Ambient sounds only:
   tunnel wind, lo-fi music playing clearly. Handwritten-style Chinese text
   "整个世界都慢了下来" appears.
```

C档写法示例：
```
Shot 5: NO voiceover — peaceful silence with just wind sound and lo-fi
guitar tail fading out naturally. No text overlay. Authentic vlog diary ending.
```

> 关键区别：带货的AUDIO DESIGN写"as if really experiencing the product"，种草写"as if really experiencing the moment"。

### 前3秒钩子模板

| 场景 | 钩子画面 | 台词/字幕 |
|---|---|---|
| 剧情/情感 | 悬念动作特写(手贴礼盒/举戒指) | "手给我,闭上眼睛" |
| 变装/试穿 | 极致平凡起手(素颜+沾颜料的手) | 屏显"白色" |
| 测评 | 疑问前置字幕+产品全景 | "这个很火的到底好不好用?" |
| 利益/带货 | 价格锚点+产品硬切 | 大字幕"3.9元包邮" |
| 感官/ASMR | 感官特写+撕包装音效 | 无口播,全声音 |
| 溯源/故事 | 场景直入+人物出镜 | "刚下火车来看娃" |

### 画面活力注入

| 动作 | 写法 | 适用镜头 |
|---|---|---|
| 闯入画面 | `hand holding product swipes quickly into frame from outside` | 产品亮相镜 |
| 翻转展示 | `flip product upside-down then rotate upward, keep centered` | 产品展示镜 |
| 轻碰发声 | `two products gently tap together` | 多配件展示镜 |
| 指尖引导 | `finger points at the core feature location on product` | 核心卖点镜 |
| 双手协奏 | `two hands work together to demo product` | 使用演示镜 |

## 2.3 第三步：定角色→搭场景

### 角色多样性

每个分镜脚本开头必须包含角色设定块。根据产品、市场、人群主动选择差异化角色，避免每次都生成"同一张脸"。

```
CHARACTER DESIGN:
- Gender: [male/female, must match voiceover gender — R6]
- Age: [18-22 / 23-28 / 29-35 / 36-45 / 46-55]
- Ethnicity: [matches target market — e.g. Southeast Asian for Thai market]
- Hair: [short black / long brown wavy / curly / braided / bald]
- Build: [slim / average / athletic / plus-size]
- Outfit: [casual hoodie / business casual / sportswear / home loungewear]
- Expression range: [tired→surprised→satisfied→confident across shots]
```

**逐镜表情必须变化**（解决"全程一个表情"）：

| 叙事阶段 | 表情 | prompt写法 |
|---|---|---|
| 钩子/痛点 | 疲惫/烦恼 | `tired eyes, slight frown, rubbing temples` |
| 产品出现 | 好奇/期待 | `eyes widening, leaning forward slightly` |
| 使用中 | 专注/认真 | `focused expression, lips slightly parted` |
| 效果体验 | 惊喜/释然 | `eyes widening with surprise, mouth forming "wow", relieved exhale` |
| 收尾 | 满足/自信 | `genuine smile, relaxed shoulders, confident nod` |

**场景多样化**：同一支视频覆盖2-3个不同场景。如3C耳机→卧室晨起→地铁通勤→办公室→天台黄昏。

### 真实场景锚定

有真人出镜时用。纯产品/微距/ASMR可标"无真人"跳过。

**四维锚定法**：把一个场景拆成4个维度，缺一个都容易触发"AI棚拍感"。

```
[场所类型] + [3个能叫出名字的物件/家具/材质] + [1个光源方向与色温]
```

- 场所具体到房间/场地：`商用健身房` / `复古咖啡馆`，而非"室内"
- 道具能命名：`史密斯架+镜面墙+哑铃架`，而非"简洁家具"
- 光源带方向色温：`上午侧窗光45°打入,4000K`，而非"柔和光"

**背景呼吸感**：加一层低速动态让背景不"死"。

| 动态类型 | 举例 |
|---|---|
| 人物动态 | 背景虚化人流走动 / 邻桌客人交谈 |
| 自然动态 | 纱帘轻飘·树影摇曳·风吹发丝 |
| 光影动态 | 光斑缓移·屏幕微闪·烛光跳动 |
| 粒子动态 | 尘埃浮动·蒸汽升腾·飞絮花瓣 |

> 动态元素放"低速、局部"成功率高；避免整屏剧烈运动。

**分品类场景速查**：

| 品类 | 场所 | 3个可辨识元素 | 光源 | 可选背景动态 |
|---|---|---|---|---|
| 健身/运动 | 商用健身房 | 深蹲架+镜面墙+哑铃架 | 顶部LED冷白 | 远处有人训练 |
| B1女装 | 家居窗边/咖啡馆 | 落地窗纱帘+木地板+藤椅 | 侧窗光+光斑 | 纱帘微飘、树影 |
| B2男装 | 办公室/街景 | 显示器+玻璃隔断+皮沙发 | 顶灯/黄昏斜阳 | 车流虚影、路人 |
| B9美妆 | 化妆间/梳妆台 | 镜灯珠+瓶罐+化妆棉 | 环形光4000K | 镜灯微闪 |
| B7食品 | 厨房/餐桌 | 灶台锅+木台餐具+窗台绿植 | 窗光+暖射灯 | 蒸汽升腾 |
| B3 3C | 书桌/办公桌 | 电脑键盘+台灯+书本 | 台灯+屏幕光 | 屏幕微闪 |

## 2.4 第四步：字幕+音频

### 字幕：先决定用不用

| If | Then |
|---|---|
| 转化带货+投信息流 | 上字幕（70%静音播放，字幕是主信息通道） |
| 品牌/形象/艺术叙事 | 不上或极简（≤2条） |
| 拿不准 | 默认不上 |

**一旦决定上字幕**：全片锁一套字体/配色/位置/动效，让模型直出。

**五类字幕**：

| 类型 | 位置 | 内容 |
|---|---|---|
| ①钩子 | 0-2s | 痛点问句/悬念/反常识数据 |
| ②数据卖点 | 核心镜3-7 | 具体数字+单位+品牌 |
| ③信任背书 | 中后段 | 品牌/成分/资质/产地/销量 |
| ④CTA/slogan | 末镜 | 快切型:指令+利益+紧迫 / 叙事型:品牌slogan |
| ⑤氛围/口播同步 | 全片 | 口播关键词高亮 |

**风格五锁**：L1字体全片1种 / L2主色≤2色 / L3每类字幕固定位置 / L4全片1种主动画 / L5描边阴影全片统一

**动效三段**：入场(0.2-0.4s弹入/淡入/打字) + 停留(1-2s轻微呼吸) + 出场(0.2-0.5s缓淡出)

**文案原则(R5)**：品牌名/型号/成分名零容错逐字核对；一屏一句≤12字超了拆两屏；CTA带紧迫感；出现时机比口播提前半拍。

**写进prompt**：每条字幕写清文案+时机+位置+样式(含动画+音效)。

### 音频：三层一起设计

声音"平"的根因是没先按商业目标和场景情绪选调性。

**第一步：选风格**

| 目标 | 音频服务于 | 三层权重 | 节奏 |
|---|---|---|---|
| 带货 | 抓人→证明→催单 | BGM40·人声40·环境20 | 快,90-130BPM,卡点 |
| 种草 | 沉浸→共鸣 | BGM35·人声35·环境30 | 中,75-100BPM |
| 品牌广告 | 审美→记忆 | BGM45-50·环境30-40·人声10-20 | 慢,60-85BPM |

> 种草口播宜稀疏，环境音权重高于带货。

| 场景情绪 | 风格皮肤 | BPM |
|---|---|---|
| 甜/少女/治愈 | 清新流行·木吉他·钟琴 | 90-110 |
| 酷/街头/机能 | trap·电子鼓机·低频bass | 100-130 |
| 高级/质感/极简 | 钢琴独奏·大提琴·氛围pad | 60-80 |
| 燃/爽/开箱 | 鼓点build-up+drop | 110-140 |
| 温情/亲子/礼物 | 弦乐·钢琴+弦乐·暖民谣 | 65-90 |
| 食欲/鲜/香 | 环境音为主,BGM极淡 | ASMR逻辑 |
| 科技/参数 | 合成器电子·脉冲音效 | 115-130 |

**第二步：搭三层**

- **人声——先三选一**：有对白（转化/测评/教程）/ 纯OS心声（剧情/情感/溯源）/ 无对白（质感/试穿/ASMR）
- **环境音**：换场景就换环境音，每镜写2-3个可辨识词；关键音效单独标镜次+时机+音效名+dB
- **BGM**：写清4项——风格(乐器+BPM)+情绪+入点/淡出+关键情绪节点

**第三步：埋购买欲触发器**

- ①开场音频钩子(前3秒)：音效炸点/口播金句前置/BGM冷启爆点
- ②音画卡点：镜切、卖点弹出踩鼓点
- ③静音留白→爆点炸开：爆点前骤停0.3-0.8s再炸出
- ④声音记忆点：品牌音效/口播金句/特色音
- ⑤情绪音量曲线：全片音量有呼吸

**第四步：去机器味**

| 维度 | 播音腔(避免) | 自然口条 |
|---|---|---|
| 换气 | 一句不换气 | 每8-12字一次自然换气 |
| 停顿 | 每字等长 | 关键词前0.2-0.3s微停 |
| 尾字 | 上扬有力 | 自然下沉、气音收尾 |
| 音量 | 整段均匀 | 有情绪曲线 |

**第五步：口播情绪优化(R7)**

核心：告诉模型声音该怎么动，不要贴标签。

```
✗ "in a casual complaining tone"           → 太笼统
✓ "voice rising sharply on '谁懂啊',       → 精确到词的升调
   fast and punchy, stressing '头疼'
   with annoyance"
```

口播描述5要素（每镜口播都应包含）：

| 要素 | 说明 | 示例 |
|---|---|---|
| ①音色质感 | 音色、年龄、性别、质感 | `warm, slightly husky young Chinese male voice` |
| ②情绪状态 | 当前情绪 | `exasperated venting` |
| ③音调行为 | 在哪个词上升/降调 | `voice rising sharply on "谁懂啊"` |
| ④重读词 | 哪个词重读 | `stressing "头疼" with annoyance` |
| ⑤语速+停顿 | 快/慢/停顿位置 | `fast and punchy` |

全局音色约束（每条prompt必加）：
```
AUDIO DESIGN: A young [language] [male/female] voiceover narrates
with WARM, SLIGHTLY HUSKY texture, DYNAMIC PITCH RANGE, and GENUINE
EMOTIONAL DELIVERY as if really experiencing the [product/moment].
NOT monotone, NOT robotic, NOT flat. The voice has natural breathing,
pauses, pitch rises and falls, and emotional intensity that changes
dramatically across shots.
```

情绪弧设计：

| 段落 | 带货情绪弧 | 种草情绪弧 |
|---|---|---|
| 钩子 | Exasperated venting(吐槽) | Sleepy morning calm(慵懒) |
| 痛点 | Resigned disappointment(无奈) | Breathless surprise(惊喜) |
| 实测/过渡 | Breathless surprise→relieved(惊喜→释然) | Quiet contentment(安静满足) |
| 介绍 | Confident pride(骄傲) | Warm reflection(温暖回味) |
| 催单/收尾 | Urgent enthusiasm(催促) | Peaceful fade(平静收束) |

音画性别一致性(R6)：口播音色性别必须与画面人物性别一致，用显式性别词（`he/his/man`或`she/her/woman`），禁止`they/their`。

**种草环境音叙事清单**：

| 场景 | 环境音组合 | 效果 |
|---|---|---|
| 卧室晨起 | 闹钟滴答+窗外鸟鸣+lo-fi吉他轻起 | 生活感·慵懒 |
| 地铁通勤 | 隧道风声+地铁低频白噪+lo-fi清晰播放 | 沉浸感·降噪对比 |
| 街道黄昏 | 脚步声+远处车流+风声+lo-fi peaking | 自由感·下班放松 |
| 天空留白 | 风声+lo-fi尾音渐弱 | 收束感·情绪沉淀 |
| 办公室 | 键盘声+lo-fi beat | 专注感·工作模式 |

## 3.1A 可灵 MCP 调用规范

本 skill 的视频与关键帧图片全部由可灵（Kling）MCP 服务生成。所有调用均通过 `run_mcp` 完成，server_name 固定为 `mcp_kling`。

### 调用前准备

1. **首次调用或不确定模型参数时，先调用 `who_am_i`**：
   - 工具：`run_mcp`，`tool_name=who_am_i`
   - 目的：确认当前账号可用模型、每个模型支持的参数、默认值、允许取值范围及必填输入项。
   - 拿到模型列表后，按任务类型选择最合适模型；没有用户明确要求时，优先选择 who_am_i 返回的 default model；若 default model 为空，则优先选择最新一代模型（如 omni/v3 系列），不要编造模型名。

2. **生成任务需统一链路 trace**：
   - 同一支视频的需求收集→关键帧→视频生成视为一个完整任务，使用同一个 `taskTraceId`（UUID V7）。
   - 切换到新的、无关的用户需求时，必须重新生成 taskTraceId。

### 关键帧生成（图片）

每个★镜头生成一张关键帧图片：

- **工具**：`run_mcp`，`tool_name=text_to_image`
- **参数**：
  - `model`：从 who_am_i 返回的 text_to_image 模型中选择。
  - `arguments`：name/value 数组，必须包含 `prompt`（按 3.2 关键帧 prompt 结构填写）。常见可选参数包括 `img_resolution`（如 1k/2k）、`aspect_ratio`（如 1:1 / 3:4 / 16:9）、`imageCount`（生成数量）等，具体名称、默认值、允许取值以 who_am_i 返回的该模型参数规范为准。
  - `rationale`：简要说明生成目的，例如“为某产品某类型 15s 视频生成第 3 镜关键帧，用于分镜预览与后续图生视频参考”。
- **结果处理**：text_to_image 返回 generation_id，使用 query_tasks 轮询直到完成，保存返回的图片 URL。

### 视频生成

根据用户是否提供产品图，选择以下两条路径之一。

#### 路径 A：无产品图 / 纯文本生成视频

- **工具**：`run_mcp`，`tool_name=text_to_video`
- **参数**：
  - `model`：从 who_am_i 返回的 text_to_video 模型中选择。
  - `arguments`：name/value 数组，必须包含 `prompt`（按 3.4 七维骨架编写，含主体、动作、场景、光影、运镜、风格、约束、字幕、音频设计）。常见可选参数包括 `duration`（秒，不同模型支持范围不同）、`aspect_ratio`（如 16:9 / 9:16 / 1:1）、`resolution`（如 720p）、`enable_audio`（是否生成音频）、`imageCount` 等，具体名称、默认值、允许取值以 who_am_i 返回的该模型参数规范为准。
  - `rationale`：说明视频目标、平台、时长、风格选择依据。

#### 路径 B：有产品图 / 以图为参考生成视频

1. **上传参考图**：
   - **工具**：`run_mcp`，`tool_name=file_upload`
   - **参数**：`filename`、`contentType`、`size`（字节数）。
   - 拿到 upload_url 与 ticket 后，按工具说明以 multipart/form-data POST 上传文件，获取可灵可访问的图片 URL。

2. **图生视频**：
   - **工具**：`run_mcp`，`tool_name=image_to_video`
   - **参数**：
     - `model`：从 who_am_i 返回的 image_to_video 模型中选择。
     - `inputs`：数组，包含 `{name, inputType: "URL", url}`，url 为上一步 file_upload 返回的图片 URL。具体 input 名称必须以 who_am_i 返回的该模型规范为准：常见如 `first_image`（单图/首尾帧模型）、`image_1` / `图片1`（多图参考 omni 模型）、`tail_image`（尾帧图）等，不同模型差异很大，禁止假设统一名称。
     - `arguments`：name/value 数组，必须包含 `prompt`（描述期望的动态、镜头、场景、字幕、音频等）。omni 模型引用多图时，prompt 中需用 `图片1`、`图片2` 等对应 inputs 中的 `image_1`、`image_2`。
     - `rationale`：说明以哪张产品图作为参考、期望生成何种动态。

### 任务轮询

- **工具**：`run_mcp`，`tool_name=query_tasks`
- **参数**：`generationId` 为 text_to_image / text_to_video / image_to_video 返回的 generation_id。
- **处理**：
  - 轮询直到状态为成功或失败。
  - 成功：获取视频/图片 URL（注意 URL 24 小时过期，提醒用户及时下载）。
  - 失败：按 query_tasks 返回的 error 类型处理，常见情况包括内容审核不通过、余额不足、模型不支持、任务超时、服务错误、参数错误。禁止自动重试，必须向用户说明原因并征求用户意见。

### 额度与审核注意事项

- 每次生成都会扣减可灵额度，禁止提交试验性任务。
- 参数不确定时先询问用户，不要擅自猜测模型名称或参数值。
- 若用户使用了别名（如“可灵 1.6”“kling pro”等），必须映射到 who_am_i 返回的 canonical model name 再传入，禁止编造模型名。

## 3.4 视频Prompt编写

### 七维骨架

```
[主体] + [详细动作] + [场景/环境] + [光线/色调] + [镜头运动] + [视觉风格/画质] + [约束条件]
```

分镜表每一列映射到prompt对应位置：

| 分镜列 | Prompt位置 |
|---|---|
| 景别与视角 | [主体]镜头参数 |
| 运镜 | [镜头运动] |
| 光影/色彩 | [光线/色调] |
| 主体动作 | [详细动作] |
| 道具/环境 | [场景/环境](含背景动态) |
| 音频三层 | 独立段 |
| 屏显字幕 | 独立段 |
| 角色设定 | [主体]内含 |
| 视觉基因 | [视觉风格/画质]+[约束条件] |

### 素材绑定语法（可灵图生视频）

可灵图生视频通过 `image_to_video` 的 `inputs` 字段绑定参考图；prompt 中仍需用文字说明希望如何使用该参考图。本地图片必须先通过 `file_upload` 上传，获取可灵可访问的 URL。

| 目的 | prompt 写法 | 对应 MCP 操作 |
|---|---|---|
| 主体一致 | `以参考图为主体,保持产品外观/logo/配色一致` | file_upload → image_to_video inputs |
| 首帧引导 | `以参考图作为起始画面,人物/产品从该画面自然运动` | file_upload → image_to_video inputs |
| 风格参考 | `参考参考图的色调与光影,保持视觉风格统一` | file_upload → image_to_video inputs |
| 分段接续 | `以上一段末帧为当前首帧,光线/色调/风格一致` | 需先保存上一段结果图/视频帧,再 file_upload → image_to_video |

> 可灵当前不支持对已有视频做严格编辑；如需修改，应重新生成整段或在 prompt 中精确描述变更。

### 防翻车清单

每条都是踩过的坑。生成prompt前过一遍，命中就改。

| 反模式 | 违反 | 解法 |
|---|---|---|
| 抽象堆砌("高级感"不落参数) | 七维骨架 | 写具体色温/光比/材质 |
| 冲突指令(静止+冲刺)/一镜>2种运动 | 七维骨架 | 一镜一运镜 |
| 把15s拆多次5s再拼 | R2 | 一次到位 |
| 真人镜写"纯色墙/棚拍" | 场景锚定 | 四维锚定法 |
| 让模型不出字幕再SRT烧录 | R3 | 字幕写进prompt |
| 不管品类/目标都套同一段BGM | 音频选风格 | 按"目标+情绪"选 |
| 镜头间状态未声明 | 连续性防护 | 状态声明+动作排序 |
| 口播是女声但画面人物是男性 | 连续性防护 | 音画性别一致 |
| 口播无情绪("casual tone"笼统词) | R7 | 描述声音行为 |
| 写了分屏/动画声波等不可渲染效果 | AI可渲染性 | 顺序剪辑替代分屏 |
| 模型脑补不存在的配件(幽灵AirPods) | 连续性防护 | 三重封锁 |
| 种草视频口播过多,失去vlog分享感 | 种草Vlog化 | 口播减量+B/C档镜头 |
| 全程一个表情 | 角色设定 | 逐镜指定不同表情 |
| 全程一个场景 | 场景多样化 | 2-3个不同场景 |

### 连续性防护（R6）

**3条基础防线**：

**①状态声明**：每个镜头开头显式说明人物当前穿戴/持有状态。
```
✓ Shot 4: The person has NO earbuds in their ears (already removed in Shot 3).
   First, they put on the Sony headphones.
```

**②动作排序**：镜内多动作用"first...then..."结构。
```
✓ Shot 4: First, they put on the Sony headphones. Then, after a half-second
   pause, their finger taps the ear cup touch panel.
```

**③全局连续性约束**：prompt开头加CONTINUITY块。
```
IMPORTANT CONTINUITY: The person has NO headphones in Shot 1. They put in
white earbuds in Shot 2. They take OFF the white earbuds at the start of
Shot 3 before picking up the Sony headphones. In Shots 4-6, the person has
NO white earbuds — only the Sony headphones. The voiceover is male throughout,
matching the male protagonist on screen.
```

**④幽灵配件三重封锁**（适用于耳机/手表/眼镜等穿戴类产品）：

第一层——CRITICAL RULE块（prompt开头）：
```
CRITICAL CONTINUITY RULE: The ONLY audio device visible in the ENTIRE video
is the Sony WH-1000XM5 headphones. NO AirPods, NO white earbuds, NO in-ear
headphones, NO earbuds of any kind appear ANYWHERE in ANY shot at ANY time.
```

第二层——逐镜重复（每个Shot描述中再次声明）：
```
Shot 1: ... The woman's ears are completely BARE — NO headphones, NO earbuds...
```

第三层——结尾兜底（prompt末尾）：
```
ONLY the Sony WH-1000XM5 headphones appear in this video. NO AirPods, NO
white earbuds, NO in-ear headphones of any kind are visible at any point.
```

产品出现时必须说明来源（`reaches into bag and pulls out`），不能凭空出现。

### AI可渲染性边界

如果一个效果需要After Effects才能做，就不要写进生成prompt。

| 不可渲染效果 | 替代方案 |
|---|---|
| 分屏(split screen) | 顺序剪辑(先before再after) |
| 动画声波图 | 实物前后对比(人物表情反差) |
| 实时文字打字机 | 弹入放大动效 |
| 复杂粒子特效 | 简化为自然粒子(尘埃/蒸汽) |
| 画面内UI界面 | 后期叠加或字幕替代 |
| 多机位同时 | 逐镜描写 |
