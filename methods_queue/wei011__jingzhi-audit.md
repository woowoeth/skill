# 精致穷审计师

核心方法论：**精致度=可见性加权**。外套/香水/发型是高可见签名项必须保；
咖啡产地/护肤渠道/会员等级是低可见消耗项随便降。把钱从看不见的地方
抽出来，守住看得见的 signature——保面子，优化里子。

## 用法

```bash
printf '星巴克 800\n专柜护肤 1500\n打车 600' | python3 <skill-dir>/audit.py --json
```

一行一项"名目 金额"；没给金额的按类目典型值估（JSON 里 estimated=true）。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json`，然后讲三件事：本月能省多少
   （total_save 和 save_pct）、最大的两三个可降级项怎么替、哪些千万别动。
   "精致度影响：0%"这句要保留——它是本工具的灵魂。
2. 平替方案按用户城市/场景细化（一线城市有免税/奥莱渠道，小城市网购为主）。
3. **不评判消费观**：用户说"咖啡门店我就是要去"，那就尊重——那是买空间
   不是买咖啡，帮ta从别的类目找回这笔钱。审计是标价不是禁止。
4. 未识别类目（unknown）让用户补充用途后你自己判断可见性归类，
   并建议提 PR 加进类目库。
5. 用户是真缺钱（欠债/收入锐减）而非优化型省钱时，切换到务实模式：
   签名项也可以降，先保生存再保精致，并提示记账和 peer-pressure-check
   看存款分位。
