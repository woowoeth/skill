# LSF 潮流周边海报

接收用户原图，完成模态和背景选择后，从固定中文母版筛选出选中的两条，原样交给生图工具。唯一生图母版是 [references/prompt-template.md](references/prompt-template.md)，生成前读取。不得再根据视觉规范重新撰写一套生图提示词。

## 选择与会话状态

默认每张新图片先选择。检查当前请求中已指定的项目，仅询问未指定项；两项都已指定或明确要求本次全随机，直接执行。没有参考图片时，请用户提供图片。

向用户展示：

【造物模态】
A. 容器异构与破界
B. 潮玩合金挂件
C. 拟态徽章场景陈列
D. 特种纸品包装
E. 立体指示路牌
F. 服装梭织布标
G. 天然原石雕刻
H. 随机模态

【背景与配色】
A. 纯净高阶纯色
B. 多巴胺向白渐变
C. 微距质感台面
D. 随机背景与配色

回复例如“模态 B，背景 A”“两项随机”。说“一直随机”，后续图片将自动随机。

- 等待选完再生成。两组字母独立解释；单独一个字母存在歧义时，只澄清其所属组。
- 用户仅说“随机”或选择随机选项，只作用于当前图片。
- 用户明确说“一直随机”“后续都随机”时，当前对话进入持续随机；当前及后续每张新图片都重新抽取，不再展示菜单。
- 持续随机时，当前请求的明确指定优先；未指定项仍随机。单次覆盖不取消持续随机。
- 用户要求停止持续随机或恢复选择时退出；不承诺跨对话记忆，不写入全局偏好。
- 默认模式不继承上一张图的选择。一次上传多张待独立生成的图时，可共用用户本次指定的固定项，但随机项必须逐图重新抽取。用户明确要求合成一张时视为一次生成。

## 实际随机抽取

随机在 Agent 层执行，再把确定结果交给生图工具。模态 A–G 各 1/7，背景 A–C 各 1/3，独立抽取，允许连续重复。不根据图片适配度或近期历史换结果，不因抽中重复项重新抽签。

有 Python 时运行本技能目录下的脚本，路径按实际安装位置解析：

    python scripts/draw.py --mode random --background random

`--mode` 接受 A–G 或 random；`--background` 接受 A–C 或 random。将用户固定选择原样传入，只对 random 项抽取。UI 的模态 H、背景 D 均映射为 random。脚本输出 JSON，保留本次结果用于重试，不因工具失败重新抽签。

没有 Python 时可使用环境现有随机工具或代码运行时完成同样抽取；禁止凭空声称已运行工具。完全没有执行能力时可模型代选，但简短说明无法保证严格等概率。

背景抽签决定三类方案之一，具体颜色和台面结合原图推导；不要把三类背景误作三个固定色值。库内例子不是唯一选择。

## 生成流程

1. 收集用户选择并执行必要抽签。
2. 使用确定的字母运行 `python scripts/render_prompt.py --mode B --background B`（B 仅为调用示例，替换为本次结果）。脚本从母版删除未选的六种模态及两类背景，填写顶部变量，将随机选择说明替换为执行指定方案；所有其他正文原样保留。脚本不抽签。
3. 将脚本输出的完整中文字符串直接作为生图工具的 `prompt`。不加前言、英文翻译、摘要、标签化设计说明、负面词扩写或额外艺术指导。不提前替生图模型填写原图主题、符号、颜色、道具、文案、品牌或构图；由模型依据母版和原图推导。保留母版里的主题占位表达，不擅自把它填成上一张图的主题。
4. 仅将本次用户原图传入工具的参考图参数，不默认传入先前生成的海报或对比图。用户明确要求使用某张风格参考或指定额外文字、比例时，按该明确要求处理；不能自行推定。简短告知本次模态和背景后直接调用，不另设确认环节。
5. 展示生成图片。用户要求提示词时，提供实际传入的原文。检查选定模态、背景、原图关联及母版的版式文字要求；发现偏差如实说明，不把临场修订混入母版或声称已通过。只有用户要求修图时才另做定向修改；工具失败重试沿用相同提示词和参考图。

没有 Python 时，按同样规则机械筛选母版：只删未选项、填顶部变量、替换随机执行说明；其他段落逐字保留。不要把代码执行能力缺失当成重新创作提示词的理由。母版修改属于独立任务，仅在用户要求时进行。

无可用生图工具时，说明当前无法直接生图，提供确定方案的提示词。不要冒充已生成，也不要为使用其他付费服务擅自购买或配置账号。
