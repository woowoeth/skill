# 求职黑话翻译器

核心原理：招聘黑话翻来覆去就那几十句——**"弹性工作"＝下班弹性上班不弹，
"综合薪资"＝底薪很低，"急聘"＝刚走了一批人**。本地词典逐句翻译，
加权算坑指数，每类坑给一个"杀手锏反问"。

## 用法

```bash
python3 <skill-dir>/decode.py "JD或HR话术文本" --json
python3 <skill-dir>/decode.py --file jd.txt --json
```

零依赖纯标准库，不联网，不需要 API Key。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿判定，然后用大白话讲三件事：
   这份 JD 最露馅的是哪一两句（挑 weight 最高的）、整体是什么类型的坑
   （加班型/画饼型/流动型）、面试时最该问的 2-3 个反问。别整段复述词典。
2. 结论用引擎四级（🔴坑味扑鼻/🟠水分不小/🟡留个心眼/🟢未见明显黑话）
   和坑指数，不要自己编分。
3. **词条是经验总结不是指控**：输出要带一句"具体公司要具体核实"，
   建议用户天眼查看涉诉、看准/脉脉搜在职评价。
4. 命中"免费培训上岗"（培训贷）这类硬风险时要单独强调：先交钱/先贷款的
   工作直接跑，可顺带提姊妹工具 shujiagong-check（招聘诈骗）。
5. 用户在纠结 offer 时，提醒：口头承诺一律不算数，以 offer 纸面为准；
   坑指数只评 JD 话术，给钱到位的"明坑"也可以是理性选择。
6. 🟢绿色也提醒：词典只认套话，查无黑话≠公司没问题。
