# H3 质检与交付

## 三层 QC（每集必做）
1. **方向审计（自动）**：批次内每条出片即跑 audit_h3_orientation_landscape.py（vLLM 视觉模型判横竖 + 人脸朝向），不过自动换 seed 重跑（MaxRetries=3）。exit 0=通过 3=存疑（人工看）
2. **ASR 重审**：粗剪前/后各跑一次 reaudit_episode.template.py，把 05_日志/asr/*.json 的 text 与提示词台词逐字比对：
   - 完全一致 / 仅同音字差异（的/嘛、挑/挖、你/泥…）→ 记为"听检项"，不是模型错
   - **静默段 CTA 幻觉**（"请不吝点赞"、"Amara.org 字幕"等与剧情无关的话）→ 记为听检项并重点标注（whisper 对静音段的幻觉，不是视频里真有这声音）
   - 台词实质性错误（漏字、错词、串句）→ 进重做清单
3. **抽帧视觉 QC**：每单元抽 3–5 个关键帧（镜头切换点 + 台词点）目检：
   角色数量（有没有演员表外的狗/人）/ 服装归属（帽子背心在谁身上）/ 道具文字（有没有乱码字）/ 站姿（有没有横躺悬浮）/ 画面文字水印 / 方向

## 已知翻车模式 → 提示词对策（都写进 h3-prompt-spec 的铁律）
| 翻车模式 | 对策条款 |
|---|---|
| 演员表外多出角色（多一只狗） | "Only the listed characters appear in this clip; no additional ... appear." + 换 seed |
| 服装/道具归属错（红帽跑到别的狗头上） | 常服角色进全局块 "X always keeps his ..."；无该角色的单元写缺席声明 |
| 服装描述自相矛盾（"穿着背心"与"背心放桌上"） | 写提示词时全局搜索该服装的所有出现处，保持单一事实 |
| 道具/招牌乱码字 | "no text, letters, or symbols on any sign, barrel or prop" |
| 台词错/漏 | 换 seed 重跑该单元；仍错则拆短台词或改分镜 |
| 静默段 CTA 幻觉 | 不是模型错；报告里单独归类"听检项" |

## 质检报告模板（05_日志/质检报告_v1.md）
```
# <集名> 质检报告 v<N>
## 生成统计
12/12 成功，参数：8 步+sage，0.8MP，16:9，10s
## 问题清单
### 硬伤（重做候选）
- <单元> <问题> <涉及台词/画面> <对策>
### 听检项（非模型错，用户确认）
- <单元> <ASR 差异>
## 重做清单
默认：<单元列表>；用户确认后的最终清单
```
交付给用户时：粗剪 mp4 + 报告 + 默认重做清单 + "直接按默认清单重做 or 你看完再圈"。

## 粗剪拼接（scripts/finalize_episode.template.ps1）
- 从 transcript 选片 → 复制进 03_片段（按单元名）→ 任一缺失则中止（提示补跑）
- 可选 ASR 报告（逐条 text 长度+前 60 字）
- ffmpeg filter_complex：每段 scale=-2:720,crop=1280:720,setsar=1,fps=24 + 音频 aformat 48k stereo；无声段自动 anullsrc 补齐；concat 后 h264_nvenc p5 cq20 + aac 192k + faststart
- 输出 <集目录>/04_剪辑/<集名>_粗剪.mp4

## 重做流程（用户确认后）
1. 按报告改对应提示词（加铁律条款）
2. 批次脚本里该单元换 seed（resume-safe，已 OK 的单元自动 SKIP）
3. 跑批次 → finalize 重拼 → reaudit + 只查重做单元 → 报告 v2
