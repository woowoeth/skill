# 苏超预测器

世界杯预测器(wei011/worldcup2026-predictor)同款方法论移植到苏超:Elo 逐场回放已赛比赛 → 泊松进球模型(λ 用苏超本赛季真实场均进球定标)→ 蒙特卡洛模拟剩余赛季 N 万遍。

## 用法

```bash
python3 <skill-dir>/predict.py --json --sims 10000   # 机器可读,约 2 秒
python3 <skill-dir>/predict.py --sims 50000           # 人类可读表格,精度更高
python3 <skill-dir>/predict.py --offline               # 网络不可达时用本地缓存
```

- 数据实时拉取 `jscl.moyu.js.cn/wp-json/jiangsu/v1/matches`(苏超数据站),自动缓存到 `data/matches.json`
- 内置完整性校验:回放积分榜与官网积分榜逐队核对,不一致会报错退出(绝不带病预测)
- `--json` 字段:`elo`(各队实时 Elo)、`forecast[].champion/top4/top8`(夺冠/四强/八强概率)
- 零第三方依赖,纯标准库

## 回答用户时的要点

1. 先报夺冠概率表(或用户问的那支队的三个概率),再给一句 Elo 解释强弱依据
2. 明示假设:剩余常规赛主客场随机、淘汰赛按 1v8/2v7/3v6/4v5 标准席位、平局点球五五开——官方公布对阵后应以官方为准
3. 概率是分布不是答案:17% 的领跑者意味着 83% 的可能是别人夺冠
4. 请勿用于赌博——方法论展示项目
