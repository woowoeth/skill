# 60岁打工匹配器

2026.7《超龄劳动者基本权益保障暂行规定》配套工具:岗位体检+AI暴露度+权益清单。

## 用法

```bash
python3 <skill-dir>/chaoling.py --age 62 --json
python3 <skill-dir>/chaoling.py --age 65 --strength 弱 --outdoor 否 --night 否 --json
```

零依赖纯标准库,离线可用。

## 回答用户时的要点

1. 先报 `open_count`/20(还开着几扇门),再讲前几名岗位:时薪、
   AI暴露度、注意事项(`note` 和 `flags`)。
2. **必讲新规工伤保险**:用人单位可为超龄劳动者单险种参加工伤保险,
   这是 2026.7 新规最大的实惠;以及"务必签书面协议"。
3. AI暴露度话术:体力现场类岗位是AI替代风险最低的一档(呼应
   ai-replace-calculator),但停车场管理/仓库分拣是例外,自动化正在替代。
4. 手工外发加工岗要主动提示"交押金领材料"是常见骗局(可联动
   shujiagong-check 的规则思路)。
5. 结尾免责:时薪/年龄上限是公开招聘常见口径的量级估计;
   不构成法律意见,维权打 12333。
