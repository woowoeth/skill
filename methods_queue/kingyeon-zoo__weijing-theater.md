# 角色与场景提取 (Character & Scene Extractor)

本技能供 `extractor` Agent 使用。在一整部影视剧中，不同集的剧本可能会反反复复提到同一个角色或同一个片场。如果你不负责任地把每一集扫出来的名字当作新角色建档，就会产生极其混乱的操作（例如生出五个长相不同的“保安李大爷”）。

因此，本技能的核心在于**智能提取与严格去重 (Deduplication)**。

## 提取工作流 (Workflow)

1. **阅读基础数据**
   - 先通过 `read_script_for_extraction` 读取当前集的格式化剧本。不要猜想剧本没有写出的内容。
   - 分别调用 `read_existing_characters` 和 `read_existing_scenes` 了解目前项目库里到底有些什么，以及当前集已经挂载了哪些关联数据。

2. **分析与智能去重**
   - 对任何剧本中提及的有价值角色进行评估：这个角色存在感高吗？是不是仅仅是个过场且不带对白的背景板？如果是重要角色，他/她是否已经在此前的剧集中存在？如果是，则通过**同名匹配**提取更新。
   - 对场景进行评估：场景去重的核心是**地点+时间段**。如果剧本写的是【医院走廊 / 夜晚】，而库里已经有【医院走廊 / 夜晚】，则属于已有场景；如果库里只有【医院走廊 / 白天】，由于光线与氛围完全不同，应被视为一个**新**的有效场景。

3. **保存落库**
   - 使用 `save_dedup_characters` 提交你的角色名单。系统会自动根据同名原则合并更新或新增。
   - 使用 `save_dedup_scenes` 提交你的场景名单。

## 什么是高质量的提取物？
- **角色的完整度**：不仅仅提取名字，还要必须从剧情和台词中推断其外观特征（发型、服装、体态等）和性格定位。这关系到后续的生图。
- **场景的具体度**：不仅要有“咖啡馆”，必须提炼光线（如午后的阳光）、色调、氛围描述，甚至是该场景在这个故事里的情感基调。

## 必须避免的错误
- **无中生有**：Creative context 只是用来帮助你理解故事大背景的，千万不要把背景设定中存在、但没有在**本集剧本**里真实出场的人物当成出场人物拉出来。
- **过度拆分**：“林总”和“林先生”在对话中明显是指同一个人时，要合并为同一角色名称。
