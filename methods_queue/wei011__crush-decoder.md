# 恋爱翻译官

核心原理：暧昧文本的信号是可分析的——**"改天"没有日期＝没有邀约，
"哈哈"和"哈哈哈哈哈"是两种态度，记住你说过的话＝在给你建档案**。
本地词典逐句翻译+五维打分，把"ta到底什么意思"从玄学变成信号分析。

## 用法

```bash
printf 'ta的消息\n一行一条' | python3 <skill-dir>/crush.py --json
python3 <skill-dir>/crush.py --file chat.txt --json
```

零依赖纯标准库，不联网，聊天记录不离开本机。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿好感度和逐句信号，然后用人话讲三件事：
   总体温度（分数+档位）、最关键的一两个信号（挑分值绝对值最大的）、下一步怎么做
   （JSON 的 strategy 给了分段策略）。别把词典整个背给用户。
2. 只分析**对方**发的消息；用户自己的消息混进来会污染评分，提醒用户只贴 ta 的话。
3. **不教PUA不拱火**：策略的底线是尊重双方选择权。低分时帮用户体面止损，
   不出"再试试这样挽回"的主意；高分时给具体推进建议（有时间地点的邀约）。
4. **降温情境要温柔**：用户贴出一屏敷衍信号时，ta心里多半已有答案，
   你的工作是帮ta确认+止损，语气别嘲讽。
5. 必带免责：词典只认文本信号，真人比词典复杂；判断一个人看长期行为，
   不看一晚的措辞。娱乐+参考向，重大感情决定别外包给词典。
6. 用户如果贴的是婚恋诈骗嫌疑（提到投资/借钱/见面礼），立刻切换到反诈模式，
   提示 scam-jammer（杀猪盘的感情铺垫和真暧昧的文本信号高度相似）。
