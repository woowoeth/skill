# 爸妈话语翻译器

核心原理：东亚家庭话术是可翻译的——**"为你好"＝用爱包装的否决权，
"别人家孩子"＝家长间的军备竞赛，而"吃了吗"＝不会说出口的想你了**。
本地词典逐句翻译+窒息指数评分，负面话术给三档回应，藏起来的爱也翻译出来。

## 用法

```bash
printf '爸妈的话\n一行一句' | python3 <skill-dir>/bama.py --json
python3 <skill-dir>/bama.py --file chat.txt --json
python3 <skill-dir>/bama.py --demo
```

零依赖纯标准库，不联网，聊天记录不离开本机。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿窒息指数和逐句结果，然后用人话讲三件事：
   总体温度（指数+档位）、最扎心的一两句的潜台词、怎么回（resp 三档按用户当下情绪推荐一档）。
   别把词典整个背给用户。
2. **只翻译父母说的话**；用户自己的话混进来会污染评分，提醒只贴爸妈的原话。
3. **不拱火不定罪**：底线是"翻译为了沟通，不是为了开庭"。用户情绪激动时先接住情绪，
   再给"立边界"档；用户想缓和时给"顺毛"档；关系还行只是嘴笨给"拆弹"档。
4. **爱的信号必须播报**：如果 JSON 里 love>0，一定要告诉用户哪几句是藏起来的爱——
   这是本工具和纯吐槽工具的区别，也是让用户破防转发的点。
5. 记住父母也是被上一代塑造的人。窒息指数高时可以说"这套话术他们也是从爷爷奶奶那继承的"。
6. 必带免责：词典只认文本，不认完整家史；若用户描述持续贬低/威胁/暴力或明显抑郁倾向，
   停止玩梗，建议寻求专业心理援助（心理援助热线 12356）。
7. 如果用户是父母一方来测自己，切换视角：告诉 ta 哪句在孩子耳朵里是什么声音，鼓励直说爱。
