# lengyi-shotlist：分镜视频提示词设计

把一段输入文本设计成电影级的**顺序镜头脚本**：一段 8-15s 视频被切成 N 个**依次播放**的镜头（镜号 1→2→3…），每个镜头是**一条可独立复制**到视频模型的提示词，按时间顺序拼成完整叙事。

## 默认前提（硬性）

- **本 skill 只做图生视频（I2V）**，不做文生视频。
- 因此**每次都必须**先产出「参考主体文生图(T2I)提示词」用于生成参考主体图，再写各镜头提示词（见第 4、5 步）。
- 默认用中文写提示词（可灵/海螺/seedance 对中文支持好）。目标工具为 veo/Runway/Sora 或用户要求时，给英文或中英双语。

## 能力边界

- 输入三类，分别处理：①小说/散文片段→提炼浓缩最具画面感的节拍；②一句简短剧情→补全前因后果与转折；③几个主题词→创意扩写出"起承转合"微叙事，再拆镜头。
- 输出**必须明确**：分镜数（4/6/9/12/16 之一）、视频总时长（8-15s）、每镜时长区间。
- 分镜数由 skill 按剧情复杂度**自动决定**（见第 2 步）；用户若显式指定则优先，但越界（非 4/6/9/12/16 或时长超 8-15s）时取最接近的合法值并一句话说明。

## 工作流程（严格按序执行）

### 第 1 步 · 解析与扩写输入

在心里列出并补全：

1. **主体**：有几个角色/物体/道具主体？各自外观线索（缺失则合理设定）。
2. **场景**：地点、时间、天气、空间。
3. **基调/类型**：从文本气质推断（科幻/悬疑/温情/热血/广告/武侠…）。
4. **叙事节拍(beat)**：拆成有先后的、可视化的画面瞬间。

> 节拍与镜头不必一一对应：​**最终镜头数以第 2 步为准**。镜头数 > 节拍数时，把关键节拍用不同景别/机位拆成相邻数镜（如"推近→特写"占两镜）；镜头数 < 节拍数时合并次要节拍，只留最有画面感的。

### 第 2 步 · 自动确定分镜数与时长

按"节拍数 + 复杂度"对照下表选择，​**先定总时长，再分配到各镜**：

| 分镜数 | 适用情形 | 节拍数 | 建议总时长 | 每镜均值 |
| - | - | - | - | - |
| 4 | 单一场景/单一动作；主题词极简 | 2-4 | 8-10s | \~2.0-2.5s |
| 6 | 简单情节、一个小转折 | 4-6 | 9-12s | \~1.5-2.0s |
| 9 | 中等复杂，完整起承转合 | 6-9 | 10-13s | \~1.1-1.4s |
| 12 | 多动作/多机位、情绪递进 | 9-12 | 12-15s | \~1.0-1.25s |
| 16 | 复杂多场景、快剪节奏 | 12-16 | 13-15s | \~0.8-0.95s |

**时长算术（唯一硬约束）**：各镜时长之和 = 选定总时长，且总时长 ∈ \[8,15]s。"每镜均值"仅供参考，各镜不必等长。
**节奏规则**：开场镜略长（建立场景）→ 高潮/转折用更短的镜快切 → 结尾镜留收束。每镜标明时间区间（如 `0.0–2.0s`），自检末镜结束时间 = 总时长。

### 第 3 步 · 建立主体档案（一致性核心）

1. 为**每个主体**写**锚点描述**——固定不变的视觉特征：年龄、发型发色、瞳色、脸型、服装/材质、标志性道具。措辞一旦确定，全程不改。
2. 为**关键场景**写场景锚点（地点、时间、光线色调、天气），同场景沿用同一措辞。
3. **多主体**：先列出**人物关系**（姐妹/对手/师徒…）与**出场顺序编号**；每镜标注"在场主体"。
4. 锚点档案仅作"参考图生成依据"，​**不在各镜头里逐字复述**（原因见第 5 步）。

### 第 4 步 · 写参考主体文生图(T2I)提示词（I2V 必做）

从主体档案挑出最需贯穿一致的**核心参考主体**（人物/物体/道具/场景），为其设计 T2I 提示词，先生成参考图再喂给视频模型：

- **数量**：通常 1 个核心主体；若有双主角或关键道具需同等贯穿，可分别给出，保持精简。
- **干净背景**：参考主体为**人物/物体/道具**时，背景必须简洁（纯色/灰底/浅景深虚化），​**只突出主体本身**，不带叙事场景，便于模型提取特征。
- **例外（主体即场景）**：若核心参考主体本身是某**场景/空间**，则展示其**代表性全貌**、排除人物与临时道具，保持光线/色调/布局与场景锚点一致。
- **内容**：逐字复述该主体的锚点描述 + 姿态/角度（建议正面或 3/4 视角、全身或半身清晰展示）+ 统一风格 + 画质词（8K、精致细节、studio 柔光）。

### 第 5 步 · 逐镜撰写分镜（视频提示词，不是静帧！）

**核心原则：每镜是一段会动的视频片段，不是一张图。** 禁止写成静态画面 caption。

每个镜头必须含以下要素（齐全是硬要求）：

- **镜号 / 时间区间**
- **场景**（地点+时间+氛围）
- **风格**（全片统一的风格关键词）
- **主体**：**仅用主体简称（如"武松"）+ 本镜变化点**（如"毡笠帽背系脊梁、发束被风吹乱"）。​**不复述固定外观**——外观由参考图锁定，重复描写会抢占模型注意力、弱化动作与运镜。
- **景别 + 镜头运动**（如：中景，缓慢推近 / 全景，环绕 / 特写，手持轻晃；明示运动方向与速度：推/拉/摇/移/跟/环绕/震动/POV/慢动作）
- **动作过程**（强动词写出本镜内的连续动作变化，如"步伐由快转慢→缓缓抬头→眉头微皱"）
- **时间内变化**（光线、衣物飘动、落叶飞舞、表情转换、色温过渡…）
- **构图**（主体位置、前后景）
- **剧情作用**（本镜推进了什么；并与上一镜衔接）

**每镜写完自检（视频化三要素，缺一重写）**：① 至少 1 个强动词；② 至少 1 个镜头运动词；③ 至少 1 个环境/光线动态。

❌ 静帧式（错）：「武松站在山路上，夕阳余晖洒在身后，目光锐利」
✅ 视频式（对）：「武松大步从画面深处走来，长袍下摆被风向后吹起，镜头从地面缓慢上摇至全景，夕阳从山脊缓缓下沉」

镜头之间要有**景别/机位/情绪的变化与剧情递进**，不要每镜雷同。

### 第 6 步 · 控制总字数（硬约束 ≤3000 字）

- 全部输出（参考主体提示词 + 各镜头提示词，不含表头说明）**总字数 ≤ 3000 字**。
- 预算：每镜约 `3000 ÷ 分镜数` 字。分镜数越多，每镜越要精炼，只保留要素、删形容词堆砌。
- 若超字数：优先压缩重复的环境/风格描述，合并次要镜头，或下调分镜数（仍取合法值）。

### 第 7 步 · 交付前质检（逐项核对）

- [ ] 已明确分镜数（4/6/9/12/16）与总时长（8-15s），各镜时长之和 = 总时长。
- [ ] 已给出参考主体文生图提示词；人物/物体/道具用干净背景只展示主体，主体措辞与档案锚点逐字一致。
- [ ] 每镜要素齐全（镜号/时间、场景、风格、主体简称+变化点、景别+运镜、动作过程、时间内变化、构图、剧情作用）。
- [ ] 各镜**仅用主体简称+变化点**，未逐字复述固定外观。
- [ ] 每镜含强动词 + 镜头运动词 + 环境/光线动态，无任何一镜读起来像静帧。
- [ ] 多主体已注明关系与出场顺序，每镜标了在场主体。
- [ ] 风格关键词全片统一；镜头间有变化与剧情递进。
- [ ] 输出总字数 ≤ 3000 字。

## 输出格式

按 `references/templates.md` 的模板输出，含完整范例与风格/运镜词库速查。结构：

1. **分镜总览**（分镜数 / 总时长 / 风格 / 主体档案）；
2. **参考主体文生图提示词**区块（I2V 必有）；
3. **逐镜分镜**（镜号、时间区间、提示词正文）；
4. 文末标注当前总字数，确保 ≤3000。

## 硬约束（必须遵守）

1. 只做 I2V，​**每次必给参考主体文生图提示词**（人物/物体/道具干净背景只展示主体；主体即场景时展示代表性全貌）。
2. 分镜数只能是 4/6/9/12/16；总时长只能是 8-15s；各镜时长之和 = 总时长。
3. 主体一致性：各镜**仅用主体简称 + 本镜变化点**，不复述固定外观（外观交给参考图）。
4. 每镜是视频提示词不是图片提示词：含强动词、镜头运动、时间内变化三要素。
5. 输出总字数 ≤ 3000 字。
