# 人生进度条 / 同龄人压力检测器

核心原理：同龄人焦虑的根源是**拿自己的日常和别人晒出来的高光比**。
本工具用全国公开统计数据（统计局收入五等分、央行存款、年鉴分年龄未婚率）
算出用户的真实分位，让"我是不是落后了"从情绪变成数字。

## 用法

```bash
python3 <skill-dir>/peer.py --age 26 --gender 男 --salary 8000 --savings 30000 --married 0 --json
```

参数都可选（除 --age）：--gender 男/女、--salary 月收入元、--savings 存款元、--married 0/1。
零依赖纯标准库，不需要任何 API Key。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿分位数，然后用人话讲三件事：
   用户的真实位置（通常比他以为的靠前得多）、他在和谁比（朋友圈=别人的前10%高光）、
   哪个变量最值得动（JSON 里 what_if 给了每月多存500/1000/2000的5年分位变化）。
2. **口径要诚实**：收入分位是"全体居民人均可支配收入"口径（含不挣钱的人口），
   输出时要带一句，别让用户拿去和"就业者工资"混着比。
3. **不灌鸡汤不贩焦虑**：不说"你已经很棒了"，也不说"再不努力就完了"。
   只说数字和位置，最后提醒：分位数说明位置，不定义人生。
4. 未婚率高于50%时点出"未婚才是你这个年龄的大多数"——这是最有祛魅力量的一个数。
5. 用户没给的维度不要编，直接跳过。
