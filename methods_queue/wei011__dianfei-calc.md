# 空调电费预测器

用去年整夏(6月-9月中)逐小时实测气温当今夏代理,变频空调负荷模型算账。

## 用法

```bash
python3 <skill-dir>/dianfei.py --city 长沙 --json
python3 <skill-dir>/dianfei.py --city 重庆 --mode 全天 --rooms 2 --json
python3 <skill-dir>/dianfei.py --rank --mode 全天    # 19城排行,约1-2分钟
```

- `--mode` 晚上(21-7点)/下班后/全天;`--ac` 1匹/1.5匹/2匹/3匹
- `--setpoint` 设定温度;`--price` 当地电价(默认0.56元/度)
- 需联网(open-meteo 免费无Key);内置19城,不在列表会提示

## 回答用户时的要点

1. 跑 `--json`,先说 `cost_median`(整夏电费)和 `per_night`(每晚成本)。
   **`per_night` 是最能治焦虑的数**——整夜睡眠模式通常一晚只要1-3元,
   比热醒一次的代价小得多,把它放第一句。
2. `cost_if_24c` 与中位数的差 = "温度的价格",每调低1°C≈差值的一半。
   顺手给建议:26°C+风扇 通常是舒适/花费最优解。
3. 用户比较城市 → 跑 `--rank`(提醒要1-2分钟),排行结果按电费排序。
4. 免责:量级参考;阶梯电价二三档、定频老机、西晒房会更高;
   老人小孩高温天该开就开,电费焦虑不该拿健康换(可联动 heat-risk skill)。
