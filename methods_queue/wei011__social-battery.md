# 社交能量计

核心原理：**讨好型回复消耗80能量，边界型只消耗20**——消耗＝开口成本＋
事后内耗＋后患成本（这次答应下次还来）。本地场景库给三档回复，
让用户看见每句话的价格再买单。

## 用法

```bash
python3 <skill-dir>/battery.py "室友第5次让我带饭但不给钱" --json
```

零依赖纯标准库，不联网。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿三档话术和能量值，再结合用户的
   具体细节（关系亲疏/对方性格/场合）把话术改到能直接复制发送。
   改写时保持该档的能量水平：硬气版别替用户加"不好意思"软化——加一句
   道歉就把15能量的话术变回70了。
2. 三档都给，但点出能量差：核心洞察是"讨好当下顺嘴、总账最贵"。
3. 带上反应预测（JSON 的 predict），特别是通用规律：对方前2次不适应，
   第3次开始尊重边界——帮用户扛过不适应期。
4. **不评判用户选温柔版**：有些关系值得花70能量，工具只负责标价。
   但用户反复为同一个人来查话术时，可以温和点出这个模式本身。
5. 涉及借钱给"网友"、投资、垫付的场景，切反诈模式提示 scam-jammer；
   涉及职场加班/劳动权益的场景，提示姊妹工具 zhichang-zuiti。
