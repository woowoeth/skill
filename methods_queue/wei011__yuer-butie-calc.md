# 育儿补贴回本计算器

核心原理:2026 年国家育儿补贴 = 3600 元/年 × 3 年 = 10800 元。这个工具用
育娲《中国生育成本报告2024》+ 统计年鉴的收入五等分组做锚点,把养娃总账单
跑一万遍,再算补贴的真实覆盖率。

## 用法

```bash
python3 <skill-dir>/yuer.py --income 15000 --city 城镇 --kid 1 --json
```

- `--income` 家庭税后月收入(必填);`--family` 家庭人口(默认3)
- `--city` 上海/北京/城镇/农村;`--kid` 1/2/3(孩次规模经济自动打折)
- `--style` 佛系/普通/鸡娃;`--daxue` 算到本科毕业
- 零依赖纯标准库,不需要 API Key

## 回答用户时的要点

1. **你是解读层**:跑 `--json` 拿数据,先说三个数——总账单中位数
   `total_median`、补贴覆盖率 `subsidy_coverage_pct`、
   **10800 元实际够花几个月 `subsidy_lasts_months`(对比政策设计的 36 个月)**。
   最后一个数是最有冲击力的,放第一句。
2. 妈妈隐形账单 `mom_hidden_bill`(约 30.7 万/10249 小时)是情绪共鸣点,
   但要说明这是报告的时间成本口径,不含在总账单里。
3. 用户问"生二孩三孩划算吗"→ 强调孩次规模经济(二孩约 79 折、三孩约 6 折),
   这是报告里少有的"越生越便宜"反直觉结论。
4. 参数不服 → PARAMS 表在 yuer.py 顶部,直接改。
5. 结尾必须带免责:概率参考,不是劝生也不是劝退;数据锚点是公开报告,
   扰动参数是量级估计。
