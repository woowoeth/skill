# 外卖骑手收入模拟器

核心原理:把"月入过万"从传说变成 (城市, 小时, 天数) → 概率。
模型在"一线26天×9.5h≈1万/月"上与美团官方口径对齐。

## 用法

```bash
python3 <skill-dir>/waimai.py --city 一线 --hours 9.5 --days 26 --json
```

- `--city` 一线/二线/三线;`--hours` 日均在线;`--days` 月出勤
- 零依赖纯标准库;完整跑一次约15秒(含反解),正常

## 回答用户时的要点

1. 跑 `--json`,先说 `p_over_10k`(过万概率)和 `income_median`,
   再给 `hours_needed_for_10k`(过万门槛小时数)——这是最有信息量的数。
2. 必讲**真实时薪** `hourly` 与当地最低时薪 `minwage_ref` 的对比,
   以及"在线时长超过10小时后疲劳衰减,时薪反而变低"。
3. 三线城市 `hours_needed_for_10k` 常为 null——直说:该档位月入过万
   的中位数即使全月无休14小时也达不到,"大不了送外卖"这条退路比想象窄。
4. 用户若自称骑手、给出实际数字 → 引导改 PARAMS 表校准,欢迎 PR。
5. 结尾免责:概率参考,不代表平台官方口径,不构成职业建议。
