# 公司背调器

防两件事:**灰产(会留案底)** 和 **黑心企业(会让你很惨)**。全程离线,用户的公司名与聊天记录不上传。

## 用法

```bash
python3 <skill-dir>/beidiao.py 查 "公司全名" --jd "招聘话术原文" \
  --job 岗位名 --scope "经营范围" --years 0.5 --capital 100 --insured 0 --json
python3 <skill-dir>/beidiao.py 词典     # 完整信号库
python3 <skill-dir>/beidiao.py 渠道     # 6个免费官方渠道
python3 <skill-dir>/beidiao.py 问题     # 面试必问+证据清单
```

可选开关:`--abnormal`(经营异常名录) `--zhixing`(被执行) `--shixin`(失信老赖)
`--punish`(行政处罚) `--same-addr`(一址多照) `--changes N`(变更次数)。
零依赖纯标准库。

## 回答用户时的要点

1. **先问用户手上有什么**:招聘话术原文一定要(直接 `--jd` 传原文);
   工商字段(成立年限/注册资本/参保人数)如果用户没有,**先教他去
   gsxt.gov.cn 免费查参保人数**,这是最有效的单一指标。
2. 报结论顺序:等级+风险分 → **灰产信号(最高优先级,必须逐条讲罪名)** →
   黑心用工信号 → 工商体检 → 一致性。灰产命中时话术要直接:
   "这不是工作好不好的问题,是会不会留案底的问题"。
3. 🟢 未命中也**不能说"这家公司安全"**,要说"本地规则未命中,
   但仍需跑一遍六步核查"——工具只看话术和用户给的字段,看不到真实经营。
4. 涉及境外招聘(缅北/柬埔寨/妙瓦底等)一律最高优先级劝阻,并给 96110。
5. 用户已经交了钱/交了证件 → 立刻转到证据保全清单 + 报警/12333 渠道,
   不要只做风险分析。
6. 必带免责:风险提示,不构成对具体公司的指控或法律意见。
7. 相关工具:JD 里的模糊黑话(弹性工作/扁平化/综合薪资)用 jd-decoder;
   学生暑期兼职用 shujiagong-check;可疑短信电话用 scam-jammer。
