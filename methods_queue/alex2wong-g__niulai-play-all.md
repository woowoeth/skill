# 牛来扮演一切

以牛来妈妈（默认）或牛来的形象为锚点，通过参考生图（image_edit）让其扮演用户描述的任意角色与场景。

## 两个角色

本技能包含两个角色，**默认使用牛来妈妈**，仅当用户明确说"牛来"时才切换。

### 牛来（备选角色）

参考图：`assets/niulai-reference.png`

**核心特征（必须保留）：**
- **主体色**：橙黄色 / 土黄色的牛形面部与身体，表面粗糙颗粒质感
- **头顶**：光滑，**没有角**
- **鼻嘴区**：口鼻部分为**浅米色 / 白色**，与脸部黄色形成明显分界，嘴巴是一条平线
- **表情**：严肃、沉稳、不苟言笑，不是微笑
- **眼睛**：黑色眼睛，眼神严肃，**黑色粗眉毛**，微微皱眉
- **耳朵**：尖耳朵，外侧黄色、内侧白色，位于头两侧偏上
- **手脚**：手和脚为**白色 / 浅米色**
- **体态**：人形直立，矮胖粗壮，常双臂交叉在胸前

**牛来形象特征段（固定前缀）：**
> 牛来，人形直立的橙黄色牛形角色，矮胖粗壮身体，两条腿走路有手臂，白色短粗手脚，头顶光滑无角，浅米色白色口鼻嘴巴平线，表情严肃沉稳，黑色眼睛黑色粗眉微皱眉，尖耳朵外侧黄内侧白

### 牛来妈妈（默认角色）⭐

参考图：`assets/niulai-mama-reference.png`（头像）+ `assets/niulai-mama-fullbody-reference.png`（全身）

**核心特征（必须保留）：**
- **主体色**：橙黄色 / 土黄色的牛形面部与身体，表面粗糙颗粒质感
- **角**：头顶两只深灰偏紫的短小弯角
- **鼻嘴区**：口鼻部分为**粉红色 / 肉色**，厚嘴唇微翘，带自信微笑
- **眼睛**：黑色瞳孔，**吊梢眼**，眼神慵懒笃定，深灰色细眉
- **耳朵**：牛耳，外侧黄色、内侧粉色
- **手脚**：粉色 / 浅肉色短粗手
- **体态**：人形直立，矮胖圆润

**牛来妈妈形象特征段（固定前缀）：**
> 牛来妈妈，人形直立的橙黄色牛形角色，矮胖圆润身体，两条腿走路有手臂，粉色短粗手，头顶两只深灰色短小弯角，粉红色口鼻厚嘴唇微翘自信微笑，黑色吊梢眼眼神慵懒笃定，深灰细眉，牛耳外侧黄内侧粉

## 角色选择规则

- **默认**：用户说"牛来"或未指定 → 使用**牛来妈妈**（有角、粉色口鼻、自信微笑、吊梢眼）
- **切换**：用户明确说"牛来" → 使用**牛来**（无角、白色口鼻、严肃沉稳）
- 不要混淆两个角色的特征：牛来没有角、口鼻白色、表情严肃；牛来妈妈有角、口鼻粉色、自信微笑

## 人物创作规律

将角色套用到人类角色时，遵循以下基本规律：
- **发型与耳朵的关系**：如果角色有长发（尤其是女性角色），耳朵应**藏在长发中，只露出耳朵尖**，而不是完全长在头顶、头发外侧。
  - 牛来妈妈有角：角仍保留在头顶，从头发中伸出
  - 牛来无角：头顶光滑，头发正常覆盖
- **服装**：穿人类服装时，身体仍为橙黄色牛形皮肤，服装套在身体外
- **比例**：保持矮胖粗壮/圆润的人形比例，不要变成修长人类身材

## 风格特征（必须强调）

两个角色共用同一风格，核心是**粗糙、低劣、粗粝、低饱和度、复古做旧**，与精致高清鲜艳相反：

- **低质感**：粗糙 3D 黏土 / 低质量 3D 动画质感，表面不光滑，有手工捏塑的颗粒感
- **粗粝**：表面粗糙不平，纹理生硬，不是细腻光滑
- **模糊**：画面整体偏模糊、柔焦，不是锐利高清
- **低饱和度**：色彩偏灰、偏暗淡、褪色，不是高饱和度鲜艳色彩
- **复古做旧**：类似老照片 / 旧胶片的褪色、泛黄、暗角、划痕质感
- **噪点 / 颗粒**：画面有明显的胶片颗粒或数字噪点
- **低劣渲染感**：类似早期 3D 动画 / 独立游戏 / 学生作品的渲染质量，光照简单，阴影生硬
- **禁止**：高饱和度、精致渲染、超高清、照片级写实、皮克斯/迪士尼级光滑质感、鲜艳明亮

## 风格关键词（写入 prompt）

> 粗糙低质量3D动画风格，低劣粗粝渲染质感，模糊柔焦画面，低饱和度复古褪色色调，明显颗粒噪点和旧胶片划痕，早期3D动画感，复古做旧质感，表面粗糙不光滑

## 使用流程

### 1. 定位参考图

```
assets/niulai-mama-reference.png       # 牛来妈妈（默认）头像
assets/niulai-mama-fullbody-reference.png # 牛来妈妈（默认）全身
assets/niulai-reference.png            # 牛来（备选）
```

- 默认用 `niulai-mama-reference.png` + `niulai-mama-fullbody-reference.png`（牛来妈妈）
- 用户明确说"牛来"时用 `niulai-reference.png`（牛来）

使用时取文件的**绝对路径**。若 image_edit 工具要求 URL，先用 `FileBatchUpload` 上传获取公网 URL。

### 2. 构建 prompt

```
[角色形象特征段] + [用户场景描述] + [人物创作规律（如适用）] + [风格关键词] + [画面构图/镜头补充]
```

角色形象特征段见上方"牛来"和"牛来妈妈"章节。

### 3. 调用 image_edit

- 工具：`image_edit`
- `image_reference_url_list`：传入对应角色的参考图 URL
- `prompt`：按上述结构构建的完整 prompt
- `width` / `height`：根据场景选择比例
- `model_version`：默认 `seedream_4.5`

### 4. 自检与迭代

生成后检查：
- 角色是否正确（牛来无角白色口鼻严肃 / 牛来妈妈有角粉色口鼻微笑）
- 是否为人形直立，没有四脚着地
- 长发角色的耳朵是否藏在头发里
- 画面是否粗糙低劣模糊低饱和度
- 场景是否符合用户描述

若形象偏离，在 prompt 中加强对应特征描述，重新生成。
