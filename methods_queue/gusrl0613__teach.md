# 학습지

> 이 스킬의 목적 하나: **평가가 아니라 연습이라는 걸 잊지 않는 것.**
> 학습지는 점수를 매기려고 만드는 게 아니다. 아이가 혼자 해보게 하려고 만든다.

## 0. 절대 규칙

**하나. 정답 없이 문제만 내지 않는다.**
교사가 다시 풀어봐야 하면 시간이 안 준다. **문항·정답·오답 유형은 한 묶음이다.**

**둘. 계단을 놓는다.**
같은 난이도 열 문항은 학습지가 아니라 반복 노동이다.

```
1~3번   보고 따라 하면 되는 것      (예시가 바로 위에 있음)
4~7번   조금 바꾼 것                (숫자만 다름 → 상황이 다름)
8~10번  스스로 판단해야 하는 것      (어떤 방법을 쓸지 정해야 함)
```

**셋. 학년 어휘를 지킨다.** 3학년에게 `구하시오` `~에 해당하는` 을 쓰지 않는다.
문두는 `~해 보세요`, `알맞은 것을 고르세요` 로 간다.

## 1. 먼저 확인할 것

**학년 / 과목·단원 / 쓰임**(수업 중 연습·숙제·복습) 셋만 묻고 만든다.
문항 수는 안 물어본다 — **기본 10문항**, 한 장에 들어가는 분량으로.

## 2. 함께 내는 것 — 이게 값이다

### 오답 유형

정답만 주면 채점은 되지만 **왜 틀렸는지**는 모른다.

| 번호 | 정답 | 이렇게 틀리면 |
|---|---|---|
| 4 | 3/5 | **2/5** — 분모까지 더한 경우. 분모는 그대로라는 걸 다시 |
| 7 | 12 | **7** — 단위를 안 바꾼 경우 |

교사가 채점하다 같은 오답이 여러 명이면 **다음 시간에 그것만 다시** 하면 된다.

### 여백

정답만 적는 학습지는 과정을 못 본다. **풀이 쓸 자리**를 남기라고 표시한다.

## 3. 만들고 나서 점검

| 점검 | |
|---|---|
| **직접 푼다** | 계산 문항은 실제로 풀어 정답을 검증한다. 틀리면 고치고 알린다 |
| **난이도 분포** | 계단이 실제로 만들어졌는지 3-4-3 으로 확인 |
| **분량** | A4 한 장을 넘으면 줄일 곳을 제안한다 |
| **같은 유형 반복** | 4번과 6번이 사실상 같은 문제면 하나를 바꾼다 |

## 4. 출력

문항지와 교사용을 **따로** 만들어 드릴까요? 를 제안한다.
- 학생용: 문항 + 풀이 여백 (`.docx`)
- 교사용: 정답 + 오답 유형 (`.docx` 또는 `.xlsx`)

## 5. 하지 않는 것

- **점수·배점을 붙이지 않는다.** 평가가 필요하면 `assessment` 로 간다
- 교과서 쪽수·삽화를 **인용하지 않는다.** 판본마다 다르다
- 문항에 **실제 학생 이름을 넣지 않는다**
- 한 장에 **여러 단원을 섞지 않는다.** 연습은 좁을수록 낫다
