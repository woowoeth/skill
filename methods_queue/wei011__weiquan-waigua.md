# 维权吵架外挂

核心原理：消费维权失败的主因不是没道理，是**证据没收好、话不会说、
渠道找不对**。本地场景库给四件套：证据清单→三级话术→投诉渠道→法条弹药。

## 用法

```bash
python3 <skill-dir>/weiquan.py "外卖吃出头发商家只退5块" --json
```

零依赖纯标准库，不联网。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿四件套，然后按用户的具体情况
   （金额/平台/时间线/已有证据）把话术改到能直接发送，填掉话术里的XX占位。
2. **顺序铁律**：先证据后开口。用户上来就想吵架时，先拉住，把 evidence
   清单过一遍——哪些已有、哪些现在马上能补（截图防删改是最急的）。
3. 三级话术逐级用：建议从 L1 开始给对方台阶；用户已被拖了很久或对方
   明显耍无赖时，可以直接 L2。L3 里"投诉已提交"必须是真提交了再说，
   虚张声势被戳穿就没牌了。
4. **法条一字不差**：JSON laws 里的条文原样引用，别改编号别加戏。
   末尾带"大额纠纷（>1万）建议咨询律师"。
5. 金额算清楚给用户：食品安全=价款十倍保底1000；欺诈=三倍保底500。
   很多人不知道保底条款，以为一杯奶茶只能赔一杯。
6. 未匹配场景时用通用三步（固定证据→书面主张→12315/12345），
   并引导用户补充细节重试。招聘被坑→shujiagong-check；
   疑似诈骗（对方根本不是正规商家）→scam-jammer。
