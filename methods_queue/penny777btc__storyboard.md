# 分镜头脚本设计（镜头序列判断库）

来源：[意] 乔瑟·克里斯提亚诺《分镜头脚本设计教程》(Storyboarding Design Course)。
本 skill 把电影分镜原理转译为**本管线的分镜规划**——口播/创意 → 镜头序列 → 录屏/出镜拍摄清单。
深度原理与章节映射见 [reference.md](reference.md)；本文件只放**何时用、怎么拆、怎么验收**。

## 核心前提（先记住这一条）

分镜不是"连环画"，是**对成片的预演（视觉预算）**——在动笔拍/录之前，把"这段话用几个镜头、每个镜头是什么景别+机位、怎么接"先定下来。
> 分镜的目标 = **让镜头到镜头的"流动"顺畅**（连贯性），让观众看不出剪辑的接缝、却被一镜一镜推着走。

跟 [[shot-language]] 是一对：分镜管"排几个镜头、怎么排序接续"，镜头语言管"每个镜头画面里看什么"。

## 何时调用 / 接入点

| 管线阶段 | 本 skill 提供的判断 |
|---|---|
| 阶段 1 写脚本**之后** | 把口播脚本/创意拆成**镜头清单**：摘关键帧、定每镜景别+机位+动作、标切换方式（见下方「分镜五步」） |
| 阶段 2 选片（G2） | 按已定的分镜序列**选 take**：这条 take 是不是该景别、机位角度对不对、能不能接上一镜 |
| 阶段 3 粗剪排序 | 镜头顺序＝分镜顺序；检查连贯性（屏幕方向/运动线）、切换太多/太少、跳轴 |
| 阶段 5b 运镜 | 分镜里标注的推拉摇移、关联剪辑、蒙太奇，落到 punch-in / 数字运镜 |
| 质检 | 跑下方「八条分镜检验」（源自书第 40 课） |

## 分镜五步（口播/创意 → 镜头清单）

把一段脚本变成分镜，照这个顺序：

1. **通读一遍**——先抓整体感觉、节奏、要传达的观点；别急着拆镜头。
2. **摘关键帧**——从文字里挑出"最值得动笔的画面"（动作发生点、产品/重点出现点）。一段广告通常 **5 个关键帧 + 1 个产品/收尾特写**就够讲清。
3. **定每镜的景别 + 机位 + 动作**——见下方速查。每镜问三件事：给观众看多大（景别）、从什么角度看（机位）、画面里在发生什么动作（用箭头标）。
4. **排序 + 标切换**——镜头怎么接（直切/关联/淡入淡出/蒙太奇）。开头几乎总是**定场镜头（主镜头）**交代地点时间。
5. **出镜头清单**——编号、一句话描述、景别、机位、时长。这就是拍摄/录屏的施工图。

## 景别序列速查（一组镜头怎么由远到近）

- **定场/主镜头（FS 全景）**：开头交代"这是什么场景、元素怎么布局"。一节/一段开头必有。录屏＝全屏概览。
- **中景（MS / MCU）**：可信、对话的常规景别，看清主体+周边关系。出镜口播主力景别。
- **特写（CU / ECU）**：突出单一动作/单一元素/一句关键台词，拉观众进"内心世界"。录屏＝punch-in。
- **过肩镜头（OTS）**：对话/对比时用，成对拍。录屏里＝"我看着这块屏"的视角。
- **序列范式**：远→近推进（全景→中景→特写）＝聚焦、收紧；近→远＝释放、收尾。一段里要有景别变换才有节奏，全程一个景别＝平。
- **安全镜头组合**（对话/口播默认配方）：中景 + 特写 + 双人/过肩，反复用，稳。

## 机位角度速查（角度＝心理）

- **平视**：对等、可信、亲和——口播/教程基准机位。但易单调。
- **微仰（低角度）**：权威、力量、优势——人物**登场**、要显专业自信时用。
- **微俯（高角度）**：弱势、孤立、看清全局——讲"全局/架构/流程"或示弱时用。
- **倾斜（荷兰角）**：不安、戏剧、动感——Hook/转场可少量用，教程慎用（损可信）。
- 极端角度（鸟瞰/虫视/顶部）要"有目的"，否则突兀。出镜数字机位优先平视+微仰。

## 镜头切换与动作衔接速查

- **直切**：默认。追求流畅、掩盖时空跳跃。
- **关联剪辑（match cut）**：用两镜里相同/相似的元素接（A 镜的圆形→B 镜的圆形），最顺。
- **淡入淡出**：场景/时间大跨度（黑夜→白天、内→外）才用；同场景别滥用。
- **蒙太奇**：一串画面压缩时间过程（训练/成长/流程），无台词靠画面节奏。
- **运动线（180°轴线）**：两人对话/对位时，机位只能在轴线一侧，否则**跳轴**，观众瞬间懵。必须跳轴就让观众看见摄像机"绕过去"的过程。
- **动作衔接**：画面里有动作时**画箭头标方向**；切换时让动作"接得上"（A 镜伸手开门→B 镜门开了）。
- **视线高度一致**：对话/对位的两镜，角色视线高度要齐，否则接起来"飘"。

## 时长与节奏

- 镜头数 ≈ 信息量：广告 6–30 镜；一条社媒口播按段落拆，每个意义单元 1 个景别变换。
- 节奏来自**景别交替 + 切换频率**：紧张/Hook＝短镜+快切+特写多；舒缓/讲解＝长镜+中景为主。
- **切换太多**＝碎、看不清，常常两三镜能合一镜；**切换太少**＝闷、信息推不动，该在两镜间补镜头。

## 八条分镜检验（质检清单 · 源自书第 40 课 · 逐条过）

命中即记入 `work/qa-report`：

- [ ] **缺乏连贯性** — 镜头到镜头接不上、屏幕方向乱、动作衔接断。最常见是屏幕方向出错。
- [ ] **跳轴 / 运动线混乱** — 对话两人突然"看向相反方向"、机位跳到轴线另一侧没交代。
- [ ] **跳接** — 同一角色同一位置的两镜硬接（除非刻意），看着"抽帧/穿帮"。
- [ ] **切换太多** — 该合的没合，画面碎、抓不住重点。合镜或拉长。
- [ ] **切换太少** — 信息推不动、节奏闷。两镜之间补画面。
- [ ] **不明确的镜头序列** — 顺序读不通、缺定场/过渡，得重排或加交代镜头。
- [ ] **拍摄角度过于极端** — 极端机位没目的、显突兀。回到标准角度。
- [ ] **景别/角度选错** — 该特写时给了全景（重点没突出）、该平视给了俯仰（情绪错）。

检验的目标不是"画面更精细"，而是**让序列更"聪明"**——在景别、机位、镜头流动上做得更对。

## 关注度 vs 可信度（同 [[shot-language]] / [[layout-design]]）

极端角度、强切换、荷兰角＝吸睛但损可信；标准景别序列、平视、直切＝可信但平。
教程/产品＝连贯可信优先；Hook/片头＝可花哨博关注。按 brief 调性定档。

## 进化闭环

本 skill 是**分镜原理依据**；某次分镜判断（某段拆几镜、某处用什么切换）被用户确认/纠正后，
按惯例提炼成一条规则补进 `pipeline/taste.md`（分镜/节奏节），让判断沉淀为本频道可复用的"镜头序列范式"。
