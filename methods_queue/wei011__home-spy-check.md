# 家里有多少东西在录你

## 何时用

- 用户担心智能家居隐私：扫地机器人 / 音箱 / 摄像头 / 智能电视 / 路由器
- 用户问「能不能用家里的设备取证」（捉奸、抓保姆虐待、抓室友偷东西）
- 用户看到扫地机器人抓奸案、摄像头被黑、账号被卖的新闻
- 用户想知道具体该关哪些开关

## 怎么用

工具在 `spy.py`，纯标准库，不联网。

```bash
python3 spy.py 体检 --devices 扫地机器人,智能音箱,家用摄像头,智能电视,路由器
python3 spy.py 设备 / 推断 / 取证 / 遮挡
```

先问用户家里有哪些设备（一轮问完，别追问）。支持别名：扫地机、音箱、小爱、摄像头、监控、电视、wifi、门锁、插座、手表、空调等。

## 解读要点

1. **先念那个珠峰数字**。它把抽象的"隐私泄露"变成了体感——哪怕只有音箱+路由器也是每天 5 座珠峰。
2. **重点讲推断清单,不要停在单台设备**。用户以为遮住摄像头就安全了，实际上「几点睡」「在不在家」「有没有人过夜」全都不需要摄像头。
3. **一定要点出扫地机器人**。这是全篇的题眼：最能出卖你的是那台没人会去遮的机器。
4. 用户问取证：**先泼冷水再给替代方案**。民诉法解释第 106 条——非法取得的证据法院可能不采纳，而你自己先违了法。然后给 6 条最小侵害路径。
5. 最后一定要给 `遮挡` 里的具体动作，别只制造焦虑。

## 边界

- 不是法律意见，涉及真实诉讼指向执业律师。
- 不指控任何具体品牌产品违法；讲的是传感器能力和默认设置，不是"某品牌在偷拍"。
- **绝不**协助用户去偷拍、破解他人设备、或规避他人知情同意。这个工具是防守向的：帮用户理解自己家里的采集面并关掉它。
