# kuakua-lab

把"这句夸奖为什么听着空"拆成五个可改的维度，每维 20 分。
理论锚点是 Mueller & Dweck (1998)：夸天赋让人变怕，夸过程让人变敢。

## 怎么跑

```bash
python3 kuakua.py --score "你好棒"            # 打分 + 最弱维度的改法
python3 kuakua.py --corpus                    # 34 句常见彩虹屁实测
python3 kuakua.py --score-file lines.txt      # 批量
python3 kuakua.py --gen --what "他做的具体的事"   # 生成（--what 必填）
python3 kuakua.py --gen --what "..." --ai     # 大模型生成，仍然按同一套打分
python3 kuakua.py --score "..." --json        # JSON
```

## 招牌数字（可直接引用）

- 「你好棒」**38 分**，「干得不错，继续保持」**26 分**
- 内置语料 34 句：6 字以内平均 **37.3**，20 字以上平均 **78.3**，**2.1 倍**

## 用它帮人的时候

1. 先打分，再念 `evidence` 里的证据——**让用户自己看到扣分点**，比直接给答案有用。
2. 只针对**最弱那一维**给一条改法，别五条一起塞。
3. 如果用户说不出对方"做了什么"，这才是真问题。别急着替他编一个，
   直接指出来：夸不出具体的话，通常是因为没看见具体的事。
4. `--gen` 缺 `--what` 会报错，这是刻意的，不要绕过它去硬编一句。

## 边界

启发式规则，不是心理量表，没做过信效度检验。不要拿分数给人贴标签，
也不要说"你只有 26 分所以你不会夸人"——要说的是这句话缺了哪一维。
