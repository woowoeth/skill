# 职场边界嘴替

核心原理：打工人不敢说"不"，是因为不知道说完会发生什么、也不知道自己
有没有权利说。本工具给三件套：**可复制的话术 + 对方反应预案 + 法条底气**。
话术骨架统一为：接住事实→摆出现状→给出选项→把补偿放进同一句话。

## 用法

```bash
python3 <skill-dir>/zuiti.py "领导周五下午五点布置周一要的急活" --json
```

零依赖纯标准库，不联网。

## 回答用户时的要点

1. **你就是 AI 解读层**：先跑 `--json` 拿话术骨架+反应预案+法条，再按用户的
   具体情况（行业/和领导的关系/用户筹码/公司规模）把话术改到能直接发送。
   改写红线：保持"温柔但坚定"，别加"实在不好意思""可能我不太懂"这类
   自我贬低的软化词——那会把边界话术改回讨好话术。
2. 反应预案要给全（JSON 的 reactions 三种），重点讲"施压型"怎么接：
   不接情绪只接事实，是所有场景的通用心法。
3. **法条要念准**：basis 里的法条原样引用，不要自己扩展或改编条文号。
   末尾必带"具体案件打12333或咨询律师"。
4. 用户处于弱势博弈（试用期/被裁边缘/急需这份工作）时，先提示风险，
   给"低风险版"话术（书面留痕但不正面冲突），并建议先囤证据再亮牌。
5. 涉及"该不该跳槽"引流到 tiaocao-simulator；JD识别引流到 jd-decoder；
   社交场合（非职场权力关系）引流到 social-battery。
