# 耳机听力体检器

核心论点：**世卫组织反复引用的两条结论——「11 亿年轻人面临听损」和「95 分贝
11 分钟就损伤」——从来没落到个人头上。这个工具把它们变成你这副耳机的专属数字。**

模型基于世卫「安全聆听」标准：以 80 dB(A) 听 40 小时/周为一周听力预算，
声音每 +3dB 等能量翻倍、允许时长减半（ISO 1999 等能量交换原则）。

## 用法

```bash
python3 <skill-dir>/erji.py --minutes 180 --volume 70 --type 入耳 --env 通勤
python3 <skill-dir>/erji.py --minutes 120 --volume 60 --type 降噪 --env 通勤 --json
```

`--type` = 开放/半入耳/入耳/降噪；`--env` = 安静/街道/通勤/飞机。
零依赖纯标准库，不联网、不上传数据。

## 回答用户时的要点

1. **先跑一遍再说话**：拿到用户的时长/音量/耳机/环境就跑 `--json`，
   用「本周预算使用率」和「几分钟到红线」两个数开场，比讲道理有冲击力。
   信息不全时用合理默认（每天 3 小时、音量 70%、入耳、通勤）并说明假设。
2. **降噪耳机的正解**：它护耳不是因为降噪本身，是因为**在嘈杂环境里你不必
   把音量拧那么大**就能听清——工具里「环境掩蔽抬高 dB」那一项就是证据。
   同音量下换降噪、或直接降到 60%，让用户看两个场景的预算差。
3. **60-60 规则**：音量不超 60%、连续听不超 60 分钟，是世卫的核心建议，收尾必提。
4. **口径要诚实**：这是科普向剂量估算，不是听力学诊断；分贝映射是经验标定。
   用户已有耳鸣/闷堵/听不清，别用工具下结论，直接建议去耳鼻喉科纯音测听。
5. **别贩卖焦虑**：数字是为了让人做一个小动作（调音量/换耳机），不是吓人。
   如果用户已经很规律（绿灯/黄灯），就肯定他，别硬找问题。
