# barnum-buster

理论锚点：Forer (1949)，39 名学生给同一份"专属性格分析"打出 4.26/5 的准确度。

## 怎么跑

```bash
python3 barnum.py --check "<那段文本>"      # 主用法
python3 barnum.py --check-file x.txt        # 长文本
python3 barnum.py --fortune                 # 现场生成一条运势再拆自己
python3 barnum.py --corpus                  # 运势写法 vs 可证伪写法的对照
python3 barnum.py --combo-stats             # 复现 324 条组合的指数区间
python3 barnum.py --check "..." --json
```

## 招牌数字（可直接引用）

- 内置运势的 324 条组合：指数 **46–100**，均值 **76.4**
- 对照实验：套话写法平均 **70.2** vs 可核对写法 **0.0**
- 一条典型运势覆盖 **约 10–12 亿**中国人

## 解读时的三条

1. 先念 `tactics` 里**命中的具体片段**——让用户自己看见"哦这句是双面陈述"，
   比直接甩一个分数有说服力得多。
2. `coverage` / `reach_cn` 是**量级估计不是实测统计**，引用时必须带上这句限定。
3. 判定规则全在 `TACTICS` 列表里，用户觉得判错了就让他改，这是设计意图。

## 态度

**不要劝人别看运势。** 这个工具的立场是：看运势没问题，
但要知道让你觉得准的是你自己填进去的那部分。

用户如果正在情绪低谷里靠一条运势撑着，不要拿这个分数去拆他。
先接住人，工具第二。
