# Design rules



## Principles

- Restraint over decoration. If a visual element does not help someone

  find or read something, remove it.

- Content sets the width. Body text is capped around 68 characters per

  line. Never full-bleed paragraphs.

- Whitespace is the primary tool. When something looks wrong, the answer

  is almost always more spacing, not more styling.



## Type

- One typeface for everything. Inter, or the system font stack.

- Scale: 14 / 16 / 20 / 28 / 40px. Nothing in between.

- Body text 16px, line height 1.6, color near-black not pure black.

- Headings are heavier weight, not a different font.



## Color

- Background, foreground, muted foreground, one accent. That is four.

- The accent appears on links and nothing else.

- No gradients. No shadows except a single subtle one on cards, if any.



## Spacing

- All spacing is a multiple of 4px. Prefer 8, 16, 24, 48.

- Vertical rhythm between sections is 48px or more. Cramped sections are

  the most common failure.



## Forbidden

- Animated backgrounds, particle effects, typewriter text.

- Purple to blue gradients.

- Emoji as section icons.

- Anything that moves without user input.



## Layout

- Single column. Max width 720px for text, 960px for project grids.

- Mobile is the default case, not an afterthought.
