做什麼用

從真實圖表庫實現生成 HTML，不靠截圖或手寫。十二套中英整頁報告模板，地圖只在你要時才啟用，色系不混搭。以 Mono 為保底，按數據語義自動挑彩色預設，也可用你給的色板——但同一份交付絕不混色系。

應用範圍

用在「玩樂」這一格。只認 Lupi/Basics/Glance/Maps/Interactive 五類圖表實現；地圖必須顯式點名才啟用。

如何使用

  • 就按「圖表先問數據語義再選色，報告模板十二套」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/larashero3-dotcom/lieflat-charts.git
mv lieflat-charts ~/.claude/skills/lieflat-charts
