做什麼用

YC 掌門 Garry Tan 的 Claude Code 配置原樣開源：23 個工具分飾 CEO、設計師、工程經理、QA。看頂級投資人怎麼用 agent 幹活，光是角色分工這張圖就值得裝一遍。

應用範圍

用在「工作」這一格。這是一套流程，不是一個會寫代碼的人設，只要聊天式回答會嫌它囉嗦。隨件 scripts/preflight-agent-sdk.ts 裡寫著 permissionMode: 'bypassPermissions'，設計文檔也把 --dangerously-skip-permissions 當 CI 用法寫；跑之前知道這件事。59 件。

如何使用

  • 就按「YC 掌門的 Claude Code 全套配置，23 個角色分工」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。
