會替你刪掉一半心願單的行程地圖生成器

把零散截圖和收藏整理成一天一片區的行程，查完點評和小紅書，輸出可點導航的單頁交互地圖。

hiyeshu

做什麼用

把零散截圖和收藏整理成一天一片區的行程，查完點評和小紅書，輸出可點導航的單頁交互地圖。它認為你列的東西塞不進去，所以替你刪；一天最多安排一個需要訂位的地方。

應用範圍

用在「生活」這一格。調研環節綁死大眾點評和小紅書，非中文目的地信號很弱；要裝第三方 OpenCLI 並自己開帶調試端口的 Chrome；產出的地圖是一份靜態快照，行程當天不會自己更新。 小紅書那段是在你自己開的 Chrome 裡攔站內搜索接口取數，賬號風險你自己擔。

如何使用

  • 就按「會替你刪掉一半心願單的行程地圖生成器」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/hiyeshu/trip-map-builder.git
mv trip-map-builder ~/.claude/skills/trip-map-builder
