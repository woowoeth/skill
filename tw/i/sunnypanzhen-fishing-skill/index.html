新手買竿，老手看天：從選位講起

做什麼用

沒口的時候多半不是餌不對，是位置和天氣不對。它把選位排在全篇第一，氣壓風向溫差降雨講完才輪到裝備，臺釣路亞海釣黑坑都覆蓋。目錄本身就是論點：選位寫在最前。先講位置和天氣，再談裝備——把老手和新手真正分開的那一層。

應用範圍

用在「生活」這一格。經驗知識，無實時水位/天氣接口，仍要自己對照當天。偏中國淡水臺釣路亞；海釣篇幅更薄。

如何使用

  • 就按「新手買竿，老手看天：從選位講起」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/SunnyPanzhen/fishing-skill.git
