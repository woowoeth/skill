做什麼用

孩子發燒、咬人、不肯吃飯時，最怕搜到一篇署名權威的假文章。它逼自己每個結論湊夠兩個獨立來源，湊不夠就明說降可信度。它給自己列了一張「AI 可能說的藉口」對照表——「症狀太典型了基本能確定」在表裡是必須叫停的信號。

應用範圍

用在「生活」這一格。檔案默認寫進 Obsidian 式知識庫的固定路徑（08-全局記憶/L1-畫像記憶/孩子名），沒有知識庫得先指定一個本地目錄。覆蓋 0–13 歲，只說「症狀被關聯到 XX」不說「得了 XX」，不推薦任何藥品和劑量；輸入命中呼吸困難、抽搐等詞會跳過全部流程，只輸出就醫引導。

如何使用

  • 就按「專防「假託崔玉濤」文章的 0–13 歲育兒參謀」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/yeyulangzi/parenting-advisor.git
cp -r parenting-advisor ~/.claude/skills/parenting-advisor
