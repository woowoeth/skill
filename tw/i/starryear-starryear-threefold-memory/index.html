照片分三層：記憶碎片、證據原件、心情路線圖

上層把照片重組成大塊不規則碎片的視覺記憶，中層原片不動當證據，下層把路線、方向、情緒畫成一張記憶地圖。

Starryear

做什麼用

上層把照片重組成大塊不規則碎片的視覺記憶，中層原片不動當證據，下層把路線、方向、情緒畫成一張記憶地圖。它規定每一條路線、節點、碎片、圖標、配色都必須從這張照片推出來，不許寫死地點，也不許套裝飾性的星座。

應用範圍

用在「生活」這一格。只吃一張鎖定的照片，三層等高豎排，版式不可改。下層的「記憶地圖」是從照片推的空間信號，不是真地圖，別拿它導航。倉裡 3 個 SKILL.md，這是主件。

如何使用

  • 就按「照片分三層：記憶碎片、證據原件、心情路線圖」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/Starryear/Starryear-Threefold-Memory.git
mv Starryear-Threefold-Memory ~/.claude/skills/starryear-threefold-memory
