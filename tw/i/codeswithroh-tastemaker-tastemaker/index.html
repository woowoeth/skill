看一眼參考圖就生成同氣質界面的設計手

你貼一張Dribbble/Pinterest圖，它提取配色、字體、圓角、間距，直接產出同風格界面。

codeswithroh

做什麼用

你貼一張Dribbble/Pinterest圖，它提取配色、字體、圓角、間距，直接產出同風格界面。它先解析參考圖的視覺語言，再套用你的組件庫，而不是憑空生成。風格遷移有結構，不是濾鏡糊上去。

應用範圍

用在「工作」這一格。只認靜態參考圖，不認Figma文件或設計token；產物是前端代碼，不負責導出設計稿；若參考圖是插畫/3D渲染。

如何使用

  • 就按「看一眼參考圖就生成同氣質界面的設計手」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

git clone --depth 1 https://github.com/codeswithroh/tastemaker.git
