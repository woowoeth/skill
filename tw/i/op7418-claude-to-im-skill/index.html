做什麼用

長任務要跑一小時，你卻得出門。把會話橋到 Telegram、飛書、微信，手機上發一句就能遠程派活，幹完還推給你。歸藏出品，解決的是真痛點：agent 的時間和人的時間從此不用綁在一起。

應用範圍

用在「工作」這一格。本機得一直開著：橋是常駐 Node 進程，裝完還要在 skill 目錄 npm install 和 build。微信只能掃碼綁一個號，沒有內聯授權按鈕和流式預覽，語音只收微信自己轉的文字。飛書要兩輪發版加管理員審批。

如何使用

  • 就按「從手機指揮電腦裡跑著的 agent」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/op7418/Claude-to-IM-skill.git
mv Claude-to-IM-skill ~/.claude/skills/Claude-to-IM-skill
