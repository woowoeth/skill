做什麼用

旅行照別整張貼——它替你選出敘事性元素，統一成暖調低飽和紙感手繪。復古編輯風，透明 PNG 直接拖進手帳。不是摳圖，是翻譯。它先理解場景裡哪幾樣東西在講故事，再用手繪語言重畫，讓貼紙和你的手帳紙面天生一體。

應用範圍

用在「生活」這一格。只認暖調低飽和紙感手繪這一種視覺；原樣摳圖、照片修復、精確復刻參考圖、矢量/logo 工作它不做。輸出透明 PNG。

如何使用

  • 就按「照片裡只挑有故事的那幾樣，畫成手帳貼紙」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

git clone --depth 1 https://github.com/yvonnechen202608-byte/picture-design.git
