做什麼用

AI 當 KP 最煩的是一口氣把三個場景演完。它給自己設了硬上限：一回合一拍、2–4 句，停在你能動手的那一刻。隊友 NPC 是 AI 扮的調查員不是提示頻道：不許總結主線、不許給路線排正確度，要拿信息也得擲骰。

應用範圍

用在「玩樂」這一格。模組正文得你自己有——它明寫有原文時不許憑記憶講，沒有原文就只能即興。配樂是在瀏覽器裡開一個搜索結果頁，作者承認查不到具體曲目時就讓你自己按播放。它還會照模組把 1920 年代的種族歧視當成線索門禁執行，只在開局前問你能接受到什麼程度。

如何使用

  • 就按「寫到第三段就把回合交回來的克蘇魯跑團 KP」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/SumanasJ/coc-kp-host.git
cp -r coc-kp-host ~/.claude/skills/coc-kp-host
