做什麼用

AI 寫的文章一眼假，改起來比自己寫還累。它強制注入人類觀點和細節，配讀者測試評估和自動圖文排版，全流程走完。國產模型友好（DeepSeek/GLM/MiniMax），把「防 AI 味」從口號做成了強制規則——中文寫作全家桶裡立意很高的一套。

應用範圍

用在「寫字」這一格。9 份 SKILL.md 其實是同樣三件放在 .claude、claude-runtime、plugins 三個目錄裡，真貨只有三件。作者實測過的模型只列了 DeepSeek-V3.2、GLM、MiniMax，桌面版只出了 Windows 預覽。

如何使用

  • 就按「從選題到發布的去 AI 味中文寫作系統」這一件來做，不要中途改風格。
  • 按它的句式改這一段，能刪就刪。
  • 先標出越界的句子，再重寫，不要通篇潤色。
  • 寫完對照應用範圍，串味就停。

安裝

git clone --depth 1 https://github.com/dongbeixiaohuo/writing-agent.git
