做什麼用

學生問『為什麼不選B』時，不再口乾舌燥講三遍。把閱讀題變成能自學的交互頁，練完自動浮出錯題模式，老師備課。不是靜態解析頁，而是帶診斷引擎的練習系統：每道題標註陷阱類型，跨題聚合出個人錯題模式，讓出題邏輯顯形。

應用範圍

用在「生活」這一格。只處理四選一英語閱讀客觀題（含題幹+原文+答案）；不生成新題，不做聽力/完形/寫作。輸出為單文件HTML。

如何使用

  • 就按「選擇題每個選項都標出題人陷阱的解剖器」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/edu-ai-builders/language-learning-sop-kit.git
cp -r language-learning-sop-kit/option-anatomy ~/.claude/skills/skill-option-anatomy
