做什麼用

查重、分層驗證門、固定骨架、Step 式 PoC、真實截圖、語義化命名、放對目錄——從確認到成稿一條龍。把報告格式變成硬門禁而非軟建議：驗證不過不出稿，截圖缺失不落盤，駁回自動追補。

應用範圍

用在「工作」這一格。只收已確認的漏洞，不負責挖掘和驗證；只出 DOCX，不生成 PDF/Markdown；截圖必須真實存在。

如何使用

  • 就按「漏洞確認後直接產出可提交的 DOCX 報告」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

git clone --depth 1 https://github.com/v-yun/vuln-report-skill.git
