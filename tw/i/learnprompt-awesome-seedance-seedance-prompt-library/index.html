做什麼用

寫 Seedance 提示詞總被生成器帶偏？這裡每個模板都來自 goodcase.ai 上跑通的高分案例。不是泛泛的提示詞技巧，而是從真實高分案例裡反向拆出的結構。它告訴你哪種鏡頭該用哪套句式。

應用範圍

用在「做圖」這一格。只覆蓋 Seedance 2.5/2.0 文生視頻的提示詞撰寫，不含圖生視頻、音頻或運鏡參數調優；模板基於公開案例。

如何使用

  • 就按「Seedance 2.5 視頻提示詞模板庫」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/LearnPrompt/awesome-seedance.git
cp -r awesome-seedance/agents/skills/seedance-prompt-library ~/.claude/skills/seedance-prompt-library
