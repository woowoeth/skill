做什麼用

你正要裝的那個 Skill 可能帶著提示注入或惡意指令。它把文件當不可信數據讀，逐行查風險，裝之前先給你一份判決書。把 Skill 文件當作不可信輸入而非代碼，從根上避免「裝完才後悔」。它不猜，它讀原文。

應用範圍

用在「寫字」這一格。只審文件內容與元數據，不跑動態沙箱；對混淆或加密的 payload 只能標「可疑」不能拆解；不覆蓋平臺自身漏洞。

如何使用

  • 就按「裝任何第三方 Skill 前先讓它過一遍安檢門」這一件來做，不要中途改風格。
  • 按它的句式改這一段，能刪就刪。
  • 先標出越界的句子，再重寫，不要通篇潤色。
  • 寫完對照應用範圍，串味就停。

安裝

git clone --depth 1 https://github.com/ai-safe-lens/vetaskill.git
