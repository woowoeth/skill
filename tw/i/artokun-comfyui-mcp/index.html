做什麼用

ComfyUI 的連線勸退過無數人。裝上它用說話就能生成圖/視頻/音頻、搭工作流、改你正在跑的節點圖，全程本地不上傳素材。把「拖節點」變成「說人話」，而且本地跑——碰私密素材時這點關鍵。

應用範圍

用在「做圖」這一格。本體是 npm 上的 MCP server，39 件 skill 給它當外圍。前提是有一臺跑著 ComfyUI 的機器——沒有 ComfyUI，這一整包一件都用不上。另外推薦管線裡含一個 abliterated（去掉了拒答方向）的文本編碼器 LoRA，作者標它是修臉用的；模型表另有一行 abliterated 出圖模型標著 uncensored，可換成同表的普通寫實模型。

如何使用

  • 就按「自然語言改工作流，178 個工具隨叫隨到」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/artokun/comfyui-mcp.git
