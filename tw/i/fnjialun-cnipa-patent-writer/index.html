做什麼用

從技術方案到全套 .docx 專利文檔，含白底黑線附圖。有模板只取版式，無模板按國知局標準排，內容配圖全部現寫現畫。模板只當尺子用，不當複印機。頁眉頁腳、分節、字號縮進全對齊，但每個字、每張圖都從你的方案重新長出來。

應用範圍

用在「工作」這一格。只產出申請文檔和附圖，不查新穎性、不寫審查意見答覆。需你提供完整技術交底；若方案缺關鍵實施例或數據，它不會替你編造。

如何使用

  • 就按「只借版式不借內容的 CNIPA 專利文檔生成器」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

git clone --depth 1 https://github.com/fnjialun/cnipa-patent-writer.git
