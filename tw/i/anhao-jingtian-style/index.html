一份會替你按住抒情衝動的第一人稱記賬筆

短行白描、數字替情緒、稱謂即關係、空置收尾——把情緒藏進勞動鏡頭裡，第一人稱記賬體，剋制到不像廣告。

anhao

做什麼用

短行白描、數字替情緒、稱謂即關係、空置收尾——把情緒藏進勞動鏡頭裡，第一人稱記賬體，剋制到不像廣告。不是仿寫，是結構復刻：抵押對位、外圍勞動、空置收束，每一句都有機制可循，改完自帶景甜體的冷感。

應用範圍

用在「寫字」這一格。只認中文輸入，英文稿會先譯再改；只產出文案本身，不負責排版或配圖；若原文無具體數字或勞動細節，需先補足才能動筆。

如何使用

  • 就按「一份會替你按住抒情衝動的第一人稱記賬筆」這一件來做，不要中途改風格。
  • 按它的句式改這一段，能刪就刪。
  • 先標出越界的句子，再重寫，不要通篇潤色。
  • 寫完對照應用範圍，串味就停。

安裝

git clone --depth 1 https://github.com/anhao/jingtian-style.git
mv jingtian-style ~/.claude/skills/jingtian-style
