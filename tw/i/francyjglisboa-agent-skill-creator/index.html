做什麼用

把任何工作流寫成一次、裝到 17 個平臺：Claude Code、Cursor、Copilot、Gemini 全兼容的 skill 鑄造機。跨平臺是 skill 生態的下一站。

應用範圍

用在「工作」這一格。17 個平臺裡只有 12 個原樣能裝，Cursor、Windsurf 等 4 個要轉格式，Zed、Aider 等 4 個得你手抄進配置。校驗和安全掃描都是 python3 腳本，過了它會直接裝進你的配置目錄。

如何使用

  • 就按「把口頭流程變成能跑的跨平臺技能，三步內交付」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/FrancyJGLisboa/agent-skill-creator.git
mv agent-skill-creator ~/.claude/skills/agent-skill-creator
