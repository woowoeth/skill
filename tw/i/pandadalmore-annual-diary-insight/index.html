把十年日記攤成一張可下鑽的年輪看板

年度洞察要精讀全年日記後人寫；大事記只問一句「哪天之後你回不去了」，一年五到八條，還專收「未遂里程碑」。

PandaDalmore

做什麼用

年度洞察要精讀全年日記後人寫；大事記只問一句「哪天之後你回不去了」，一年五到八條，還專收「未遂里程碑」。它故意不給「自動生成正文」的腳本：統計只說明反覆提到什麼，跳過精讀的必然是換年份也成立的廢話。

應用範圍

用在「生活」這一格。得先有幾年成體量的日記，沒日記它無事可做。看板的時間線直接讀洞察里人工標的條目，洞察沒寫就是空的，順序只能先 A 再 B。單頁 HTML 有 1.1 MB，正文說這是把 ECharts 內聯進去換離線可用的刻意取捨。

如何使用

  • 就按「把十年日記攤成一張可下鑽的年輪看板」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/PandaDalmore/annual-diary-insight.git
mv annual-diary-insight ~/.claude/skills/annual-diary-insight
