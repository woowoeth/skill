做什麼用

學生交來的作業總是一團亂？把它變成一眼能檢查的格式：題幹、算式、答案分開寫，批改時不用再猜他到底會不會。不是模板，是強制分欄——學生必須把「想的過程」和「算的結果」分開，老師一眼看出卡在哪一步。

應用範圍

用在「玩樂」這一格。只處理數學科文字題，不認圖形題、不認選擇題；輸出是工作紙版面，不負責出題或批改。

如何使用

  • 就按「數學題拆成三步：題幹、算式、答案各佔一格」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/sja-homeworkclass/skills.git
cp -r skills/homework-tutor ~/.claude/skills/數學科-極簡步驟工作紙-課題名稱-topic
