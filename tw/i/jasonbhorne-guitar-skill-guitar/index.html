只給和絃走向、絕不替你抄歌詞的吉他譜生成器

說一個歌名，它出一份坐下就能彈的譜：和絃圖、帶小節數的段落結構、前奏 riff 和 solo 的六線譜。

jasonbhorne

做什麼用

說一個歌名，它出一份坐下就能彈的譜：和絃圖、帶小節數的段落結構、前奏 riff 和 solo 的六線譜。譜裡只有和絃走向、不含歌詞——它讓你自己從有授權的來源補上，並寫明這些譜不許轉發。

應用範圍

用在「玩樂」這一格。冷門曲目它會標 MEDIUM/LOW 置信度，讓你自己對著錄音核哪幾段是猜的。和絃圖靠隨件 python 腳本渲染成 ASCII，沒有五線譜也沒有音頻。譜固定存到 ~/Documents/Guitar/Songs 下。它給的是「大概是這樣」，不是官方譜。

如何使用

  • 就按「只給和絃走向、絕不替你抄歌詞的吉他譜生成器」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/jasonbhorne/guitar-skill.git
cp -r guitar-skill/guitar ~/.claude/skills/guitar
