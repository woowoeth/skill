gnipbao

做什麼用

上傳一張照片，它先用本地神經網絡抽出線稿，再一筆一筆畫出來、配一隻跟著筆尖走的手。兩個本地模型一個都沒裝時，它規定必須直接失敗 —— 不許用邊緣檢測糊一版弱線稿交差。

應用範圍

用在「做圖」這一格。它只是適配層：引擎要 pip 裝另一個倉庫，Informative Drawings 或 Anime2Sketch 至少裝一個並設環境變量，而模型的安裝指南在引擎倉庫裡、不在這一件。一個都沒裝時它直接失敗，不給降級方案。

如何使用

  • 就按「線稿只准本地模型抽、不許 AI 生成的白板手繪視頻」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/gnipbao/codex-whiteboard-video-skill.git
