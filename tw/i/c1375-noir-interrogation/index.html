做什麼用

玩推理最怕 AI 中途被你說服改口。這個把答案的哈希公示在開場簡報裡，你一間間審嫌疑人，它只照腳本發的卡演。困難模式會塞進一個指錯人的假證人。

應用範圍

用在「玩樂」這一格。一局 5–15 分鐘，單場結束就完，不做多線戰役。只有黑色電影一種類型，中途要奇幻或科幻會被拒絕；兩套設定是 1940 年代美式與 1930 年代民國上海。作者明寫不許 agent 去 Read 或 cat 案件 JSON，一旦繞過腳本。

如何使用

  • 就按「審問式追問，直到你交出真需求」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/c1375/noir-interrogation.git
