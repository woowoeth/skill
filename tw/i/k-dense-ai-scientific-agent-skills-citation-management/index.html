K-Dense-AI

做什麼用

檢索 OpenAlex、PubMed、Google Scholar，抽取準確元數據、校驗引用、格式化文獻——引用錯誤終結者。AI 編造引用是學術圈最怕的事，它反其道而行：每條引用都可驗證、有出處。

應用範圍

用在「工作」這一格。要 Python 3.9+ 和 requests，還要連得上 openalex、crossref、pubmed。Google Scholar 沒有 API，靠 scholarly 爬，每條歇 2 到 5 秒還常被封，作者自己說只能當補充。

如何使用

  • 就按「每條引用都回數據庫核驗，揪出 AI 編造的參考文獻」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

git clone --depth 1 https://github.com/K-Dense-AI/scientific-agent-skills.git
cp -r scientific-agent-skills/skills/citation-management ~/.claude/skills/citation-management
