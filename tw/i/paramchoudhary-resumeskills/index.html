做什麼用

投了 50 份沒回音？不是你不配，是簡歷沒撞對 ATS 的鐘。這套技能把求職拆成可執行的每一步。不是單個提示詞，而是按求職流程分模塊的技能集合：簡歷重寫、ATS 掃描、面試模擬各司其職。

應用範圍

用在「生活」這一格。只覆蓋求職文本與面試話術，不生成職位匹配度報告，也不替你做薪資談判。需要你已有目標 JD 或簡歷原文。

如何使用

  • 就按「只改動詞和數字就過篩的簡歷潤色師」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/Paramchoudhary/ResumeSkills.git
