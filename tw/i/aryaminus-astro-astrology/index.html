做什麼用

西洋、印度、八字三套盤都由本地引擎實算，再按古典規則解讀；三套說法一致的地方才當結論，絕不憑記憶報行星位置。底線只有一條：引擎算天空，模型只負責讀。和會胡編行星位置的聊天機器人不是一類東西。

應用範圍

用在「玩樂」這一格。解讀是占星傳統不是科學；健康只談體質傾向並讓你去看醫生；要跑本地 Python，角秒精度和 Placidus 宮位需另裝 pyswisseph。

如何使用

  • 就按「本地星曆實算西洋·印度·八字三盤」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/aryaminus/astro.git
cp -r astro/skills/astrology ~/.claude/skills/astrology
