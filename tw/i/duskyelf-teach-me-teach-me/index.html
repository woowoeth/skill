會打斷你含糊用詞的蘇格拉底式陪練

先把話題鋪成一棵樹，分清哪一層只是分支、哪一層才是研究者真在吵的分歧，然後一路反問你。

duskyelf

做什麼用

先把話題鋪成一棵樹，分清哪一層只是分支、哪一層才是研究者真在吵的分歧，然後一路反問你。分支和真分歧不是一回事：監督對自監督只是分支，數據越多是否傷泛化才是分歧。

應用範圍

用在「生活」這一格。它不給答案，只逼你想，急著要結論時會很難受；會話日記落在 diary/ 下；配套的文獻綜述依賴 Semantic Scholar 和聯網搜索，沒網時它會把整棵樹標成未驗證。

如何使用

  • 就按「會打斷你含糊用詞的蘇格拉底式陪練」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/duskyelf/teach-me.git
cp -r teach-me/skills/teach-me ~/.claude/skills/teach-me
