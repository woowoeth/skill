做什麼用

發視頻/文章前先盲猜數據，三天後復盤校準。內置觀點視頻 rubric，也能導入對標賬號當初始信號源。把「感覺會火」變成可驗證的假設——先打分再盲猜，復盤時逼你面對偏差，rubric 隨每次反饋進化。

應用範圍

用在「做圖」這一格。只適用於能拿到量化反饋的內容（播放/閱讀/收聽/點擊）。首次必須跑 /hit-init 初始化。

如何使用

  • 就按「發完先別走，三天後回來對答案的內容預測循環」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/rose-for-future/hit-lab.git
mv hit-lab ~/.claude/skills/hit-lab
