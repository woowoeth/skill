旅行照片做成記憶貼紙卡

厭倦了千篇一律的濾鏡？上傳照片，得到一張帶手賬貼紙、紙紋和笨拙色塊的雜誌風卡片，像從舊刊撕下來的一頁。

做什麼用

厭倦了千篇一律的濾鏡？上傳照片，得到一張帶手賬貼紙、紙紋和笨拙色塊的雜誌風卡片，像從舊刊撕下來的一頁。產出是能收藏的貼紙卡，不是又一段旅行 vlog 文案。

應用範圍

用在「生活」這一格。卡片規格鎖死。要長圖文筆記、要地圖軌跡，不是這件的活。

如何使用

  • 就按「旅行照片做成記憶貼紙卡」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/carolinaaafy/travel-memory-sticker-card.git
mv travel-memory-sticker-card ~/.claude/skills/travel-memory-sticker-card
