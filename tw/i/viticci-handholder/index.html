做什麼用

新掌機到手最怕重設模擬器、丟通關存檔。它直接走 ADB 接管 Cocoon、RetroArch 熱鍵著色器。不是給模擬器套殼，而是用 ADB 直接讀寫設備分區，遷移合法 ROM 和存檔時保留原始目錄結構。

應用範圍

用在「玩樂」這一格。僅限 Android 掌機且需本機 ADB 環境；不含 iOS/Windows 設備、不代找 BIOS。

如何使用

  • 就按「ADB 直連掌機，換機遷移不丟存檔不重配按鍵」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/viticci/handholder.git
mv handholder ~/.claude/skills/handholder
