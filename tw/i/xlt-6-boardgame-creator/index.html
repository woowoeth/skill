做什麼用

點子有了，卡在「到底好不好玩」。它先把 6–10 個關鍵決策一次交底，再逼出一份今天就能手寫出來的紙面原型。它給自己上了禁令：沒經過真人試玩只能說「可試玩」，不能說「平衡」——紙面審查只找風險，不發合格證。

應用範圍

用在「玩樂」這一格。平衡只能靠真人試玩驗，所以你得自己湊齊人——它明寫紙面審查不能證明平衡。交付物是紙面原型，美術、量產、眾籌一概不管，第一版明說不追求出版。多視角批評裡連「易感到被針對者」都算上了，但那仍是模擬，不是玩家。不做電子遊戲實現。

如何使用

  • 就按「從靈感草稿到朋友試玩，一張桌遊的完整出生證明」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/XLT-6/boardgame-creator.git
mv boardgame-creator ~/.claude/skills/boardgame-creator
