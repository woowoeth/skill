照片留一條證據帶，碎成幹印再暈成水墨

不整幅糊成水墨，而是保留原圖證據帶，把畫面碎成乾涸印刷記憶，再暈出源圖色相的彩色殘像。適合做編輯感攝影印刷轉譯。

Starryear

做什麼用

不整幅糊成水墨，而是保留原圖證據帶，把畫面碎成乾涸印刷記憶，再暈出源圖色相的彩色殘像。適合做編輯感攝影印刷轉譯。證據帶鎖住真實，幹印碎形切斷柔焦慣性，色相殘像從源圖反推——三層機制讓每張輸出都是可核驗的轉譯。

應用範圍

用在「生活」這一格。只接受單張豎幅照片，橫圖或組圖會直接停。不做全幅水墨濾鏡，也不仿傳統山水。產物是編輯感印墨版面，不是可打印的高清原圖。

如何使用

  • 就按「照片留一條證據帶，碎成幹印再暈成水墨」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

git clone --depth 1 https://github.com/Starryear/Starryear-Ink.git
