做什麼用

PR、評論、郵件、聊天……凡是要給人看的文字，先讀規則再落筆。省得發出去才後悔，收回來又尷尬。它不是事後檢查，而是前置約束。在起草任何對外文本前強制加載規則，從源頭減少冒犯與誤解。

應用範圍

用在「工作」這一格。僅約束 AI 生成的對外文本，不覆蓋語音、表情符號或非文字媒介；若你已習慣手動檢查，此技能可能顯得多餘。

如何使用

  • 就按「動筆前先過一遍人類溝通守則的 AI 助手」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

安裝

git clone --depth 1 https://github.com/danielroe/empathy.git
mv empathy ~/.claude/skills/empathy
