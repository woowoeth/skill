做什麼用

講思路時精確框圖顯得冷，手繪草圖更讓人願意看。它出真正的 Excalidraw 文件，畫完你還能自己拖著改。產物是可編輯源文件而不是截圖——這一點決定了它能進日常工作流，而不只是配圖。

應用範圍

用在「做圖」這一格。必做的渲染校驗要用 uv 裝 Playwright 和 Chromium。正文禁止寫腳本生成、禁止轉交別的 agent，只能一段段手敲 JSON，再渲染—看圖—改，通常來回 2-4 輪。 隨件的渲染模板從 esm.sh 拉 excalidraw，傳遞依賴現在 404、腳本會等到超時；釘版本到 0.18.0 才渲得出來。

如何使用

  • 就按「生成手繪白板風格的示意圖」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/coleam00/excalidraw-diagram-skill.git
mv excalidraw-diagram-skill ~/.claude/skills/excalidraw-diagram-skill
