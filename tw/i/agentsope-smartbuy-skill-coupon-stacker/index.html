疊券順序算得比下單頁還清楚的小賬本

做什麼用

標價+一堆券丟進去，按平臺真實疊加順序算出實付，還一步步告訴你下單頁怎麼點。不編規則，不知道就讓你去查官方。不猜券規則，只按平臺真實疊加順序算；每一步操作都落到下單頁具體位置，算完即會買。

應用範圍

用在「玩樂」這一格。只覆蓋京東自營（平臺券+國補+Plus+滿減）；天貓/拼多多/蘇寧暫不適用。不處理預售、定金膨脹、限時秒殺價。

如何使用

  • 就按「疊券順序算得比下單頁還清楚的小賬本」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

git clone --depth 1 https://github.com/agentsope/smartbuy-skill.git
