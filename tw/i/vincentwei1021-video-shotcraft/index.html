做什麼用

用 Remotion 拍電影感產品視頻：106 張分鏡配方卡、161 個運鏡預設，一句話描述產品就能出一支成片。把「拍產品宣傳片」這種要外包的活變成了本地技能，分鏡卡的設計尤其講究。

應用範圍

用在「做圖」這一格。要 Remotion 工程和 npm，真實頁面鏡頭必須起本地 dev server 用無頭瀏覽器截圖。剪映導出走 pyJianYingDraft，Mac 剪映 11.2 實測過，Windows 那支沒真機驗證。

如何使用

  • 就按「照著 106 張分鏡配方卡，把一句話拍成產品宣傳片」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

git clone --depth 1 https://github.com/Vincentwei1021/video-shotcraft.git
