做什麼用

表面改詞沒用——它專治段落級AI腔：強行昇華的結尾、單線敘事、情緒表演。基於2026敘事結構研究，只動骨架不動血肉。多數去AI工具只換詞，它拆的是敘事骨架——識別並移除'教訓式結尾''情緒表演''含糊指涉'等結構痕跡。

應用範圍

用在「寫字」這一格。只處理英文文本；需要輸入為完整篇章（非單句）；不保證改寫後風格統一，可能讓文字更鬆散；無中文支持，中文用戶請勿安裝。

如何使用

  • 就按「專刪AI味敘事骨架，留下你原本的毛邊」這一件來做，不要中途改風格。
  • 按它的句式改這一段，能刪就刪。
  • 先標出越界的句子，再重寫，不要通篇潤色。
  • 寫完對照應用範圍，串味就停。

安裝

git clone --depth 1 https://github.com/NulightJens/humanizer-stack.git
cp -r humanizer-stack/skills/structural-humanizer ~/.claude/skills/structural-humanizer
