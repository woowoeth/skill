做什麼用

混排中英文標點、表格頁碼、公文模板一鍵歸一。Codex 改完的 Word 不再被領導退回重排，修訂痕跡想留就留。不是零散宏命令，而是按中文辦公流程組織的成套動作：先診斷再修，模板與自定義並存，批註修訂有明確開關。

應用範圍

用在「工作」這一格。只認 .docx/.doc/.wps 輸入，輸出為 DOCX；不處理 PDF 或掃描件。

如何使用

  • 就按「中文公文排版一步到位，連修訂痕跡都替你管好」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

安裝

git clone --depth 1 https://github.com/KaguraNanaga/document-format-skills.git
mv document-format-skills ~/.claude/skills/document-format-skills
