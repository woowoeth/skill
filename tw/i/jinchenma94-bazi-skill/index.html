做什麼用

報上出生信息，它按窮通寶典、滴天髓等典籍排盤解盤。不玩星座式泛談，每句斷語都標得出處，像帶了一位老派命理師。中文現場裡少見把八字寫成可裝 skill 的。它賣的是排盤方法，不是雞湯運勢。

應用範圍

用在「玩樂」這一格。術數有門派。它按作者那一套排，跟你師傅不是同一宗時，結論對不上。不算命準不準的擔保。

如何使用

  • 就按「四柱八字，把生辰當成一張表來排」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/jinchenma94/bazi-skill.git
