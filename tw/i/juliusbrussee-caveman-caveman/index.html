做什麼用

讓 Claude 像原始人一樣說話：「為什麼用很多 token，少 token 就行」——據稱實測省 65% token，還越用越上頭。一個玩笑做成了真產品：token 賬單實打實地降（據稱 65%），還順手治好了 AI 的囉嗦病。

應用範圍

用在「玩樂」這一格。65% 是作者自己標註的實測，正文沒給測法。凡是寫到聊天之外的字——代碼註釋、commit、文檔、issue、記憶文件——一律恢復正常散文，那部分省不到。安全警告也自動切回。

如何使用

  • 就按「讓 Claude 用原始人腔說話，據稱省下 65% 的 token」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/JuliusBrussee/caveman.git
cp -r caveman/plugins/caveman/skills/caveman ~/.claude/skills/caveman
