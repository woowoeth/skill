只記你說過的話，不替你補半句的人生訪談錄

做什麼用

一場一場地採訪你或你父母的人生，逐字稿原樣留檔，另出一份下次接著問的筆記；成不成書隨你，檔案先歸你自己。不許遞一個細節讓老人點頭確認：「大概 2003 年冬天吧」進待核清單，正文寫「我不確定」。

應用範圍

用在「寫字」這一格。它只採訪在場的本人，不替不在場的人寫傳記，也拒絕改寫成簡歷、領英簡介或創始人故事。情緒一上來就全停：只給「留在這裡／換話題／今天到這」三個選項，一個追問都不許有。倉庫 dev/ 目錄裡抄了同行的整份 skill 當對照，安裝時別一起拷進去。

如何使用

  • 就按「只記你說過的話，不替你補半句的人生訪談錄」這一件來做，不要中途改風格。
  • 按它的句式改這一段，能刪就刪。
  • 先標出越界的句子，再重寫，不要通篇潤色。
  • 寫完對照應用範圍，串味就停。

安裝

git clone --depth 1 https://github.com/elhamid/as-told-to.git
cp -r as-told-to/as-told-to ~/.claude/skills/as-told-to
