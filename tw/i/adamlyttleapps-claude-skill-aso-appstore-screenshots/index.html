做什麼用

獨立開發者最不擅長又最影響下載量的就是商店截圖。它先讀你的代碼庫找出核心賣點，再生成 ASO 優化的展示圖。從代碼反推賣點，比對著空白頁想文案聰明——素材來自產品本身而不是想像。

應用範圍

用在「工作」這一格。檢測不到 Gemini MCP（npm i -g gemini-mcp）它就直接停手不生成；裁切那步調的是 macOS 專有的 sips。尺寸只給 iPhone 6.5/6.7/6.9 三種，沒有 iPad，模擬器截圖還得你自己拍。 compose.py 把字體寫死成 /Library/Fonts/SF-Pro-Display-Black.otf，macOS 不自帶、缺了直接崩沒兜底；第二段還要付費模型。

如何使用

  • 就按「從代碼反推賣點生成 App Store 截圖」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

安裝

git clone --depth 1 https://github.com/adamlyttleapps/claude-skill-aso-appstore-screenshots.git
mv claude-skill-aso-appstore-screenshots ~/.claude/skills/claude-skill-aso-appstore-screenshots
