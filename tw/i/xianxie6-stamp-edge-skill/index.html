做什麼用

不用摳圖、不用白邊，孔洞處 alpha 全零，拖到深色海報上也乾淨。多張還能自動拼成等寬瀑布流郵票合集。孔洞不是畫上去的白色模擬，而是 alpha=0 的真透明；投影柔和且只在孔洞外緣，疊深色底不露灰塊。

應用範圍

用在「做圖」這一格。只處理位圖（PNG/JPG/WebP），不認 SVG/PDF；輸出固定 300 DPI 的 PNG。

如何使用

  • 就按「原圖四周直接打半圓孔，真透明背景的郵票生成器」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/xianxie6/stamp-edge-skill.git
