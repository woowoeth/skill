做什麼用

回放 argent 流程錄屏，給截圖套機身邊框、配底色和文案，出 4~5 張成品加一段預覽視頻，本地起個 studio 按真實商店頁排給你看。預覽視頻它堅持交原始錄屏不加邊框字幕——因為蘋果就是這麼要求的，它沒替你「美化」成會被打回的東西。

應用範圍

用在「做圖」這一格。要在這個 App 自己的倉裡跑，且要有 iOS 模擬器或安卓模擬器。挑哪幾屏值得營銷、寫流程、寫文案還是你的活，它只負責跑和渲。studio 起在 localhost:4321，視頻在後臺渲。

如何使用

  • 就按「重放 App 操作錄屏，套上真實商店頁邊框和文案」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/kacperkapusciak/goldie.git
cp -r goldie/skills/goldie ~/.claude/skills/goldie
