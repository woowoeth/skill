做什麼用

到了當地沒網、翻聊天記錄找攻略最抓狂。它出單文件 HTML：交互地圖 + 每日時間軸 + 出發前訂票提醒，存手機上離線可讀。「離線可讀、手機優先、單文件」——這三個約束是真在國外用過才想得到的。

應用範圍

用在「生活」這一格。地圖引的是 Leaflet CDN，所謂「離線可讀」保得住文字和時間軸，地圖那塊斷網就是空的。實時票價、代訂票、多語言、後端，作者在「不做」一節裡明寫一概不做。最後那步校驗要本機有 node 跑 assets/validate.js。

如何使用

  • 就按「離線可讀的手機旅行頁，地圖時間軸訂票提醒一頁裝完」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/zexuanw958-svg/travel-plan-viz.git
cp -r travel-plan-viz/travel-plan-viz ~/.claude/skills/travel-plan-viz
