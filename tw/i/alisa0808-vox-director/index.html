做什麼用

一個主題進去，一支 Vox 風紙拼貼解說視頻出來：腳本、拼貼關鍵幀、配音、剪輯全自動跑完。Vox 的拼貼美學是解說視頻的天花板之一，這件把整個片場壓進了一條命令。

應用範圍

用在「做圖」這一格。整條鏈只跑 Atlas Cloud 一家，沒有 ATLASCLOUD_API_KEY 就只剩一份提示詞清單讓你自己去粘。本機還要 ffmpeg 和 Pillow。真人和品牌 Omni 會拒，得改用 Kling。

如何使用

  • 就按「給一個主題，出一支 Vox 式紙拼貼解說視頻」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/Alisa0808/vox-director.git
mv vox-director ~/.claude/skills/vox-director
