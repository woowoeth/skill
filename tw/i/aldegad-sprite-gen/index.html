做什麼用

一句話出一套乾淨的 2D 遊戲精靈圖：狀態行排布、透明底、逐幀拆分、運行時圖集，產物直接丟進遊戲引擎就能用。遊戲素材是獨立開發最大的坑之一，它把「畫小人」變成了一句話的事，產物直接進引擎。

應用範圍

用在「做圖」這一格。生成那步要本機裝好 codex 或 grok CLI 並登錄。腳本只認倉庫自建的 .venv，缺 NumPy 就在 import 處硬報錯——作者明寫沒有純 Python 降級。正文大半是韓文。

如何使用

  • 就按「組件行流水線出精靈圖集，帶 QA 報告和運行時清單」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。
