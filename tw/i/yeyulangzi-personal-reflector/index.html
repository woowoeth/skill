做什麼用

當焦慮、自我懷疑、關係困局反覆出現，它不給你雞湯，而是幫你照見舊系統如何運作、新系統卡在哪，讓轉型期不再原地打轉。它不分析你，而是鏡像你——把情緒事件拆成可觀察的模式與觸發點，像一面會提問的鏡子。

應用範圍

用在「玩樂」這一格。只覆蓋個人內心議題（情緒、身份、方向），不處理外部決策或人際衝突的具體解法；產物是結構化反思而非行動方案。

如何使用

  • 就按「不餵雞湯只拆模式的自我復盤鏡」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/yeyulangzi/personal-reflector.git
mv personal-reflector ~/.claude/skills/personal-reflector
