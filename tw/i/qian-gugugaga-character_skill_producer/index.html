做什麼用

本地腳本檢索萌娘百科等站點，五路並行調研，交叉驗證後蒸出三到七條可執行的行為規則。它抓的是她怎麼行動，不是她說過什麼：標籤給人看，行為規則給 AI 執行。

應用範圍

用在「玩樂」這一格。要 Python，且默認只跑最高保真模式，很費 token；來源黑名單排除知乎、公眾號和百度百科；生成的角色包會寫死資料截止日期，作品一齣新劇情就得重跑。

如何使用

  • 就按「只寫「她會怎麼反應」不抄臺詞的角色蒸餾器」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/qian-gugugaga/character_skill_producer.git
mv character_skill_producer ~/.claude/skills/csp
