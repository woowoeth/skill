做什麼用

由 12 年產品老兵帶路：把純新手的模糊點子變成能開工的計劃，邊建邊教 GitHub 和乾淨代碼習慣。vibe coding 時代最缺的是「有人扶一把」，這件就是那隻手，姿勢還很專業。

應用範圍

用在「工作」這一格。調研這步靠抓 Reddit 和 G2 評論，抓不動就退成把網址和搜索詞交給你自己去粘。作圖引擎要瀏覽器和臨時文件，跑不起來退回 mermaid。正文全英文，且明說不管有經驗開發者的調試、重構和 CI/CD。

如何使用

  • 就按「帶純新手把模糊點子變成計劃，順手教會他用 GitHub」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。
