做什麼用

把計劃寫成 Markdown 文件常駐磁盤：崩潰、/clear、上下文壓縮都不丟進度，隨時從斷點接著施工。長任務的命根子是「狀態不丟」，它用最樸素的文件方案解決，比花哨的記憶系統皮實。

應用範圍

用在「工作」這一格。裝法決定功能：npx skills add 裝的沒有 /plan-goal 和 /plan-loop。「沒做完不許停」的門也只在 Claude Code、Codex CLI 真攔得住，OpenCode、Gemini CLI 只彈提示。

如何使用

  • 就按「任務拆解寫到磁盤，/clear 後自動續上進度」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

git clone --depth 1 https://github.com/OthmanAdi/planning-with-files.git
