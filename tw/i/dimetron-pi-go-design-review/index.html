做什麼用

Go 裡「能跑」和「地道」差得遠。命名、結構、一致性、接口、錯誤處理逐維打分，還附可執行的修法。按維度打分讓評審意見特別可落地，不是籠統說「建議重構」。

應用範圍

用在「做圖」這一格。正文明說單個 PR 或未提交 diff 不歸它管，那要另一件 code-review。而且末尾嵌著 pi-go 這個項目自己的檢查項（ADK、internal/provider/、禁 init()），換倉庫得先刪。

如何使用

  • 就按「給 Go 代碼庫做地道性評審」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。

安裝

git clone --depth 1 https://github.com/dimetron/pi-go.git
cp -r pi-go/.pi-go/skills/design-review ~/.claude/skills/design-review
