做什麼用

跑到第十次團，線索、NPC 和 SAN 值散在十份記錄對不上。它把表寫進 Markdown，檢索交給 SQLite。寫入只追加 Markdown、查詢只走 SQL，寫壞一行只壞一行——為的是不像 JSON 那樣整份報廢。

應用範圍

用在「玩樂」這一格。名字是它唯一的跨文件索引鍵，寫簡稱或錯一個字就斷聯，NPC 和線索接不上。它是玩家側的副官，不主持、不替角色做決定，想找人開團的別裝。跑起來要 Python 和 SQLite，還得先用內置模板生成一份項目級規則再用。

如何使用

  • 就按「跑團桌旁幫你車卡歸檔線索的副官，防超遊」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/JadeL-Kemo/trpg-log-copilot-skill.git
mv trpg-log-copilot-skill ~/.claude/skills/trpg-log-copilot
