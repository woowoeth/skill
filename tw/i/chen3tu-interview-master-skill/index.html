做什麼用

把招聘要求拆成可演練的追問清單，模擬面試後自動生成改進點，連薪資談判話術都備好——不是泛泛的面試題庫。它先解析目標崗位的能力權重，再據此生成問題與追問，模擬後按你的回答逐條對照JD差距。

應用範圍

用在「生活」這一格。需要你提供具體崗位JD或簡歷文本；不覆蓋線下面試的肢體語言、眼神接觸；產出的模擬問答是文字稿，無語音交互。

如何使用

  • 就按「從崗位JD反推面試題，練完還帶復盤和談薪」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/chen3tu/interview-master-skill.git
mv interview-master-skill ~/.claude/skills/interview-master
