做什麼用

做舟、終末地還是工業科幻落地頁？先報產品家族和複雜度檔位，再按證據庫出稿——不套模板，不猜風格，直接對齊鷹角審美。把「像不像鷹角」從玄學變成可審計流程：每個視覺決策都掛到產品族與深度檔的證據鏈上，改稿有據可依。

應用範圍

用在「做圖」這一格。只認鷹角系產品族（方舟/終末地/羅德島/工業科幻/編輯式遊戲UI），非該語境的通用網頁設計會硬套風格。

如何使用

  • 就按「鷹角視覺語言先問產品線再定深度的界面設計器」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。
