做什麼用

核對合同、報表、聊天記錄裡的數字時，不用再翻頁找半天。它直接定位到那一行，高亮截圖，讓你拿著圖去對質。不是摘要，不是引用——它把視覺證據直接釘在頁面上。你看到的就是對方看到的。

應用範圍

用在「工作」這一格。只認 PDF 文件內的文字層；掃描版或圖片型 PDF 需先經 OCR 才能用。高亮截圖止於單頁。

如何使用

  • 就按「PDF 裡哪個數在哪一頁，截圖圈給你看」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

git clone --depth 1 https://github.com/metedata/pdf-proof.git
