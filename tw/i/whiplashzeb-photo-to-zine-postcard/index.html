照片收成一張可寄的刊物明信片

一張明信片的版心，不是長圖文

Whiplashzeb

做什麼用

一張明信片的版心，不是長圖文。旅行照片壓進可寄出的薄頁：圖在上、字很少。

應用範圍

用在「玩樂」這一格。頁是明信片。要畫冊、要九宮格、要視頻封面，對不上。

如何使用

  • 就按「照片收成一張可寄的刊物明信片」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/Whiplashzeb/photo-to-zine-postcard.git
mv photo-to-zine-postcard ~/.claude/skills/photo-to-zine-postcard
