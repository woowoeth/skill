做什麼用

別再猜對手憑什麼排你前面。輸入對方域名，直接列出你缺哪些詞、每個詞能帶來多少流量、值不值得搶。附可贏性評分。不是簡單差集。它把每個缺口詞按搜索量和你的現有排名綜合打分，告訴你先搶哪個、哪個搶了也白搶。

應用範圍

用在「工作」這一格。只認公開搜索數據，不覆蓋 Google Ads 私有詞或長尾意圖；需要你已配置搜索 API 密鑰。產物是候選詞表。

如何使用

  • 就按「專挖對手有而你沒有的搜索詞，按流量和可贏性排好序」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。
