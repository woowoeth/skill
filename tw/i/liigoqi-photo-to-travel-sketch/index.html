旅行照片收成趕路速寫

黑線亂走、大量省略，像纖維筆當場畫

liigoQi

站方按它的能力做的樣張，不是產出物截圖

做什麼用

黑線亂走、大量省略，像纖維筆當場畫。觀察式速寫，不是精修風景畫。走得快，輪廓亂，故意少畫。

應用範圍

用在「生活」這一格。要乾淨線稿、要上色完成稿，會嫌它髒。

如何使用

  • 就按「旅行照片收成趕路速寫」這一件來做，不要中途改風格。
  • 按我給的現場條件出方案，條件不夠就說做不到。
  • 不要寫成對誰都適用的攻略。
  • 結論裡把限制寫在最前面。

安裝

git clone --depth 1 https://github.com/liigoQi/photo-to-travel-sketch.git
mv photo-to-travel-sketch ~/.claude/skills/photo-to-travel-sketch
