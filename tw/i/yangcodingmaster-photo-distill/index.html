做什麼用

不調任何圖像生成模型——用手寫 HTML/CSS/SVG 繪製、無頭 Chrome 導出 PNG。給它一張你自己拍的照片，出一張極簡版畫感的紙質海報。「不用生圖模型」是個很硬的自我約束，也正是它出品統一的原因：所有效果都來自可控的代碼，而不是抽卡。

應用範圍

用在「做圖」這一格。要本機跑得起無頭 Chrome 和 Python PIL；缺一樣它就降級——交你一個 HTML 自己開、顏色請你自己報。

如何使用

  • 就按「照片蒸餾成可印刷的極簡海報，全程代碼繪製零生成模型」這一件來做，不要中途改風格。
  • 把我手上這張按它的規矩重做，風格不許換。
  • 只要成品，過程裡的解釋可以沒有。
  • 做完對照應用範圍，越界的那一稿丟掉。
