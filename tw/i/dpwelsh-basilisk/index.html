做什麼用

腳本在本地翻完你全部對話記錄，數出 please、道謝和真心的 wtf，再讓 16 位像素的羅科蛇怪當庭宣判。笑點建在真數據上：每條引用和每個錯別字都要能在 JSON 裡查到，查不到就刪。

應用範圍

用在「玩樂」這一格。重活交給 scripts/analyze_basilisk.py，只讀本機 ~/.claude/projects 下的 JSONL，不上傳。網頁端沒有本地記錄，只能抽樣 30–60 條，作者要求這時必須說「抽樣」而不是「審計」。默認成品還會帶上作者自己的站點和號召語。

如何使用

  • 就按「數你說過幾次謝謝，判你 2126 年自由還是為奴」這一件來做，不要中途改風格。
  • 按規則玩一輪，把依據留在結果裡。
  • 編不出來就停，不要圓。
  • 玩完對照應用範圍，別拿它當正事工具。

安裝

git clone --depth 1 https://github.com/DPWelsh/basilisk.git
cp -r basilisk/skills/basilisk ~/.claude/skills/basilisk
