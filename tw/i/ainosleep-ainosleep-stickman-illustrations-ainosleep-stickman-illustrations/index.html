做什麼用

寫方法論、流程、狀態、隱喻時總找不到不搶戲的配圖？這套自帶輕表情的火柴人，默認大量留白，像文檔頁邊的手繪註釋。它不生成華麗插畫，而是鎖定“普通人視角”的極簡火柴人：白底、黑線、低強度表情。默認構圖就為正文留白。

應用範圍

用在「工作」這一格。只認中文正文配圖場景，不認海報、封面、Logo 或任何需要高情緒張力的圖。產物是單張靜態圖，不輸出多格漫畫或分鏡。

如何使用

  • 就按「白底黑線火柴人，給中文文章配安靜小圖」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

git clone --depth 1 https://github.com/AINoSleep/ainosleep-stickman-illustrations.git
cp -r ainosleep-stickman-illustrations/ainosleep-stickman-illustrations ~/.claude/skills/ainosleep-stickman-illustrations
