做什麼用

別再說「模仿文風」了——它把語言、結構、選題、素材、認知、視覺六層拆開蒸餾，寫新稿時連原文片段都調出來對照。不是泛泛的風格描述，而是從20篇完整文章裡提取可操作的規則，寫作時動態讀取DNA和原文。

應用範圍

用在「寫字」這一格。至少需要20篇完整原文，少於這個數它拒絕開工；只做文本風格分析，不含圖片視覺生成；產出是Markdown文檔。

如何使用

  • 就按「20篇原文榨出一份寫作DNA，新稿自動對齊老筆鋒」這一件來做，不要中途改風格。
  • 按它的句式改這一段，能刪就刪。
  • 先標出越界的句子，再重寫，不要通篇潤色。
  • 寫完對照應用範圍，串味就停。

git clone --depth 1 https://github.com/larashero3-dotcom/writing-dna-skill.git
