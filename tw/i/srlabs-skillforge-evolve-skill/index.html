做什麼用

別在空提示詞裡調技能了。丟給它一個倉庫，它會跑任務、看失敗、改指令，直到技能在你自己的代碼上真正變強。它把「優化技能」從拍腦袋改成閉環：以真實代碼庫為測試集，用失敗反推指令修改，每次迭代都有可驗證的進步。

應用範圍

用在「工作」這一格。只針對已安裝的 Claude Code 技能做迭代，不負責寫新技能；需要你提供可運行的目標倉庫和明確任務。

如何使用

  • 就按「拿真實代碼庫當考場，給已裝技能做迭代升級」這一件來做，不要中途改風格。
  • 按它的流程走完這一件，不要跳步驟。
  • 輸出要能進倉庫或工單，不要只給感想。
  • 做完對照應用範圍，越權的活另找工具。

安裝

git clone --depth 1 https://github.com/srlabs/skillforge.git
cp -r skillforge/.claude/skills/evolve-skill ~/.claude/skills/evolve-skill
