提交记录里不留 AI 署名的 git 守门员

每次 commit、PR、merge 都自动剥掉 Co-Authored-By 和 AI 生成脚注。

cd-ndk

做什么用

每次 commit、PR、merge 都自动剥掉 Co-Authored-By 和 AI 生成脚注。不是事后清理，而是拦截在写入动作前。它理解 git 全生命周期操作，在用户沉默时也默认执行。

应用范围

用在「工作」这一格。只处理 git/github 写入操作，不碰文件内容本身；若你确实想让 AI 署名，需显式配置例外名单。

如何使用

  • 就按「提交记录里不留 AI 署名的 git 守门员」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/cd-ndk/ghostwriter.git
