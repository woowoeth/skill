做什么用

想知道这周末附近有没有稀有鸟、哪个热点在出货，它直连康奈尔 eBird 官方接口取真实观察记录，不靠模型记忆瞎编。20 个端点逐个实测过，还写明哪两个已经 404/403、别调；观测数据一律来自接口，不许凭训练知识补。

应用范围

用在「生活」这一格。要自己去 ebird.org/api/keygen 申请免费 key，该 key 限非商业用途、并发超过 3 就 429。recent 端点最多回溯 30 天，全量历史得另申请 EBD。locale=zh 返回繁体台湾名（如「鉛色水鶇」），大陆常用名作者明说要自己维护别名表。

如何使用

  • 就按「查稀有鸟最近落在哪，顺带说清中文名是台湾译名」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

git clone --depth 1 https://github.com/r0ses1r-dev/BirdSight.git
