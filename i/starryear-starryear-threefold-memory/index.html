把一张照片变成上中下三段式记忆圣物

照片会骗人，记忆会碎。它把碎片拼成视觉拼贴、保留原图作证、再画一张空间信号图，让「看见的、发生的、留下的」各归其位。

Starryear

做什么用

照片会骗人，记忆会碎。它把碎片拼成视觉拼贴、保留原图作证、再画一张空间信号图，让「看见的、发生的、留下的」各归其位。不是滤镜，是结构。它把「记忆」拆成三层独立证据链，每层用不同视觉语法（拼贴/原图/信号图）说话。

应用范围

用在「生活」这一格。只吃单张用户照片，且必须能识别出空间路线或节点；否则信号图会退化成随机噪点。产物是竖版三拼图，不导出分层文件。

如何使用

  • 就按「把一张照片变成上中下三段式记忆圣物」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

git clone --depth 1 https://github.com/Starryear/Starryear-Threefold-Memory.git
