一张旅行照片出成三联画：所见、所在、所留

上层把照片重组成大块不规则碎片的视觉记忆，中层原片不动当证据，下层把路线、方向、情绪画成一张记忆地图。

Starryear

做什么用

上层把照片重组成大块不规则碎片的视觉记忆，中层原片不动当证据，下层把路线、方向、情绪画成一张记忆地图。它规定每一条路线、节点、碎片、图标、配色都必须从这张照片推出来，不许写死地点，也不许套装饰性的星座。

应用范围

用在「生活」这一格。只吃一张锁定的照片，三层等高竖排，版式不可改。下层的「记忆地图」是从照片推的空间信号，不是真地图，别拿它导航。仓里 3 个 SKILL.md，这是主件。

如何使用

  • 就按「一张旅行照片出成三联画：所见、所在、所留」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Starryear/Starryear-Threefold-Memory.git
mv Starryear-Threefold-Memory ~/.claude/skills/starryear-threefold-memory
