笔记变形记

把随手写的文字变成正经笔记：自动补 frontmatter、按标题改名、修好断掉的链接。不用手动整理，一步到位。

developmentskillzby
点评同类工具只做格式化，它却连文件名和反向链接一起修，让笔记真正融入你的知识库。

git clone --depth 1 https://github.com/zby/commonplace.git 然后把智能体指向这个 skill 目录即可。
