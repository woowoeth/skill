做什么用

让 Claude 像原始人一样说话：「为什么用很多 token，少 token 就行」——据称实测省 65% token，还越用越上头。一个玩笑做成了真产品：token 账单实打实地降（据称 65%），还顺手治好了 AI 的啰嗦病。

应用范围

用在「玩乐」这一格。65% 是作者自己标注的实测，正文没给测法。凡是写到聊天之外的字——代码注释、commit、文档、issue、记忆文件——一律恢复正常散文，那部分省不到。安全警告也自动切回。

如何使用

  • 就按「让 Claude 用原始人腔说话，据称省下 65% 的 token」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/JuliusBrussee/caveman.git
cp -r caveman/plugins/caveman/skills/caveman ~/.claude/skills/caveman
