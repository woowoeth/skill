design-harness

Drowning in options? Agent gathers evidence, you decide. Three-layer markdown board, synced on command, traceable.

Updated 2026-07-27 · Source https://github.com/tigerless-labs/design-harness/tree/HEAD/plugins/des…

What does this skill do?

A decision board for evidence-based calls — the human adjudicates, the agent runs the errands. Three layers (sources → ideas → output) in plain markdown, synced on the human's command, projected onto a visual canvas. Use for vendor/tool selection, literature reviews, due diligence, competitive analysis, or any contested call that must stand on traceable evidence — triggers like "file these papers"

Why is it worth installing?

Unlike auto-summarizers, it separates sources, ideas, and output, letting you trace every claim—you judge, it fetches.

How do you install it?

git clone --depth 1 https://github.com/tigerless-labs/design-harness.git Then point your agent at the skill directory.
