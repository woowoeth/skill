做什么用

新手写长篇最怕开头定错调、中途推倒重来。它把大纲、设定、章节拆成可编辑工件，每步先确认高影响创意选择。不是一次性吐稿机，而是把创作拆成可回退的工件链。受众渠道、题材热度、参考书拆解都先过你这一关。

应用范围

用在「写字」这一格。只服务中文长篇小说的规划与诊断，不产出最终排版文稿；需要你提供授权参考书或榜单元数据，否则只能停在通用大纲。

如何使用

  • 就按「分阶段产出可改稿的长篇中文小说，关键设定先问你」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

git clone --depth 1 https://github.com/ExplosiveCoderflome/ani-book-skill.git
