做什么用

讲思路时精确框图显得冷，手绘草图更让人愿意看。它出真正的 Excalidraw 文件，画完你还能自己拖着改。产物是可编辑源文件而不是截图——这一点决定了它能进日常工作流，而不只是配图。

应用范围

用在「做图」这一格。必做的渲染校验要用 uv 装 Playwright 和 Chromium。正文禁止写脚本生成、禁止转交别的 agent，只能一段段手敲 JSON，再渲染—看图—改，通常来回 2-4 轮。 随件的渲染模板从 esm.sh 拉 excalidraw，传递依赖现在 404、脚本会等到超时；钉版本到 0.18.0 才渲得出来。

如何使用

  • 就按「生成手绘白板风格的示意图」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/coleam00/excalidraw-diagram-skill.git
mv excalidraw-diagram-skill ~/.claude/skills/excalidraw-diagram-skill
