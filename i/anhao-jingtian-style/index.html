一份会替你按住抒情冲动的第一人称记账笔

短行白描、数字替情绪、称谓即关系、空置收尾——把情绪藏进劳动镜头里，第一人称记账体，克制到不像广告。

anhao

做什么用

短行白描、数字替情绪、称谓即关系、空置收尾——把情绪藏进劳动镜头里，第一人称记账体，克制到不像广告。不是仿写，是结构复刻：抵押对位、外围劳动、空置收束，每一句都有机制可循，改完自带景甜体的冷感。

应用范围

用在「写字」这一格。只认中文输入，英文稿会先译再改；只产出文案本身，不负责排版或配图；若原文无具体数字或劳动细节，需先补足才能动笔。

如何使用

  • 就按「一份会替你按住抒情冲动的第一人称记账笔」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/anhao/jingtian-style.git
mv jingtian-style ~/.claude/skills/jingtian-style
