做什么用

大块平涂色区，每区一种手工纹理（窗格点阵、缝线虚线、织纹颗粒、墨线轮廓），撒满做日常事的无脸小人。纸白、暖墨黑、2–4 个场景色，外加恰好一个饱和高亮色。那「恰好一个高亮色」必须真的在构图里干活，不是点缀——它把民间艺术的天真感变成了可执行的约束。

应用范围

用在「做图」这一格。小人是实心剪影、无脸、不许是火柴人——作者反复强调。照片只当语义参考，不复制细节。仓里 3 个 SKILL.md，这件是 outsider-art。

如何使用

  • 就按「大色块平涂加手工纹理，小人做日常事，只留一个高饱和点」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/fihaaade/skills.git
cp -r skills/outsider-art ~/.claude/skills/outsider-art
