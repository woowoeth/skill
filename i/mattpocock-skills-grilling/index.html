做什么用

做决策前总觉得自己想清楚了？让它连问二十个「为什么」，专挑你逻辑里最软的那块肉下嘴，直到你改口或认输。不是给建议，是专门制造认知失调。每轮追问都基于你上一句回答。

应用范围

用在「工作」这一格。只对「计划、决定、想法」三类对象开火，不负责查资料、不算数据、不提供替代方案。你给不出明确前提，它只会一直问下去。

如何使用

  • 就按「连续追问直到你自相矛盾的方案压力测试器」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/mattpocock/skills.git
cp -r skills/skills/productivity/grilling ~/.claude/skills/grilling
