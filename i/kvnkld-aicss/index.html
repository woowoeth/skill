做什么用

思考中、流式输出这类 AI 会话专用的界面部件，npm 装 React 版，或用 CLI 取 React／Vue／Svelte 源码直接落进你的项目。AI 产品的界面反复要造同一批零件，这里把它们做成了能直接取走的成品，还带在线预览。

应用范围

用在「工作」这一格。它不是 SKILL.md 形态的 agent skill，装不进 agent，是 npm 包和 CLI，要你自己写代码接。免费组件在 npm 上；Pro 组件不在，要用 CLI 配 AICSS_TOKEN，那是付费的。文档站是闭源的，这个仓只是包源码。

如何使用

  • 就按「AI 对话界面不重造轮子，现成思考态与流式输出组件」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。
