YouTube 长视频先切章再剪段，字幕同步烧进画面

你刷到一条 40 分钟访谈，只想留 3 分钟金句。它自动下载、按分钟切章节，你点选片段，字幕翻译、烧录。

op7418

做什么用

你刷到一条 40 分钟访谈，只想留 3 分钟金句。它自动下载、按分钟切章节，你点选片段，字幕翻译、烧录。章节粒度到分钟级，不是粗切；字幕翻译和烧录在同一流水线里完成，不用你导出后再找工具二次加工。选完片段。

应用范围

用在「写字」这一格。只吃 YouTube 链接，需能访问 YouTube；依赖 ffmpeg 和 yt-dlp 预装。

如何使用

  • 就按「YouTube 长视频先切章再剪段，字幕同步烧进画面」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/op7418/Youtube-clipper-skill.git
mv Youtube-clipper-skill ~/.claude/skills/youtube-clipper
