把 YouTube 长视频剪成带双语字幕的短视频片段

下载、AI 分章、选段、翻译、烧字幕一条龙。不用再开五个软件来回倒腾，几分钟级章节定位让找素材像翻目录。

做什么用

下载、AI 分章、选段、翻译、烧字幕一条龙。不用再开五个软件来回倒腾，几分钟级章节定位让找素材像翻目录。它把剪辑的脏活——字幕对齐、时间轴同步、翻译烧录——全包了，你只做选择题。AI 分章细到分钟级。

应用范围

用在「写字」这一格。只吃 YouTube 链接，其他平台不认；需要本机有 yt-dlp 和 ffmpeg；字幕翻译走默认引擎。

如何使用

  • 就按「把 YouTube 长视频剪成带双语字幕的短视频片段」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/op7418/Youtube-clipper-skill.git
mv Youtube-clipper-skill ~/.claude/skills/youtube-clipper
