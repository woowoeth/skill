做什么用

业务系统开发最怕需求漂移。这套 Skill 用七模型本体锁死需求、模型、代码三方对齐，每个探索阶段强制人工确认。别人用 prompt 写代码，它用 M1/M2/M3/M5/M6/M7/MU 七层本体当施工图。

应用范围

用在「工作」这一格。只认业务系统开发场景，且必须走完需求探索才能建模构建。单阶段入口仅限已有完整七模型 YAML 的项目。

如何使用

  • 就按「需求没逐条签字，代码一行都不生成」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/sharptoolbox/ontology-driven-dev.git
