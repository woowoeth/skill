做什么用

给文章配图总被嫌太满？它用极简黑线留白加一抹 #F97316 橙，把抽象观点变成《纽约客》式封面，公众号头图。不是生成一张图，而是先理解你要配的「观点」再构图——橙只出现一次，逼你选出真正重要的那个视觉焦点。

应用范围

用在「做图」这一格。只认英文提示词效果最佳；中文描述需自行翻译。只输出单张静态 SVG/PNG 风格插画，不生成多格漫画。

如何使用

  • 就按「白纸上只留一根橙线的编辑插画师」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/orange2ai/orange-line-illustration.git
mv orange-line-illustration ~/.claude/skills/orange-line-illustration
