压纸术

PDF胖成球？一键压缩，肉眼难辨画质损失。连扫描件里的噪点都帮你清掉，文件瘦身却像没动过刀。

documentationskillComPDFKit
点评别的工具只会无脑压像素，它懂得先剥离冗余内容，再按视觉重要性分配比特，所以小而不糊。

安装

git clone --depth 1 https://github.com/ComPDFKit/compdf-skills.git 然后把智能体指向这个 skill 目录即可。
