做什么用

长任务要跑一小时，你却得出门。把会话桥到 Telegram、飞书、微信，手机上发一句就能远程派活，干完还推给你。歸藏出品，解决的是真痛点：agent 的时间和人的时间从此不用绑在一起。

应用范围

用在「工作」这一格。本机得一直开着：桥是常驻 Node 进程，装完还要在 skill 目录 npm install 和 build。微信只能扫码绑一个号，没有内联授权按钮和流式预览，语音只收微信自己转的文字。飞书要两轮发版加管理员审批。

如何使用

  • 就按「从手机指挥电脑里跑着的 agent」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/op7418/Claude-to-IM-skill.git
mv Claude-to-IM-skill ~/.claude/skills/Claude-to-IM-skill
