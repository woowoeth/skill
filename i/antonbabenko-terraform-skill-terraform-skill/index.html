写 Terraform 时自动识别故障模式并给出版本

当你的 module 开始身份漂移、密钥泄漏、爆炸半径失控时，它不报错，而是告诉你这是哪一类故障、该往哪儿修。

antonbabenko

做什么用

当你的 module 开始身份漂移、密钥泄漏、爆炸半径失控时，它不报错，而是告诉你这是哪一类故障、该往哪儿修。不是 lint，是诊断器：按故障模式分类（身份漂移、密钥、爆炸半径、CI 漂移、状态损坏）。

应用范围

用在「写字」这一格。只覆盖 Terraform/OpenTofu 的 module 编写、测试、CI、扫描和状态操作。

如何使用

  • 就按「写 Terraform 时自动识别故障模式并给出版本」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/antonbabenko/terraform-skill.git
cp -r terraform-skill/skills/terraform-skill ~/.claude/skills/terraform-skill
