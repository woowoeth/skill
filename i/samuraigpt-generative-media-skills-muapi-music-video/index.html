歌变MV

给一首歌，自动拆成N个镜头，逐帧动画+配乐同步生成。不用剪辑软件，不用找素材，30秒出片。

creativeskillSamurAIGPT

安装

git clone --depth 1 https://github.com/SamurAIGPT/Generative-Media-Skills.git 然后把智能体指向这个 skill 目录即可。
