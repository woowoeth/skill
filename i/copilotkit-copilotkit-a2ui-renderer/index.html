CopilotKit

做什么用

AI不再只回文字，还能直接生成可交互界面。自动激活，无需手动传消息，一行配置即可让CopilotKit应用拥有原生。不同于传统流式文本，它通过/info自动激活渲染管线，从底层A2UIProvider到高层组件全链路打。

应用范围

用在「做图」。超出这一格，它不会变聪明。

如何使用

  • 就按「让AI界面在React应用中自动渲染的A2UI引擎」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/CopilotKit/CopilotKit.git
cp -r CopilotKit/packages/a2ui-renderer/skills/a2ui-renderer ~/.claude/skills/a2ui-renderer
