CopilotKit

做什么用

你的 Agent 开始返回 JSON 界面描述，但前端还停在纯文本聊天？这个 skill 让 A2UI 声明自动变。它把渲染管线拆成两层：运行时负责激活，provider 负责主题，底层原语（Provider/Rend。

应用范围

用在「做图」这一格。只认 CopilotKit v2 的 A2UI 格式；非 A2UI 的 Agent 消息不会渲染。

如何使用

  • 就按「A2UI 界面渲染器，装上就能让 Agent 画表单」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/CopilotKit/CopilotKit.git
cp -r CopilotKit/packages/a2ui-renderer/skills/a2ui-renderer ~/.claude/skills/a2ui-renderer
