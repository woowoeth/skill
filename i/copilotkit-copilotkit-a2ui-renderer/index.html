把 Agent 的界面声明渲染成可交互 UI

CopilotKit

做什么用

CopilotKit v2 里，Agent 说一句界面声明，你这边自动渲染成组件。不用手写 renderActiv。声明式渲染，运行时自动激活。底层原语齐全，主题可配，省掉胶水代码。

应用范围

用在「做图」这一格。只认 CopilotKit v2 的 A2UI 协议；v1 不兼容。必须自行启用 runtime 和 provider。

如何使用

  • 就按「把 Agent 的界面声明渲染成可交互 UI」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/CopilotKit/CopilotKit.git
cp -r CopilotKit/packages/a2ui-renderer/skills/a2ui-renderer ~/.claude/skills/a2ui-renderer
