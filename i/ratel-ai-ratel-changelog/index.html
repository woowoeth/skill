Updated 2026-08-15 · Source https://github.com/ratel-ai/ratel/tree/HEAD/.claude/skills/changelog

What does this skill do?

Update per-package CHANGELOG.md files for a Ratel release. Drafts entries with git-cliff (scoped per package), lets you curate, then writes the CHANGELOGs. Handles both RC entries and GA-graduation collapse (merging X.Y.Z-rc.* sections into a single X.Y.Z section). Invoke before tagging a release.

Why is it worth installing?

Unlike generic tools, it scopes per package and collapses RC sections into GA—built for Ratel releases.

How do you install it?

git clone --depth 1 https://github.com/ratel-ai/ratel.git Then point your agent at the skill directory.
