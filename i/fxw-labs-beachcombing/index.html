做什么用

最难得的是它给自己设了上限：走天文骨架估算时，适用性评分强制压到五档里的第二档，不假装精确。

应用范围

这件落在「生活」。只覆盖中国大陆沿海，内置点库 11 省 51 处，其余靠 geocoding 兜底。没接真实潮汐 API 时走农历半日潮天文骨架，正文标「估算 ±1h」且评分不超过五档中的第二档。明确不做钓鱼预报、不做生物图像识别、不做休渔期与保护区的法律核对。

如何使用

  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。
