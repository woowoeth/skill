做什么用

学生问『为什么不选B』时，不再口干舌燥讲三遍。把阅读题变成能自学的交互页，练完自动浮出错题模式，老师备课。不是静态解析页，而是带诊断引擎的练习系统：每道题标注陷阱类型，跨题聚合出个人错题模式，让出题逻辑显形。

应用范围

用在「生活」这一格。只处理四选一英语阅读客观题（含题干+原文+答案）；不生成新题，不做听力/完形/写作。输出为单文件HTML。

如何使用

  • 就按「选择题每个选项都标出题人陷阱的解剖器」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/edu-ai-builders/language-learning-sop-kit.git
cp -r language-learning-sop-kit/option-anatomy ~/.claude/skills/skill-option-anatomy
