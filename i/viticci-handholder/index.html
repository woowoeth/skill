做什么用

新掌机到手最怕重设模拟器、丢通关存档。它直接走 ADB 接管 Cocoon、RetroArch 热键着色器。不是给模拟器套壳，而是用 ADB 直接读写设备分区，迁移合法 ROM 和存档时保留原始目录结构。

应用范围

用在「玩乐」这一格。仅限 Android 掌机且需本机 ADB 环境；不含 iOS/Windows 设备、不代找 BIOS。

如何使用

  • 就按「ADB 直连掌机，换机迁移不丢存档不重配按键」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/viticci/handholder.git
mv handholder ~/.claude/skills/handholder
