做什么用

改端口、设 API key、开功能开关，翻遍 README 找不到的默认关闭原因，它直接告诉你。把散落在代码里的配置项、环境变量、端口和 feature flag 收拢成一张清单。

应用范围

用在「工作」这一格。只覆盖 agentmemory 这一个项目的配置面，不解释业务逻辑；改完配置不负责验证生效，也不管重启流程。

如何使用

  • 就按「不翻源码就改配置，环境变量端口开关全在这」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/rohitg00/agentmemory.git
cp -r agentmemory/plugin/skills/agentmemory-config ~/.claude/skills/agentmemory-config
