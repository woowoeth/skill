做什么用

想给 3D 场景加个会呼吸的波纹、顶点扭曲或发光边缘？不用再翻文档拼凑，直接照着 GLSL 的写法。它把 GLSL 的坑提前填平：内置常见特效模板，uniform 类型与 Three.js 绑定方式直接。

应用范围

用在「写字」这一格。只覆盖 Three.js 的 ShaderMaterial 与 RawShaderMaterial。

如何使用

  • 就按「Three.js 着色器：从零写 GLSL 自定义特」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
