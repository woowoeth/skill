不碰内置材质，直接写 GLSL 顶点与片元着色器

当内置材质调不出你要的扭曲、发光或顶点动画，直接上手 ShaderMaterial。不用翻文档拼凑。

CloudAI-X

做什么用

当内置材质调不出你要的扭曲、发光或顶点动画，直接上手 ShaderMaterial。不用翻文档拼凑。它不丢给你一段裸代码，而是按 Three.js 的渲染管线组织 vertex/fragment 结构。

应用范围

用在「写字」这一格。只覆盖 WebGL/WebGPU 的 GLSL 编写与 ShaderMaterial 接入；不涉及后处理 Effect。

如何使用

  • 就按「不碰内置材质，直接写 GLSL 顶点与片元着色器」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
cp -r threejs-skills/skills/threejs-shaders ~/.claude/skills/threejs-shaders
