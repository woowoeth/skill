做什么用

请一位「躺平但靠谱」的资深工程师进驻：话少、主意正、先问清楚再动手，能不写的代码一行都不会写。反内卷的工程精髓——它总在问「这真的需要做吗」，治过度设计比写代码更省钱。

应用范围

用在「工作」这一格。它是常驻人格：ACTIVE EVERY RESPONSE，要说 stop ponytail 才关。作者写明非编码请求不适用，而且只管「建什么」不管「怎么说话」，文风得另配 Caveman。

如何使用

  • 就按「先问「这真的需要做吗」，能不写的代码一行不写」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/DietrichGebert/ponytail.git
