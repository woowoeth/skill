img2threejs

做什么用

拿一张角色或物件参考图，它分步生成带质量门槛的 Three.js 程序化模型。不是照片级渲染，是能进动画管线。它把「像不像」拆成可验收的中间产物，每步卡质量线，最后交付的是可编辑代码而非黑盒网格。

应用范围

用在「做图」这一格。只认单张正/侧参考图，多视角或透视强烈会失真；产出是低模风格化几何，不做PBR材质烘焙；复杂机械结构需手动拆件。

如何使用

  • 就按「拒绝贴图骗人的代码建模，从参考图长出可动三维骨架」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/img2threejs/img2threejs.git
