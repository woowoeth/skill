做什么用

换装视频最容易翻车的是换完不像同一个人。它先出一张拼贴首帧当结构母图，视频时间轴强制继承主体身份和贴图位置。人和宠物都能做。把「身份一致性」当成硬约束而不是碰运气——先定首帧再派生视频，这个顺序就是它和一堆换装提示词的全部区别。

应用范围

用在「做图」这一格。它交付的是提示词和时间轴，不是视频——真出片要你自己拿去生视频模型跑，成片效果取决于那个模型不取决于它。参数预设、转场库、服装方案分散在三个 references 文件里，正文只给路由。

如何使用

  • 就按「一次拍出多套造型的换装视频脚本」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/liyue-aigc/outfit-director.git
cp -r outfit-director/skill ~/.claude/skills/outfit-director
