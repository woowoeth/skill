做什么用

上传一张照片，它拆解视觉证据、提炼关系，重组成带编号日期的下栏抽象构图。19 张参考图兜底，专治只会套滤镜不会重构。把一张过曝的度假照收成还能上杂志的薄稿，跟蒸馏海报是同一类手艺。

应用范围

用在「生活」这一格。原片信息会被抽走。要保留路牌、菜单、人脸细节，会丢。

如何使用

  • 就按「旅行照片蒸成稀疏编辑稿」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Evianis/travel-photo-abstraction.git
cp -r travel-photo-abstraction/travel-photo-abstraction ~/.claude/skills/travel-photo-abstraction
