做什么用

Go 里「能跑」和「地道」差得远。命名、结构、一致性、接口、错误处理逐维打分，还附可执行的修法。按维度打分让评审意见特别可落地，不是笼统说「建议重构」。

应用范围

用在「做图」这一格。正文明说单个 PR 或未提交 diff 不归它管，那要另一件 code-review。而且末尾嵌着 pi-go 这个项目自己的检查项（ADK、internal/provider/、禁 init()），换仓库得先删。

如何使用

  • 就按「给 Go 代码库做地道性评审」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/dimetron/pi-go.git
cp -r pi-go/.pi-go/skills/design-review ~/.claude/skills/design-review
