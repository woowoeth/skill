做什么用

公众号长文、推特长 thread、随便一段笔记，都能变成一张竖版高 DPI 信息图。不用排版、不用找模板。不是把文字塞进现成模板，而是先解析内容结构，再按移动端阅读习惯重排视觉层级。出图即终稿。

应用范围

用在「做图」这一格。只吃结构化或半结构化文本（文章、推文、列表）；纯扫描 PDF 或手写笔记需先转文字。产物是 PNG 图。

如何使用

  • 就按「文章丢给它，吐回一张能发朋友圈的高清信息图」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/jincai/openclaw-skills.git
cp -r openclaw-skills/infographic ~/.claude/skills/infographic
