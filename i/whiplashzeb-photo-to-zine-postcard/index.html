照片收成一张可寄的刊物明信片

一张明信片的版心，不是长图文

Whiplashzeb

做什么用

一张明信片的版心，不是长图文。旅行照片压进可寄出的薄页：图在上、字很少。

应用范围

用在「玩乐」这一格。页是明信片。要画册、要九宫格、要视频封面，对不上。

如何使用

  • 就按「照片收成一张可寄的刊物明信片」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/Whiplashzeb/photo-to-zine-postcard.git
mv photo-to-zine-postcard ~/.claude/skills/photo-to-zine-postcard
