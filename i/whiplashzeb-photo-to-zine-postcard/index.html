照片收成 zine 明信片

一张明信片的版心，不是长图文

Whiplashzeb

做什么用

旅行照片压进可寄出的薄页：图在上、字很少。

应用范围

这件落在「做图」。页是明信片。要画册、要九宫格、要视频封面，对不上。

如何使用

  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Whiplashzeb/photo-to-zine-postcard.git
mv photo-to-zine-postcard ~/.claude/skills/photo-to-zine-postcard
