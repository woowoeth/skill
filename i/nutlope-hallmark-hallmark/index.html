做什么用

Nutlope 出品的 anti-slop 设计 skill：把「一眼 AI」的页面救回来。作者是产出过一堆爆款开源应用的老手，这份审美清单是他 ship 出来的经验，不是理论。

应用范围

用在「做图」这一格。只管网页与组件这一层的视觉。防重复靠项目根目录的 .hallmark/log.json，换个项目就从头轮，组件级的活压根不记账。study 读网页走 WebFetch，碰到要登录或纯 JS 的 SPA 只能改让你截图。

如何使用

  • 就按「把一眼就看出是 AI 做的页面，改回像人做的」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Nutlope/hallmark.git
cp -r hallmark/skills/hallmark ~/.claude/skills/hallmark
