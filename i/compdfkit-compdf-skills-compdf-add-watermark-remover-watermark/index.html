水印净手

给PDF加品牌水印或抹掉草稿标记，一页页来太慢？这个Skill能批量处理，连图片水印也能精准清除。

creativeskillComPDFKit
点评同类工具只删文本水印，它连图片水印都能识别清除，且批量操作不糊版，机制上直接省掉逐页手动。

安装

git clone --depth 1 https://github.com/ComPDFKit/compdf-skills.git 然后把智能体指向这个 skill 目录即可。
