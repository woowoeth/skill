做什么用

客户说照片换不了、CMS 存完内容就没了、上传崩了构建——它不重做，只针对已交付的旧版本站点做状态诊断与修复。它认的是「交付后状态未知」的站点，不是从零建站。能定位是 CMS 写入链路。

应用范围

用在「工作」这一格。只认本 kit 生成并已交付的营销站；不接非 kit 站点、不处理设计改版、不负责 CMS 账号权限。

如何使用

  • 就按「交付后网站改不动、内容消失，它进场查修」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/nurkamol/website-build-kit.git
