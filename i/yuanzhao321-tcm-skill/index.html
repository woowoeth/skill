做什么用

家里人不舒服，最难的是判断「要不要现在就去医院」。它把疑似致命的情况列成红线层——高热神昏、胸痛彻背、假神脱汗，一律叫急救不辨证。这类里我见过最安全的边界：先点名「传统框架拖成急诊」的失败模式，并在红线层直接拒绝辨证。

应用范围

用在「生活」这一格。定位是「家庭参谋而非医师」，不出处方。针刺绝对禁止自行操作，只解释指路。教材派立场，与经方派、温病派的结论会不一致，它不替你调和。 上游 SKILL.md 的 name 是中文「中医」，装上后可能不被识别，改成 tcm 更稳。 门面说不出处方，但硬约束文件给了 101 味毒性药的内服克数 —— 那是上限表，不是处方。

如何使用

  • 就按「会劝你去挂急诊的中医参谋」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/YuanZHAO321/TCM.Skill.git
