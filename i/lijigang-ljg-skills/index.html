做什么用

AI 写观点文最容易变成正确的废话。它的目标很具体：1000-1500 字，可理解、可迁移、经得住反例——而且明说不做普通摘要。「经得住反例」是我见过对写作最狠的自我要求，比「高质量」这类词实在得多。作者知道自己在做什么。

应用范围

用在「写字」这一格。产出直接落成 Org 文件写进 ~/Documents/notes，文件头的 author 写死「李继刚」，保存后还要过 org-lint 和 Denote 校验——不用 Emacs/Org 的人得先拆掉这一整套。默认 1000–1500 字，摘要和事实查询作者明写不接。

如何使用

  • 就按「一个观点经得住反例才肯落笔的写作引擎」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/lijigang/ljg-skills.git
cp -r ljg-skills/skills/ljg-writes ~/.claude/skills/ljg-writes
