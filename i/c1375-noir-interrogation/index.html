做什么用

玩推理最怕 AI 中途被你说服改口。这个把答案的哈希公示在开场简报里，你一间间审嫌疑人，它只照脚本发的卡演。困难模式会塞进一个指错人的假证人，而扮演那个嫌疑人的模型自己也不知道那是假的。

应用范围

用在「玩乐」这一格。一局 5–15 分钟，单场结束就完，不做多线战役。只有黑色电影一种类型，中途要奇幻或科幻会被拒绝；两套设定是 1940 年代美式与 1930 年代民国上海。作者明写不许 agent 去 Read 或 cat 案件 JSON，一旦绕过脚本，这个设计就作废了。

如何使用

  • 就按「用 SHA-256 锁死凶手的黑色电影审讯游戏」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。
