做什么用

起名难的从来不是想不出字，是爷爷要字辈、妈妈嫌笔画多、爸爸信五行。它专门做了协商模式，把冲突摆到台面上一条条谈。反模式写得清醒：没给出生时刻绝不伪造命盘；不为凑五行去用冷僻字——「孩子要写、要被叫一辈子」。

应用范围

用在「生活」这一格。不做店名/品牌/宠物/游戏角色/虚构名，不做纯算命、不解读已有名字。方言校验只覆盖它掌握的语组。

如何使用

  • 就按「全家为起名吵架时出来当中间人」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Seiya89757/naming-skill.git
cp -r naming-skill ~/.claude/skills/chinese-baby-naming
