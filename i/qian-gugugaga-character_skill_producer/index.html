这件干什么

它抓的是她怎么行动，不是她说过什么：标签给人看，行为规则给 AI 执行。

局限

要 Python，且默认只跑最高保真模式，很费 token；来源黑名单排除知乎、公众号和百度百科；生成的角色包会写死资料截止日期，作品一出新剧情就得重跑。

这样用它

  • 按这个 skill 做一版「只写「她会怎么反应」不抄台词的角色蒸馏器」。
  • 先用它的规矩改我手上这张，不许换风格。
  • 做完对照局限那一条，越界就停。

安装

git clone --depth 1 https://github.com/qian-gugugaga/character_skill_producer.git
mv character_skill_producer ~/.claude/skills/csp
