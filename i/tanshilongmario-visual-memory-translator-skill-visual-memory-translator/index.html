做什么用

给随手拍的照片做编辑级排版：先判断什么该留下，再定留白、版式和抽象度。不是滤镜，是让照片变成一本可以翻的册子。它先分析照片里什么值得存活，再决定版式与抽象程度，而不是套模板。高留白和受控抽象是它的语言，不是装饰。

应用范围

用在「做图」这一格。只处理单张照片或单句概念，不做多图拼贴、不重绘人像全貌、不生成引号金句卡片。输出是图像提示词，不是成品图。

如何使用

  • 就按「照片不修图，重排成能翻的艺术家书页」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。
