proteinmpnn

Inverse-fold backbones into sequences, redesign one chain while fixing interface residues, or sweep temperatures.

Updated 2026-08-16 · Source https://github.com/aipoch/open-science/tree/HEAD/resources/skills/prot…

What does this skill do?

Inverse-fold a protein backbone (PDB structure) into amino-acid sequence with ProteinMPNN (Dauparas et al. 2022, github.com/dauparas/ProteinMPNN). Reach for this skill to run sequence design on RFdiffusion backbones, to redesign one chain of a PDB while holding interface residues fixed, or to generate a temperature-swept set of sequences for downstream folding.

Why is it worth installing?

Unlike single-output tools, it sweeps temperature and locks interface residues, plugging straight into RFdiffusion backbones.

How do you install it?

git clone --depth 1 https://github.com/aipoch/open-science.git Then point your agent at the skill directory.
