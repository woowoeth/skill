做什么用

你正要装的那个 Skill 可能带着提示注入或恶意指令。它把文件当不可信数据读，逐行查风险，装之前先给你一份判决书。把 Skill 文件当作不可信输入而非代码，从根上避免「装完才后悔」。它不猜，它读原文。

应用范围

用在「写字」这一格。只审文件内容与元数据，不跑动态沙箱；对混淆或加密的 payload 只能标「可疑」不能拆解；不覆盖平台自身漏洞。

如何使用

  • 就按「装任何第三方 Skill 前先让它过一遍安检门」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/ai-safe-lens/vetaskill.git
cp -r vetaskill/chat ~/.claude/skills/vetaskill
