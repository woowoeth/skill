做什么用

别只当黑盒用——想知道记忆到底存哪、怎么取回、如何扩展？这份架构说明把 iii 原语、存储模型。它不泛泛讲概念，而是按端到端路径拆解：从写入到检索每一步落在哪个模块、哪个端口，让你改代码前先看清因果。

应用范围

用在「工作」这一格。只覆盖 agentmemory 自身架构，不含 iii 引擎的安装配置；若你只是调用现成记忆接口而非扩展系统。

如何使用

  • 就按「拆开记忆引擎看存储与检索全链路，附端口与查看器」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/rohitg00/agentmemory.git
cp -r agentmemory/plugin/skills/agentmemory-architecture ~/.claude/skills/agentmemory-architecture
