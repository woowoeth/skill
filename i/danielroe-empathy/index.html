做什么用

PR、评论、邮件、聊天……凡是人要看的话，它都先拦一道。不是改措辞，是让你想清楚该不该说、怎么说，再开口。它把「沟通规则」前置成写作前的强制检查，而不是写完后补救。你还没落笔，它已帮你避开冷硬、含糊、冒犯的坑。

应用范围

用在「工作」这一格。只约束文本沟通，不处理语音、代码逻辑或视觉输出；且需你主动在每次写作前调用，不会自动拦截后台生成内容。

如何使用

  • 就按「动笔前先过一遍人类沟通守则的 AI 礼貌开关」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/danielroe/empathy.git
mv empathy ~/.claude/skills/empathy
