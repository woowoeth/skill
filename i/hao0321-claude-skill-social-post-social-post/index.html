做什么用

学你的 Facebook 语气，按 14 天内容日历自动写并发到 FB/IG/Threads/X——实测单帖 8 万触达。「学语气 + 排日历 + 真发布」三步闭环，是个人 IP 运营少见的全自动解。

应用范围

用在「工作」这一格。正文是繁体。真发帖要 chrome:control-chrome 和已登录的浏览器，每篇都得你当场确认，没有 IG 图片素材它就停。成效全落本地 data/*.jsonl，换台机器归零。

如何使用

  • 就按「学你的语气排好 14 天日历，再替你按下发布键」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/Hao0321/claude-skill-social-post.git
cp -r claude-skill-social-post/social-post ~/.claude/skills/social-post
