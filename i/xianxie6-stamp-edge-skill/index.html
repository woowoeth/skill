做什么用

不用抠图、不用白边，孔洞处 alpha 全零，拖到深色海报上也干净。多张还能自动拼成等宽瀑布流邮票合集。孔洞不是画上去的白色模拟，而是 alpha=0 的真透明；投影柔和且只在孔洞外缘，叠深色底不露灰块。

应用范围

用在「做图」这一格。只处理位图（PNG/JPG/WebP），不认 SVG/PDF；输出固定 300 DPI 的 PNG。

如何使用

  • 就按「原图四周直接打半圆孔，真透明背景的邮票生成器」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/xianxie6/stamp-edge-skill.git
mv stamp-edge-skill ~/.claude/skills/stamp-edge
