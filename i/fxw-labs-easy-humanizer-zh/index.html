做什么用

检测24种AI腔，一键切换成技术博客/公号/产品/学术口吻。不是简单换词，是连句子的呼吸节奏都重写。先诊断后手术：先列出具体AI痕迹清单，再按声纹特征逐句重构，而非套模板。四种预设覆盖主流写作场景。

应用范围

用在「写字」。超出这一格，它不会变聪明。

如何使用

  • 就按「把AI文本改写成四种真人声纹的中文润色器」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

git clone --depth 1 https://github.com/fxw-labs/easy-humanizer-zh.git
