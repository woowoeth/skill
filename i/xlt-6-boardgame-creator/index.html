做什么用

点子有了，卡在「到底好不好玩」。它先把 6–10 个关键决策一次交底，再逼出一份今天就能手写出来的纸面原型。它给自己上了禁令：没经过真人试玩只能说「可试玩」，不能说「平衡」——纸面审查只找风险，不发合格证。

应用范围

用在「玩乐」这一格。平衡只能靠真人试玩验，所以你得自己凑齐人——它明写纸面审查不能证明平衡。交付物是纸面原型，美术、量产、众筹一概不管，第一版明说不追求出版。多视角批评里连「易感到被针对者」都算上了，但那仍是模拟，不是玩家。不做电子游戏实现。

如何使用

  • 就按「把点子做成今天就能手写出来的纸面原型和试玩问题」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/XLT-6/boardgame-creator.git
mv boardgame-creator ~/.claude/skills/boardgame-creator
