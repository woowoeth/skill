做什么用

做 HARA、安全目标、ASIL 分解、FTA 时，它不只生成文档，还会以审核员口吻反问你的假设，直到证据链闭合。内置依赖失效分析与 ASIL 分解一致性校验，能主动指出安全目标与 FMEA 之间的逻辑裂缝。

应用范围

用在「玩乐」这一格。只覆盖 ISO 26262 第 3~6 部分及第 8 部分相关工件；不处理 SOTIF（ISO 21448）。

如何使用

  • 就按「ISO 26262 安全档案的起草、挑错与质询台」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/ffffffffelix/automotive-functional-safety.git
mv automotive-functional-safety ~/.claude/skills/automotive-functional-safety
