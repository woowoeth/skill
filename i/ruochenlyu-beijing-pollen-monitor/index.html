做什么用

每年三四月对花粉过敏的人来说是渡劫。它拉 16 个站点的实时监测和分类预报，按区查，出门前知道今天该不该戴口罩。垂直到一个城市、一种过敏原——但对那批人是刚需。这种「窄得理直气壮」正是大市场覆盖不到的东西。

应用范围

用在「生活」这一格。metadata 里明写要本机有 curl 和 jq，全靠 scripts/beijing-pollen-query.sh 打公开接口。范围钉死北京 16 区，作者写明北京以外不要用。而且它只查不推——「每天早上发我」那种晨报要调用方自己接。

如何使用

  • 就按「查北京 16 区花粉浓度和过敏预报」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/ruochenlyu/beijing-pollen-monitor.git
cp -r beijing-pollen-monitor/skills/beijing-pollen-monitor ~/.claude/skills/beijing-pollen-monitor
