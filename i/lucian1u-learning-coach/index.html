做什么用

不按你的要求讲，按你答错的题讲。先出三道探测题摸清底细，再决定是补概念还是上实战。适合学完就忘、想真掌握的人。它把「讲」和「练」拆成两段：先考后教，考不过就补，考过了直接练。你永远在主动回忆。

应用范围

用在「生活」这一格。只覆盖概念或技能的学习闭环，到「你能独立做对」为止。不做直接问答、不做会议纪要、不代写成品。若你只想要答案或速成。

如何使用

  • 就按「会先考你一遍再决定讲多细的学习陪练」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Lucian1u/learning-coach.git
