专防「假托崔玉涛」文章的 0–13 岁育儿参谋

孩子发烧、咬人、不肯吃饭时，最怕搜到一篇署名权威的假文章。它逼自己每个结论凑够两个独立来源，凑不够就明说降可信度。

过日子yeyulangzi店长推荐
点评它给自己列了一张「AI 可能说的借口」对照表——「症状太典型了基本能确定」在表里是必须叫停的信号。

局限

档案默认写进 Obsidian 式知识库的固定路径（08-全局记忆/L1-画像记忆/孩子名），没有知识库得先指定一个本地目录。覆盖 0–13 岁，只说「症状被关联到 XX」不说「得了 XX」，不推荐任何药品和剂量；输入命中呼吸困难、抽搐等词会跳过全部流程，只输出就医引导。

git clone --depth 1 https://github.com/yeyulangzi/parenting-advisor.git
