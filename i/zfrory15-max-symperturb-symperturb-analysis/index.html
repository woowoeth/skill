虚拟敲除症状网络节点，先看七类效用再排干预顺序

症状网络里哪个节点该先动？不用真做实验，虚拟扰动算出七类效用值，直接排出 VPPS 靶点优先级，省掉一轮轮试错。

做什么用

症状网络里哪个节点该先动？不用真做实验，虚拟扰动算出七类效用值，直接排出 VPPS 靶点优先级，省掉一轮轮试错。它把「扰动谁、怎么扰、按什么顺序」变成可审计的框架：边阻断、剂量扰动、组合方案都能算，且每一步都留痕。

应用范围

用在「玩乐」这一格。只认交叉截面症状网络（cross-sectional），不处理纵向或时序数据；输入需为现成网络对象。

如何使用

  • 就按「虚拟敲除症状网络节点，先看七类效用再排干预顺序」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/zfrory15-max/SymPerturb.git
cp -r SymPerturb/.agents/skills/symperturb-analysis ~/.claude/skills/symperturb-analysis
