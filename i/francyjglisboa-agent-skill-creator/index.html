做什么用

把任何工作流写成一次、装到 17 个平台：Claude Code、Cursor、Copilot、Gemini 全兼容的 skill 铸造机。跨平台是 skill 生态的下一站，这件把「一处编写到处运行」提前做出来了。

应用范围

用在「工作」这一格。17 个平台里只有 12 个原样能装，Cursor、Windsurf 等 4 个要转格式，Zed、Aider 等 4 个得你手抄进配置。校验和安全扫描都是 python3 脚本，过了它会直接装进你的配置目录。

如何使用

  • 就按「把口头流程变成能跑的跨平台技能，三步内交付」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/FrancyJGLisboa/agent-skill-creator.git
mv agent-skill-creator ~/.claude/skills/agent-skill-creator
