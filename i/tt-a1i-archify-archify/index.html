做什么用

产出可验证的架构、时序、数据流、生命周期图：自包含 HTML 自带动效，导出清晰锐利可直接交付。「可验证」是关键词：图和描述对得上号，不是好看但骗人的装饰画。

应用范围

用在「工作」这一格。靠 node bin/archify.mjs 出图；收尾的 visual-check 要本机有 Chrome，没有就退出码 2 给张 skipped 收据。只做架构、流程、时序、数据流、生命周期五类，主节点建议不超过 12 个。

如何使用

  • 就按「画出来的架构图要和代码对得上，导出自带动效的 HTML」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/tt-a1i/archify.git
cp -r archify/archify ~/.claude/skills/archify
