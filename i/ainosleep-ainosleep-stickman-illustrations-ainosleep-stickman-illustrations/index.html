AINoSleep店长推荐

做什么用

写方法论、流程、状态、隐喻时总找不到不抢戏的配图？这套自带轻表情的火柴人，默认大量留白，像文档页边的手绘注释。它不生成华丽插画，而是锁定“普通人视角”的极简火柴人：白底、黑线、低强度表情。默认构图就为正文留白。

应用范围

用在「工作」这一格。只认中文正文配图场景，不认海报、封面、Logo 或任何需要高情绪张力的图。产物是单张静态图，不输出多格漫画或分镜。

如何使用

  • 就按「白底黑线火柴人，给中文文章配安静小图」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/AINoSleep/ainosleep-stickman-illustrations.git
cp -r ainosleep-stickman-illustrations/ainosleep-stickman-illustrations ~/.claude/skills/ainosleep-stickman-illustrations
