JuneYaooo店长推荐

做什么用

不用再对着空白页想封面、想文案、想话题。丢文字/图片/视频进去，出来就是竖版卡片或分镜脚本。它不只会写文案——把素材拆成一套能直接发的成品：图文模式出卡片，视频模式出分镜。

应用范围

用在「做图」这一格。只认小红书单篇笔记的格式，不写公众号或抖音脚本；素材要你自己给，它不负责找图找视频；产物是排版好的卡片/脚本+文案。

如何使用

  • 就按「素材丢进来，小红书图文或视频稿成套落盘」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/JuneYaooo/xhs-writer-skill.git
mv xhs-writer-skill ~/.claude/skills/xhs-writer
