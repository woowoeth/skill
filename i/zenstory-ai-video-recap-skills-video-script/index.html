做什么用

已有 VLM 分析但不知怎么剪？它替你定故事线、挑片段、分镜分工，再写出带时间戳的中文解说并自动校验，一步到位。不是模板填空，而是按导演思维先立故事方向，再倒推片段与声画分工；产物带校验闭环，解说与画面错位会当场被。

应用范围

用在「做图」这一格。只吃已含 agent_narration_brief.md 和 vlm_analysis.json 的 work_di。

如何使用

  • 就按「只认已分析完的视频，出带时间戳的解说稿」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/zenstory-ai/video-recap-skills.git
cp -r video-recap-skills/skills/video-script ~/.claude/skills/video-script
