专删AI味叙事骨架，留下你原本的毛边

表面改词没用——它专治段落级AI腔：强行升华的结尾、单线叙事、情绪表演。基于2026叙事结构研究，只动骨架不动血肉。

NulightJens

做什么用

表面改词没用——它专治段落级AI腔：强行升华的结尾、单线叙事、情绪表演。基于2026叙事结构研究，只动骨架不动血肉。多数去AI工具只换词，它拆的是叙事骨架——识别并移除'教训式结尾''情绪表演''含糊指涉'等结构痕迹。

应用范围

用在「写字」这一格。只处理英文文本；需要输入为完整篇章（非单句）；不保证改写后风格统一，可能让文字更松散；无中文支持，中文用户请勿安装。

如何使用

  • 就按「专删AI味叙事骨架，留下你原本的毛边」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/NulightJens/humanizer-stack.git
cp -r humanizer-stack/skills/structural-humanizer ~/.claude/skills/structural-humanizer
