只评不批的Dependabot PR分流员，三档结论

每天堆积的依赖更新PR，它逐条读上游源码改动后给出Merge/先审/别合三档结论，附高/中/低置信度。

cli

做什么用

每天堆积的依赖更新PR，它逐条读上游源码改动后给出Merge/先审/别合三档结论，附高/中/低置信度。结论扎根于上游源码变更而非依赖元数据，能识别版本跳跃中的真实风险；状态机确保同一PR状态只评论一次。

应用范围

用在「写字」这一格。只处理Dependabot开的PR，且需能访问上游仓库源码；不合并、不批准、不打标签，仅输出建议。

如何使用

  • 就按「只评不批的Dependabot PR分流员，三档结论」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/cli/cli.git
cp -r cli/.github/skills/dependabot-triager ~/.claude/skills/dependabot-triager
