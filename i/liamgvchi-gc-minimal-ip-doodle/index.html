保住角色的手绘涂鸦

同一张脸反复画，五官不许漂

LiamGvchi

站方按它的能力做的样张，不是产出物截图

做什么用

同一张脸反复画，五官不许漂。涂鸦可以松，脸必须认得出来。这件卖的是不漂，不是可爱。

应用范围

用在「生活」这一格。不是角色设定全集。要三视图、要服装表，另找。

如何使用

  • 就按「保住角色的手绘涂鸦」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/LiamGvchi/gc-minimal-ip-doodle.git
mv gc-minimal-ip-doodle ~/.claude/skills/gc-minimal-ip-doodle
