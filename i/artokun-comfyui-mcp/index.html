做什么用

ComfyUI 的连线劝退过无数人。装上它用说话就能生成图/视频/音频、搭工作流、改你正在跑的节点图，全程本地不上传素材。把「拖节点」变成「说人话」，而且本地跑——碰私密素材时这点关键。

应用范围

用在「做图」这一格。本体是 npm 上的 MCP server，39 件 skill 给它当外围。前提是有一台跑着 ComfyUI 的机器——没有 ComfyUI，这一整包一件都用不上。另外推荐管线里含一个 abliterated（去掉了拒答方向）的文本编码器 LoRA，作者标它是修脸用的；模型表另有一行 abliterated 出图模型标着 uncensored，可换成同表的普通写实模型。

如何使用

  • 就按「自然语言改工作流，178 个工具随叫随到」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/artokun/comfyui-mcp.git
