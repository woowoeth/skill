只记你说过的话，不替你补半句的人生访谈录

一场一场地采访你或你父母的人生，逐字稿原样留档，另出一份下次接着问的笔记；成不成书随你，档案先归你自己。

elhamid

做什么用

一场一场地采访你或你父母的人生，逐字稿原样留档，另出一份下次接着问的笔记；成不成书随你，档案先归你自己。不许递一个细节让老人点头确认：「大概 2003 年冬天吧」进待核清单，正文写「我不确定」。

应用范围

用在「写字」这一格。它只采访在场的本人，不替不在场的人写传记，也拒绝改写成简历、领英简介或创始人故事。情绪一上来就全停：只给「留在这里／换话题／今天到这」三个选项，一个追问都不许有。仓库 dev/ 目录里抄了同行的整份 skill 当对照，安装时别一起拷进去。

如何使用

  • 就按「只记你说过的话，不替你补半句的人生访谈录」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/elhamid/as-told-to.git
cp -r as-told-to/as-told-to ~/.claude/skills/as-told-to
