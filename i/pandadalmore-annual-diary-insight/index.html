把十年日记摊成一张可下钻的年轮看板

做什么用

年度洞察要精读全年日记后人写；大事记只问一句「哪天之后你回不去了」，一年五到八条，还专收「未遂里程碑」。它故意不给「自动生成正文」的脚本：统计只说明反复提到什么，跳过精读的必然是换年份也成立的废话。

应用范围

用在「生活」这一格。得先有几年成体量的日记，没日记它无事可做。看板的时间线直接读洞察里人工标的条目，洞察没写就是空的，顺序只能先 A 再 B。单页 HTML 有 1.1 MB，正文说这是把 ECharts 内联进去换离线可用的刻意取舍。

如何使用

  • 就按「把十年日记摊成一张可下钻的年轮看板」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/PandaDalmore/annual-diary-insight.git
mv annual-diary-insight ~/.claude/skills/annual-diary-insight
