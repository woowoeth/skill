做什么用

笔记都在 Obsidian 里，AI 却看不见。装上它 agent 能直接读写笔记、搜索、改属性和任务——作者就是 Obsidian 的 CEO。一手权威：没人比作者更懂这个库的数据模型，比任何第三方封装都可靠。

应用范围

用在「工作」这一格。要装 obsidian 命令行，而且 Obsidian 必须开着，关掉就全断。命令清单以 obsidian help 为准，这里只列了常用几条。不写 vault= 时动的是最近聚焦的那个库。

如何使用

  • 就按「用命令行让 agent 读写你的 Obsidian 库」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/kepano/obsidian-skills.git
