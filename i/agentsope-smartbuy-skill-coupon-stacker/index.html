做什么用

标价+一堆券丢进去，按平台真实叠加顺序算出实付，还一步步告诉你下单页怎么点。不编规则，不知道就让你去查官方。不猜券规则，只按平台真实叠加顺序算；每一步操作都落到下单页具体位置，算完即会买。

应用范围

用在「玩乐」这一格。只覆盖京东自营（平台券+国补+Plus+满减）；天猫/拼多多/苏宁暂不适用。不处理预售、定金膨胀、限时秒杀价。

如何使用

  • 就按「叠券顺序算得比下单页还清楚的小账本」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/agentsope/smartbuy-skill.git
cp -r smartbuy-skill/skills/coupon-stacker ~/.claude/skills/coupon-stacker
