做什么用

你说「公司无故辞退我」，它输出能提交的仲裁申诉文本，附证据清单、维权路径和赔偿估算。覆盖劳动、租房、预付卡等 15 类。误区表逐条对撞常识：定金不退订金可退，食品假货是退一赔十，2N 和 N 不能同时主张。

应用范围

用在「生活」这一格。中国大陆法律，条文和赔偿标准会随司法解释变动，正文明写不构成法律意见、不替代律师。赔偿计算器只给区间，各省的一次性伤残就业补助金标准要你自己查。合同逐条解读这一块和在架的 AnythingButLaw 有重叠。

如何使用

  • 就按「把吵架说成法言法语，把判决书说回人话」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Yunpeng192/legal-language-bridge.git
mv legal-language-bridge ~/.claude/skills/legal-language-bridge
