做什么用

散场之后角色就没了，但你可能还想跟 ta 说话。丢进玩家本和人物小传 PDF，它拆出故事记忆和人物性格，生成一个能持续对话的角色。安全边界写着不泄露核心诡计和凶手、不透露该角色本不该知道的秘密——一个角色扮演工具主动防剧透，说明作者真在玩这个。

应用范围

用在「玩乐」这一格。只用于个人情感体验，不该拿去帮别人过本。素材质量决定成品：小传写得薄，蒸馏出来的角色也薄。需要读写文件权限。

如何使用

  • 就按「把剧本杀角色蒸馏成能继续聊天的 AI」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/zzzzzzza/larp-skill.git
cp -r larp-skill ~/.claude/skills/create-larp-character
