Vincentwei1021店长推荐

做什么用

用 Remotion 拍电影感产品视频：106 张分镜配方卡、161 个运镜预设，一句话描述产品就能出一支成片。把「拍产品宣传片」这种要外包的活变成了本地技能，分镜卡的设计尤其讲究。

应用范围

用在「做图」这一格。要 Remotion 工程和 npm，真实页面镜头必须起本地 dev server 用无头浏览器截图。剪映导出走 pyJianYingDraft，Mac 剪映 11.2 实测过，Windows 那支没真机验证。

如何使用

  • 就按「照着 106 张分镜配方卡，把一句话拍成产品宣传片」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Vincentwei1021/video-shotcraft.git
mv video-shotcraft ~/.claude/skills/video-shotcraft
