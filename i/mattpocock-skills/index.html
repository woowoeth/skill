工程师日常那套可改的小技能

拷问需求、转工单、红绿重构，故意做小

mattpocock

做什么用

从真实工作目录里掏出来的散件，让你能改，而不是接管流程。

应用范围

这件落在「工作」。不是开箱即用的平台。要一个按钮跑完全部工程，不对。

如何使用

  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/mattpocock/skills.git
mv skills ~/.claude/skills/skills
