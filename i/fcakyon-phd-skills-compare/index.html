做什么用

训练到一半想比进度？它把 wandb/Neptune/TB/MLflow 的 run 对齐到当前步。多数工具默认拿当前曲线对比已结束的基线，误导判断。它强制同 step 对齐，并区分代理指标与真实目标。

应用范围

用在「做图」这一格。只认 wandb、Neptune、TensorBoard、MLflow 四种后端；需在脚本里已记录 step 和 me。

如何使用

  • 就按「同一步伐对齐训练曲线，拒绝拿终局当基准的对比」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/fcakyon/phd-skills.git
cp -r phd-skills/plugin/skills/compare ~/.claude/skills/compare
