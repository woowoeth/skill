做什么用

跑团最难的是凑人和一个好 DM。它管战役、角色卡、战斗轮次和 NPC，还带可选的影院式画面，一个人也能沉浸开团。它补上的是 DM 这个最难替代的位置，规则和状态全托管，所以单人玩不塌。

应用范围

用在「玩乐」这一格。战役数据全在本机 ~/.claude/dnd，换台机器就从零开。随包只有 5e SRD 数据集，跑正式模组得你自己导入书。影院画面是本地/局域网起的 Flask 面板。默认 roll_mode 是玩家自己掷骰，它不替你的 PC 代掷。

如何使用

  • 就按「一个人也能玩的 D&D 地下城主」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/neuralinitiative/claude-dnd-skill.git
cp -r claude-dnd-skill/skills/dnd ~/.claude/skills/dnd
