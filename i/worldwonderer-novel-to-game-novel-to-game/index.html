喂进一本小说，产出的不是概念稿是真能玩的游戏

「把喜欢的小说做成能玩的游戏」是很多人的童年梦想，这个 skill 把整条流水线打包好了，交给 Claude Code 就能开工。

要 novel-game-analyze、game-concept、game-qa 一整家子都在才转得动。默认做的是验证切片不是全本游戏；完成只认启动、渲染、输入、核心循环、一次结果、重开六项，趣味和平衡它明说证明不了。
