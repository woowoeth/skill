danilo-znamerovszkij

做什么用

拍一张你的手写字母，产出真正可安装的字体（TTF/WOFF）：免费、开源、本地跑，不上传任何东西。「拥有自己笔迹的字体」是很多人想过没做过的浪漫，本地处理这点尤其体面。

应用范围

用在「做图」这一格。只做拉丁字母：字符集就 minimal 和 spanish 两套，汉字做不了。要 Node ≥18 先跑 scripts/resolve-cli.js，CLI 只认文件路径。

如何使用

  • 就按「拍一张手写字母，本地生成能装进系统的 TTF 字体」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/danilo-znamerovszkij/draw-your-font.git
cp -r draw-your-font/skills/draw-your-font ~/.claude/skills/draw-your-font
