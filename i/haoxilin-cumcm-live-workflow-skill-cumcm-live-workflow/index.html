做什么用

真题练手总在格式上扣分？它把环境检查、AI合规、LaTeX编号、AIGC去痕全串成一条线，按国赛标准走完。不是零散模板，而是把竞赛流程固化成可执行关卡：每步有红线清单，终审按2026官方AI规则逐项核对。

应用范围

用在「写字」这一格。只服务CUMCM真题全流程，不接单题求解或论文润色；需自备LaTeX环境和竞赛数据；产物为完整参赛包，不含评委评分。

如何使用

  • 就按「从读题到打包全程不踩雷的数模竞赛裁判长」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/haoxilin/cumcm-live-workflow-skill.git
cp -r cumcm-live-workflow-skill/cumcm-live-workflow ~/.claude/skills/cumcm-live-workflow
