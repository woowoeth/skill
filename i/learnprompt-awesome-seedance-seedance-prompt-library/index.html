做什么用

写 Seedance 提示词总被生成器带偏？这里每个模板都来自 goodcase.ai 上跑通的高分案例。不是泛泛的提示词技巧，而是从真实高分案例里反向拆出的结构。它告诉你哪种镜头该用哪套句式。

应用范围

用在「做图」这一格。只覆盖 Seedance 2.5/2.0 文生视频的提示词撰写，不含图生视频、音频或运镜参数调优；模板基于公开案例。

如何使用

  • 就按「Seedance 2.5 视频提示词模板库」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/LearnPrompt/awesome-seedance.git
cp -r awesome-seedance/agents/skills/seedance-prompt-library ~/.claude/skills/seedance-prompt-library
