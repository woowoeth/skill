metedata

做什么用

核对合同、报表、聊天记录里的数字时，不用再翻页找半天。它直接定位到那一行，高亮截图，让你拿着图去对质。不是摘要，不是引用——它把视觉证据直接钉在页面上。你看到的就是对方看到的。

应用范围

用在「工作」这一格。只认 PDF 文件内的文字层；扫描版或图片型 PDF 需先经 OCR 才能用。高亮截图止于单页。

如何使用

  • 就按「PDF 里哪个数在哪一页，截图圈给你看」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/metedata/pdf-proof.git
mv pdf-proof ~/.claude/skills/pdf-proof
