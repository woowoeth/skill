做什么用

混排中英文标点、表格页码、公文模板一键归一。Codex 改完的 Word 不再被领导退回重排，修订痕迹想留就留。不是零散宏命令，而是按中文办公流程组织的成套动作：先诊断再修，模板与自定义并存，批注修订有明确开关。

应用范围

用在「工作」这一格。只认 .docx/.doc/.wps 输入，输出为 DOCX；不处理 PDF 或扫描件。

如何使用

  • 就按「中文公文排版一步到位，连修订痕迹都替你管好」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/KaguraNanaga/document-format-skills.git
