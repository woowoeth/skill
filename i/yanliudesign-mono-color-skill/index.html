做什么用

给一句话、一张照片或一个念头，还你一张可直接送印的孔版风海报。白、灰、米色底自适应，网点与叠印自动处理。不是滤镜套壳——它按孔版印刷的真实逻辑工作：先定纸张底色，再算油墨叠印顺序，网点密度随底纸明度自适应。

应用范围

用在「做图」这一格。只输出单张静态图，不生成多页zine或动图；仅限两色以内，超出会强制合并；需自备字体，不处理中文排版；照片需提供。

如何使用

  • 就按「单色孔版印刷海报生成器，两色封顶」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/yanliudesign/mono-color-skill.git
