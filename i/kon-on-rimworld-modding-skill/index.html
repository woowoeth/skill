做什么用

别在论坛翻三天帖了。环境、Def、Harmony 补丁、贴图、发布，一条链走完。零基础到能跑。不是零散教程堆砌，而是按真实开发顺序排好的完整流程。每一步都有可执行代码和验证点。

应用范围

用在「工作」这一格。只认 RimWorld 1.6 的 mod 开发；不涉及游戏内剧本编辑、DLC 专属系统。

如何使用

  • 就按「从零搓出能上创意工坊的 RimWorld 模组」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/Kon-on/rimworld-modding-skill.git
mv rimworld-modding-skill ~/.claude/skills/rimworld-modding
