左下角永远钉着地名徽章的车窗风景照

做什么用

坐在车里想发朋友圈，却总拍出反光玻璃和脏边框？它直接生成从车窗望出去的写实风景，每张左下角自动盖好地名徽章。不是简单贴图，而是把车窗框、玻璃反光和窗外景深一起算出来，徽章位置固定，批量出图时风格统一得像同一台相。

应用范围

用在「生活」这一格。只认交通工具窗景（车/船/飞机/缆车），不生成窗外特写或人像；地名徽章仅限左下角，不能改位置；要真实地名需自备列表。

如何使用

  • 就按「左下角永远钉着地名徽章的车窗风景照」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/dacnay816y62-hub/window-scenery-skill.git
mv window-scenery-skill ~/.claude/skills/window-scenery
