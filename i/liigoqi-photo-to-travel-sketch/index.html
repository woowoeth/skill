旅行照片收成赶路速写

黑线乱走、大量省略，像纤维笔当场画

liigoQi

做什么用

黑线乱走、大量省略，像纤维笔当场画。观察式速写，不是精修风景画。走得快，轮廓乱，故意少画。

应用范围

用在「生活」这一格。要干净线稿、要上色完成稿，会嫌它脏。

如何使用

  • 就按「旅行照片收成赶路速写」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/liigoQi/photo-to-travel-sketch.git
mv photo-to-travel-sketch ~/.claude/skills/photo-to-travel-sketch
