做什么用

README 和报错文本里那些「具有重要意义」「进行了优化」被逐句拆掉：情态词按必须/应该/可以分三级。它给的是可执行的改写规则，不是风格建议：条件从句前置、一词一义、回复限 5 句散文。

应用范围

用在「写字」这一格。只管中文技术写作，不碰文学、营销、法律文案；不替你补技术事实，原文缺的参数和版本号它不会编；只给规则和改写。

如何使用

  • 就按「短句、实义动词、条件在前的中文技术写作规范」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。
