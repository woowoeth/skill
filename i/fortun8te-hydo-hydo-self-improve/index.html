做什么用

想给 Hydo 加功能又怕弄坏正在用的它？在一次性工作树里改，跑测试、构建、截真图，最后只交回一个分支。它把“改自己”变成隔离实验：不碰运行中的程序、不碰数据、不自动合并。验证靠真实截图而非嘴说。

应用范围

用在「工作」这一格。只适用于 Hydo 自身代码的修改，不碰数据迁移或配置迁移；需要本机有 git 和测试环境；产物止于分支，合并、部署。

如何使用

  • 就按「改完先跑测试和截图，才把分支交回给你的自我改造工具」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/fortun8te/hydo.git
cp -r hydo/skills/hydo-self-improve ~/.claude/skills/hydo-self-improve
