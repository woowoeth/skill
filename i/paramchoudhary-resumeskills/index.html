做什么用

简历、ATS、面试、求职策略，一次装齐。别让 AI 只帮你改错别字，让它从投递前到谈薪都替你铺路。按求职阶段拆成独立 skill，可单点调用也可串联。针对 ATS 解析规则和面试追问逻辑做了专门适配。

应用范围

用在「生活」这一格。只覆盖英文求职市场，中文简历格式与国内 ATS 规则未适配。技能产出为策略与文本草稿，不保证投递系统兼容性。

如何使用

  • 就按「把求职全流程打包成可复用的技能集」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Paramchoudhary/ResumeSkills.git
