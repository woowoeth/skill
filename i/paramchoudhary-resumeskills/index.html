做什么用

改简历、过 ATS、练面试、定策略——四类 skill 打包上架。投递前让 Claude 按岗位逐条比对。不是单点技巧，而是按求职动线组织的 skill 集合：从简历初稿到投递后复盘都有对应工具。

应用范围

用在「生活」这一格。只覆盖英文求职场景；skill 输出的是修改建议与问答稿，不代投、不代填网申系统。ATS 优化基于通用规则。

如何使用

  • 就按「把求职全流程装进 Agent 的简历优化工具箱」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Paramchoudhary/ResumeSkills.git
