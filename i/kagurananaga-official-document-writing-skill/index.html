按 GB/T 9704 规范写党政机关公文

请示、通知、函、纪要——体制内的公文错一个格式就要返工。它按国标给格式规范、模板和用语建议，还带质量检查。

kagurananaga店长推荐

做什么用

极致垂直，而且是国外市场绝不会有的东西。作者引了具体国标号，说明他真的在这行里。

应用范围

这件落在「写字」。它管 GB/T 9704 的格式与用语，不管这份文该不该发、内容对不对。全文没写任何适用边界，实质内容还是你自己扛。

如何使用

  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/kagurananaga/official-document-writing-skill.git
mv official-document-writing-skill ~/.claude/skills/official-document-writing-skill
