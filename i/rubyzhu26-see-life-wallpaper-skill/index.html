做什么用

今天闻到桂花、听见雨——一句感受配一段极细宋体和一张手写的抽象 SVG，直接渲成锁屏壁纸，图形还避开顶部时钟区。它给引用的诗人定了规矩：小字、低透明度，不能比你自己那句话抢风头。

应用范围

用在「做图」这一格。默认输出尺寸是 1264×2780，也就是作者那台一加 13，其它机型要手动挑备选分辨率。渲染依赖 Playwright，成品自动复制到 ~/Downloads。六种情绪对应固定的六位艺术家和固定渐变，语录库是写死的一小批中西作者，超出这个范围就没有匹配项。

如何使用

  • 就按「把手机壁纸变成每天更新的生活观察窗」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/rubyzhu26/see-life-wallpaper-skill.git
cp -r see-life-wallpaper-skill ~/.claude/skills/see-life-wallpaper
