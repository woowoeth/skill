做什么用

给方案、复盘、甚至朋友圈小作文套上大厂黑话铠甲。想被challenge？。不是简单贴黑话标签，而是按职位视角重构逻辑链——先立项再复盘，逼你补上缺失的假设、指标和风险。

应用范围

用在「玩乐」这一格。只输出中文互联网大厂风格的分析文本，不生成代码、不查数据、不冒充真实公司或个人发正式声明。

如何使用

  • 就按「项目启动会口吻把任何事拆成可挑战的OKR」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/TongDog/big-tech-rhetoric.git
mv big-tech-rhetoric ~/.claude/skills/big-tech-rhetoric
