做什么用

查重、分层验证门、固定骨架、Step 式 PoC、真实截图、语义化命名、放对目录——从确认到成稿一条龙。把报告格式变成硬门禁而非软建议：验证不过不出稿，截图缺失不落盘，驳回自动追补。

应用范围

用在「工作」这一格。只收已确认的漏洞，不负责挖掘和验证；只出 DOCX，不生成 PDF/Markdown；截图必须真实存在。

如何使用

  • 就按「漏洞确认后直接产出可提交的 DOCX 报告」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/v-yun/vuln-report-skill.git
