做什么用

把招聘要求拆成可演练的追问清单，模拟面试后自动生成改进点，连薪资谈判话术都备好——不是泛泛的面试题库。它先解析目标岗位的能力权重，再据此生成问题与追问，模拟后按你的回答逐条对照JD差距。

应用范围

用在「生活」这一格。需要你提供具体岗位JD或简历文本；不覆盖线下面试的肢体语言、眼神接触；产出的模拟问答是文字稿，无语音交互。

如何使用

  • 就按「从岗位JD反推面试题，练完还带复盘和谈薪」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/chen3tu/interview-master-skill.git
mv interview-master-skill ~/.claude/skills/interview-master
