做什么用

GLTF 动画、骨骼蒙皮、形变目标、动画混合，一次装齐。不用再翻文档拼 API，直接上手调出电影级动效。不是零散示例，而是把 Three.js 动画四件套串成一条流水线：从加载到混合，状态机替你管好每一帧。

应用范围

用在「做图」这一格。只覆盖 Three.js 动画域，不碰物理引擎或自定义着色器。需要你已有 GLTF 模型或基本场景；不负责建模。

如何使用

  • 就按「在浏览器里编排三维动画的完整工作台」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
