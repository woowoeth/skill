做什么用

骨骼、变形、关键帧、混合，GLTF 动画拿来即播。写代码前先问它，省得自己翻文档拼 API。它把官方示例拆成可复用的动作片段，按语义调用而非抄代码。你描述意图，它给出对应实现。

应用范围

用在「做图」这一格。仅覆盖 Three.js 动画模块，不含场景搭建、模型加载或渲染优化。超出此范围需自行处理，且要求环境已安装 Thre。

如何使用

  • 就按「骨骼、变形、混合全包，GLTF 动画直接上手」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
