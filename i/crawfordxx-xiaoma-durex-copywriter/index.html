做什么用

热点来了只会硬蹭？借势海报总像喊口号？这套方法把2011-2017环时互动的双层语义+留白拆成步骤。从 260 张原海报拆出双层语义和视觉公式，不是「写得性感一点」这种空指令。

应用范围

用在「写字」这一格。配方来自避孕套海报。拿去写政务、写药品说明书、写严肃讣告，会很脏。

如何使用

  • 就按「按杜蕾斯海报那套双关写文案」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/crawfordxx/xiaoma-durex-copywriter.git
mv xiaoma-durex-copywriter ~/.claude/skills/xiaoma-durex-copywriter
