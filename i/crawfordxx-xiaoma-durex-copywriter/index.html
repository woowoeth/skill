按杜蕾斯海报那套双关写文案

从二百六十张原海报拆双关，不是写性感一点

crawfordxx店长推荐

做什么用

从 260 张原海报拆出双层语义和视觉公式，不是「写得性感一点」这种空指令。

应用范围

这件落在「写字」。配方来自避孕套海报。拿去写政务、写药品说明书、写严肃讣告，会很脏。

如何使用

  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/crawfordxx/xiaoma-durex-copywriter.git
mv xiaoma-durex-copywriter ~/.claude/skills/xiaoma-durex-copywriter
