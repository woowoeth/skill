codex-delegate

Hand the coding to Codex in the background, then review the diff and merge. You stay the reviewer, not the typist.

Updated 2026-08-09 · Source https://github.com/amElnagdy/delegate-skills/tree/HEAD/skills/codex-de…

What does this skill do?

Delegate a coding task to the OpenAI Codex CLI as a background implementer, then review its diff and land it yourself. Use this whenever the user wants to hand implementation work to Codex — phrasings like "have Codex do X", "delegate this to Codex", "run it through Codex", or "use Codex to implement/fix/refactor" — or to run a queue of coding tasks through Codex while staying the reviewer. Prefer

Why is it worth installing?

Unlike tools that just generate code, this keeps you as reviewer—queue tasks, run in background, review diffs, stay in control.

How do you install it?

git clone --depth 1 https://github.com/amElnagdy/delegate-skills.git Then point your agent at the skill directory.
