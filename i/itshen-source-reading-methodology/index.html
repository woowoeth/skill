做什么用

带 AI 啃陌生大型仓库，产出书稿/课程/文档。零幻觉是底线：引用逐字节核实，行号实读。别的工具给你总结，它给你证据链。锁版本锚点+机器校验+并行子Agent。

应用范围

用在「工作」这一格。只服务「读懂+产出」闭环：需已有可编译/可解析的源码树，且产出限于书稿/课程/文档，不生成可运行补丁或重构建议。

如何使用

  • 就按「每句话都能回溯到源码行号的开源仓库精读器」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/itshen/source-reading-methodology.git
mv source-reading-methodology ~/.claude/skills/source-reading
