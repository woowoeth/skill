做什么用

别人晒九宫格，你晒一张 3:4 意境海报。真实风景在上，地点或动作在下晕成水彩，城市河流运动家庭都吃。不是滤镜叠加，而是把照片下半部重绘成记忆的水彩痕迹——地点变色块、动作变笔触，让‘去过’变成‘梦到过’。

应用范围

用在「生活」这一格。只认单张照片，输入多图会取第一张；人物系列必须启用 Watercolor Motion 规则否则出图发灰。

如何使用

  • 就按「上半张照片下半张水彩，旅行记忆变成可寄出的海报」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/Kimberlying/watercolor-memory-poster.git
mv watercolor-memory-poster ~/.claude/skills/postcard-memory-poster
