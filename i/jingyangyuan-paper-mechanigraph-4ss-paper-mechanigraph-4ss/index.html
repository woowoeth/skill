做什么用

把文字假说变成能投稿的 SVG 机制图，后台无头渲染逐像素自检，直到线条、箭头、标注都符合期刊出版规范。它把「制图规范」写进自检循环：先问风格偏好，再解析机制，渲染后逐像素比对，不合格就自动改。

应用范围

用在「做图」这一格。只认文字描述或已有原图，不认手绘草图；只出 SVG 矢量图，不负责帮你选刊投稿；复杂政策网络超过 20 个节点时。

如何使用

  • 就按「CSSCI 级矢量机制图，出图前先问你风格偏好」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/jingyangyuan/paper-mechanigraph-4ss.git
cp -r paper-mechanigraph-4ss/paper-mechanigraph-4ss ~/.claude/skills/paper-mechanigraph-4ss
