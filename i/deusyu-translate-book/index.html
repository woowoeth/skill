做什么用

一本书几十万字，串行翻要等到天荒地老。它用并行子 agent 分块同时翻，保留原书排版，输出 HTML/DOCX/EPUB。并行是关键：把几小时压到几十分钟，而且排版不散——这才让「翻整本书」从设想变成可做的事。

应用范围

用在「写字」这一格。本机要有 python3 和 pandoc，DOCX/EPUB/PDF 还得装 Calibre，缺了只剩 HTML。默认放 8 个子 agent 并发，整本书的 token 你自己付；术语表只从 5 个抽样块里提。

如何使用

  • 就按「整本书拆给多个分身并行翻译，再拼回原排版」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/deusyu/translate-book.git
mv translate-book ~/.claude/skills/translate-book
