把一场戏蒸成一本小 zine

可翻的薄刊物，不是一张海报

Zeejay0店长推荐

做什么用

可翻的薄刊物，不是一张海报。一场戏压成能翻的几页：顺序、留白、纸感都按刊物走。

应用范围

用在「做图」这一格。页少。要长篇画册、要分镜脚本，装不下。

如何使用

  • 就按「把一场戏蒸成一本小 zine」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Zeejay0/gathered-scenes-zine-skill.git
cp -r gathered-scenes-zine-skill/skills/scene-distillation-zine-v1-3 ~/.claude/skills/scene-distillation-zine-v1-3
