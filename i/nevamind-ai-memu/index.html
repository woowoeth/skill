做什么用

不管你是 Claude、GPT 还是本地脚本，一条命令识别宿主、打印专属接线图，把记录和注入两条缝都焊上——或干净。不猜宿主、不写死路径。它先自报家门再给图，按图施工，两条缝都接上才算完。卸载也走同一张图，不留半截线头。

应用范围

用在「玩乐」这一格。只处理 memU 自身的安装/卸载，不碰其他插件或系统配置。需要你有终端执行权限；若宿主是封闭平台（如纯网页版）。

如何使用

  • 就按「给任何 Agent 装上或卸下 memU 记忆插件」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/NevaMind-AI/memU.git
mv memU ~/.claude/skills/install-memu
