做什么用

从零搭建 3D 场景，相机、灯光、几何体、动画、交互一次配齐。不用再翻文档拼代码，装完即用。十个技能按场景生命周期编排，从初始化到渲染循环无缝衔接，省去你反复查找 API 和调试样板代码的时间。

应用范围

用在「玩乐」这一格。只覆盖 Three.js 核心场景搭建，不含 GLSL 着色器、后期特效、物理引擎或模型加载优化。超出这些范围。

如何使用

  • 就按「Three.js 场景搭建的十件套技能包」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
