做什么用

写分镜最怕情绪戏拍出来像木头。它把剧本拆成节拍表，标好每颗镜头几秒、脸往哪转、用哪种表演技法。它不给你泛泛的镜头建议，而是把表演技法写进提示词——节拍时长、面部朝向、情绪转折点都量化。

应用范围

用在「工作」这一格。只认 MiniMax H3 的提示词格式，不输出通用分镜脚本；需要你先有完整剧本或场景文本，不能从零生成故事。

如何使用

  • 就按「剧本进 H3 分镜前先算好每颗镜头能装几个情绪节拍」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/phileiny/h3-storyboard-skill.git
cp -r h3-storyboard-skill/skills/h3-storyboard ~/.claude/skills/h3-storyboard
