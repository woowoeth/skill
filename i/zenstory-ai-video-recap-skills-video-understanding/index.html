做什么用

看完一部纪录片，你只记得'好像不错'。装上它，视频自动变成场景、台词、画面观察、静音、时间线和写作 brief——。不是单一转录，而是六层产物互相咬合：ASR 对齐场景，VLM 观察画面，静音窗补叙事空隙。

应用范围

用在「做图」这一格。只吃本地视频文件，不吃 YouTube 链接；需预装 ffmpeg 和一台能跑 VLM 的 GPU（无 GPU 则视觉。

如何使用

  • 就按「拒绝逐帧空转，把视频拆成可检索的场景时间线」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/zenstory-ai/video-recap-skills.git
cp -r video-recap-skills/skills/video-understanding ~/.claude/skills/video-understanding
