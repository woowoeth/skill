先摸清遗产代码再动手的逆向审计员

接盘没文档、没测试、没维护者的老代码库？它先做侦察、映射清单、逐文件通读，再给你一份按严重度分级的 bug 目录。

hyetigran

做什么用

接盘没文档、没测试、没维护者的老代码库？它先做侦察、映射清单、逐文件通读，再给你一份按严重度分级的 bug 目录。它把「理解代码」从凭感觉变成可执行流程：先反向侦察再逐文件覆盖式分析，产出的是带严重度标签的缺陷清单。

应用范围

用在「工作」这一格。只认本地已有代码库，不接远程仓库自动拉取；产物是审计报告与 bug 目录，不含修复补丁。

如何使用

  • 就按「先摸清遗产代码再动手的逆向审计员」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/hyetigran/legacy-skills.git
cp -r legacy-skills/skills/legacy-audit ~/.claude/skills/legacy-audit
