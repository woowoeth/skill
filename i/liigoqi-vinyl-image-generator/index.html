照片压成一张黑胶封面

圆盘、沟槽、封套，不是方图加贴纸

liigoQi

做什么用

圆盘、沟槽、封套，不是方图加贴纸。按黑胶封套的规矩重做照片。圆心和环是结构，不是装饰。

应用范围

用在「做图」这一格。页是一张唱片。要海报、要九宫格、要证件照，对不上。

如何使用

  • 就按「照片压成一张黑胶封面」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/liigoQi/vinyl-image-generator.git
mv vinyl-image-generator ~/.claude/skills/vinyl-image-generator
