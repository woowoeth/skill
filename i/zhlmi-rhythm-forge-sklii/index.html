做什么用

不用写谱、不用调判定。它自己听出起音、排好双拇指能按的轨，三档难度打包成单文件，发链接就能玩。谱面不是随机撒点，是约束求解：保证双拇指不打架、密度符合难度档位。起音检测让谱面跟着音乐的真实打击点走。

应用范围

用在「玩乐」这一格。只产出 4 轨下落式单文件网页；不做上滑/长按/多指同按。输入音频需本地文件，在线链接要先下载。谱面难度基于能量密度。

如何使用

  • 就按「音频拖进来，出来一个能玩的网页音游」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/zhlmi/rhythm-forge-sklii.git
mv rhythm-forge-sklii ~/.claude/skills/节奏锻造师
