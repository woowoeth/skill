做什么用

模型写小小说总是同一套：领导宣布、众人执行、底层受苦、老人落泪。它把这些列成模板清单，撞上就强制换两个维度重写。拒绝模仿任何具体作家的文风，只把要求翻译成冷幽默、荒诞因果、留白这些可迁移技法；结尾掏磨损物件这类套路直接禁止。

应用范围

用在「写字」这一格。只写中文超短篇，上限 3000 字。默认只输出标题和正文，不给寓意、落点、创作说明。不把真实个人或机构写成加害者，不用地域/职业/贫困/残障做快捷笑点，不为煽情临时加死亡与重病。

如何使用

  • 就按「把人生事件转成可复用的寓言引擎」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/wr5912/human-allegory-engine.git
cp -r human-allegory-engine ~/.claude/skills/human-allegory-engine
