做什么用

传一张图或一句话，先确认你的个人 IP 和主题色，再把 Markdown 长文拆成书封＋窗口插图＋01 起编号的知…。先定 IP 再排版，不是套模板：每张卡都从你确认过的形象和色板里长出来，长文里的截图、图表。

应用范围

用在「工作」这一格。只吃 Markdown 长文，且必须能提取出作者名或主题色；若原文没有可保留的关键图，它会跳过插图步骤。

如何使用

  • 就按「同一套主题色贯穿封面、IP 图与编号正文卡」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/adrianpunk/punk-xhs-cards.git
cp -r punk-xhs-cards/punk-xhs-cards ~/.claude/skills/punk-xhs-cards
