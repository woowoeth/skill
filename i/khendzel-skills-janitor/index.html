做什么用

装得越多上下文越挤，还不知道哪个在偷偷吃 token、哪个藏着提示注入。它左滑扔掉浪费的、扫风险、给诚实的 token 账单。这个生态罕见的「减法」工具：装得多不等于装得好，它同时管省上下文、防注入、看清成本。

应用范围

用在「工作」这一格。它会真动手删：左滑就把那个 MCP server 从配置文件里移除，只留一个带时间戳的 .bak。判断依据是本机会话记录里的调用次数——刚装没多久的 skill 天然显示成「没用过」，容易误杀。安全扫描作者写明是启发式。

如何使用

  • 就按「给你装的技能库做体检和减法」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/khendzel/skills-janitor.git
