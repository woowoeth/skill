日常照片收成雾面编辑稿

抽出主角，大留白，像在动的杂志页

lzs0594

做什么用

抽出主角，大留白，像在动的杂志页。从随便一张里找出该被看见的那个，重建成带雾的编辑图。

应用范围

用在「做图」这一格。现场杂物和背景故事会让路。要纪录完整场景，别装这件。

如何使用

  • 就按「日常照片收成雾面编辑稿」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/lzs0594/dreamy-motion-editorial.git
mv dreamy-motion-editorial ~/.claude/skills/dreamy-motion-editorial
