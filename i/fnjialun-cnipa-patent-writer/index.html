做什么用

从技术方案到全套 .docx 专利文档，含白底黑线附图。有模板只取版式，无模板按国知局标准排，内容配图全部现写现画。模板只当尺子用，不当复印机。页眉页脚、分节、字号缩进全对齐，但每个字、每张图都从你的方案重新长出来。

应用范围

用在「工作」这一格。只产出申请文档和附图，不查新颖性、不写审查意见答复。需你提供完整技术交底；若方案缺关键实施例或数据，它不会替你编造。

如何使用

  • 就按「只借版式不借内容的 CNIPA 专利文档生成器」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/fnjialun/cnipa-patent-writer.git
