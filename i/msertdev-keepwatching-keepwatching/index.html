做什么用

别赌爆款。每个模板都带真实留存曲线和样本量，从选题到渲染成 MP4 一条龙，A/B 两个版本直接出片对比。把「感觉会火」换成「数据说留到第 3 秒」——留存数字反哺决策，渲染器确定性复现，不靠剪辑手感碰运气。

应用范围

用在「工作」这一格。只认竖屏短视频（TikTok/Reels/Shorts）；需要本机装 Node。

如何使用

  • 就按「9:16 竖屏完播率实测库，选题先查再拍」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/msertdev/keepwatching.git
cp -r keepwatching/skills/keepwatching ~/.claude/skills/keepwatching
