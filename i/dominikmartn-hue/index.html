做什么用

学习任何品牌并输出完整设计系统：装一次，之后 agent 做的每个界面都长在你的品牌基因上。「品牌一致性」从人肉盯改变成系统保证，小团队也能有大厂级的视觉纪律。

应用范围

用在「做图」这一格。它产的是一件新 skill，不是界面；而且生成的 description 硬写 NEVER trigger automatically，之后每次都得点名叫它。没接 Chrome DevTools MCP 就降级取色并自报低可信。

如何使用

  • 就按「学一次你的品牌，之后 agent 做的每个界面都照着来」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/dominikmartn/hue.git
mv hue ~/.claude/skills/hue
