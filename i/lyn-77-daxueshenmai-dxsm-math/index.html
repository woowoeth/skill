做什么用

截图、文字、LaTeX、纯公式都认。不光给答案，还推导定理原理，揪出你解题过程里的错。统考范围内。不是题库检索，是逐题推理。能顺着你的过程指出哪步错、为什么错，再补上定理推导，像助教坐在旁边。

应用范围

用在「生活」这一格。只覆盖数一数二数三统考范围；不背定义、不做规划、不估分。超纲题它会直接说不会，不硬答。

如何使用

  • 就按「数一数二数三的题，它敢接敢讲敢纠错」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

git clone --depth 1 https://github.com/lyn-77/daxueshenmai.git
