做什么用

别再用文字描述游戏想法了。丢进来，它给你几个方向各异的可玩原型，每个都自包含。它不写'看起来像游戏'的静态稿，而是产出可运行原型，并让无头机器人真实交互验证。

应用范围

用在「工作」这一格。只产出浏览器内可玩的小型原型，不做资源打磨、不做数值平衡、不接后端存档。玩法越复杂。

如何使用

  • 就按「一次出五个能玩的游戏原型，机器人替你按过键」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/didrod205/claude-astra.git
