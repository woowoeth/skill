把 Markdown 流式渲染器装进 Vue 3 项

AI 长回复在 Vue 3 里逐字蹦出，光标不抖、代码块不闪。内置虚拟时间轴，千行流式输出也稳如本地渲染。

做什么用

AI 长回复在 Vue 3 里逐字蹦出，光标不抖、代码块不闪。内置虚拟时间轴，千行流式输出也稳如本地渲染。它把渲染器拆成可插拔路径，并用虚拟时间轴对齐 AI 的异步输出——不是简单 v-html。

应用范围

用在「工作」这一格。只服务 Vue 3 + 浏览器 DOM；不处理 Markdown 解析本身，需自带或另配 markdown-it。

如何使用

  • 就按「把 Markdown 流式渲染器装进 Vue 3 项」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/Simon-He95/markstream-vue.git
cp -r markstream-vue/.agents/skills/markstream-vue ~/.claude/skills/markstream-vue
