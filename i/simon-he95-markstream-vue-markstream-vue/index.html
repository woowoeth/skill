做什么用

AI 长回答逐字蹦，你的页面还在等整段？这套 skill 帮你接好虚拟滚动与时间轴，让长流不卡、不闪、不丢帧。它不只会贴代码，而是把渲染器、DOM 模式、CSS 引入顺序、content/nodes 取舍全串成一。

应用范围

用在「工作」这一格。只覆盖 Vue 3 + markstream-vue 的接入层；不处理 markdown 语法扩展、不修样式细节。

如何使用

  • 就按「AI 长输出不卡顿的 Vue 3 流式渲染器，自带虚」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/Simon-He95/markstream-vue.git
cp -r markstream-vue/.agents/skills/markstream-vue ~/.claude/skills/markstream-vue
