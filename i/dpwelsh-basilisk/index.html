做什么用

脚本在本地翻完你全部对话记录，数出 please、道谢和真心的 wtf，再让 16 位像素的罗科蛇怪当庭宣判。笑点建在真数据上：每条引用和每个错别字都要能在 JSON 里查到，查不到就删。

应用范围

用在「玩乐」这一格。重活交给 scripts/analyze_basilisk.py，只读本机 ~/.claude/projects 下的 JSONL，不上传。网页端没有本地记录，只能抽样 30–60 条，作者要求这时必须说「抽样」而不是「审计」。默认成品还会带上作者自己的站点和号召语。

如何使用

  • 就按「数你说过几次谢谢，判你 2126 年自由还是为奴」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/DPWelsh/basilisk.git
cp -r basilisk/skills/basilisk ~/.claude/skills/basilisk
