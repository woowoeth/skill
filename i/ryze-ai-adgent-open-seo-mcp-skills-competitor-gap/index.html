做什么用

别再猜对手凭什么排你前面。输入对方域名，直接列出你缺哪些词、每个词能带来多少流量、值不值得抢。附可赢性评分。不是简单差集。它把每个缺口词按搜索量和你的现有排名综合打分，告诉你先抢哪个、哪个抢了也白抢。

应用范围

用在「工作」这一格。只认公开搜索数据，不覆盖 Google Ads 私有词或长尾意图；需要你已配置搜索 API 密钥。产物是候选词表。

如何使用

  • 就按「专挖对手有而你没有的搜索词，按流量和可赢性排好序」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。
