做什么用

AI 当 KP 最烦的是一口气把三个场景演完。它给自己设了硬上限：一回合一拍、2–4 句，停在你能动手的那一刻。队友 NPC 是 AI 扮的调查员不是提示频道：不许总结主线、不许给路线排正确度，要拿信息也得掷骰。

应用范围

用在「玩乐」这一格。模组正文得你自己有——它明写有原文时不许凭记忆讲，没有原文就只能即兴。配乐是在浏览器里开一个搜索结果页，作者承认查不到具体曲目时就让你自己按播放。它还会照模组把 1920 年代的种族歧视当成线索门禁执行，只在开局前问你能接受到什么程度。

如何使用

  • 就按「写到第三段就把回合交回来的克苏鲁跑团 KP」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/SumanasJ/coc-kp-host.git
cp -r coc-kp-host ~/.claude/skills/coc-kp-host
