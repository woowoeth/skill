断点续审的千文件代码库深挖器

vladimir-cicovic

做什么用

几万行代码、跨服务调用、并发与泄漏，它分阶段审完还能续上——token 断了也不丢已查过的线索。把审查拆成可恢复的多阶段流水线，每阶段产出物落盘，token 耗尽后从断点接着跑，不重审已查文件。

应用范围

用在「工作」这一格。只认代码库整体审查，不处理单文件或小改动；需要能跑构建/静态分析的环境；不生成修复补丁，只输出问题清单与证据链。

如何使用

  • 就按「断点续审的千文件代码库深挖器」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/vladimir-cicovic/ai_review_skills.git
mv ai_review_skills ~/.claude/skills/phased-code-review
