做什么用

WizTree扫出大文件，两层分析辨风险，每步都等你批复。备份后才动手，观察期自动回滚——小白也能放心清出10GB。不是闷头删，而是把「安全」做成流程：扫描→分析→批复→备份→执行→观察，六步闭环，不确定的绝不碰。

应用范围

用在「玩乐」这一格。仅限Windows系统，需安装WizTree并联网下载模式库；只清理用户目录和临时文件，不碰系统核心。

如何使用

  • 就按「只动你点头的C盘清理，先扫后议再备份」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/iziqing/-disk-cleaner.git
mv -disk-cleaner ~/.claude/skills/clean-c-drive
