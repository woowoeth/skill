duskyelf

做什么用

先把话题铺成一棵树，分清哪一层只是分支、哪一层才是研究者真在吵的分歧，然后一路反问你。分支和真分歧不是一回事：监督对自监督只是分支，数据越多是否伤泛化才是分歧。

应用范围

用在「生活」这一格。它不给答案，只逼你想，急着要结论时会很难受；会话日记落在 diary/ 下；配套的文献综述依赖 Semantic Scholar 和联网搜索，没网时它会把整棵树标成未验证。

如何使用

  • 就按「会打断你含糊用词的苏格拉底式陪练」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/duskyelf/teach-me.git
cp -r teach-me/skills/teach-me ~/.claude/skills/teach-me
