做什么用

建模题不再闷头冲：每问先给候选思路，你点头才写代码，每段结果自动落成论文草稿，再审完再走下一步。把「审核」做成流程关卡而非事后检查——思路、代码、论文三段各自设卡，逼你在写代码前就想清算法。

应用范围

用在「工作」这一格。只服务国赛真题或完整建模流程，不接单问速解；要求你逐段审核，急性子会嫌慢。

如何使用

  • 就按「每步先交方案再写代码的国赛建模流水线」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/yuanchen-home/cumcm-step-review.git
