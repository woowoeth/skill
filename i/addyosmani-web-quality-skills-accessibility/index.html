做什么用

用户说「做个无障碍」时，别只加 alt。它按 2.2 逐条查键盘、读屏、对比度，给出能直接改的修复项。不是给「建议」，而是给「断言」：每条失败都对应 WCAG 2.2 的具体条款和修复动作。比人工走查快。

应用范围

用在「玩乐」这一格。只审静态 HTML/CSS 可判定的项；动态交互、焦点陷阱、真实读屏体验需人工验证。产物是问题清单，不含自动修复补丁。

如何使用

  • 就按「按 WCAG 2.2 给网页做无障碍体检并给修复清单」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/addyosmani/web-quality-skills.git
cp -r web-quality-skills/skills/accessibility ~/.claude/skills/accessibility
