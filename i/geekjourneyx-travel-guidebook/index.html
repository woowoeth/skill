一张 AI 插图都不许有、emoji 也禁的旅行路书

把行程调研做成能打印的 PDF 路书：暖色纸底、衬线体、Tabler 图标和内联 SVG 装饰，靠排版撑设计感。

geekjourneyx
点评「零 AI 插图」是硬规则不是风格偏好——旅行册子最容易骗人的就是一张不存在的风景图。

局限

要 Node.js 和 Playwright 才能导 PDF，装环境有成本。深度调研阶段会并行开五个 agent，很吃 token。成品是印刷导向的长文档，不是手机上随时改的行程 App。只做排版和成书，订票订房都不管。

安装

git clone --depth 1 https://github.com/geekjourneyx/travel-guidebook.git
mv travel-guidebook ~/.claude/skills/travel-guidebook
