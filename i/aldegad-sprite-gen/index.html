做什么用

一句话出一套干净的 2D 游戏精灵图：状态行排布、透明底、逐帧拆分、运行时图集，产物直接丢进游戏引擎就能用。游戏素材是独立开发最大的坑之一，它把「画小人」变成了一句话的事，产物直接进引擎。

应用范围

用在「做图」这一格。生成那步要本机装好 codex 或 grok CLI 并登录。脚本只认仓库自建的 .venv，缺 NumPy 就在 import 处硬报错——作者明写没有纯 Python 降级。正文大半是韩文。

如何使用

  • 就按「组件行流水线出精灵图集，带 QA 报告和运行时清单」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/aldegad/sprite-gen.git
mv sprite-gen ~/.claude/skills/sprite-gen
