做什么用

跑到第十次团，线索、NPC 和 SAN 值散在十份记录对不上。它把表写进 Markdown，检索交给 SQLite。写入只追加 Markdown、查询只走 SQL，写坏一行只坏一行——为的是不像 JSON 那样整份报废。

应用范围

用在「玩乐」这一格。名字是它唯一的跨文件索引键，写简称或错一个字就断联，NPC 和线索接不上。它是玩家侧的副官，不主持、不替角色做决定，想找人开团的别装。跑起来要 Python 和 SQLite，还得先用内置模板生成一份项目级规则再用。

如何使用

  • 就按「跑团桌旁帮你车卡归档线索的副官，防超游」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

git clone --depth 1 https://github.com/JadeL-Kemo/trpg-log-copilot-skill.git
