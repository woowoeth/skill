K-Dense-AI

做什么用

检索 OpenAlex、PubMed、Google Scholar，抽取准确元数据、校验引用、格式化文献——引用错误终结者。AI 编造引用是学术圈最怕的事，它反其道而行：每条引用都可验证、有出处。

应用范围

用在「工作」这一格。要 Python 3.9+ 和 requests，还要连得上 openalex、crossref、pubmed。Google Scholar 没有 API，靠 scholarly 爬，每条歇 2 到 5 秒还常被封，作者自己说只能当补充。

如何使用

  • 就按「每条引用都回数据库核验，揪出 AI 编造的参考文献」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/K-Dense-AI/scientific-agent-skills.git
