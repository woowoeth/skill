做什么用

做舟、终末地还是工业科幻落地页？先报产品家族和复杂度档位，再按证据库出稿——不套模板，不猜风格，直接对齐鹰角审美。把「像不像鹰角」从玄学变成可审计流程：每个视觉决策都挂到产品族与深度档的证据链上，改稿有据可依。

应用范围

用在「做图」这一格。只认鹰角系产品族（方舟/终末地/罗德岛/工业科幻/编辑式游戏UI），非该语境的通用网页设计会硬套风格。

如何使用

  • 就按「鹰角视觉语言先问产品线再定深度的界面设计器」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/Brandon030722/ark-ui-skill.git
