做什么用

上传一张照片，它先用本地神经网络抽出线稿，再一笔一笔画出来、配一只跟着笔尖走的手。两个本地模型一个都没装时，它规定必须直接失败 —— 不许用边缘检测糊一版弱线稿交差。

应用范围

用在「做图」这一格。它只是适配层：引擎要 pip 装另一个仓库，Informative Drawings 或 Anime2Sketch 至少装一个并设环境变量，而模型的安装指南在引擎仓库里、不在这一件。一个都没装时它直接失败，不给降级方案。

如何使用

  • 就按「线稿只准本地模型抽、不许 AI 生成的白板手绘视频」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/gnipbao/codex-whiteboard-video-skill.git
mv codex-whiteboard-video-skill ~/.claude/skills/whiteboard-video
