做什么用

没口的时候多半不是饵不对，是位置和天气不对。它把选位排在全篇第一，气压风向温差降雨讲完才轮到装备，台钓路亚海钓黑坑都覆盖。目录本身就是论点：选位写在最前。先讲位置和天气，再谈装备——把老手和新手真正分开的那一层。

应用范围

用在「生活」这一格。经验知识，无实时水位/天气接口，仍要自己对照当天。偏中国淡水台钓路亚；海钓篇幅更薄。

如何使用

  • 就按「新手买竿，老手看天：从选位讲起」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

git clone --depth 1 https://github.com/SunnyPanzhen/fishing-skill.git
