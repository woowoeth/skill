做什么用

写稿、改稿、审稿时自动揪出「显著性通胀」「-ing 尾巴」「模糊归因」等 41 种机器味。不是笼统说「这不像人话」，而是按内容、语言、风格、沟通、填充、修辞六类拆出 41 种可复现模式。

应用范围

用在「写字」这一格。只认英文文本；对中文、代码混排、诗歌或刻意风格化文本无效。它挑的是模式不是品味，若你本就爱用排比或夸张修辞，会被误报。

如何使用

  • 就按「41 种 AI 腔逐个挑出，改完才准进仓库」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/kyle-bartlett/soundshuman.git
mv soundshuman ~/.claude/skills/humanize
