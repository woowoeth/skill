做什么用

到了当地没网、翻聊天记录找攻略最抓狂。它出单文件 HTML：交互地图 + 每日时间轴 + 出发前订票提醒，存手机上离线可读。「离线可读、手机优先、单文件」——这三个约束是真在国外用过才想得到的。

应用范围

用在「生活」这一格。地图引的是 Leaflet CDN，所谓「离线可读」保得住文字和时间轴，地图那块断网就是空的。实时票价、代订票、多语言、后端，作者在「不做」一节里明写一概不做。最后那步校验要本机有 node 跑 assets/validate.js。

如何使用

  • 就按「离线可读的手机旅行页，地图时间轴订票提醒一页装完」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/zexuanw958-svg/travel-plan-viz.git
cp -r travel-plan-viz/travel-plan-viz ~/.claude/skills/travel-plan-viz
