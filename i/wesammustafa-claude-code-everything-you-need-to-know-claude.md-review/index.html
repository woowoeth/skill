做什么用

当 Claude 反复重读同一段上下文、结果忽好忽坏时，别猜了。它专查模糊表述、未命名文件、过期事实和臃肿段落——。不是泛泛的『写得更好』，而是按四类已知劣化模式逐条扫描，每条给出可执行改法。机制上像 lint。

应用范围

用在「工作」这一格。只审 CLAUDE.md 单文件，不碰其他配置或代码库；不自动改写，只输出诊断与建议；若你的 CLAUDE.md 本就。

如何使用

  • 就按「审计 CLAUDE.md，揪出拖垮输出的四类病灶」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。
