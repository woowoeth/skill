做什么用

考的是老师的 PPT 和课本，AI 却按通用知识给你讲。它强制你先传真材料，再用苏格拉底式提问带你想，不灌答案。「没材料就不辅导」这条硬约束很诚实：逼你对着真考纲学，而不是听 AI 编一套。

应用范围

用在「生活」这一格。没传课本/PPT/考纲它就只要材料，不开讲。PDF、Word 得另借 docx/pdf skill 提取。正文全中文，射程锁在大学期中期末，脚本只有 analyze_material.py 和 generate_questions.py。

如何使用

  • 就按「对着真实课本和考纲突击复习」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/staruhub/ClaudeSkills.git
cp -r ClaudeSkills/lab/Geek-skills-university-exam-prep ~/.claude/skills/Geek-skills-university-exam-prep
