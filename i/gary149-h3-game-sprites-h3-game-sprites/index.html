视频生成转逐帧精灵图，动作全对齐绿幕抠像

用 MiniMax H3 生成动作视频再切帧，省掉逐帧手绘。角色静止帧打底、待机帧锁形，每招每式都能循环且不跑型。

做什么用

用 MiniMax H3 生成动作视频再切帧，省掉逐帧手绘。角色静止帧打底、待机帧锁形，每招每式都能循环且不跑型。拿视频模型当动作演员，再用待机帧当锚点锁住角色形变。比直接抽帧多一道数值质检，废帧当场筛掉。

应用范围

用在「做图」这一格。只出绿幕抠好的精灵帧和质检报告，不打包成引擎动画、不处理透明背景合成。需要 MiniMax H3 视频 API 权限。

如何使用

  • 就按「视频生成转逐帧精灵图，动作全对齐绿幕抠像」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/gary149/h3-game-sprites.git
cp -r h3-game-sprites/skills/h3-game-sprites ~/.claude/skills/h3-game-sprites
