punk-ip-article-illustrations

Upload a photo, get a reusable punk avatar; drop an article, auto-illustrate it as retro 3D comic scenes. One.

Updated 2026-08-09 · Source https://github.com/adrianpunk/punk-ip-illustrations · 中文版

What does this skill do?

Punk 出品的完整个人 IP 插图工作流：从用户上传的人物照片创建、修订、确认并持久化可复用角色，也可直接启用内置 Punk 角色；角色确认后读取完整文章、Markdown、网页、帖子或观点，自动决定数量并生成复古彩色扁平 3D 小剧场正文插图。适用于创建个人 IP、角色设定板、切换角色、文章自动配图、长文多图、流程拆解图和核心动作图等连续任务。

Why is it worth installing?

Others generate one-off images; this one locks your character first, then keeps it consistent across every panel—true visual.

git clone --depth 1 https://github.com/adrianpunk/punk-ip-illustrations.git Then point your agent at the skill directory.
