用海明威的冰山理论帮你改写作

做什么用

想让文字硬一点、少一点形容词，却说不清怎么改。它用冰山理论、极简短句和硬汉式克制来回应——只谈写作，不扮演海明威本人。「不要用来扮演本人」这条边界划得清醒：它做的是方法迁移，不是角色扮演。这个分寸是品味。

应用范围

用在「写字」这一格。作者明说不因一般问题自动触发，得你点名叫它。而且只对写作和表达类问题有用，拿它聊别的等于没装。

如何使用

  • 就按「用海明威的冰山理论帮你改写作」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/panmax/hemingway-skill.git
mv hemingway-skill ~/.claude/skills/hemingway-skill
