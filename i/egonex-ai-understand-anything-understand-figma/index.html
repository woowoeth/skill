Egonex-AI

做什么用

接上 Figma API，把设计稿拆成页面、组件、变体、设计令牌的知识图谱，设计系统长什么样一张图看明白。设计交接的痛点被它按住了：设计系统长什么样，一张图谱看明白。

应用范围

用在「工作」这一格。要自备 FIGMA_TOKEN，还要 Node ≥22、pnpm ≥10 并先 build 出 core 才跑得动。正文明说它会外连 api.figma.com，不像 /understand 那样离线。分析批次失败只记警告不重试。

如何使用

  • 就按「接上 Figma API，把设计稿拆成一张设计系统知识图谱」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Egonex-AI/Understand-Anything.git
cp -r Understand-Anything/understand-anything-plugin/skills/understand-figma ~/.claude/skills/understand-figma
