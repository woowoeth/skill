照片留一条证据带，碎成干印再晕成水墨

不整幅糊成水墨，而是保留原图证据带，把画面碎成干涸印刷记忆，再晕出源图色相的彩色残像。适合做编辑感摄影印刷转译。

Starryear

做什么用

不整幅糊成水墨，而是保留原图证据带，把画面碎成干涸印刷记忆，再晕出源图色相的彩色残像。适合做编辑感摄影印刷转译。证据带锁住真实，干印碎形切断柔焦惯性，色相残像从源图反推——三层机制让每张输出都是可核验的转译。

应用范围

用在「生活」这一格。只接受单张竖幅照片，横图或组图会直接停。不做全幅水墨滤镜，也不仿传统山水。产物是编辑感印墨版面，不是可打印的高清原图。

如何使用

  • 就按「照片留一条证据带，碎成干印再晕成水墨」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

git clone --depth 1 https://github.com/Starryear/Starryear-Ink.git
