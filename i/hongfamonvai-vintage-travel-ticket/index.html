把一张照片变成一张有年代感的中国老门票

手头有旅行、街景、美食旧照？不用翻资料，直接生成一张以假乱真的复古门票。设计语法提炼自 66 张历史票根。

hongfamonvAI

做什么用

手头有旅行、街景、美食旧照？不用翻资料，直接生成一张以假乱真的复古门票。设计语法提炼自 66 张历史票根。不是滤镜叠加，而是从 66 张真实票根里提炼版式、字体、印章、褪色规律，按你的照片内容自动套用。

应用范围

用在「生活」这一格。只做单张票证，不做套票或系列；输入需是清晰照片（模糊或低分辨率会直接失败）；不保证票面文字可读性。

如何使用

  • 就按「把一张照片变成一张有年代感的中国老门票」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/hongfamonvAI/vintage-travel-ticket.git
mv vintage-travel-ticket ~/.claude/skills/vintage-travel-ticket
