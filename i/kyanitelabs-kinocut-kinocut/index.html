做什么用

让 AI 直接剪素材，最怕一刀把原片剪废。它先规划后执行、每步可回溯，FFmpeg 操作、字幕、音频、成片改编都管。「guarded」是它的灵魂：剪辑指令可追溯、可回退，敢让 agent 碰真素材。

应用范围

用在「做图」这一格。本体是要装的 kinocut CLI（uvx + FFmpeg），先跑 kino doctor。只碰本地文件，上云要另开 egress 审批。360 只吃拼好的等距 MP4，.insv 直接拒。图层合成不当 NLE 用，音频合成 fail-closed。

如何使用

  • 就按「有护栏的 AI 视频剪辑」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/KyaniteLabs/kinocut.git
cp -r kinocut/skills/kinocut ~/.claude/skills/kinocut
