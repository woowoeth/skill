做什么用

别再说「模仿文风」了——它把语言、结构、选题、素材、认知、视觉六层拆开蒸馏，写新稿时连原文片段都调出来对照。不是泛泛的风格描述，而是从20篇完整文章里提取可操作的规则，写作时动态读取DNA和原文。

应用范围

用在「写字」这一格。至少需要20篇完整原文，少于这个数它拒绝开工；只做文本风格分析，不含图片视觉生成；产出是Markdown文档。

如何使用

  • 就按「20篇原文榨出一份写作DNA，新稿自动对齐老笔锋」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/larashero3-dotcom/writing-dna-skill.git
mv writing-dna-skill ~/.claude/skills/writing-dna-skill
