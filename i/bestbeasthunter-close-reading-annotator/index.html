做什么用

读小说只划金句？它把结构、阐释、情感、文笔拆成四层批注，连伏笔链和叙述者可靠性都标出来，适合精读拆解和写作复盘。不是泛泛读后感，而是带位置断言的机器精读：每处批注都锚定原文 span，跨段伏笔链自动串联。

应用范围

用在「写字」这一格。只认小说、剧本等叙事文本；技术文档、论文、代码会误判。需本地跑 Python 环境。

如何使用

  • 就按「四层批注拆开小说，连伏笔链都给你标出来」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/bestbeasthunter/close-reading-annotator.git
mv close-reading-annotator ~/.claude/skills/close-reading-annotator
