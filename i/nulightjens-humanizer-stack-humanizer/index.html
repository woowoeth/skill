做什么用

改稿时总被说“一看就是AI写的”？它按维基百科的权威清单逐条排查，专治破折号滥用、规则三连、空洞比喻，让文字像人话。不靠玄学语感，而是把维基百科的《AI写作迹象》指南变成可执行的检查项，逐条比对，改得有理有据。

应用范围

用在「写字」这一格。只处理英文文本；需要联网获取维基百科原文；不保证改写后通过所有AI检测器；对创意写作或口语化文本可能过度修正。

如何使用

  • 就按「只认维基百科那份AI写作痕迹清单的文本去味器」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/NulightJens/humanizer-stack.git
cp -r humanizer-stack/skills/humanizer ~/.claude/skills/humanizer
