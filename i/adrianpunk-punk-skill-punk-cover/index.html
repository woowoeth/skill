做什么用

每篇文章都要封面，找图配字最耗时。11 种精调风格（商业杂志头版、复古手撕拼贴、巨型透视中文标题…），每种都标了适合什么内容。风格库真下过功夫：选风格像点菜一样准，出的封面有编辑部气质而不是 AI 糊图。

应用范围

用在「做图」这一格。没告诉它平台和风格，它就停在提问那一步，不会先出一版给你看。预置比例只有小红书 3:4、公众号 2.35:1、X 5:2；一次一张、不给多版对比，也不许两种风格混用。

如何使用

  • 就按「把文章一句话变成封面图」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/adrianpunk/Punk-Skill.git
cp -r Punk-Skill/skills/punk-cover ~/.claude/skills/punk-cover
