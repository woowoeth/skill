做什么用

怕战力越级、伤势自愈、身份忽爆忽藏？它逐章核对时间线+资源+人物行为，揪出和前文矛盾的每一处，直接给改法。不是泛泛提建议，而是拿六条固定逻辑链（时间/资源/伤势/战力/身份/行为）当尺子。

应用范围

用在「写字」这一格。只认中文网文叙事（玄幻/都市/科幻等），不认剧本、大纲、非连续章节片段；需要你提供前文或设定档案才能比对。

如何使用

  • 就按「六条逻辑链逐章核对，专治写到一百章崩设定」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/tance-mang/chinese-webnovel-skills.git
