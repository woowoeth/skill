把吵架话术翻译成观察感受需要请求

做什么用

当你想怼人、被怼懵、劝不动架时，它把情绪话拆成四要素，让你听见对方真正要什么，也让自己把话说到点子上。不是教你背模板，而是内置马歇尔式提问引擎，逐句追问观察与评判、需要与策略，直到对话底层浮现。

应用范围

用在「写字」这一格。只处理人际沟通文本，不诊断心理疾病；需用户提供原始对话或自我陈述，否则无法开始；产出是建议话术，不保证对方接受。

如何使用

  • 就按「把吵架话术翻译成观察感受需要请求」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/ayi-ai/ayi-nonviolent-communication.git
