做什么用

技术能做出来，卖不出去。定位、找首批用户、发布、定价——它先访谈你一次，之后所有建议都基于你的真实业务。「先访谈再建议」这个设计诚实：不套教科书，而是长在你的业务上。

应用范围

用在「工作」这一格。18 件是编号 00–17 的一条链，单拎一件出来等于只拿到半张地图。全套英文，连 founder-brief、gtm-roadmap 两个模板也是。作者把适用面钉在开发者工具和 AI 产品，消费品和本地生意套不进去。

如何使用

  • 就按「给独自做产品的技术创始人当 GTM 合伙人」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/AIDevGTM/gtm-cofounder.git
