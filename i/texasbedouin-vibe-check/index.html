做什么用

由 12 年产品老兵带路：把纯新手的模糊点子变成能开工的计划，边建边教 GitHub 和干净代码习惯。vibe coding 时代最缺的是「有人扶一把」，这件就是那只手，姿势还很专业。

应用范围

用在「工作」这一格。调研这步靠抓 Reddit 和 G2 评论，抓不动就退成把网址和搜索词交给你自己去粘。作图引擎要浏览器和临时文件，跑不起来退回 mermaid。正文全英文，且明说不管有经验开发者的调试、重构和 CI/CD。

如何使用

  • 就按「带纯新手把模糊点子变成计划，顺手教会他用 GitHub」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。
