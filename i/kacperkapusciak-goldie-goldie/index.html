做什么用

回放 argent 流程录屏，给截图套机身边框、配底色和文案，出 4~5 张成品加一段预览视频，本地起个 studio 按真实商店页排给你看。预览视频它坚持交原始录屏不加边框字幕——因为苹果就是这么要求的，它没替你「美化」成会被打回的东西。

应用范围

用在「做图」这一格。要在这个 App 自己的仓里跑，且要有 iOS 模拟器或安卓模拟器。挑哪几屏值得营销、写流程、写文案还是你的活，它只负责跑和渲。studio 起在 localhost:4321，视频在后台渲。

如何使用

  • 就按「在模拟器里跑一遍你的 App，出上架用的截图和预览视频」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/kacperkapusciak/goldie.git
cp -r goldie/skills/goldie ~/.claude/skills/goldie
