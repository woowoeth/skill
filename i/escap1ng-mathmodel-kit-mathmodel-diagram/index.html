做什么用

五套学术示意图模板，JSON 驱动改字不改版。300dpi PNG 加矢量 PDF 双格式，答辩投论文都拿得出手。别家画图工具只给画布，它给的是论文第二章的思维骨架。五套模板对应五种论证结构，改 JSON 就能换字。

应用范围

用在「做图」这一格。只认五套模板：五带技术路线、三栏框架、三栏阶段流程、横版流水线、问题分析。超出这五种结构它不硬画，会停下让你换工具。

如何使用

  • 就按「论文插图先问清是给哪一章用的示意图师傅」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Escap1ng/mathmodel-kit.git
cp -r mathmodel-kit/skills/mathmodel-diagram ~/.claude/skills/mathmodel-diagram
