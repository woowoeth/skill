做什么用

健身 skill 大多发你一张通用计划表。它要的是你的训记、CSV 或截图，然后只答一件事：下次练什么、加多少、要不要减量。它把胸痛、晕厥、放射性麻木写成硬停止条件，还默认只读、不回显任何 key——一个健身件肯写这两条。

应用范围

用在「生活」这一格。没有训练记录它就退化成通用建议——它全部的价值建立在你手上已经有训记、CSV 或 JSON。作者明写不做医疗诊断、不接与训练无关的营养查询；出现胸痛晕厥这类信号它会停下让你去看急诊，不会继续排计划。

如何使用

  • 就按「按你的训练记录算下一次该练什么」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/Reluctant2828/System-Fitness-Advisor-skill.git
