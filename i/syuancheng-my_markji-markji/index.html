做什么用

背单词最怕卡片格式错，导入全崩。它按官方语法逐条校验，挖空、答案线、遮罩图片音频，错一处当场标红告诉你改哪。不是丢给官方接口碰运气，而是先本地解析整副牌组，把语法错误、缺字段、遮罩引用失效全揪出来。

应用范围

用在「生活」这一格。只认 Markji 官方语法，不兼容 Anki 或自定义模板；只处理卡片文本与媒体引用校验，不负责排版美化。

如何使用

  • 就按「墨墨卡片的语法检查官，错一处当场标红」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/syuancheng/my_markji.git
cp -r my_markji/.claude/skills/markji ~/.claude/skills/markji
