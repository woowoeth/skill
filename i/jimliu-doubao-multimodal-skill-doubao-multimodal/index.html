做什么用

开会录音、采访视频、技术讲座——不用本地装 Whisper，豆包多模态直接出带时间戳的字幕、说话人分离和关键帧。它把火山方舟的多模态能力包成了顺手工具：自动传 TOS、自动下载结果，ASR 还分纯文本/逐字时间戳/。

应用范围

用在「做图」这一格。只认火山方舟的豆包模型，需要你已有 Ark API Key 且开通 TOS 存储；本地文件必须能上传。

如何使用

  • 就按「音视频丢给它，回来的是字幕、时间轴和谁在说话」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/JimLiu/doubao-multimodal-skill.git
cp -r doubao-multimodal-skill/skill ~/.claude/skills/doubao-multimodal
