按活人那套改中文长文

知乎帖、人物故事、行业文，先删腔再写

KKKKhazix

做什么用

知乎帖、人物故事、行业文，先删腔再写。卡兹克这件卖的是中文现场的人味，不是通用润色按钮。

应用范围

用在「写字」这一格。不是短视频口播稿。要英文明信片、要公文，另装。

如何使用

  • 就按「按活人那套改中文长文」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/KKKKhazix/human-writing.git
cp -r human-writing/human-writing ~/.claude/skills/human-writing
