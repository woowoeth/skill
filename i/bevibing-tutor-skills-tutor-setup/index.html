做什么用

PDF、网页或代码仓库，自动识别模式并生成带练习题的笔记库。新成员看代码库不再从零摸索，直接拿到一份带路地图。不是模板填充，而是按项目标记自动切换文档/代码两种模式，产物直接是 Obsidian 库结构。

应用范围

用在「生活」这一格。只认 CWD 里的项目标记（如 .git、package.json）来判定代码模式；纯图片 PDF 无法提取文字。

如何使用

  • 就按「把任意知识源变成可提问的 Obsidian 学习库」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/bevibing/tutor-skills.git
cp -r tutor-skills/skills/tutor-setup ~/.claude/skills/tutor-setup
