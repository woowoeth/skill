做什么用

不用打开网页找模板，命令行里搜、预览、生成一步到位。自带 298 个经典梗图，连 petpet、slap。它把 meme CLI 的完整能力包成 Skill，不用记命令参数，说人话就能调。模板库离线可用。

应用范围

用在「玩乐」这一格。只认 meme CLI 支持的 298 个模板，超出范围会报错；需要本机已安装 meme CLI 且能联网下载模板。

如何使用

  • 就按「298 个模板随叫随到，连 petpet 都能现做」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/geekjourneyx/meme-generator-skill.git
cp -r meme-generator-skill/skills/generating-memes ~/.claude/skills/generating-memes
