做什么用

西洋、印度、八字三套盘都由本地引擎实算，再按古典规则解读；三套说法一致的地方才当结论，绝不凭记忆报行星位置。底线只有一条：引擎算天空，模型只负责读。和会胡编行星位置的聊天机器人不是一类东西。

应用范围

用在「玩乐」这一格。解读是占星传统不是科学；健康只谈体质倾向并让你去看医生；要跑本地 Python，角秒精度和 Placidus 宫位需另装 pyswisseph。

如何使用

  • 就按「本地星历实算西洋·印度·八字三盘」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/aryaminus/astro.git
cp -r astro/skills/astrology ~/.claude/skills/astrology
