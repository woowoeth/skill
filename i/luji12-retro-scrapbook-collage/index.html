做什么用

人物居中不裁切，物件抠成完整贴纸，暖白扫描纸感加语义短句。复刻 90 年代家庭相册，一张图就够。不是滤镜叠加，而是先做主体检测与物件完整性保留，再按语义配字。贴纸层级和纸纹质感按真实剪贴流程生成。

应用范围

用在「做图」这一格。只认单人或双人且主体占画面 30% 以上的照片；多人合照或主体过小会直接失败。输出固定 1086×1448。

如何使用

  • 就按「把日常照片转成复古剪贴簿海报」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/luji12/retro-scrapbook-collage.git
mv retro-scrapbook-collage ~/.claude/skills/retro-scrapbook-collage
