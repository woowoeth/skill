CloudAI-X

做什么用

泛光、景深、调色、屏幕特效，不用翻文档拼参数。从 EffectComposer 到自定义着色器，照着装就能出片。把官方示例里散落的后期链路收敛成可复用的 skill，按场景描述直接给参数组合，省掉你从零搭 comp。

应用范围

用在「玩乐」这一格。只覆盖 Three.js 生态，不碰 WebGL 原生或 Babylon.js。依赖 r150+ 的 EffectCo。

如何使用

  • 就按「会先问你「要辉光还是景深」的Three.js后期链搭」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
cp -r threejs-skills/skills/threejs-postprocessing ~/.claude/skills/threejs-postprocessing
