给 Three.js 场景加电影级后期特效

Bloom 辉光、景深、调色、屏幕空间着色器，一行接入 EffectComposer。不用翻文档拼管线。

CloudAI-X

做什么用

Bloom 辉光、景深、调色、屏幕空间着色器，一行接入 EffectComposer。不用翻文档拼管线。把官方示例里散落的后期代码收敛成声明式配置，按需组合 pass，自动处理尺寸与顺序，改参数即时生效。

应用范围

用在「玩乐」这一格。只覆盖 WebGLRenderer 的 EffectComposer 链路，不碰 CSS3DRenderer 或 We。

如何使用

  • 就按「给 Three.js 场景加电影级后期特效」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/CloudAI-X/threejs-skills.git
cp -r threejs-skills/skills/threejs-postprocessing ~/.claude/skills/threejs-postprocessing
