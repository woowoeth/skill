访客模式

当你的联合类型被 2+ 处 switch 拆得七零八落，用 frozen-class 访客模式收拢。改一处。

developmentskillprisma
点评比手写 switch 强在：编译器强制你处理所有变体，新增分支时漏改直接报错，而非运行时静默失败。

安装

git clone --depth 1 https://github.com/prisma/prisma.git 然后把智能体指向这个 skill 目录即可。
