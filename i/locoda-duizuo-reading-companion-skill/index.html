做什么用

小说、散文、非虚构都能陪读。它记住你读到哪、什么感受，下次接着聊，绝不提前剧透。读不下去时，它会问你怎么了。它把读书变成有状态的对话：记得版本、媒介、进度，还能验证文本细节。每次回应都贴合当下情节。

应用范围

用在「写字」这一格。只支持文本类书籍，不处理有声书或视频；需要你主动汇报进度，它不会自动翻页；对长篇复杂情节的跨章记忆有限。

如何使用

  • 就按「读书记不住进度？它替你记着，还防剧透」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/locoda/duizuo-reading-companion-skill.git
