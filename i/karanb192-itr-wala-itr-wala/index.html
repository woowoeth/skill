把印度报税全流程装进一个技能

从 Form 16 到新旧税制对比，再到 Zerodha 资本利得，一个技能走完 FY25-26 报税。

karanb192

做什么用

从 Form 16 到新旧税制对比，再到 Zerodha 资本利得，一个技能走完 FY25-26 报税。它把 AIS/TIS/26AS 的 TDS 对账和资本利得解析做成了同一套数据流。

应用范围

用在「工作」这一格。只认 FY 2025-26 / AY 2026-27，且仅覆盖 ITR-1/2/3/4。不处理公司税、GST。

如何使用

  • 就按「把印度报税全流程装进一个技能」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/karanb192/itr-wala.git
cp -r itr-wala/skills/itr-wala ~/.claude/skills/itr-wala
