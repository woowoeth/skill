把每次纠正沉淀成永久记忆的自我进化系统

会话中你纠正它的每个错误，它都记进 CLAUDE.md。下次开场前提醒你跑 /reflect。

BayramAnnakov

做什么用

会话中你纠正它的每个错误，它都记进 CLAUDE.md。下次开场前提醒你跑 /reflect。不是事后总结，而是捕获机制：在错误发生的当下就标记，再通过主动提醒闭环。记忆不是靠它自觉。

应用范围

用在「生活」这一格。只记录你明确纠正过的内容，不会自动发现隐性错误；且必须手动跑 /reflect 才写入，忘了跑就白记。

如何使用

  • 就按「把每次纠正沉淀成永久记忆的自我进化系统」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/BayramAnnakov/claude-reflect.git
mv claude-reflect ~/.claude/skills/claude-reflect
