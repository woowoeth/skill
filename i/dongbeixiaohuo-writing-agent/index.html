writing-agent

Tired of AI-flavored text? This system forces in your views & details, tests readers, auto-formats, supports.

Updated 2026-08-08 · Source https://github.com/dongbeixiaohuo/writing-agent · 中文版

What does this skill do?

🚀 一个基于 Claude Code (Skills + Subagents) 的“去AI味”全栈写作系统。不仅防套路，更通过专属规则强制注入人类观点与细节，搭配读者测试评估与自动图文排版。全面支持 DeepSeek / 智谱GLM / MiniMax 等国产低成本大模型，提供从选题、风格建模到审稿发布的高维全自动写作工作流。

Why is it worth installing?

Others avoid clichés; this one injects your human perspective and details, then validates with reader tests—mechanically killing.

How do you install it?

git clone --depth 1 https://github.com/dongbeixiaohuo/writing-agent.git Then point your agent at the skill directory.
