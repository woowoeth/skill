做什么用

简历、白皮书、落地页、PPT 都排成同一套书香门第的气质。中文字体自动切 TsangerJinKai02。不是套模板，是按内容层级选字体和间距，让专业文档长得像同一家出版社出的。

应用范围

用在「生活」这一格。只认 Markdown 输入；不处理 DOCX/PDF 原稿。日文字体是尽力而为，缺字体就回退系统默认。

如何使用

  • 就按「羊皮纸底色配墨蓝强调的文档排版师」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/tw93/kami.git
cp -r kami/skills/kami ~/.claude/skills/kami
