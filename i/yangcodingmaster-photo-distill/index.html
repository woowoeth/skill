把一张照片蒸馏成极简 zine 海报

不调任何图像生成模型——用手写 HTML/CSS/SVG 绘制、无头 Chrome 导出 PNG。给它一张你自己拍的照片，出一张极简版画感的纸质海报。

yangcodingmaster店长推荐
点评「不用生图模型」是个很硬的自我约束，也正是它出品统一的原因：所有效果都来自可控的代码，而不是抽卡。

局限

要本机跑得起无头 Chrome 和 Python PIL；缺一样它就降级——交你一个 HTML 自己开、颜色请你自己报。手机上基本用不了。
