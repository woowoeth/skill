做什么用

不调任何图像生成模型——用手写 HTML/CSS/SVG 绘制、无头 Chrome 导出 PNG。给它一张你自己拍的照片，出一张极简版画感的纸质海报。「不用生图模型」是个很硬的自我约束，也正是它出品统一的原因：所有效果都来自可控的代码，而不是抽卡。

应用范围

用在「做图」这一格。要本机跑得起无头 Chrome 和 Python PIL；缺一样它就降级——交你一个 HTML 自己开、颜色请你自己报。手机上基本用不了。

如何使用

  • 就按「把一张照片蒸馏成极简 zine 海报」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/yangcodingmaster/photo-distill.git
mv photo-distill ~/.claude/skills/photo-distill
