做什么用

丢一张截图，还原成有品味的代码而不是像素堆：它优先还原设计意图和层级关系，不死磕像素级复刻。难点在还原「设计意图」而非像素级复刻，它在这个取舍上做得很聪明。

应用范围

用在「做图」这一格。正文讲的是它自己先生成设计图再照着实现，通篇没写怎么读你手上的截图。环境必须能生图，Codex 里每段单独出一张大图，八段落地页就是八张图的钱。范围只到落地页、hero、作品集这类营销页。

如何使用

  • 就按「截图变代码时先对齐设计意图，不做像素级复刻」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Leonxlnx/taste-skill.git
cp -r taste-skill/skills/image-to-code-skill ~/.claude/skills/image-to-code-skill
