拿真实代码库当考场，给已装技能做迭代升级

别在空提示词里调技能了。丢给它一个仓库，它会跑任务、看失败、改指令，直到技能在你自己的代码上真正变强。

srlabs

做什么用

别在空提示词里调技能了。丢给它一个仓库，它会跑任务、看失败、改指令，直到技能在你自己的代码上真正变强。它把「优化技能」从拍脑袋改成闭环：以真实代码库为测试集，用失败反推指令修改，每次迭代都有可验证的进步。

应用范围

用在「工作」这一格。只针对已安装的 Claude Code 技能做迭代，不负责写新技能；需要你提供可运行的目标仓库和明确任务。

如何使用

  • 就按「拿真实代码库当考场，给已装技能做迭代升级」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/srlabs/skillforge.git
cp -r skillforge/.claude/skills/evolve-skill ~/.claude/skills/evolve-skill
