做什么用

团队从『人肉开会』切换到『AI 全程陪跑』。这套方法把冲刺、复盘、需求拆解都变成可执行的提示词链。它不是零散技巧，而是一套有状态的工作流协议：每个阶段产出物自动成为下一阶段的上下文。

应用范围

用在「玩乐」这一格。只覆盖软件开发流程（需求→设计→开发→测试→复盘），不涉及硬件、市场或运营。需要团队已有敏捷实践基础。

如何使用

  • 就按「把敏捷开发流程蒸馏成可复用的 AI 驱动方法」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/bmad-code-org/BMAD-METHOD.git
