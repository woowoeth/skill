做什么用

每个模块是一栋楼，楼高是真实指标，道路是调用关系。所有结论都标注在源码行旁——新人上手、架构评审、给外行讲清楚。不是画示意图，而是把代码度量直接映射成城市尺度——楼高、路网、街区都从仓库里算出来，所见即所测。

应用范围

用在「做图」这一格。只接受能克隆的 Git 仓库；产物是单页 HTML，不含交互式代码导航或点击跳转源码。超大仓库（>10万行）生成慢。

如何使用

  • 就按「一座能走进去的代码城，每栋楼都是模块」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/adityaakr/repo-city.git
cp -r repo-city/skills/repo-city ~/.claude/skills/repo-city
