做什么用

改稿到一半发现参考文献编号全乱了？它自动重排引文顺序、补交叉引用超链接，还能一键切换中英文标准，不用手动数序号。它读的是 docx 内部的引用关系，不是表面文字，所以能真正重排编号并同步正文，而不是只改个格式。

应用范围

用在「工作」这一格。只处理 docx 文件，且要求文档内已有可识别的引文标记；纯文本或 PDF 需先转换。不负责检索文献元数据。

如何使用

  • 就按「Word 参考文献乱了，按 GB/T 7714 重排补链接」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/fuwenhao12/academic-ref-inserter.git
mv academic-ref-inserter ~/.claude/skills/academic-ref-inserter
