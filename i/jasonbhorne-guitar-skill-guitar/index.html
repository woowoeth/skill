只给和弦走向、绝不替你抄歌词的吉他谱生成器

说一个歌名，它出一份坐下就能弹的谱：和弦图、带小节数的段落结构、前奏 riff 和 solo 的六线谱。

jasonbhorne

做什么用

谱里只有和弦走向、不含歌词——它让你自己从有授权的来源补上，并写明这些谱不许转发。

应用范围

这件落在「玩乐」。冷门曲目它会标 MEDIUM/LOW 置信度，让你自己对着录音核哪几段是猜的。和弦图靠随件 python 脚本渲染成 ASCII，没有五线谱也没有音频。谱固定存到 ~/Documents/Guitar/Songs 下。它给的是「大概是这样」，不是官方谱。

如何使用

  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/jasonbhorne/guitar-skill.git
cp -r guitar-skill/guitar ~/.claude/skills/guitar
