baoyu-image-gen

One skill, ten image APIs. Use reference images, set ratios, batch-run saved prompts without queueing.

Updated 2026-07-04 · Source https://github.com/JimLiu/baoyu-skills/tree/HEAD/skills/baoyu-image-ge…

What does this skill do?

AI image generation with OpenAI GPT Image 2, Azure OpenAI, Google, OpenRouter, DashScope, Z.AI GLM-Image, MiniMax, Jimeng, Seedream, Replicate and Agnes APIs. Supports text-to-image, reference images, aspect ratios, and batch generation from saved prompt files. Sequential by default; use batch parallel generation when the user already has multiple prompts or wants stable multi-image throughput. Us

Why is it worth installing?

Ten image APIs in one skill, with parallel batch runs—no more switching between services.

How do you install it?

git clone --depth 1 https://github.com/JimLiu/baoyu-skills.git Then point your agent at the skill directory.
