做什么用

人机协作的 Suno 音乐生产流：风格模板、歌词工作流、混音清单，把「玩 Suno」升级成「做音乐」。Suno 玩家众多但成品率低，这套流程补的正是「从段子到作品」的那段路。

应用范围

用在「玩乐」这一格。歌不是它生成的：音频得你自己去 Suno 出、把 stems 拿回来，它管概念、歌词、Suno 提示词、母带和发行。52 件里 8 件是插件自用件（about/help/setup/test 等），真能用的 44 件。

如何使用

  • 就按「给 Suno 配上歌词工作流和混音清单，从玩票做到成品」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/bitwize-music-studio/claude-ai-music-skills.git
