做什么用

把乱糟糟的 docx 按你的格式规范重排。AI 不碰文档，只产出两份 JSON；所有修改由确定性代码完成。AI 幻觉不碰正文。规则与执行彻底分离：格式规则和段落角色先落成 JSON，再由代码逐条执行。

应用范围

用在「工作」这一格。只接受 docx 输入，且必须同时提供格式规范（文字说明或排好版的 Word 模板）。产出物是命名样式文档。

如何使用

  • 就按「AI只出规则、代码动手改的格式排版工」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。
