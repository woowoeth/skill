从代码反推卖点生成 App Store 截图

独立开发者最不擅长又最影响下载量的就是商店截图。它先读你的代码库找出核心卖点，再生成 ASO 优化的展示图。

做什么用

独立开发者最不擅长又最影响下载量的就是商店截图。它先读你的代码库找出核心卖点，再生成 ASO 优化的展示图。从代码反推卖点，比对着空白页想文案聪明——素材来自产品本身而不是想象。

应用范围

用在「工作」这一格。检测不到 Gemini MCP（npm i -g gemini-mcp）它就直接停手不生成；裁切那步调的是 macOS 专有的 sips。尺寸只给 iPhone 6.5/6.7/6.9 三种，没有 iPad，模拟器截图还得你自己拍。 compose.py 把字体写死成 /Library/Fonts/SF-Pro-Display-Black.otf，macOS 不自带、缺了直接崩没兜底；第二段还要付费模型。

如何使用

  • 就按「从代码反推卖点生成 App Store 截图」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/adamlyttleapps/claude-skill-aso-appstore-screenshots.git
mv claude-skill-aso-appstore-screenshots ~/.claude/skills/claude-skill-aso-appstore-screenshots
