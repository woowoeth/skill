做什么用

菜谱最坑的是「炒至断生」这种话。它按阶段给火候和时长，每一步附一条「怎么看这步完成了」，末尾再出一张菜谱海报的生图提示词。把「判断标准」写进每一步，正是新手和菜谱之间缺的那一层——不是配方不够细，是不知道什么时候该进下一步。

应用范围

用在「生活」这一格。它靠 search_web 现查权威做法，没有联网工具就退化成模型自己编。检索源写死在中文站点（米其林指南、舌尖上的中国、下厨房），做西餐日料会明显变弱；末尾的海报提示词也写死「传统中式风格」。

如何使用

  • 就按「每一步都告诉你怎么算做好了的菜谱」这一件来做，不要中途改风格。
  • 按我给的现场条件出方案，条件不够就说做不到。
  • 不要写成对谁都适用的攻略。
  • 结论里把限制写在最前面。

安装

git clone --depth 1 https://github.com/cclank/recipe-generator.git
mv recipe-generator ~/.claude/skills/recipe-generator
