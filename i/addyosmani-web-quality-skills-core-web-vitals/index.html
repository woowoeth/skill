用现场与实验室数据修复 Core Web Vital

LCP 慢、CLS 跳、INP 卡？不用猜，直接拿 CrUX 现场数据和 Lighthouse 实验室证据。

addyosmani

做什么用

LCP 慢、CLS 跳、INP 卡？不用猜，直接拿 CrUX 现场数据和 Lighthouse 实验室证据。它把现场与实验室证据分开处理，先看真实用户分布，再对照实验室诊断，避免用合成数据误导优化方向。

应用范围

用在「玩乐」这一格。只覆盖 LCP、INP、CLS 三项，不处理 TTFB、FCP 等其他指标；需要能访问 PageSpeed Insig。

如何使用

  • 就按「用现场与实验室数据修复 Core Web Vital」这一件来做，不要中途改风格。
  • 按规则玩一轮，把依据留在结果里。
  • 编不出来就停，不要圆。
  • 玩完对照应用范围，别拿它当正事工具。

安装

git clone --depth 1 https://github.com/addyosmani/web-quality-skills.git
cp -r web-quality-skills/skills/core-web-vitals ~/.claude/skills/core-web-vitals
