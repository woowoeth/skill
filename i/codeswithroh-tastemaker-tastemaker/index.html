做什么用

你贴一张Dribbble/Pinterest图，它提取配色、字体、圆角、间距，直接产出同风格界面。它先解析参考图的视觉语言，再套用你的组件库，而不是凭空生成。风格迁移有结构，不是滤镜糊上去。

应用范围

用在「工作」这一格。只认静态参考图，不认Figma文件或设计token；产物是前端代码，不负责导出设计稿；若参考图是插画/3D渲染。

如何使用

  • 就按「看一眼参考图就生成同气质界面的设计手」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/codeswithroh/tastemaker.git
cp -r tastemaker/skills/tastemaker ~/.claude/skills/tastemaker
