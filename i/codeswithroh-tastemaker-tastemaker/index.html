做什么用

粘贴 Pinterest/Dribbble 链接或截图，它就能拆解配色、字体、间距、质感，生成真正有品牌感的界面。不是套模板，而是逐层解析参考图的视觉语法，再映射到可维护的 Tailwind/组件代码。

应用范围

用在「工作」这一格。只认静态视觉参考（截图/链接），不处理动效或交互规范；产物是前端代码，不含设计系统文档；复杂设计需人工微调。

如何使用

  • 就按「把参考图变成同风格 UI 代码，告别 AI 味」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

git clone --depth 1 https://github.com/codeswithroh/tastemaker.git
cp -r tastemaker/skills/tastemaker ~/.claude/skills/tastemaker
