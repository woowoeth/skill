做什么用

受够了千篇一律的 AI 蓝白界面？贴一张 Pinterest 或 Dribbble 图，它就能让落地页、仪表盘。它不靠提示词猜风格，而是直接解析参考图的视觉特征（配色、间距、字体、质感），再映射到目标界面。

应用范围

用在「工作」这一格。只认静态参考图（PNG/JPG/链接），不解析视频或动效；产物是前端代码（HTML/CSS/React）。

如何使用

  • 就按「把参考图变成同风格 UI 的生成器」这一件来做，不要中途改风格。
  • 按它的流程走完这一件，不要跳步骤。
  • 输出要能进仓库或工单，不要只给感想。
  • 做完对照应用范围，越权的活另找工具。

安装

git clone --depth 1 https://github.com/codeswithroh/tastemaker.git
cp -r tastemaker/skills/tastemaker ~/.claude/skills/tastemaker
