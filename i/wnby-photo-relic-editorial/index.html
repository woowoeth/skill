做什么用

想要一张不像滤镜的纪念海报？它保留真实照片，叠上抽象记忆残影，像现代版画，又带东方留白。适合做画廊感装饰画或 Do。承认原片是文物，再做成编辑稿，不是滤镜打卡。

应用范围

用在「做图」这一格。要美颜、要瘦身、要网红棚拍感，会跟它的「文物」立场打架。

如何使用

  • 就按「照片不裁不糊，旁边长出一块记忆残片」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/wnby/photo-relic-editorial.git
