把长期健身做成有剧情的 RPG

健身最难的是坚持，不是动作。它用本地文件记录你的训练、疲劳和复训，再让训练结果推进剧情——练得好剧情才往前走。

chenklein26-maker店长推荐

做什么用

把「坚持」这个真问题用游戏机制解决，而不是再给一份训练计划表。全本地存档，数据不外传。

应用范围

这件落在「生活」。数据全存本地 user-data/，换台机器就从零开始。没有 Python 环境时改由模型手写 JSON，脚本那层的单位和日期校验就失效了。

如何使用

  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/chenklein26-maker/fitness-coach-rpg.git
mv fitness-coach-rpg ~/.claude/skills/fitness-coach-rpg
