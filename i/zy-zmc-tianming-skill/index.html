做什么用

写长篇最怕前后矛盾、伏笔烂尾。这套系统用外部知识库锁死世界观和文风，每章动笔前先体检，节奏失控会直接叫停。它把写作拆成七个指令，每个阶段都强制对照《世界基石》《角色档案》等知识库。

应用范围

用在「写字」这一格。必须自备五个 Markdown 知识库文件（世界基石、世界观规则、角色档案、档案事件、文风样本），缺一个就罢工。

如何使用

  • 就按「七卷本起步的协同写作系统，大纲到存档全管」这一件来做，不要中途改风格。
  • 按它的句式改这一段，能删就删。
  • 先标出越界的句子，再重写，不要通篇润色。
  • 写完对照应用范围，串味就停。

安装

git clone --depth 1 https://github.com/zy-zmc/tianming-skill.git
mv tianming-skill ~/.claude/skills/tianming-novel-system
