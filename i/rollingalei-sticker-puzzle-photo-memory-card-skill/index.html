植被多就换品红键色，把照片做成能剪下来的贴纸页

照片做成好看的图不难，难的是拿到一张真能打印、真能剪的透明贴纸。它一次交记忆卡和六枚图案的透明 PNG。

RollingAlei
点评去背走色度键，绿场景会撞色，所以植被多的图改用品红打底，最后还要验四角 alpha 是不是 0。

局限

生图模型被写死成 seedream_5.0_pro，接不上这个模型的 agent 装了没用。贴纸恰好六枚、手写关键词恰好三个，都是定死的，不接受你要八枚。原图里的文字只在真的标识了地点时才留，广告、菜单、价格、时间戳一律剔掉。 上游 SKILL.md 的 name 是中文，装上后可能不被识别，改成英文更稳。
