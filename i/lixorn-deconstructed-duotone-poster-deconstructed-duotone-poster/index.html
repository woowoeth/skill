把任意图片拆解成留白双色海报版式

给一张图、一段文字或一个主题，自动生成杂志级双色印刷排版。支持 3:4 九宫格、4:3 六宫格、竖/横四联幅。

Lixorn

做什么用

给一张图、一段文字或一个主题，自动生成杂志级双色印刷排版。支持 3:4 九宫格、4:3 六宫格、竖/横四联幅。不是滤镜，是排版引擎：坐标、边距、网格全部硬编码，输出即印刷稿。同一套方形瓦片模板复用所有布局。

应用范围

用在「做图」这一格。只处理静态位图输入（JPG/PNG），不读 SVG 或 PDF；输出为排版坐标与切图建议，不直接生成成品印刷文件。

如何使用

  • 就按「把任意图片拆解成留白双色海报版式」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

安装

git clone --depth 1 https://github.com/Lixorn/deconstructed-duotone-poster.git
cp -r deconstructed-duotone-poster/deconstructed-duotone-poster ~/.claude/skills/deconstructed-duotone-poster
