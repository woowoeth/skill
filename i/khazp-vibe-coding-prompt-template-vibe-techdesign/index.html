做什么用

当你纠结“该用什么栈、怎么搭”时，它把架构、依赖、风险一次性摊开成文档，省掉你反复找资料、问 AI 的来回拉扯。不是泛泛给建议，而是按你的 MVP 目标强制输出结构化 TDD：先定边界，再选组件，最后列风险。

应用范围

用在「做图」这一格。只服务 MVP 阶段的技术设计，不覆盖已有系统的重构、性能调优或迁移方案；输出是文档不是代码，拿到后仍需自己写实现。

如何使用

  • 就按「把 MVP 技术选型变成一张可执行的设计图」这一件来做，不要中途改风格。
  • 把我手上这张按它的规矩重做，风格不许换。
  • 只要成品，过程里的解释可以没有。
  • 做完对照应用范围，越界的那一稿丢掉。

git clone --depth 1 https://github.com/KhazP/vibe-coding-prompt-template.git
