## 何时使用此技能

### ✅ 应当使用（正向条件）
当用户意图属于以下任一情况时，**必须**调用本技能：

1. 用户明确提到"行走的艺术"技能名称
2. 用户希望将宠物照片与名画/古典艺术/油画风格结合
3. 用户要求生成"宠物的古典肖像""宠物的文艺复兴画像""宠物在星月夜/宫娥里"等
4. 用户上传了宠物照片，希望制作艺术化/名画风格的创意图片
5. 用户提到"随机生成""随便选一幅""帮我挑一幅"
6. 用户提到"对比图""左右对比""成图对比原画"
7. 用户提到"下载""导出""保存图片"

### ❌ 不得使用（负向条件）
当用户意图属于以下情况时，**禁止**调用本技能：

1. 仅需要普通的宠物照片美化/滤镜/修图（无"名画"或"古典艺术"意图）
2. 仅需要生成宠物的普通卡通/插画风格（非经典名画特定作品）
3. 询问名画知识但不涉及宠物图像生成
4. 生成非宠物类对象的名画融合（如人物、食物、风景）
5. 仅要求对名画本身进行描述或赏析，不涉及宠物创作

### Step 0：用户上传 → 展示选项 → 确定模式与名画

**触发条件**：用户上传宠物照片

**动作 1 - 识别宠物**：快速识别宠物类型、品种、毛色

**动作 2 - 展示选项**：按上方「用户交互流程」中的格式展示 [🎲 随机生成] [🎨 选择名画] 两个选项

**动作 3 - 等待用户选择**：

| 用户选择 | 进入模式 | 名画选择方式 |
|---------|---------|-------------|
| "1" / "随机" / "随便" | 随机模式 | 权重随机算法选取 |
| "2" / "选名画" / "选择" | 选择模式 | 展示风格列表 → 用户选择 |
| 直接说了画名（如"用宫娥"）| 指定模式 | 直接匹配，跳过选项展示 |

**随机权重规则**：
- 70%：从宠物类型匹配池 TOP 10 中随机
- 20%：从同风格全池中随机
- 10%：从全库200幅随机（惊喜盲盒！）

---

### Step 1：识别宠物信息（特征锁定矩阵）

> **核心原则**：仔细、逐项地观察宠物照片的每一个细节。漏掉任何一个特征，融合图就会"不像原宠物"或"变形"。必须像法医素描师一样精确。

**必须逐项提取**（缺一项不可进入 Step 2）：

| # | 字段 | 说明 | 示例 |
|---|------|------|------|
| 1 | `petType` | 类型 | 猫/狗/兔/鸟/其他 |
| 2 | `breed` | 品种（不确定就写"混种/田园"） | 英国短毛猫 / 中华田园猫 |
| 3 | `baseColor` | 主毛色（面积最大的色块） | 灰色 / 橘色 / 黑色 |
| 4 | `secondaryColor` | 辅毛色（第二大面积） | 白色 / 奶油色 |
| 5 | `patternType` | 斑纹类型 | 虎斑 / 纯色 / 三花 / 重点色 |
| 6 | `patternDistribution` | 斑纹分布（精确到部位） | 背部深灰虎斑条纹，四肢白色"手套"，胸口白毛V字区 |
| 7 | `eyeColor` | 眼睛颜色 | 黄绿色 / 琥珀色 / 蓝色 |
| 8 | `eyeShape` | 眼睛形状 | 圆眼 / 杏仁眼 / 半月眼 |
| 9 | `noseColor` | 鼻头颜色 | 粉色 / 黑色 / 灰色 |
| 10 | `earShape` | 耳朵形状与朝向 | 尖耳直立 / 折耳 / 大耳微后 |
| 11 | `build` | 体型 | 圆胖 / 修长 / 健壮 / 小型 |
| 12 | `furLength` | 毛长 | 短毛 / 中长毛 / 长毛 |
| 13 | `furTexture` | 毛质 | 丝滑 / 绒密 / 粗硬 |
| 14 | `distinctiveMarks` | 特殊标记（白尾尖/异瞳/缺口耳等） | 左耳有小缺口 / 异瞳（左蓝右黄）|
| 15 | `facialExpression` | 面部表情 | 淡定 / 惊讶 / 慵懒 / 警觉 |

**特征锁定输出格式**（写入 `petContext`）：
```
petContext = {
  petType, breed,
  baseColor, secondaryColor, patternType, patternDistribution,
  eyeColor, eyeShape, noseColor, earShape,
  build, furLength, furTexture,
  distinctiveMarks, facialExpression,
  fullDescription: "一段不超过80词的英文精确描述，包含以上所有字段"
}
```

**自检**：`fullDescription` 是否能让人**不看照片就画出这只宠物**？如果不行，回去补字段。

**失败处理**：
- 未上传照片 → 礼貌请用户上传：「请先上传宠物照片～」
- 照片模糊/遮挡 → 主动询问：「照片中 XX 部分看不太清，请问 TA 的 [眼睛颜色/斑纹分布] 是？」
- 照片只露头部 → 标注"仅头部可见，身体特征参考品种标准"

### Step 2：加载名画数据与生成原画参考

**动作 A - 加载名画数据**：从 `resources/paintings-database-v3.md` 读取完整信息（200幅）。

**动作 B - 生成原画参考图**：生成一幅**不含宠物**的原画参考图。

**原画参考图提示词模板**：
```
[GENERATION PURPOSE]: Museum-quality oil painting reproducing the original masterpiece "{titleZh}" ({titleOriginal}) by {author}, {year}. Faithful copy for comparison reference.

[SCENE DESCRIPTION]: {完整描述原画作的画面内容，不含宠物元素}

[PAINTING STYLE]: {styleFeatures} by {artist}, {year}. {movement}.

[QUALITY CONSTRAINTS]:
- Museum-quality oil painting texture, visible brushstrokes
- Faithful reproduction of the original composition
- NO animals/pets/cats/dogs in this reference image
- Accurate color palette: {colorPalette}
- Aged canvas warmth, museum lighting
```

**保存路径**：`./output/reference/{timestamp}_{painting-id}_original.png`

### Step 3：组装宠物融合提示词（特征保真 + 风格一致）

> **双核心**：① 宠物特征 100% 还原（不变形、不丢标记）；② 笔触/光影/色温与原画 100% 一致。

**核心填充规则**：

1. **宠物描述**（英文，80-120 词，必须包含 Step 1 的全部 15 个字段）：
   - 逐项写入：品种 → 主色 → 辅色 → 斑纹类型 → **斑纹精确分布** → 眼睛颜色+形状 → 鼻头色 → 耳形 → 体型 → 毛长 → 毛质 → 特殊标记 → 表情
   - 禁止模糊词："cute cat" / "tabby" 单独使用 / "beautiful pet"
   - 强制精确词：具体颜色名（gray / charcoal / cream）+ 具体部位（chest / paws / back / tail tip）

2. **场景描述**：明确宠物替换/融合的具体位置 + 姿态 + 与名画元素的互动

3. **光影一致性**：
   - 严格匹配画作光源方向（左上 / 右侧窗 / 正前）
   - 宠物身上的高光面/阴影面与原画人物一致
   - 阴影投射方向一致

4. **笔触一致性**（最关键）：
   - 明确写出"fur rendered with {画家}的 {笔触特征}"
   - 例：梵高厚涂 impasto / 维米尔光滑罩染 glazing / 委拉斯开兹松散笔触 loose brushwork
   - 禁止"photorealistic fur"——宠物必须是**画出来的**，不是照片贴上去的

5. **保留元素**：3-5 个标志性元素列入 preserve

**提示词自检**（必须全部通过，否则不进入 Step 4）：
```
【宠物特征保真】
□ 15 个字段全部写入提示词（逐项核对 Step 1 表格）
□ 斑纹分布精确到部位（不是只写"tabby"）
□ 眼睛颜色+形状都写了
□ 特殊标记已写入（白手套/异瞳/缺口耳等）
□ 没有使用模糊词（cute/beautiful 单独出现）

【风格一致性】
□ 明确引用"上传的宠物照片"作为参考
□ 宠物位置/姿态/互动具体描述
□ 光影方向明确且与原画一致
□ 笔触特征已指定（impasto/glazing/loose brushwork 等）
□ "无剪切感/笔触一致/无缝融合"已包含
□ 禁止"photorealistic"——必须是 painterly
□ 3-5 个标志性元素已列出
□ 色彩基调已指定
```

### Step 5：质量自检与迭代（特征还原 + 风格一致）

> **核心**：把生成图和用户上传的原照片**并排对比**，逐项核对宠物特征是否还原；再和原画参考图对比，核对风格是否一致。

**检查清单**（必须全部 ✅，否则迭代）：

```
【原画参考图】
□ 构图正确，一眼可识别是哪幅名画
□ 无宠物/动物元素
□ 风格与原作一致

【宠物融合图 · 特征还原度】（对比用户原照片逐项核对）
□ 毛色主色正确（不偏色）
□ 毛色辅色正确（白色手套/胸口白毛等位置对）
□ 斑纹类型正确（虎斑/三花/纯色）
□ 斑纹分布正确（条纹在背部而非腹部等）
□ 眼睛颜色正确
□ 眼睛形状正确（圆眼不是杏仁眼）
□ 鼻头颜色正确
□ 耳朵形状正确
□ 体型正确（圆胖没画成修长）
□ 特殊标记保留（白尾尖/异瞳/缺口耳等——一个都不能丢）
□ 面部表情符合原宠物气质
□ 宠物没有变形（多眼/少腿/扭曲面部 → 直接重画）

【宠物融合图 · 风格一致性】（对比原画参考图逐项核对）
□ 宠物无剪切边缘，完全融入
□ 光线方向与原画一致（高光面/阴影面对）
□ 笔触质感与原画一致（不是照片贴上去的）
□ 色温与原画一致（不偏冷/偏暖）
□ 3个标志性元素保留
□ 色彩与画作和谐
□ 宠物是"画出来的"质感（painterly），不是"拍出来的"（photorealistic）
```

**迭代规则**：
- 最多 2 次自动迭代
- 每次迭代**针对性**修改提示词失败项：
  - 特征丢失 → 在提示词中**加粗强调**该特征
  - 风格不一致 → 强化笔触/光影描述
  - 变形 → 降低生成自由度，增加"anatomically correct"约束
- 2 次后仍不达标 → 坦诚告知用户，询问具体调整方向

### Step 6：合成左右对比图

**使用脚本**：`./scripts/compose_comparison.py`

**执行命令**：
```bash
python3 scripts/compose_comparison.py \
  ./output/reference/{ts}_{id}_original.png \
  ./output/generated-art/{ts}_{id}_pet.png \
  ./output/comparison/{ts}_{id}_comparison.png \
  '{
    "title_zh": "{titleZh}",
    "title_original": "{titleOriginal}",
    "author_cn": "{authorCn}",
    "author": "{authorEn}",
    "year": "{year}",
    "style": "{movement}",
    "style_tag": "{styleTag}"
  }'
```

**合成图规格**：
- 尺寸：2400 × 1900 px

## 图像生成质量标准

### 硬性红线（绝对不可接受）
1. ❌ 宠物出现畸形（多只眼/少只腿/扭曲面部）
2. ❌ 名画标志性元素严重缺失
3. ❌ 宠物边缘有明显"白色描边"或"剪切蒙版"感
4. ❌ 人物/动物面部变成了恐怖谷畸形
5. ❌ 画面出现低俗、血腥、冒犯性元素

### 软性优选
1. ✅ 宠物面部保留用户宠物的特征相似度
2. ✅ 笔触质感接近原画
3. ✅ 色彩还原度高
4. ✅ 构图稳定，宠物是视觉焦点但不突兀
5. ✅ 细节层次丰富
