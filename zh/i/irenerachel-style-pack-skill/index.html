风格包

让 Claude 帮你搞创作：风格包。英文简介见下。

更新于 2026-08-12 · 来源 https://github.com/irenerachel/style-pack-skill · 英文版

Q：这个 skill 做什么？

从一组参考图、电影剧照、视频截图或用户给定文件夹中提取可复用的视觉风格 DNA，打包成中文风格包；提取模式强制为每个视觉分组同时生成统一 10 色标注色卡和完全无文字纯色色卡，并生成两套色卡总览与可复用色值 JSON。也可读取已有风格包的 design.md 和提示词模板，把剧本、脚本表格或创意需求拆成文生图提示词 + 视频提示词表格文档。触发词包括“风格包”“提取某电影风格包”“按这个风格包生成提示词”“读取这个文件夹的风格 DNA”“用风格包拆剧本”“生成色卡”“生成文生图和视频提示词表格”。核心原则：只参考视觉语法，绝对避免场景和元素雷同。

Q：怎么装？

git clone --depth 1 https://github.com/irenerachel/style-pack-skill.git 然后把智能体指向这个 skill 目录即可。
