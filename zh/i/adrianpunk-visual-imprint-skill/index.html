视觉印记

上传一张照片，先定人设再配图：角色确认后，长文自动拆成复古3D小剧场，连配图数量都替你决定。

更新于 2026-08-09 · 来源 https://github.com/adrianpunk/visual-imprint-skill · 英文版

Q：这个 skill 做什么？

从用户上传的人物照片创建、修订、确认并持久化可复用个人 IP 角色资产；角色确认后，读取完整文章、Markdown、网页、帖子或观点，自动决定配图数量并生成复古彩色扁平 3D 小剧场正文插图。适用于创建个人 IP、生成角色设定板、确认或切换角色、文章自动配图、长文多图、流程拆解图和核心动作图等连续任务。

Q：为什么值得装？

同类工具只配图，它先固化角色资产，再按内容自动规划图数，让连续配图风格统一、不跑偏。

Q：怎么装？

git clone --depth 1 https://github.com/adrianpunk/visual-imprint-skill.git 然后把智能体指向这个 skill 目录即可。
