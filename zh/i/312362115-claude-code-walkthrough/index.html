代码导读

接手陌生项目像读天书？别从第一行硬啃。这个技能帮你从全局架构到核心流程，层层拆解，直接告诉你每段代码为何存在。

更新于 2026-05-14 · 来源 https://github.com/312362115/claude/tree/HEAD/skills/code-walkthrough · 英文版

Q：这个 skill 做什么？

代码导读技能：帮助快速理解不熟悉的项目或模块，建立心智模型。 从全局架构到核心流程再到关键设计决策，分层递进地梳理代码。 不是简单地读文件列目录，而是提炼出"这段代码在做什么、为什么这么做、和其他部分怎么连接"。 触发词：帮我梳理一下、这块代码怎么运作的、导读、接手项目、看看这个模块、代码走读、walkthrough。 触发场景：接手新项目、进入不熟悉的模块、重构前理解现状、Code Review 需要理解上下文。 即使用户没有说"导读"，只要意图是"理解一段不熟悉的代码"，都应触发此技能。

Q：为什么值得装？

它不列目录，而是提炼设计决策和模块间的因果链，像有个老程序员在耳边讲重点。

Q：怎么装？

git clone --depth 1 https://github.com/312362115/claude.git 然后把智能体指向这个 skill 目录即可。
