按八字字辈期望方言四维度给孩子起名

起名真正的难点不是想不出字，是全家人吵架。它专门做了「协商模式」，把爷爷要字辈、妈妈嫌难写、爸爸信五行这类冲突摆到台面上谈。

lifeskillSeiya89757
点评反模式那节写得极清醒：不许在没有出生时间时假装算准了八字，不许为凑五行用生僻字——「孩子一辈子要写无数次、读无数次错音」。

安装

git clone --depth 1 https://github.com/Seiya89757/naming-skill.git 然后把智能体指向这个 skill 目录即可。
