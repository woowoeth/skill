朋克小剧场

上传一张照片，生成可复用的朋克角色；再丢篇文章，自动配出复古3D小剧场。角色定妆后，长文多图不重样。

更新于 2026-08-09 · 来源 https://github.com/adrianpunk/punk-ip-illustrations · 英文版

Q：这个 skill 做什么？

Punk 出品的完整个人 IP 插图工作流：从用户上传的人物照片创建、修订、确认并持久化可复用角色，也可直接启用内置 Punk 角色；角色确认后读取完整文章、Markdown、网页、帖子或观点，自动决定数量并生成复古彩色扁平 3D 小剧场正文插图。适用于创建个人 IP、角色设定板、切换角色、文章自动配图、长文多图、流程拆解图和核心动作图等连续任务。

Q：为什么值得装？

同类工具只配单图，它却先固化角色再批量出图，让同一张脸贯穿整篇文章，叙事连贯感独一份。

Q：怎么装？

git clone --depth 1 https://github.com/adrianpunk/punk-ip-illustrations.git 然后把智能体指向这个 skill 目录即可。
