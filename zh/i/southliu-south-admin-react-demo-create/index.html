demo-create

写代码的顺手工具：demo-create。英文简介见下。

更新于 2026-08-19 · 来源 https://github.com/southliu/south-admin-react/tree/HEAD/.claude/skills… · 英文版

Q：这个 skill 做什么？

基于项目中 .vscode/south.code-snippets 定义的 CRUD 模板，快速生成后台管理系统的标准 CRUD 页面代码。该技能根据用户提供的业务模块信息（如模块名称、API路径、字段配置等），自动生成完整的页面文件（Page）、数据模型文件（Model）和 API 接口文件（Api），支持分页列表页面（demoPage）、独立操作页面（demoOptionPage）两种页面模式。

Q：怎么装？

git clone --depth 1 https://github.com/southliu/south-admin-react.git 然后把智能体指向这个 skill 目录即可。
