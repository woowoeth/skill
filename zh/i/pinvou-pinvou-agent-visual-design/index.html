视觉锁匠

说句“做个落地页”，它直接交付成品级HTML——不靠模板，用规则锁死排版、配色、间距，颜值稳定在线。

更新于 2026-08-17 · 来源 https://github.com/Pinvou/pinvou-agent/tree/HEAD/pinvou3-app/src-tauri… · 英文版

Q：这个 skill 做什么？

直出好看的网页/落地页/banner/海报/产品介绍页/数据报告/简历/作品集等视觉物料——套一套设计系统，模型自由写自包含 HTML，颜值由规则锁死、不靠模板。用户说"做个网页/页面/落地页/banner/海报/报告页/作品集/简历"或"把这份内容做成网页版"时使用。⚠️ 不含信息检索：查天气/查行情/查股价/查数据请走对应连接器，不是本技能。

Q：为什么值得装？

同类靠模板拼凑，它靠设计系统硬编码——每次输出都像设计师亲手调过，且完全自包含，零依赖。

Q：怎么装？

git clone --depth 1 https://github.com/Pinvou/pinvou-agent.git 然后把智能体指向这个 skill 目录即可。
