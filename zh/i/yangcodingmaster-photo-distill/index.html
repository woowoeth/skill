photo-distill

让 Claude 帮你搞创作：photo-distill。英文简介见下。

更新于 2026-08-03 · 来源 https://github.com/yangcodingmaster/photo-distill · 英文版

Q：这个 skill 做什么？

> 把一张照片蒸馏成极简 zine 纸质海报——不用图像生成模型，用手写 HTML/CSS/SVG 绘制、 无头 Chrome 导出 PNG。当用户给出一张自己拍的照片、想把它做成极简海报/版画/zine 风格作品时使用。 触发词：照片蒸馏、photo distill、把这张照片做成海报、极简海报、zine 海报、 蒸馏这张照片、做成版画那种、用代码画这张照片、纸质海报、海报系列再做一张。 即使用户只说"把这张照片处理成那个风格"、"这张也来一张"、"帮我把这照片抽象一下"， 只要是把摄影作品变成印刷符号，就应触发。 不用于 AI 生图海报（那用 gc-minimal-zine-poster）

Q：怎么装？

git clone --depth 1 https://github.com/yangcodingmaster/photo-distill.git 然后把智能体指向这个 skill 目录即可。
