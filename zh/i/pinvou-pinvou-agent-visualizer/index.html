图表工坊

扔进Excel或CSV，秒变交互图表与看板。预算、销售、运营指标，自动挑最合适的图表类型，连颜色都替你配好。

更新于 2026-08-12 · 来源 https://github.com/Pinvou/pinvou-agent/tree/HEAD/pinvou3-app/src-tauri… · 英文版

Q：这个 skill 做什么？

当用户要求数据可视化、做图表、生成看板、数据仪表盘、可视化报告、Excel/CSV 转图表、预算/销售/运营等指标分析页面、Chart.js 可视化时使用。只处理数据可视化任务；纯网页、banner、海报、简历等非数据图表设计任务应交给 visual-design。

Q：为什么值得装？

同类工具要你手动选图表类型，它却能根据数据语义自动匹配，连配色都按品牌调性生成，省掉一半调整时间。

Q：怎么装？

git clone --depth 1 https://github.com/Pinvou/pinvou-agent.git 然后把智能体指向这个 skill 目录即可。
