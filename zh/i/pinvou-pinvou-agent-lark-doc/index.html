飞书文档手

当你说“发到飞书”，它才出手；读、建、改、插图样样通。别家只会写文件，它能从豆包链接里挖出文档。

documentationskillPinvou
点评同类工具只会读写文档，它却懂得先判断场景，不误用本地工具，还能自动提取内嵌表格的 token。

安装

git clone --depth 1 https://github.com/Pinvou/pinvou-agent.git 然后把智能体指向这个 skill 目录即可。
