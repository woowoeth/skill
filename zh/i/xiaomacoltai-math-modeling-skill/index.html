建模三阶魔

从赛题到论文，三阶段自动跑通；每步有独立质检员盯梢，默认轻量把关，想加码就加码——竞赛党熬夜救星。

更新于 2026-08-18 · 来源 https://github.com/XiaoMaColtAI/math-modeling-skill · 英文版

Q：这个 skill 做什么？

当用户要求数学建模、建模竞赛、建模分析、代码求解、结果可视化或生成数学建模论文时使用。支持完整三阶段流程、单独执行任一角色，以及在关键节点使用独立 Subagent 进行阶段内质检；默认只启用质检 Subagent，用户可明确选择额外协作。

Q：为什么值得装？

同类只会顺序跑流程，它却在每个阶段内置独立质检子代理，默认轻量、可选加码，防错不拖慢。

Q：怎么装？

git clone --depth 1 https://github.com/XiaoMaColtAI/math-modeling-skill.git 然后把智能体指向这个 skill 目录即可。
