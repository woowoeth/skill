去AI味写作台

受够AI腔？这套系统强制注入你的观点和细节，用读者测试揪出套路，自动排版，还支持国产模型，从选题到发布全自动。

更新于 2026-08-14 · 来源 https://github.com/dongbeixiaohuo/writing-agent · 英文版

Q：这个 skill 做什么？

🚀 一个基于 Claude Code (Skills + Subagents) 的“去AI味”全栈写作系统。不仅防套路，更通过专属规则强制注入人类观点与细节，搭配读者测试评估与自动图文排版。全面支持 DeepSeek / 智谱GLM / MiniMax 等国产低成本大模型，提供从选题、风格建模到审稿发布的高维全自动写作工作流。

Q：为什么值得装？

同类只防套路，它却强制加入人类观点与细节，并用读者测试验证，机制上杜绝AI味。

Q：怎么装？

git clone --depth 1 https://github.com/dongbeixiaohuo/writing-agent.git 然后把智能体指向这个 skill 目录即可。
